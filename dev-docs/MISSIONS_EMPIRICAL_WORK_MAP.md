## Empirical loop

1. Compile the smallest coherent product candidate.
2. Start an actual short Mission through its real entry: inspect a bounded
   implementation slice using a child and grandchild, return a concrete finding
   and a reproducible check. No broad audit, deployment, merge, or long work.
3. Observe what actually broke: product, provider, harness, or packaging.
4. Correct that issue in its lane; retain unsuccessful receipts too.
5. Rebuild and repeat; then exercise close idle, close busy, and reopen.
6. Final independent gatekeeper loops only when this product is coherent.
