# פרויקטים ו־worktrees

לשונית פרויקט מחברת את CodeNomad לתיקייה במחשב שרת הקצה. פתיחת לשונית, עיון בעותק עבודה והעברת משפחת שיחה הן פעולות שונות.

## פתיחת פרויקט {#open-project}

1. לחצו **מופע חדש** (`+`) לפתיחת דף הבית.
2. בחרו **עיון בתיקיות**, בחרו את תיקיית שרת הקצה ופתחו אותה; או בחרו רשומה תחת **תיקיות אחרונות**.
3. לעותק מאגר, בחרו **שכפל מאגר Git**, הזינו **כתובת המאגר** ו־**תיקיית יעד**, ואז **שכפל**.

עיון בשרת מרוחק הוא עיון במערכת הקבצים שלו, לא בטלפון או במחשב הנייד שלכם. פתיחת פרויקט אינה יוצרת דמון OpenCode נפרד לכל לשונית. שיחות הן סשנים מקוריים של OpenCode; משך חייהן אינו משך חיי הלשונית.

שכפול כותב מאגר ליעד. **מחק תחילה את תיקיית היעד אם היא כבר קיימת.** היא אפשרות הרסנית: הפעילו אותה רק כשמותר למחוק את כל מה שכבר נמצא שם. השתמשו ביעד חדש אם אינכם בטוחים. שכפול שנכשל אינו סיבה למחוק פרויקט קיים; בדקו את היעד והשגיאה שדווחו לפני ניסיון חוזר.

רשומות אחרונות הן קיצורי דרך. **שנה שם סביבת עבודה** משנה את שמה המוצג; **הסר מהרשימה האחרונה** מסיר את קיצור הדרך, לא את קבציו או שיחותיו. לחיצה על פרויקט אחרון שכבר פתוח פותחת לשונית חדשה; הכפתור **פתוח** שלו (**עבור לפרויקט הפתוח**) בוחר במקום זאת את הלשונית הקיימת.

## שימוש במשגר המופע החדש {#new-instance-launcher}

1. לחצו לחיצה ארוכה או לחיצה ימנית על `+`; כשהמקלדת ממוקדת בו, השתמשו ב־**Alt+Down**, ב־**Shift+F10** או במקש Menu.
2. חפשו פרויקטים אחרונים, או בחרו **עיון…**, **זמני** או **שכפול…**.

לחיצה רגילה עדיין פותחת את דף הבית המלא. המשגר הוא קיצור דרך, לא ממשק הניהול: שנו שמות/הסירו פרויקטים אחרונים ונהלו סימניות שרתים בדף הבית. Escape סוגר את המשגר ומחזיר מיקוד ל־`+`.

## סגירת לשונית פרויקט {#close-stop}

1. השתמשו בכפתור הסגירה של הלשונית או ב־**סגור לשונית** בלוח הפקודות (`Ctrl/Cmd+W` בתהליך התצוגה).
2. סגירת הלשונית סוגרת את הפרויקט שלה ב־CodeNomad: הוא מפסיק לעקוב אחר האירועים והבקשות שלו. הסשנים ממשיכים לפעול ב־OpenCode.
3. פתחו את התיקייה מחדש דרך עיון או אחרונים כדי למצוא שוב את השיחות.

| פעולה | היקף והשפעה | מה אינה עושה |
| --- | --- | --- |
| סגור לשונית | מסירה את חיבור הפרויקט של CodeNomad באותה לשונית; לשונית אחרת שנפתחה בנפרד על אותה תיקייה אינה מושפעת | אינה מוחקת קובצי פרויקט או היסטוריה מקורית, אינה עוצרת סשנים ואינה פורקת את ה־Location של OpenCode |
| עצירת סשן | הרצת השיחה הנבחרת | אינה סוגרת את הפרויקט או מוחקת את ההיסטוריה שלו |

אם חלון אחר מציג את אותו חיבור פרויקט, גם הלשונית שלו נסגרת ואותו חלון מציג התראה. החלון שיזם את הסגירה אינו מציג התראה. הסגירה מיידית; אם שרת הקצה אינו יכול לסגור את הפרויקט, מופיעה שגיאה ו־**עבור לפרויקט הפתוח** בדף הבית עדיין מגיע אליו. אין ניסיון חוזר אוטומטי. טיוטות שלא נשלחו מהלשונית שנסגרה אינן נשמרות בשחזור בהפעלה.

סגירת חלון שלם, יציאה או טעינה מחדש אינן סוגרות את חיבורי הפרויקטים שלו; השחזור הרגיל בהפעלה עדיין חל. עצרו הרצות רלוונטיות במפורש אם עליכם לוודא שההרצה הסתיימה. CodeNomad לעולם אינו פורק Locations מקוריים; תחזוקת השירות המשותף מתוארת ב־[הגדרת OpenCode](opencode.md).

## סביבות עבודה זמניות {#temporary-workspaces}

1. בחרו **זמני** במשגר או **מופע זמני חדש** בדף הבית.
2. עבדו בתיקייה הריקה שבניהול CodeNomad; Git אינו מאותחל אוטומטית.
3. בסגירת הלשונית, בחרו **שמור**, **מחק** או **ביטול**. תפריט הלשונית מציע גם **שמור כפרויקט**.

| בחירה | השפעה | התאוששות |
| --- | --- | --- |
| שמירה | סוגרת את הפרויקט ב־CodeNomad, שומרת את התיקייה והשיחות, מסירה את מעמדה כזמנית ומוסיפה פרויקט אחרון | פתחו מחדש מאחרונים; התיקייה אינה מועברת |
| מחיקה | מוחקת את השיחות והקבצים של סביבת העבודה הזמנית | ללא ביטול; שמרו תחילה כל דבר נחוץ במקום אחר |
| ביטול | משאיר את סביבת העבודה הזמנית פתוחה | המשיכו לעבוד או החליטו בהמשך |

לשונית זמנית שלא נעשה בה דבר, ללא שיחה, קובץ או טיוטה שלא נשלחה, נמחקת בשקט בסגירה. לשוניות זמניות פתוחות משתתפות בשחזור הרגיל בהפעלה, אך בדף הבית אין רשימה נפרדת לחידוש תיקיות זמניות שנסגרו.

מחיקה מסרבת לפעול בזמן ששיחה רצה או שהתיקייה פתוחה בלשונית/חלון אחרים. עצרו את ההרצה וסגרו את התצוגות האחרות תחילה. מחיקה שנכשלה משאירה את המצב הזמני: פתרו את הבעיה המדווחת ונסו שוב במקום למחוק ידנית תיקיית הורה.

## בחירת worktree או יצירתו {#select-create-worktree}

1. פתחו שיחת הורה והשתמשו בבורר ה־worktree בשדה הקלט שלה. בפריסות צרות זהו פקד חץ בלבד.
2. בחרו worktree קיים שהתגלה, או בחרו **+ צור worktree**.
3. ליצירה, הזינו **שם** ובחרו **יצירה ושימוש ב-worktree**.

CodeNomad מגלה worktrees דרך OpenCode ומאמת שהם שייכים למאגר הפתוח. שם ענף חדש מתחיל ב־HEAD של עותק העבודה שנבחר. שם ענף קיים משתמש בגרסה הנוכחית של אותו ענף; Git עשוי לסרב לענף שכבר משויך לעותק עבודה במקום אחר. Worktrees משתמשים במיקום ברירת המחדל `.codenomad/worktrees`. שינויים שלא בוצע להם commit נשארים בעותק העבודה המקורי; היצירה אינה מעתיקה אותם ל־worktree החדש.

הבורר בשדה הקלט מעביר את שיחת ההורה ואת צאצאיה בכל העומקים כמשפחה מאומתת. תת־סשן אינו יכול לשנות בורר זה באופן עצמאי. סשנים פעילים חוסמים את הפעולה: אפשרו למשפחה לסיים או עצרו תחילה את הרצתה. המתינו להתייצבות העברה לפני בקשת העברה נוספת; בשגיאה, בדקו את מצב השיחה/ה־worktree המרוענן לפני ניסיון חוזר.

לעומת זאת, **עץ עבודה לעיון** ב־[קבצים](files.md) משנה רק איזה עותק עבודה הלוח קורא. הוא אינו מעביר שיחה, מחליף ענף או משנה היכן תרוץ פקודת המעטפת הבאה שלה.

## הסרת worktree {#remove-worktree}

1. ברשימת ה־worktrees בשדה הקלט, השתמשו ב־**מחק worktree** עבור worktree של ענף הניתן להסרה.
2. בדקו את תיקיית היעד. השאירו **מחיקה בכפייה (זריקת שינויים מקומיים)** כבויה אלא אם מותר לאבד שינויים מקומיים.
3. אשרו מחיקה ובדקו את המלאי שנוצר.

המחיקה מסירה את התיקייה המקומית של ה־worktree. עותק העבודה הראשי של Git אינו יעד הניתן להסרה. CodeNomad מחזיר משפחות שיחה מושפעות לעותק העבודה בשורש ומאמת את מיקומן לפני הסרת ה־worktree; סשנים פעילים יכולים לחסום הסרה. מחיקה אינה ארכוב או גיבוי של קבצים שלא בוצע להם commit.

אם Git מסרב עקב קבצים ששונו/אינם במעקב, שמרו או נקו אותם לפני ניסיון חוזר. מחיקה בכפייה משליכה אותם במפורש. לתיקייה נעולה, סגרו מסופים, עורכים, עוקבים ותהליכי רקע המשתמשים בה. לרשומה חסרה, רעננו worktrees ובדקו את הנתיב לפני ניסיון חוזר. חלון השגיאה מציע **העתק גרסה מסוננת** בשיתוף אבחון; בדקו גם טקסט מסונן תחילה.

## אתחול Git או עבודה בלעדיו {#initialize-git}

1. לתיקייה רגילה כש־Git זמין, פתחו **קבצים → שינויים** או **קומיטים**.
2. בחרו **אתחול Git**. הפעולה מתבצעת מיד, ללא אישור נוסף.
3. המתינו לרענון מטא־נתוני הפרויקט והשיחות; השתמשו ב־**רענן** אם Git אותחל מחוץ ל־CodeNomad.

אתחול יוצר את המאגר בתיקייה שנפתחה במפורש, לא בהורה שלה. הוא אינו יוצר commit. בכשל, בדקו את ההודעה ורעננו לפני ניסיון חוזר: תשובה לא ודאית אינה גורמת לשליחה חוזרת אוטומטית.

אם שרת הקצה אינו יכול להריץ Git, שיחות ועיון מוגבל בקבצים נשארים זמינים לתיקייה שנפתחה במפורש במצב מוגבל לתיקייה. פעולות worktree ואתחול Git דורשים Git באותו שרת קצה. ראו [התקנה](install.md) ו־[קבצים](files.md).
