# פרויקטים ו־worktrees

לשונית פרויקט מחברת את CodeNomad לתיקייה במחשב שרת הקצה. פתיחת לשונית, עיון בעותק עבודה והעברת משפחת שיחה הן פעולות שונות.

## פתיחת פרויקט {#open-project}

לחצו על **מופע חדש** (`+`) או `Ctrl/Cmd+N` לפתיחת לשונית ריקה חדשה. בחרו פרויקט דרך **כרטיסיות אחרונות** או **עיון**. כשאין לשוניות לשחזור או כשהלשונית האחרונה נסגרת, CodeNomad מציג לשונית ריקה. שכפול ולשוניות זמניות משתמשים בשרת המקומי.

בכרטיסיות האחרונות, **פתוח** עובר לכרטיסייה בחלון הזה. הנקודה הירוקה **פתוח בחלון אחר** מסמנת חיבור לשרת של הפרויקט מחוץ לחלון הזה. לחיצה על השורה פותחת כרטיסייה נפרדת.

[פתיחת פרויקט מרוחק בלשונית](remote-access.md#remote-project-tabs) · [SideCars](browser-sidecars.md#register-sidecar)

לעותק מאגר, בחרו **שכפל מאגר Git**, הזינו **כתובת המאגר** ו־**תיקיית יעד**, ואז **שכפל**. **תיקיית יעד** ממולא מראש בשם המאגר, בתיקייה שמכילה את השכפול האחרון שלך, או לצד הפרויקט האחרון שלך. **עיון** בוחר את התיקייה שתכיל את השכפול; אפשר גם לערוך את הנתיב, כולל שם התיקייה של השכפול.

עיון בשרת מרוחק הוא עיון במערכת הקבצים שלו, לא בטלפון או במחשב הנייד שלכם. פתיחת פרויקט אינה יוצרת דמון OpenCode נפרד לכל לשונית. שיחות הן סשנים מקוריים של OpenCode; משך חייהן אינו משך חיי הלשונית.

שכפול כותב מאגר ליעד. **מחק תחילה את תיקיית היעד אם היא כבר קיימת.** היא אפשרות הרסנית: הפעילו אותה רק כשמותר למחוק את כל מה שכבר נמצא שם. השתמשו ביעד חדש אם אינכם בטוחים. שכפול שנכשל אינו סיבה למחוק פרויקט קיים; בדקו את היעד והשגיאה שדווחו לפני ניסיון חוזר.

רשומות אחרונות הן קיצורי דרך. תפריט הפעולות בלשונית הריקה מציע **שנה שם סביבת עבודה** ו־**הסר מהרשימה האחרונה** לפי הרשומה; הקבצים והשיחות נשמרים. בלשונית הריקה ובמשגר המהיר, לחיצה על פרויקט מקומי, מרוחק או SideCar יוצרת מופע חדש גם כשהוא כבר פתוח. הפעולה הנפרדת **פתוח** (**עבור לפרויקט הפתוח**) בוחרת במופע הקיים.

פעולת הפתיחה בוחרת גם לשונית שממתינה לשרת וסוגרת את הלשונית הריקה שממנה התחלתם.

## שימוש במשגר המופע החדש {#new-instance-launcher}

לחצו לחיצה ארוכה או לחיצה ימנית על `+`; כשהמקלדת ממוקדת בו, השתמשו ב־**Alt+Down**, ב־**Shift+F10** או במקש Menu.
Tab עובר לחיפוש, החצים ו־Enter בוחרים, ו־Escape מחזיר את המיקוד ל־`+`.

## סגירת לשונית פרויקט {#close-stop}

1. השתמשו בכפתור הסגירה של הלשונית או ב־**סגור לשונית** בלוח הפקודות (`Ctrl/Cmd+W` בתהליך התצוגה).
2. סגירת הלשונית סוגרת את הפרויקט שלה ב־CodeNomad: הוא מפסיק לעקוב אחר האירועים והבקשות שלו. הסשנים ממשיכים לפעול ב־OpenCode.
3. פתחו את התיקייה מחדש דרך עיון או אחרונים כדי למצוא שוב את השיחות.

| פעולה | היקף והשפעה | מה אינה עושה |
| --- | --- | --- |
| סגור לשונית | מסירה את חיבור הפרויקט של CodeNomad באותה לשונית; לשונית אחרת שנפתחה בנפרד על אותה תיקייה אינה מושפעת | אינה מוחקת קובצי פרויקט או היסטוריה מקורית, אינה עוצרת סשנים ואינה פורקת את ה־Location של OpenCode |
| עצירת סשן | הרצת השיחה הנבחרת | אינה סוגרת את הפרויקט או מוחקת את ההיסטוריה שלו |

טיוטות וקבצים מצורפים שלא נשלחו מהלשונית שנסגרה חוזרים כשפותחים מחדש את אותה תיקייה באותו חלון; החלון שומר אותם עבור 16 הפרויקטים שנסגרו בו לאחרונה, עד שהוא נטען מחדש או נסגר. הם אינם חלק מהשחזור בהפעלה.

בעת סגירה או טעינה מחדש של חלון או לשונית דפדפן, או בעת יציאה מהיישום, CodeNomad מבקש מהשרתים לשחרר את חיבורי הפרויקטים המתאימים. אם לא ניתן להגיע לשרת, הרשומות עשויות להישאר בו. החלונות האחרים שומרים על הלשוניות שלהם. השחזור בהפעלה מחבר מחדש את הלשוניות השמורות ושומר על התיקיות הזמניות הפתוחות. כדי לסיים הרצות יש לעצור אותן במפורש; ראו [הגדרת OpenCode](opencode.md) לתחזוקת השירות המשותף.

כששחזור בהפעלה מופעל, כל לשונית שנותרה משחזרת את בחירות הלוחות שלה, בחירת המשימה והקורא שלה, והבחירה בין צ׳אט לתצוגה מקדימה של אתר. כתובות הדפדפן וההיסטוריה משותפות לכל סשן; דפים שמורים נטענים רק בפתיחה מחדש מפורשת של התצוגה המקדימה של האתר. סגירת אחד המופעים מסירה רק את התצוגה השמורה שלו; פתיחת התיקייה מחדש יוצרת מופע חדש.

שכפול לשונית בדפדפן פותח חיבורי פרויקט נפרדים. אפשר להשתמש שוב בחיבור שעדיין פתוח רק כשהדפדפן מחזיר את אותה לשונית לאחר שפינה אותה מהזיכרון.

## שחזור לשוניות מרוחקות {#restore-remote-tabs}

בטעינה מחדש, כשהשחזור פעיל, נשמרים סדר הלשוניות המרוחקות, הלשונית שנבחרה והטיוטות. שרת שאינו זמין משאיר לשונית בהמתנה: בחרו **נסה שוב** כשיחזור, או **התחבר** עם שם המשתמש והסיסמה שלו או קישור בשדה **קישור צימוד חדש**. שרתים אחרים נשארים זמינים. **השרת לא נמצא** מציין שהשרת השמור חסר.

**נסה שוב** מחבר מחדש את הפרויקט בשרת השמור ויוצר את החיבור מחדש לפי הצורך.

**נסה שוב** משחזר לשוניות ממתינות גם כשהשחזור האוטומטי בהפעלה מושבת. התראות בוחרות את הלשונית הממתינה הקיימת. בדקו את תוצאתה של פעולת שיחה שלא אושרה לפני שליחתה מחדש.

## סביבות עבודה זמניות {#temporary-workspaces}

1. בחרו **לשונית זמנית** בראש הלשונית הריקה.
2. עבדו בתיקייה הריקה שבניהול CodeNomad; Git אינו מאותחל אוטומטית.
3. בסגירת הלשונית, בחרו **שמור**, **מחק** או **ביטול**. תפריט הלשונית מציע גם **שמור כפרויקט**.

| בחירה | השפעה | התאוששות |
| --- | --- | --- |
| שמירה | סוגרת את הפרויקט ב־CodeNomad, שומרת את התיקייה והשיחות, מסירה את מעמדה כזמנית ומוסיפה פרויקט אחרון | פתחו מחדש מאחרונים; התיקייה אינה מועברת |
| מחיקה | מוחקת את השיחות, הקבצים והטיוטות שלא נשלחו של סביבת העבודה הזמנית | ללא ביטול; שמרו תחילה כל דבר נחוץ במקום אחר |
| ביטול | משאיר את סביבת העבודה הזמנית פתוחה | המשיכו לעבוד או החליטו בהמשך |

לשונית זמנית שלא נעשה בה דבר, ללא שיחה, קובץ או טיוטה שלא נשלחה, נמחקת בשקט בסגירה. לשוניות זמניות פתוחות משתתפות בשחזור הרגיל בהפעלה.

מחיקה מסרבת לפעול בזמן ששיחה רצה או שהתיקייה פתוחה בלשונית/חלון אחרים. עצרו את ההרצה וסגרו את התצוגות האחרות תחילה. מחיקה שנכשלה משאירה את המצב הזמני: פתרו את הבעיה המדווחת ונסו שוב במקום למחוק ידנית תיקיית הורה.

## בחירת worktree או יצירתו {#select-create-worktree}

1. פתחו שיחת הורה והשתמשו בבורר ה־worktree בשדה הקלט שלה. בפריסות צרות זהו פקד חץ בלבד.
2. בחרו worktree קיים שהתגלה, או בחרו **+ צור worktree**.
3. ליצירה, הזינו **שם** ובחרו **יצירה ושימוש ב-worktree**.

כשהפרויקט הוא תיקייה בתוך מאגר, מוצגים רק worktrees שמכילים את התיקייה הזו. כדי ליצור worktree מתיקייה כזו, Git חייב לעקוב אחריה. שם ענף חדש מתחיל ב־HEAD של עותק העבודה שנבחר. שם ענף קיים משתמש בגרסה הנוכחית של אותו ענף; Git עשוי לסרב לענף שכבר משויך לעותק עבודה במקום אחר. Worktrees משתמשים במיקום ברירת המחדל `.codenomad/worktrees`. שינויים שלא בוצע להם commit נשארים בעותק העבודה המקורי; היצירה אינה מעתיקה אותם ל־worktree החדש.

הבורר בשדה הקלט מעביר את שיחת ההורה ואת צאצאיה בכל העומקים כמשפחה מאומתת. תת־סשן אינו יכול לשנות בורר זה באופן עצמאי. סשנים פעילים חוסמים את הפעולה: אפשרו למשפחה לסיים או עצרו תחילה את הרצתה. המתינו להתייצבות העברה לפני בקשת העברה נוספת; בשגיאה, בדקו את מצב השיחה/ה־worktree המרוענן לפני ניסיון חוזר.

לעומת זאת, **עץ עבודה לעיון** ב־[קבצים](files.md) משנה רק איזה עותק עבודה הלוח קורא. הוא אינו מעביר שיחה, מחליף ענף או משנה היכן תרוץ פקודת המעטפת הבאה שלה.

## הסרת worktree {#remove-worktree}

1. ברשימת ה־worktrees בשדה הקלט, השתמשו ב־**מחק worktree** עבור worktree של ענף הניתן להסרה.
2. בדקו את תיקיית היעד. השאירו **מחיקה בכפייה (זריקת שינויים מקומיים)** כבויה אלא אם מותר לאבד שינויים מקומיים.
3. אשרו מחיקה ובדקו את המלאי שנוצר.

המחיקה מסירה את התיקייה המקומית של ה־worktree. עותק העבודה הראשי של Git אינו יעד הניתן להסרה. CodeNomad מחזיר משפחות שיחה מושפעות לעותק העבודה בשורש ומאמת את מיקומן לפני הסרת ה־worktree; סשנים פעילים יכולים לחסום הסרה. מחיקה אינה ארכוב או גיבוי של קבצים שלא בוצע להם commit.

אם Git מסרב עקב קבצים ששונו/אינם במעקב, שמרו או נקו אותם לפני ניסיון חוזר. מחיקה בכפייה משליכה אותם במפורש. לתיקייה נעולה, סגרו מסופים, עורכים, עוקבים ותהליכי רקע המשתמשים בה. חלון השגיאה מציע **העתק גרסה מסוננת** בשיתוף אבחון; בדקו גם טקסט מסונן תחילה.

## אתחול Git או עבודה בלעדיו {#initialize-git}

1. לתיקייה רגילה כש־Git זמין, פתחו **קבצים → שינויים** או **קומיטים**.
2. בחרו **אתחול Git**. הפעולה מתבצעת מיד, ללא אישור נוסף.
3. המתינו לרענון מטא־נתוני הפרויקט והשיחות; השתמשו ב־**רענן** אם Git אותחל מחוץ ל־CodeNomad.

אתחול יוצר את המאגר בתיקייה שנפתחה במפורש, לא בהורה שלה. הוא אינו יוצר commit.

אם שרת הקצה אינו יכול להריץ Git, שיחות ועיון מוגבל בקבצים נשארים זמינים לתיקייה שנפתחה במפורש במצב מוגבל לתיקייה. פעולות worktree ואתחול Git דורשים Git באותו שרת קצה. ראו [התקנה](install.md) ו־[קבצים](files.md).
