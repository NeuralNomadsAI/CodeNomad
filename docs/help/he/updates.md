# עדכונים

## בחירת ערוץ העדכונים {#feed}

1. פתחו **הגדרות → מידע → עדכונים**.
2. הגדירו **ערוץ עדכונים** ל־**גרסאות יציבות** או ל־**גרסאות תצוגה מקדימה ויציבות**.
3. רעננו/בדקו עדכונים ועיינו בגרסה המוצעת לפני אישור התקנה.

הערוץ נשמר בתצורת שרת CodeNomad ומשנה רק אילו גרסאות מוצעות. הוא אינו משנה פרופילי נתונים לשולחן העבודה, טיוטות, חלונות, סשנים של OpenCode או תצורת שירות. ללא בחירה מפורשת, בניות המסומנות כתצוגה מקדימה משתמשות בתצוגות מקדימות כברירת מחדל, ובניות אחרות ביציבות.

הערוץ היציב בוחר את הגרסה הסופית האחרונה. תצוגה מקדימה עוקבת אחר סדר הפרסום כי בניות פיתוח עשויות לשתף מספר גרסת בסיס; אל תשוו רק מספרי גרסאות. חבילות תצוגה מקדימה מיועדות למי שמוכנים לבדוק התנהגות קדם־הפצה; עיינו בהערות הגרסה והגנו על טיוטות חשובות לפני הפעלה מחדש.

## עדכון התקנת שולחן עבודה {#desktop-update}

1. השתמשו ב־**Help → Get Updates...**, בהתראת העדכון או בכפתור שב־**הגדרות → מידע → עדכונים**.
2. ב־Electron, עברו לדף הגרסה והשיגו את הארכיון/החבילה למארח/לפלטפורמה שבהם אתם משתמשים.
3. בהתקנות Tauri מקומיות מתאימות, בדקו את ההצעה המקורית ובחרו במפורש **התקנה והפעלה מחדש**.
4. שמרו עבודה חשובה בכל חלון לפני התקנה/הפעלה מחדש, ואז אמתו את **מידע** לאחר ההפעלה.

| התקנת Tauri | זכאות להתקנה בתוך היישום |
| --- | --- |
| התקנת NSIS ב־Windows x64 | נתמכת עם מפתח העדכון המוטמע ומטען גרסה חתום. |
| יישום macOS x64 / arm64 | נתמך עם מפתח העדכון המוטמע ומטען `.app.tar.gz` חתום. |
| AppImage ב־Linux x64 | דורש סמן חבילת AppImage ונתיב `APPIMAGE` לא ריק, וכן תמיכה בעדכונים חתומים. `APPRUN` לבדו אינו מספיק. |
| Debian/RPM, קובץ הרצה נפרד של Windows, בנייה לא חתומה/ללא מפתח | פותח את דף הגרסה במקום להתקין בתוך היישום. |

בחלונות היישום של Tauri ובחלונות **העדפות** המקוריים, מקטע העדכונים מציג **התקן עדכון** כאשר מוצעת גרסה. הוא בודק את הערוץ שנבחר ומציע **התקנה והפעלה מחדש** כאשר עדכון בתוך היישום זמין; אחרת הוא פותח את דף הגרסה המוצג במקטע. חלונות Electron, דפדפן וחלונות מרוחקים מציגים במקום זאת את הקישור **הורד עדכון**, ללא בדיקה של מנגנון העדכון המקורי.

תפריט **Help → Get Updates...** של Tauri מפעיל את תהליך העדכון בחלון היישום שבמוקד. מתוך העדפות או חלון מרוחק, הוא מביא לחזית את חלון היישום שבו נעשה שימוש לאחרונה כדי לבצע את הבדיקה; הוא אינו מתקין דרך החלון המרוחק. אם אין חלון יישום שיכול לקבל את הפעולה, לרבות כאשר החלון שאליו היא מכוונת מציג מסך טעינה, התחברות או צימוד, התפריט פותח במקום זאת את דף הגרסה.

Tauri מציע רק גרסאות עם מניפסט עדכון שפורסם עבור הערוץ/היעד שנבחרו. גרסה שזה עתה הוכרזה אולי עדיין אינה ניתנת להתקנה; ההתראה עשויה לפתוח במקום זאת את דף הגרסה. נדרש אימות חתימה מקורי לפני התקנה. חתימות עדכון נפרדות מהבטחות אישור נוטריוני/חתימת קוד של מערכת ההפעלה.

ההתקנה שומרת את מצב כל חלונות היישום ועוצרת את שרת הקצה שבבעלות CodeNomad לפני החלפת/הפעלת היישום מחדש. דמון OpenCode שבבעלות נפרדת אינו חלק מהכיבוי. סגירת CodeNomad עדיין מסירה תכונות התלויות בשרת הקצה עד חזרתו; אל תסיקו רציפות שירותי ממשק מסשן OpenCode שממשיך לפעול.

אם בדיקה עסוקה, המתינו לפעולה בחלון האחר. בכשל הורדה, אימות או כיבוי, קראו את השגיאה ובצעו בדיקה חדשה; התראה ישנה אינה היתר להתקין מחדש בתים מיושנים. התקנה שנכשלה יכולה לשחזר את שרת הקצה ולטעון מחדש חלונות, ואינה חוזרת אוטומטית על ההתקנה. אם התקנה מקורית אינה זמינה, השתמשו בדף הגרסה לחבילה המתאימה; ראו [התקנה](install.md).

## עדכון שרת עצמאי {#standalone-update}

1. זהו כיצד הפעלתם את CodeNomad ושמרו עבודה התלויה בשרת הקצה הזה.
2. עצרו את תהליך שרת CodeNomad באמצעות בקרת התהליך/השירות הרגילה שלו.
3. עדכנו את אותה התקנת חבילה, ואז הפעילו מחדש עם התצורה והדגלים הרצויים.

| שיטת הפעלה/התקנה | פקודת עדכון |
| --- | --- |
| הפעלת npm יציבה חד־פעמית | `npx @neuralnomads/codenomad@latest` עם הדגלים הרגילים שלכם |
| התקנה יציבה גלובלית | `npm install -g @neuralnomads/codenomad@latest` |
| התקנה יציבה מקומית | `npm install @neuralnomads/codenomad@latest` בתיקיית החבילה |
| הפעלת תצוגה מקדימה חד־פעמית | `npx @neuralnomads/codenomad-dev@latest` עם הדגלים הרגילים שלכם |
| התקנת תצוגה מקדימה גלובלית/מקומית | התקינו `@neuralnomads/codenomad-dev@latest` באותה צורת npm גלובלית/מקומית |

תהליך שכבר פועל אינו מקבל קוד חדש רק מפני ש־npm התקין אותו. שמרו במכוון על אותו נתיב תצורה; בחירת ערוץ בהגדרות אינה מחליפה את חבילת npm או מחליפה אוטומטית שמות חבילות יציבות/תצוגה מקדימה. שמרו את דגלי האימות/TLS בהפעלה מחדש; ראו [שרת](server.md).

## הפרדת תחזוקת OpenCode {#opencode-separate}

עדכון CodeNomad אינו עדכון OpenCode CLI שנבחר. עדכון ה־CLI אינו הפעלה מחדש של הדמון המשותף הפועל. טעינת תצורה מקורית מחדש היא פעולה מפורשת נוספת עם השפעות משלה על Locations טעונים ובקשות.

משאבי Node/npm לשולחן העבודה נשלחים עם היישום; גרסת יישום מספקת את עדכוניהם. הדבר אינו מחליף את Node/npm במערכת, את סביבת הריצה הפנימית של Electron, את ה־webview של הפלטפורמה או את שירות OpenCode המנוהל בנפרד.

השתמשו ב־**הגדרות → OpenCode** לבחירת סביבת ריצה, התקנה/עדכון ופקדי שירות מפורשים. בדקו [הגדרת OpenCode](opencode.md) לפני הפעלה מחדש או טעינה מחדש, במיוחד כשחלונות/משתמשים אחרים או משימות חולקים את הדמון. לעולם אל תחזרו על קלט או על פעולת שינוי לא ודאיים רק מפני שעדכון/חיבור מחדש הסתיים.
