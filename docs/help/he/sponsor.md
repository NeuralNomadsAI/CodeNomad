# תמכו ב־CodeNomad

{{funding}}

אני מפתח ומתחזק את CodeNomad במשרה מלאה. הוא חופשי וקוד פתוח, ואני רוצה להמשיך להעניק לו את תשומת הלב שמגיעה לכלי שמשמש לעבודה אמיתית.

הרקע שלי הוא בתלת־ממד ובאפקטים חזותיים: שלושה עשורים של יצירה, פתרון בעיות הפקה ופיתוח תוכנה לצד האנשים שמשתמשים בה. הניסיון הזה מעצב את הדרך שבה אני ניגש ל־CodeNomad: כלי צריך להחזיק מעמד גם אחרי ההדגמה הראשונה, בסשנים ארוכים, בפרויקטים מורכבים ומול כל הבלתי צפוי של העבודה היומיומית.

משוב, דיווחי באגים ותרומות קוד עוזרים לשפר את CodeNomad. התרומות הכספיות מממנות את הזמן שאני מקדיש כדי להפוך את כל זה למשהו אמין, ולתחזק אותו ככל ש־OpenCode מתפתח.

כדי להמשיך בזה במשרה מלאה, אני זקוק לתמיכה הכספית הזו. אם CodeNomad הפך לחלק מהעבודה שלכם, החסות עוזרת לי להתפרנס מפיתוח ותחזוקה של כלי שנשאר זמין לכולם.

Pascal André

## דרכים נוספות לעזור {#other-ways}

- סמנו בכוכב את [המאגר](https://github.com/NeuralNomadsAI/CodeNomad) וספרו על CodeNomad לאנשים שמשתמשים ב־OpenCode.
- [דווחו על באג](support.md#report-a-bug) עם שחזור מינימלי.
- תקנו עמוד עזרה או תרגום בעזרת הקישור **עריכת העמוד הזה** בתחתית כל עמוד עזרה.
- [תרמו קוד](support.md#contribute) באמצעות בקשת משיכה ממוקדת ל־`dev`.
