# ספקים וחשבונות

אימות ספקים שייך לשירות OpenCode המחובר, לא למכשיר הדפדפן או לפרויקט CodeNomad אחד. להעדפות תצוגת מודלים, למכסות מנוי ולבחירות חיפוש ברשת יש היקפים שונים.

## חיבור ספק מודלים או חיפוש {#connect}

1. פתחו סביבת עבודה, ואז **הגדרות → ספקים**. **מודלים** מתחיל מורחב; הרחיבו את **חיפוש ברשת** עבור ספקי חיפוש. **תמונות** מרכז את הגדרות התמונות.
2. באותה קבוצה, בחרו **בחר ספק**, ואז **התחבר**. עבור ספק מודלים שכבר מופיע ברשימה למטה, השתמשו ב־**הוספת חשבון** (+) בשורה שלו, גם לחיבור הראשון.
3. לספק מודלים, השלימו את **שיטת אימות** המקורית המוצעת: מפתח API, OAuth או פקודה. ל־OAuth, השתמשו ב־**פתח דף הרשאה** ושלחו קוד הרשאה רק כשמתבקשים. ספקי חיפוש מתחברים באמצעות מפתח API.
4. בדקו את שורת הספק המוגדר לאחר השלמה.

שילובים לחיפוש בלבד מופיעים תחת **חיפוש ברשת**, לא **מודלים**. שמירת אימות אינה בוחרת מודל או משנה את ספק החיפוש כברירת מחדל. מפתחות API ואישורי OAuth נשמרים בשרת OpenCode הפעיל. הדפדפן מקבל מטא־נתוני חיבור, לא סודות אישורים שמורים. חיבור שמקורו במשתני סביבה הוא לקריאה בלבד בממשק זה: שנו את הסביבה שבבעלותה הוא נמצא במקום לנסות לנתקו כאן.

אל תפרסמו את קישור ההרשאה או הקוד באבחון.

## בחירת חשבונות וניהולם {#accounts}

1. בשורת הספק, השתמשו ב־**חשבון פעיל** לבחירת אישור שמור.
2. השתמשו ב־**הוספת חשבון** לאימות חיבור נוסף.
3. לניהול חשבון שמור אחר, בחרו אותו תחילה, ואז השתמשו ב־**שינוי שם החשבון** או ב־**הסרת חשבון**. שינוי שם משתמש ב־**שם החשבון** וב־**שמור**; **הסרת חשבון** פועלת מיד, ללא אישור.

בחירה, שינוי שם והסרה משפיעים על אותו שילוב בכל שירות OpenCode, לרבות פרויקטים ולקוחות אחרים. הסרת אישור עלולה להשאיר לקוחות אלה ללא אימות; היא אינה מוחקת היסטוריית שיחות או מבטלת את החשבון המרוחק אצל הספק. אי אפשר לבחור חיבורי סביבה כאישורים שמורים הניתנים לכתיבה או להסירם כאן.

### מגבלות בחירה אוטומטית {#automatic-selection}

כשיש מספר אישורים שמורים בשילוב נתמך, **בחירת חשבון אוטומטית** מפעילה מרצון בחירה לפי מכסה לפני קבלת הקלט/הפקודה המותאמת הבאים דרך CodeNomad. ההגדרה היא לכל שילוב בתצורת CodeNomad; בחירת החשבון המתקבלת חלה על כל השירות.

| שילוב זכאי | סוג חשבון זכאי |
| --- | --- |
| OpenAI / Codex | חשבונות מנוי OAuth של Codex דרך דפדפן/מכשיר, לא מפתחות OpenAI בתשלום לפי שימוש ולא שיטת ההתחברות של ChatGPT ש־OpenAI אינה מספקת עבורה נתוני שימוש. |
| OpenCode Go | מפתח Go, או התחברות/מפתח של OpenCode Console המשמשים **לספק Go בלבד**; הבחירה במודלי Console בתשלום נשארת ידנית. |
| Anthropic | התחברות OAuth של Claude Pro/Max ב־OpenCode, **לא** התחברות Claude Code. |
| GitHub Copilot | OAuth עם מכסת בקשות פרימיום קריאה; אישורי נקודת קצה ארגונית אינם מועמדים הניתנים לקריאה. |
| תוכניות קוד | מבוססות מפתח: `zai-coding-plan`, `zhipuai-coding-plan`, `kimi-for-coding`, `minimax-coding-plan`, `minimax-cn-coding-plan`. |

רק חשבון נוכחי שמכסתו מלאה מפעיל החלפה; עצם קיומה של חלופה עם יותר יתרה אינו מספיק. Codex, Copilot ותוכניות קוד דורשים מועמד שזמינותו מוכחת. Go, Console ו־Claude עשויים להשתמש במועמד שמכסתו לא ידועה, אלא אם כשל מכסה מקורי מהזמן האחרון מסמן אותו כמנוצל.

זה **אינו מעבר גיבוי במהלך הרצה**. הוא אינו מנסה שוב בקשות שנכשלו או שולח מחדש קלטים, פקודות או שינויים. הוא אינו מחליף חיבורי סביבה, ספקים שרירותיים, יתרות בתשלום לפי שימוש או התחברויות Claude Code חיצוניות.

## נראות מודלים, מועדפים וחשיבה {#models}

1. בחרו **ניהול מודלים** לצד ספק מודלים.
2. חפשו לפי שם/מזהה ושנו נראות; **הצג הכול** ו־**הסתר הכול** משפיעים על רשימת הבורר של אותו ספק. גררו מעל תיבות הסימון כדי לשנות כמה מודלים בבת אחת.
3. בבורר **מודל** של שיחה, השתמשו ב־**הוסף למועדפים** או ב־**הסר ממועדפים**; **הצג את כל המודלים** יוצא מסינון למועדפים בלבד.
4. השתמשו ב־**חשיבה** בשדה הקלט לווריאנטים שהמודל שנבחר חושף.

נראות ומועדפים מסדרים את בוררי CodeNomad; הם אינם מסירים מודלים מותקנים, מסירים אישורים או מונעים מלקוחות OpenCode אחרים להשתמש בהם. חשיבה בוחרת וריאנט מודל לשליחות עתידיות, לא את נראות החשיבה שכבר בתמליל. שחזרו מודלים מוסתרים באמצעות **ניהול מודלים → הצג הכול**.

## שימוש, ספירת טוקנים והתחברויות שפגו {#usage}

השתמשו ב־**שימוש** בלוח הימני לחלונות תוכנית הספק, זמני האיפוס והיתרות הנתמכות של השיחה הפעילה. קריאות ספק אלה שונות מ־**טוקנים** לכל הודעה ומאומדני עלות: מכסת מנוי אינה חשבון המחושב מהתמליל הגלוי. קריאה חסרה, מיושנת או לא ידועה אינה שימוש אפס או הוכחה לקיבולת שנותרה. **יתרת קרדיטים של הספק** ב־**הגדרות → מתקדם** שולטת בתצוגת יתרות משלימות.

לפי [השאלות הנפוצות של Antigravity](https://antigravity.google/docs/faq/) מטעם Google, שימוש בתוכנת צד שלישי עם התחברות Antigravity מפר את תנאי השימוש ועלול להוביל להשעיית החשבון או לסגירתו.

עבור מודלים בתשלום באינטגרציה `opencode`, **OpenCode Console** מציג **בקשות** עבור **24 שעות**, **7 ימים** ו־**30 ימים**, כפי ש־Console מדווח. **בקשות לפי מודל · 30 ימים** מפרט כל מודל ואת הספק שלו. המונים מתייחסים לחשבון Console המחובר ומעוצבים לפי שפת האפליקציה. **תקציבי חשבונות שירות** מציג **התקציבים אינם זמינים.** כש־**יתרת קרדיטים של הספק** מופעלת, יתרת הקרדיטים של Console מוצגת כ־**זיכויים**. OpenCode Go משתמש בקורא מכסה משלו.

תקנו חיבור OAuth של Console שאינו תקף או שפג תוקפו דרך הגורם שמנהל אותו, גם אם נשמר מפתח API נוסף.

בשגיאת חיבור ל־Console ‏(401 או 403), בדקו את ההתחברות, את מזהה הארגון שלה ואת הרשאת **Usage › Read** תחת **הגדרות → ספקים**, ואז רעננו את **שימוש**. OAuth דורש את `https://opencode.ai/console`.

עבור מודלי OpenCode חינמיים (`big-pickle` ומזהים שמסתיימים ב־`-free`), **שימוש** מציג פס אחד: הבקשות החינמיות של חשבון Console המחובר ב־24 השעות האחרונות לפי Console, מול ערך ייחוס של **800**; המגבלות בפועל עשויות להשתנות. המונה כולל לקוחות נוספים של החשבון ואין לו מועד איפוס. כש־**יתרת קרדיטים של הספק** מופעלת, יתרת הקרדיטים של Console מוצגת כ־**זיכויים**. חברו את OpenCode Console דרך **הגדרות → ספקים** למעקב אחר בקשות למודלים חינמיים.

השימוש החינמי ומוני Console בתשלום משמשים לתצוגה בלבד; בחירת חשבון אוטומטית משתמשת בקוראים ובכללים נפרדים.

OpenAI אינה מספקת נתוני שימוש עבור אחת משיטות ההתחברות של ChatGPT: לוח השימוש מציין זאת במקום להציג חלונות מכסה. בחרו [הצגת השימוש ב-ChatGPT](https://chatgpt.com/settings/usage) כדי לבדוק את השימוש באפליקציות ולנהל את הגישה שלהן למסלול ולקרדיטים שלכם ב-ChatGPT.

Claude דרך `anthropic`/`claude` משתמש ב־OAuth של Anthropic ב־OpenCode. הספק **Claude Agent** של OpenCode (`claude-agent`) והספק `claude-code` משתמשים בהתחברות Claude Code במארח הדמון, לרבות הפצת WSL שלו: `CLAUDE_CODE_OAUTH_TOKEN`, ואז ההתחברות השמורה, כאשר `CLAUDE_SECURESTORAGE_CONFIG_DIR` / `CLAUDE_CONFIG_DIR` או `~/.claude` קובעים אחסון קבצים; macOS מקומי יכול להשתמש ב־Keychain.

ב־OpenRouter, **מגבלת המפתח** מציגה את הסכום שנותר בדולרים מול מגבלת ההוצאה של המפתח; למפתח ללא מגבלה אין שורה כזו. השימוש נעזר ב־`baseURL` המוגדר של הספק, כולל קידומת הנתיב, או ב־`https://openrouter.ai/api/v1` אם אינו מוגדר. יש להשתמש בשם מארח HTTPS ציבורי ללא פרטי כניסה, יציאה מפורשת, שאילתה או מקטע; כתובות IP ו־localhost נדחות. כתובת לא תקינה או שער ללא `/key` הופכים את השימוש ללא זמין; המפתח נשאר ביעד שהוגדר והפניות נדחות.

ב־GitHub Copilot, **שימוש** מציג את הצריכה בצורת **נוצלו / מגבלה נוצלו**, או את נקודות הזכות שנוצלו ממכסה ללא הגבלה כש־GitHub מספקת אותן; אחרת מוצג **ללא הגבלה**. חיבורי Enterprise משתמשים ב־`https://api.<host>/copilot_internal/user` לפי המארח או כתובת ה־HTTPS הראשית של החיבור השמור. יש להשתמש בשם מארח מלא ללא פרטי כניסה, יציאה מפורשת (גם `:443`), נתיב מעבר ל־`/`, שאילתה או מקטע; כתובות IP ו־localhost נדחות לפני שליחת האסימון. הפניות נדחות. חיבורי Enterprise נשארים מחוץ לבחירת החשבון האוטומטית.

Kimi תומכת ב־`kimi-code-plan-cn` ‏, ב־`kimi-code-plan-global` ‏, ב־`kimi-for-coding` וב־`kimi`. המגבלות הזמינות לחמש שעות, לשבוע, **חודשי** ו־**תכנות חודשי** מציגות את אחוז הניצול.

המגבלות החודשיות פועלות לפי מועד האיפוס של הספק; חשבון `kimi-for-coding` שאחת מהן נוצלה בו במלואה אינו זמין לבחירה אוטומטית, גם אם נותרה מכסה בחלון קצר יותר.

מפתחות API של OpenCode Go מציגים אחוזי ניצול וזמני איפוס זמינים. כניסה ל־OpenCode Console קוראת גם את יתרת הארנק ב־USD כאשר הרשאות החיוב מאפשרות זאת. הפעילו **יתרת קרדיטים של הספק** להצגת היתרה הנפרדת (כבוי כברירת מחדל); מכסות Go ו־Extra Usage נשארות נפרדות. יתרה בלבד משאירה את המכסה לא ידועה לבחירה אוטומטית.

עבור **נתוני השימוש אינם זמינים כרגע.** או **לא ניתן להתחבר ל־OpenCode Console.**, בדקו את חיבור הרשת ורעננו את **שימוש**.

אם פג תוקף מפתח OpenCode Go, צרו מפתח חלופי ב־[OpenCode Console](https://opencode.ai/console/login), תחת **Account → Personal API keys**, ואז החליפו את המפתח השמור דרך חיבור הספק.

### משתני סביבה אופציונליים לשימוש {#usage-environment}

יש לספק אסימון גישה עדכני של Cursor באמצעות המשתנים להלן. קריאות Enterprise דורשות הרשאה לקרוא את נתוני לוח הבקרה של הצוות; [ממשק הניהול](https://cursor.com/docs/account/teams/admin-api) משתמש במפתח ניהול נפרד. יש לעדכן אסימון שפג ולהפעיל מחדש את שרת הקצה האחורי עם הסביבה המעודכנת.

הגדירו אותם בסביבה של **תהליך שרת הקצה של CodeNomad** לפני הפעלתו. שינוי עורך **משתני סביבה** של הסשן אינו מעדכן את `process.env` של שרת קצה פועל עבור קוראים אלה. הפעילו מחדש את שרת הקצה בסביבה הרצויה כשמשנים אותם; אל תפעילו מחדש את שירות OpenCode המשותף רק בשביל משתנה של קורא שימוש.

| שילוב שימוש | משתנה סביבה |
| --- | --- |
| Cursor | `CURSOR_ACCESS_TOKEN`, עם חלופה `CURSOR_TOKEN` |
| Ollama Cloud | `OLLAMA_CLOUD_COOKIE` |
| שימוש משלים של OpenCode Go | `OPENCODE_GO_WORKSPACE_ID` ו־`OPENCODE_GO_AUTH_COOKIE` יחד |
| ZenMux | `ZENMUX_PLATFORM_API_KEY` — מפתח פלטפורמה, נפרד ממפתח ההסקה |
| exe.dev | `EXE_DEV_USAGE_TOKEN` |
| Command Code | חלופת `COMMAND_CODE_API_KEY` כשאישור מקורי אינו זמין |

שמרו אסימונים/עוגיות מחוץ להיסטוריית מעטפת, צילומי מסך ודוחות.

## ברירת מחדל לחיפוש ברשת ודריסת פרויקט {#web-search}

1. ב־**הגדרות → ספקים**, הרחיבו את **חיפוש ברשת** וחברו את שילוב החיפוש עם מפתח ה־API שלו אם הוא דורש מפתח.
2. בחרו **חיפוש ברירת מחדל** לתצורה כללית.
3. השתמשו ב־**עבור הפרויקט הנוכחי** לדריסה ב־Location הפעיל. רחפו מעל בורר זה או מקדו אותו כדי לראות את **חיפוש בפרויקט זה** עם התוצאה בפועל.

שינויים נשמרים אוטומטית. **ברירת מחדל / בירושה** משתמש בתצורה בירושה או בבחירה המקורית השמורה; דריסת פרויקט גוברת על כללי. **מושבת** מכבה חיפוש בהיקף הנבחר; **ספק אוטומטי** מבקש בחירת ספק אוטומטית מקורית. **נתק** מסיר מפתח חיפוש שמור; חיבור שמסופק באמצעות משתנה סביבה מסומן לקריאה בלבד ואין לו **נתק**.

אישורי חיפוש נשארים גלובליים לשירות גם כשבחירת הספק היא ברמת פרויקט. שמירת מפתח אינה בוחרת בו כברירת המחדל לחיפוש. לפרטי תצורה מקורית, ראו [תיעוד OpenCode](https://opencode.ai/v2/docs/) ו־[הגדרת OpenCode](opencode.md).

## יצירת תמונות ושמירתן {#images}

1. ב-**הגדרות → ספקים**, הרחיבו את **תמונות**.
2. **יצירת תמונות** מוגדרת ל־**פעילה, מודל אוטומטי** כל עוד לא שיניתם אותה: בחרו במקום זאת אחד ממודלי התמונות שמציעים הספקים המחוברים, או **כבויה** כדי לכבות אותה בתצורה הגלובלית.
3. סמנו **שמירת תמונות פעם אחת** כדי לשמור כל תמונה מצורפת או שנוצרה פעם אחת בלבד, במקום בתוך כל הודעה שמשתמשת בה.

השינויים נשמרים אוטומטית בתצורת OpenCode הגלובלית וחלים על כל הפרויקטים. אלה תכונות ניסיוניות של OpenCode: **תמונות** מציג רק את ההגדרות שגרסת OpenCode המחוברת תומכת בהן. הסוכנים מקבלים את כלי התמונות רק כל עוד ספק מחובר מציע מודל תמונות. **שמירת תמונות פעם אחת** חלה על הודעות חדשות. אם קובץ תצורת OpenCode של הפרויקט עצמו קובע את **שמירת תמונות פעם אחת**, התיבה מציגה את הערך שחל בו, והשמירה כותבת אותו גם לקובץ הזה. אם שמירה תסתיר הגדרות OpenCode אחרות, **תמונות** נשאר לקריאה בלבד; שנו את האפשרויות בקובץ התצורה שמופיע בתיאור הצף של האזהרה.

כדי ליצור, להשוות ולשפר תמונות בשיחה ייעודית, ראו [יצירת תמונות עם הרחבת Design](extensions.md#design).
