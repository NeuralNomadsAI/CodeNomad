# ספקים וחשבונות

אימות ספקים שייך לשירות OpenCode המחובר, לא למכשיר הדפדפן או לפרויקט CodeNomad אחד. להעדפות תצוגת מודלים, למכסות מנוי ולבחירות חיפוש ברשת יש היקפים שונים.

## חיבור ספק מודלים או חיפוש {#connect}

1. פתחו סביבת עבודה, ואז **הגדרות → ספקים**. **מודלים** מתחיל מורחב; הרחיבו את **חיפוש ברשת** עבור ספקי חיפוש.
2. באותה קבוצה, בחרו **בחר ספק**, ואז **התחבר**.
3. לספק מודלים, השלימו את **שיטת אימות** המקורית המוצעת: מפתח API, OAuth או פקודה. ל־OAuth, השתמשו ב־**פתח דף הרשאה** ושלחו קוד הרשאה רק כשמתבקשים. ספקי חיפוש מתחברים באמצעות מפתח API.
4. בדקו את שורת הספק המוגדר לאחר השלמה. **מודלים** נקרא מחדש לאחר חיבורים, שינויי חשבון וחיבורים מחדש; ל־**חיפוש ברשת** יש גם **רענן**.

שילובים לחיפוש בלבד מופיעים תחת **חיפוש ברשת**, לא **מודלים**. שמירת אימות אינה בוחרת מודל או משנה את ספק החיפוש כברירת מחדל. מפתחות API ואישורי OAuth נשמרים בשרת OpenCode הפעיל. הדפדפן מקבל מטא־נתוני חיבור, לא סודות אישורים שמורים. חיבור שמקורו במשתני סביבה הוא לקריאה בלבד בממשק זה: שנו את הסביבה שבבעלותה הוא נמצא במקום לנסות לנתקו כאן.

אם חלון ההרשאה חסום, השתמשו ב־**פתח דף הרשאה**, ב־**פתח בלשונית זו** או ב־**העתק קישור** מתוך התהליך. אל תפרסמו את קישור ההרשאה או הקוד באבחון.

## בחירת חשבונות וניהולם {#accounts}

1. בשורת הספק, השתמשו ב־**חשבון פעיל** לבחירת אישור שמור.
2. השתמשו ב־**הוספת חשבון** לאימות חיבור נוסף.
3. לניהול חשבון שמור אחר, בחרו אותו תחילה, ואז השתמשו ב־**שינוי שם החשבון** או ב־**הסרת חשבון**. שינוי שם משתמש ב־**שם החשבון** וב־**שמור**; **הסרת חשבון** פועלת מיד, ללא אישור.

בחירה, שינוי שם והסרה משפיעים על אותו שילוב בכל שירות OpenCode, לרבות פרויקטים ולקוחות אחרים. הסרת אישור עלולה להשאיר לקוחות אלה ללא אימות; היא אינה מוחקת היסטוריית שיחות או מבטלת את החשבון המרוחק אצל הספק. אי אפשר לבחור חיבורי סביבה כאישורים שמורים הניתנים לכתיבה או להסירם כאן. אם פעולה נכשלת, CodeNomad קורא מחדש את החשבונות: בדקו שוב את **חשבון פעיל** לפני פעולה נוספת.

### מגבלות בחירה אוטומטית {#automatic-selection}

כשיש מספר אישורים שמורים בשילוב נתמך, **בחירת חשבון אוטומטית** מפעילה מרצון בחירה לפי מכסה לפני קבלת הקלט/הפקודה המותאמת הבאים דרך CodeNomad. ההגדרה היא לכל שילוב בתצורת CodeNomad; בחירת החשבון המתקבלת חלה על כל השירות.

| שילוב זכאי | סוג חשבון זכאי |
| --- | --- |
| OpenAI / Codex | חשבונות מנוי OAuth של Codex דרך דפדפן/מכשיר, לא מפתחות OpenAI בתשלום לפי שימוש ולא שיטת ההתחברות של ChatGPT ש־OpenAI אינה מספקת עבורה נתוני שימוש. |
| OpenCode Go | מפתח Go, או התחברות/מפתח של OpenCode Console המשמשים **לספק Go בלבד**, לא קרדיטים של Zen בתשלום לפי שימוש. |
| Anthropic | התחברות OAuth של Claude Pro/Max ב־OpenCode, **לא** התחברות Claude Code. |
| GitHub Copilot | OAuth עם מכסת בקשות פרימיום קריאה; אישורי נקודת קצה ארגונית אינם מועמדים הניתנים לקריאה. |
| תוכניות קוד | מבוססות מפתח: `zai-coding-plan`, `zhipuai-coding-plan`, `kimi-for-coding`, `minimax-coding-plan`, `minimax-cn-coding-plan`. |

רק חשבון נוכחי שמכסתו מלאה מפעיל החלפה; עצם קיומה של חלופה עם יותר יתרה אינו מספיק. הקריאות בודקות אישורים שמורים מפורשים בלי להפעיל מועמדים או להחליף אסימוני רענון. Codex, Copilot ותוכניות קוד דורשים מועמד שזמינותו מוכחת. Go, Console ו־Claude עשויים להשתמש במועמד שמכסתו לא ידועה, אלא אם כשל מכסה מקורי מהזמן האחרון מסמן אותו כמנוצל. נקודת הקצה לשימוש של OpenCode Go ושימוש OAuth של Console נשארים לא מאומתים במקור, ולכן הזמינות אינה מובטחת.

זה **אינו מעבר גיבוי במהלך הרצה**. הוא אינו מנסה שוב בקשות שנכשלו או שולח מחדש קלטים, פקודות או שינויים. הוא אינו מחליף חיבורי סביבה, ספקים שרירותיים, יתרות בתשלום לפי שימוש או התחברויות Claude Code חיצוניות. שינויים ידניים בחשבון מכובדים בהכנת הבחירה; אין נעילת חשבון חוצת־לקוחות. בשגיאות מכסה/אימות, בדקו **חשבון פעיל**, רעננו שימוש והתחברו דרך בעל האישורים לפי הצורך לפני שליחה מכוונת נוספת.

## נראות מודלים, מועדפים וחשיבה {#models}

1. בחרו **ניהול מודלים** לצד ספק מודלים.
2. חפשו לפי שם/מזהה ושנו נראות; **הצג הכול** ו־**הסתר הכול** משפיעים על רשימת הבורר של אותו ספק.
3. בבורר **מודל** של שיחה, השתמשו ב־**הוסף למועדפים** או ב־**הסר ממועדפים**; **הצג את כל המודלים** יוצא מסינון למועדפים בלבד.
4. השתמשו ב־**חשיבה** בשדה הקלט לווריאנטים שהמודל שנבחר חושף.

נראות ומועדפים מסדרים את בוררי CodeNomad; הם אינם מסירים מודלים מותקנים, מסירים אישורים או מונעים מלקוחות OpenCode אחרים להשתמש בהם. הסתרת מודל אינה ניתוק חשבון. חשיבה בוחרת וריאנט מודל לשליחות עתידיות, לא את נראות החשיבה שכבר בתמליל. שחזרו מודלים מוסתרים באמצעות **ניהול מודלים → הצג הכול**.

## שימוש, ספירת טוקנים והתחברויות שפגו {#usage}

השתמשו ב־**שימוש** בלוח הימני לחלונות תוכנית הספק, זמני האיפוס והיתרות הנתמכות של השיחה הפעילה. קריאות ספק אלה שונות מ־**טוקנים** לכל הודעה ומאומדני עלות: מכסת מנוי אינה חשבון המחושב מהתמליל הגלוי. קריאה חסרה, מיושנת או לא ידועה אינה שימוש אפס או הוכחה לקיבולת שנותרה. **יתרת קרדיטים של הספק** ב־**הגדרות → מתקדם** שולטת בתצוגת יתרות משלימות.

OpenAI אינה מספקת נתוני שימוש עבור אחת משיטות ההתחברות של ChatGPT: לוח השימוש מציין זאת במקום להציג חלונות מכסה. השיחה עדיין עובדת, וחיבור מחדש של אותה התחברות אינו משחזר את הקריאה.

שימוש עוקב אחר האישור המקורי שנבחר. Claude דרך `anthropic`/`claude` משתמש ב־OAuth של Anthropic ב־OpenCode. הספק `claude-code` משתמש בהתחברות Claude Code במארח הדמון, לרבות הפצת WSL שלו: `CLAUDE_CODE_OAUTH_TOKEN`, ואז ההתחברות השמורה, כאשר `CLAUDE_SECURESTORAGE_CONFIG_DIR` / `CLAUDE_CONFIG_DIR` או `~/.claude` קובעים אחסון קבצים; macOS מקומי יכול להשתמש ב־Keychain. CodeNomad אינו מחליף התחברות Claude אחת באחרת.

להתחברות ספק שפגה, רעננו/התחברו דרך בעליה — OpenCode, Claude Code או Codex CLI — ואז רעננו את CodeNomad. CodeNomad אינו מחליף אסימוני רענון בבעלות חיצונית. תפוגת התחברות לשרת CodeNomad נפרדת: התחברו מחדש ל־CodeNomad בלי להניח שבקשת ספק שנכשלה תישלח שוב. ראו [פתרון בעיות](troubleshooting.md).

### משתני סביבה אופציונליים לשימוש {#usage-environment}

הגדירו אותם בסביבה של **תהליך שרת הקצה של CodeNomad** לפני הפעלתו. אלו אישורים לקוראי שימוש, לא הגדרות דפדפן או פקדי בחירת מודל. שינוי עורך **משתני סביבה** של הסשן אינו מעדכן את `process.env` של שרת קצה פועל עבור קוראים אלה. הפעילו מחדש את שרת הקצה בסביבה הרצויה כשמשנים אותם; אל תפעילו מחדש את שירות OpenCode המשותף רק בשביל משתנה של קורא שימוש.

| שילוב שימוש | משתנה סביבה |
| --- | --- |
| Cursor | `CURSOR_ACCESS_TOKEN`, עם חלופה `CURSOR_TOKEN` |
| Ollama Cloud | `OLLAMA_CLOUD_COOKIE` |
| שימוש משלים של OpenCode Go | `OPENCODE_GO_WORKSPACE_ID` ו־`OPENCODE_GO_AUTH_COOKIE` יחד |
| ZenMux | `ZENMUX_PLATFORM_API_KEY` — מפתח פלטפורמה, נפרד ממפתח ההסקה |
| exe.dev | `EXE_DEV_USAGE_TOKEN` |
| Command Code | חלופת `COMMAND_CODE_API_KEY` כשאישור מקורי אינו זמין |

שמרו אסימונים/עוגיות מחוץ להיסטוריית מעטפת, צילומי מסך ודוחות. קוראים אופציונליים תלויים ב־API של הספק ובתוקף האישורים; הגדרת משתנה אינה הבטחה לנתוני מכסה שימושיים.

## ברירת מחדל לחיפוש ברשת ודריסת פרויקט {#web-search}

1. ב־**הגדרות → ספקים**, הרחיבו את **חיפוש ברשת** וחברו את שילוב החיפוש עם מפתח ה־API שלו אם הוא דורש מפתח.
2. בחרו **חיפוש ברירת מחדל** לתצורה כללית.
3. השתמשו ב־**עבור הפרויקט הנוכחי** לדריסה ב־Location הפעיל. רחפו מעל בורר זה או מקדו אותו כדי לראות את **חיפוש בפרויקט זה** עם התוצאה בפועל.

שינויים נשמרים אוטומטית. **ברירת מחדל / בירושה** משתמש בתצורה בירושה או בבחירה המקורית השמורה; דריסת פרויקט גוברת על כללי. **מושבת** מכבה חיפוש בהיקף הנבחר; **ספק אוטומטי** מבקש בחירת ספק אוטומטית מקורית. **חיפוש ברשת** טוען את החיבורים והבחירות שלו רק כשהוא מורחב. **נתק** מסיר מפתח חיפוש שמור; חיבור שמסופק באמצעות משתנה סביבה מסומן לקריאה בלבד ואין לו **נתק**.

אישורי חיפוש נשארים גלובליים לשירות גם כשבחירת הספק היא ברמת פרויקט. שמירת מפתח אינה בוחרת בו כברירת המחדל לחיפוש. אם קריאה/שמירה נכשלת, רעננו לפני ניסיון חוזר; אל תחליפו תצורה בעיוורון. לפרטי תצורה מקורית, ראו [תיעוד OpenCode](https://opencode.ai/v2/docs/) ו־[הגדרת OpenCode](opencode.md).
