# התקנת CodeNomad

בחרו מארח מקומי לשולחן העבודה או הפעילו את [השרת העצמאי](server.md). בשני המקרים, השירות המקורי המשותף וההיסטוריה שייכים ל־OpenCode.

## הורדות לשולחן העבודה {#desktop-downloads}

1. פתחו את [הגרסה האחרונה](https://github.com/NeuralNomadsAI/CodeNomad/releases/latest).
2. בחרו חבילה התואמת למערכת ההפעלה ולמעבד שלכם.
3. חלצו את קובץ ה־ZIP או התקינו/הריצו את חבילת הפלטפורמה, ואז הפעילו את CodeNomad.

| פלטפורמה | גרסת Electron | גרסת Tauri | הערות לפלטפורמה |
| --- | --- | --- | --- |
| macOS | ZIP, Intel או Apple Silicon | ZIP, Intel או Apple Silicon | סביבת הריצה הכלולה מחייבת macOS 13.5 ואילך. |
| Windows | ZIP, x64 | מתקין, x64 | Windows 10 ואילך; Tauri משתמש ב־WebView2. |
| Linux | חבילת Debian, x64 | AppImage, x64 | נבנה ונבדק ב־Ubuntu 24.04; תאימות להפצות ישנות יותר אינה מובטחת. |

גרסאות שולחן העבודה כוללות את משאבי הריצה הנחוצים לשרת הקצה ולמתקין OpenCode, כך שאין צורך בהתקנת Node.js/npm נפרדת לשימוש בהן. Git אינו כלול. אוטומציית דפדפן מקורית נתמכת ב־Electron וב־Tauri ב־Windows; פלטפורמות Tauri אחרות משתמשות בתצוגות iframe.

אם הורדה מאומתת נחסמת בהפעלה, ראו [פתרון בעיות לפי פלטפורמה](troubleshooting.md#desktop-launch). לעולם אל תריצו ארכיון שאינו מהימן רק כדי לעקוף אזהרה.

## התקנה ב־Linux {#linux-install}

מתוך התיקייה המכילה את הגרסה שהורדתם, החליפו בגרסה ובשם הקובץ בפועל:

```sh
sudo apt install ./CodeNomad-Electron-linux-x64-<version>.deb
```

עבור AppImage של Tauri:

```sh
chmod +x CodeNomad-Tauri-linux-x64-<version>.AppImage
./CodeNomad-Tauri-linux-x64-<version>.AppImage
```

אם FUSE אינו זמין, השתמשו במצב החילוץ וההרצה של AppImage:

```sh
./CodeNomad-Tauri-linux-x64-<version>.AppImage --appimage-extract-and-run
```

התקנת Debian של Electron מגדירה את ארגז החול של Chromium. אל תשביתו את ארגז החול כפתרון לבעיית התקנה. לבעיות גרפיקה של Tauri ב־Linux יש [מעקף ממוקד ל־WebKit](troubleshooting.md#desktop-launch).

## דרישות {#requirements}

| דרישה | היכן עליה להיות זמינה | הדרישה הנוכחית |
| --- | --- | --- |
| OpenCode CLI | מארח ההרצה שנבחר, לרבות הפצת WSL שנבחרה כשמתאים | מינימום **2.1.0**; **2.1.1** היא הגרסה המומלצת/שנבדקה. גרסאות חדשות או מותאמות עוברות אימות חוזים ולא חסימה מפני שלא נבדקו. |
| Git | ב־`PATH` של חשבון שרת הקצה של CodeNomad | נדרש לזהות מאגר, לפעולות Git ול־worktrees. |
| Node.js/npm | מארח שרת עצמאי ובנייה מקוד מקור | Node.js 24 LTS; בניות שחזוריות מקוד מקור משתמשות ב־`.node-version` (**24.20.0**). כלול במשאבי הריצה/ההתקנה לשולחן העבודה. |
| תיקיית סביבת עבודה | דיסק נגיש לשרת הקצה | תיקייה פיזית שנפתחה במפורש, לא תיקייה מקומית למכשיר שהוסקה מדפדפן מרוחק. |

ב־Windows התקינו [Git for Windows](https://gitforwindows.org/) עם גישה משורת הפקודה/יישומי צד שלישי. די בהתקנה למשתמש יחיד בתיקייה שהמשתמש רשאי לכתוב בה. ב־macOS/Linux השתמשו ב־[הוראות Git לפלטפורמה](https://git-scm.com/downloads).

לאחר שינוי `PATH`, צאו לגמרי מיישום שולחן העבודה והפעילו אותו מחדש, או הפעילו מחדש את שרת הקצה העצמאי תחת החשבון הרצוי. טעינה מחדש של הדפדפן אינה מעדכנת את סביבת שרת הקצה. Git שזמין רק בתוך WSL אינו ממלא את דרישת Git של שרת קצה ב־Windows.

ללא Git עדיין אפשר לפתוח תיקייה פיזית ולהשתמש בשיחות מוגבלות לתיקייה, לרבות בקשת עזרה בהתקנה מהסוכן. פעולות מאגר/worktree נשארות לא זמינות; הגישה לסשנים מוגבלת לאותה תיקייה בדיוק. CodeNomad מודיע לסוכן על זמינות Git בשרת הקצה לפני שליחת קלט/פקודות מותאמות, ומסיר את ההודעה לאחר התאוששות. מארח ההרצה של הסוכן עשוי להיות שונה ממארח שרת הקצה, לכן התקינו Git עבור שרת הקצה, לא רק עבור מעטפת הסוכן.

## בחירת OpenCode בהפעלה הראשונה {#first-launch}

1. בהגדרה הראשונית, בחרו קובץ הרצה קיים ותואם או השתמשו בפעולת התקנת OpenCode המוצעת.
2. אמתו את מצב סביבת הריצה לפני פתיחת פרויקט.
3. חזרו אל **העדפות → OpenCode** כדי לנהל בנפרד את קובץ ההרצה, ההתקנה והשירות המשותף.

CodeNomad מעדיף קובצי הרצה תואמים ב־`PATH` ותומך בקובץ הרצה שנבחר במפורש. אם `PATH` מפעיל OpenCode ישן יותר, ההגדרה מציעה להחליף לאחר אישור OpenCode 1.x שהותקן באמצעות npm, או להתקין OpenCode 2 עבור CodeNomad לצד התקנה שבוצעה בדרך אחרת, שאותה היא לעולם אינה משנה; ראו [הגדרת OpenCode](opencode.md#select-cli). התקנה/עדכון של CLI אינם מפעילים מחדש בשקט שירות משותף שכבר פועל. ראו [הגדרת OpenCode](opencode.md) להשלכות הפעלה מחדש/טעינה מחדש, WSL וסביבת סשן.

## שימוש בדפדפן במקום זאת {#browser-install}

התקינו Node.js/npm, Git ו־OpenCode במארח השרת, ואז השתמשו ב־[נוהלי הפעלת השרת](server.md). התחברו בכתובת המודפסת, עם האימות המוגדר ותעודה מהימנה. דפדפן/PWA זקוק לשרת קצה פעיל; הוא אינו עותק לא מקוון של הפרויקטים.

ליציאות, האזנה ו־TLS ראו [גישה ישירה](remote-access.md). לצימוד מכשיר בלי לפתוח יציאות נכנסות, השתמשו ב־[שליטה מרחוק](remote-control.md). לפקודות פיתוח ואריזה ראו [בנייה מקוד מקור](support.md#build-from-source).
