# נייד ו־PWA

השתמשו בממשק הדפדפן בטלפון או בטאבלט כדי להמשיך לעבוד במארח שרת הקצה. התקנת PWA משנה את אופן פתיחת הממשק, לא את מיקום הפרויקטים, פרטי ההתחברות או הרצת הסוכן.

## חיבור מטלפון או מטאבלט {#connect}

השרתים השמורים זמינים דרך **עיון** בלשונית ריקה ודרך הגדרות → שרתים. [שחזור לשוניות מרוחקות](projects.md#restore-remote-tabs).

1. במארח, פתחו **הגדרות → גישה מרוחקת → שליטה מרחוק**, ואז בחרו **הפעל שליטה מרחוק**.
2. סרקו את קוד ה־QR לצימוד במכשיר הנייד ופתחו את הקישור בדפדפן שבו בכוונתכם להמשיך להשתמש.
3. לחלופין, הגדירו [גישה ישירה](remote-access.md), פתחו את כתובת ה־HTTPS המהימנה והנגישה של המארח, והתחברו באמצעות סיסמת השרת שלו.

שליטה מרחוק מחייבת צימוד מכשיר; חיבורים ישירים מחייבים ניתוב, מאזין נגיש ואימות. אל תשתמשו ב־`localhost` בטלפון כדי להגיע לתחנת העבודה. אובדן נתוני האתר או מעבר בין פרופילי דפדפן עשויים לחייב התחברות או צימוד מחדש; ראו [שליטה מרחוק](remote-control.md). כשהמנהרה חסומה, צמדו במקום זאת בכתובת HTTPS מהימנה; ראו [צימוד דרך HTTPS ישיר](remote-control.md#direct-https).

## התקנת ה־PWA {#install-pwa}

1. פתחו את כתובת CodeNomad הפעילה ב־HTTPS מהימן בדפדפן התומך בהתקנה.
2. ב־Chrome/Edge ובדפדפנים דומים, השתמשו בפעולת ההתקנה בשורת הכתובת או בפעולת **Install CodeNomad** של הדפדפן כשהיא מוצעת. ב־Safari ב־iPhone/iPad השתמשו ב־**Share → Add to Home Screen**; הניסוח המדויק תלוי במערכת ההפעלה/בדפדפן.
3. פתחו את המשגר החדש והשלימו בו התחברות או צימוד אם אחסון הדפדפן שלו נפרד.

ההתקנה היא לכל מכשיר/דפדפן ומקור אתר. היא אינה מתקינה Node, Git או OpenCode בטלפון, מפעילה שרת קצה או מעניקה שילובי שולחן עבודה מקוריים. הסרת המשגר אינה מוחקת שיחות במארח; בטלו בנפרד את גישת המכשיר המצומד בעת הסרת גישה.

### הקשר מאובטח ותעודות {#secure-context}

התקנת PWA מרחוק וגישה למיקרופון דורשות הקשר שהדפדפן מזהה כמאובטח. השתמשו בתעודת HTTPS מהימנה התואמת בדיוק לשם המארח/לכתובת ה־IP. מכשיר/דפדפן הלקוח חייב לתת אמון מפורש בתעודה מקומית שנוצרה; דף אזהרה או עקיפתו אינם בסיס אמין להתקנה. חריגי localhost בדפדפן חלים על אותו מכשיר, לא על כתובת HTTP ברשת המקומית של מארח אחר.

אל תשביתו אימות או בדיקת TLS כדי לתקן התקנה.

## עבודה בפריסת מגע {#touch-layout}

השתמשו בפקדי **חלונית שמאלית** ו־**חלונית ימנית** לפתיחת ניווט וכלים. בפריסה צרה, הלוחות מוצגים מעל השיחה במקום לכפות משטח ברוחב שולחן עבודה; פתיחת לוח צף אחד סוגרת את האחר. בחירת סשן בלוח הסשנים הצף סוגרת אותו כדי להציג את בחירתכם, גם את הסשן שכבר מוצג; **אחורה** ו־**קדימה** משאירים אותו פתוח. פעולות כותרת השיחה עוברות לתפריט הנוסף שלה כשהמקום מוגבל.

שדה הקלט משאיר את הסוכן, המודל והחשיבה בשורה התחתונה שלו. גובה השדה נקבע ביחס לגובה השיחה בלי המקלדת שעל המסך. כשהמקלדת נפתחת, שדה הקלט עשוי להצטמצם זמנית כדי להשאיר מקום לפקדים ולהודעות, בלי לשנות את יחס הגובה שנשמר. עדיין אפשר לגלול בטיוטות ארוכות. במכשירי מגע בלבד, שליחה אינה פותחת מחדש את המקלדת שעל המסך, כך שתוכלו לקרוא את התשובה; הקישו על שדה הקלט כדי להמשיך. בזמן שסשן רץ, תפריט **פעולות נוספות** של שדה הקלט מציע **הוסף הודעה לתור** או **הזרק עכשיו**, את מה שהשליחה הרגילה שלכם אינה עושה, בלי צורך בקיצור של מקלדת פיזית. פתיחת בקשה מצמצמת זמנית את הקלט בלי לשנות את הגובה השמור או את הטיוטה. ענו לאישורים/שאלות באזור שמעליו, ושמרו את שורת הפעולות התחתונה נגישה. ראו [שיחות](conversations.md) ו־[אישורים](permissions.md).

## מגבלות יכולת וקישוריות {#limits}

| יכולת | דפדפן נייד / PWA |
| --- | --- |
| פרויקטים, שיחות, קבצים ואישורים | פועלים במארח שרת הקצה המחובר, בכפוף לבקרות הגישה שלו. קבצים מצורפים מהמכשיר מועלים מהטלפון; הפניות לפרויקט נפתרות במארח. |
| חלונות שולחן עבודה מקוריים, תפריטי מערכת הפעלה ואוטומציה מקורית במארח | אינם ניתנים באמצעות התקנת PWA. |
| תצוגת דפדפן | אינה מקבלת יכולות של דפדפן אורח מקורי; תצוגת הגיבוי נשארת מוגבלת ליכולות הדפדפן. |
| תוכן SideCar ו־WebSockets | תלויים בנתיב החיבור; שליטה מרחוק חוסמת את מתווך תוכן ה־SideCar ומגישה תצוגות מקדימות של אתרים, כולל ה־WebSockets שלהן, כל עוד המארח מתיר זאת. ראו את [המגבלות המדויקות](remote-control.md). |
| מיקרופון, לוח, התראות ובקשת התקנה | תלויים בתמיכת הדפדפן/מערכת ההפעלה, בהקשר מאובטח ובהרשאות המשתמש. |
| עבודה לא מקוונת | אין שרת קצה לא מקוון או היסטוריית API במטמון. נכסי ממשק סטטיים עשויים להישמר במטמון, אך מסמכים ותשובות API אינם סביבת עבודה לא מקוונת. |

שמרו על נגישות שרת הקצה. בדקו אם פעולה הושלמה לפני ניסיון חוזר. סגירת PWA אינה עוצרת שרת קצה עצמאי; יציאה מיישום שולחן העבודה במארח ומשרת הקצה שלו הופכת את השליטה מרחוק ללא זמינה עד ההפעלה הבאה.

כל לשונית דפדפן, כולל ה-PWA המותקנת, שומרת עבור אותה לשונית את הפרויקטים הפתוחים, השיחות שנבחרו, הטיוטות שלא נשלחו ומיקומי הגלילה: הם חוזרים כשהדף נטען מחדש, או כשמערכת ההפעלה בנייד טוענת אותו מחדש אחרי מעבר בין יישומים או נעילת מסך. לשונית חדשה, או PWA שמערכת ההפעלה סגרה לגמרי, מציגה לשונית ריקה. כבו זאת עבור הלשונית ב־**הגדרות → כללי → שחזור המצב הקודם**.
