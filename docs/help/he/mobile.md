# נייד ו־PWA

השתמשו בממשק הדפדפן בטלפון או בטאבלט כדי להמשיך לעבוד במארח שרת הקצה. התקנת PWA משנה את אופן פתיחת הממשק, לא את מיקום הפרויקטים, פרטי ההתחברות או הרצת הסוכן.

## חיבור מטלפון או מטאבלט {#connect}

1. במארח, פתחו **הגדרות → גישה מרוחקת → שליטה מרחוק**, ואז בחרו **הפעל שליטה מרחוק**.
2. סרקו את קוד ה־QR לצימוד במכשיר הנייד ופתחו את הקישור בדפדפן שבו בכוונתכם להמשיך להשתמש.
3. לחלופין, הגדירו [גישה ישירה](remote-access.md), פתחו את כתובת ה־HTTPS המהימנה והנגישה של המארח, והתחברו באמצעות סיסמת השרת שלו.

שליטה מרחוק מחייבת צימוד מכשיר; חיבורים ישירים מחייבים ניתוב, מאזין נגיש ואימות. אל תשתמשו ב־`localhost` בטלפון כדי להגיע לתחנת העבודה. אובדן נתוני האתר או מעבר בין פרופילי דפדפן עשויים לחייב התחברות או צימוד מחדש; ראו [שליטה מרחוק](remote-control.md).

## התקנת ה־PWA {#install-pwa}

1. פתחו את כתובת CodeNomad הפעילה ב־HTTPS מהימן בדפדפן התומך בהתקנה.
2. ב־Chrome/Edge ובדפדפנים דומים, השתמשו בפעולת ההתקנה בשורת הכתובת או בפעולת **Install CodeNomad** של הדפדפן כשהיא מוצעת. ב־Safari ב־iPhone/iPad השתמשו ב־**Share → Add to Home Screen**; הניסוח המדויק תלוי במערכת ההפעלה/בדפדפן.
3. פתחו את המשגר החדש והשלימו בו התחברות או צימוד אם אחסון הדפדפן שלו נפרד.

ההתקנה היא לכל מכשיר/דפדפן ומקור אתר. היא אינה מתקינה Node, Git או OpenCode בטלפון, מפעילה שרת קצה או מעניקה שילובי שולחן עבודה מקוריים. הסרת המשגר אינה מוחקת שיחות במארח; בטלו בנפרד את גישת המכשיר המצומד בעת הסרת גישה.

### הקשר מאובטח ותעודות {#secure-context}

התקנת PWA מרחוק וגישה למיקרופון דורשות הקשר שהדפדפן מזהה כמאובטח. השתמשו בתעודת HTTPS מהימנה התואמת בדיוק לשם המארח/לכתובת ה־IP. מכשיר/דפדפן הלקוח חייב לתת אמון מפורש בתעודה מקומית שנוצרה; דף אזהרה או עקיפתו אינם בסיס אמין להתקנה. חריגי localhost בדפדפן חלים על אותו מכשיר, לא על כתובת HTTP ברשת המקומית של מארח אחר.

אם אפשרות ההתקנה חסרה, ודאו תחילה אמון ב־HTTPS ותמיכת דפדפן, ואז פתחו מחדש את הדף בדפדפן המלא ולא בדפדפן QR/דפדפן בתוך יישום. לתקלות מיקרופון בדקו הרשאות אתר בדפדפן/במערכת ההפעלה ו־[קול](voice.md). אל תשביתו אימות או בדיקת TLS כדי לתקן התקנה.

## עבודה בפריסת מגע {#touch-layout}

השתמשו בפקדי **חלונית שמאלית** ו־**חלונית ימנית** לפתיחת ניווט וכלים. בפריסה צרה, הלוחות מוצגים מעל השיחה במקום לכפות משטח ברוחב שולחן עבודה; פתיחת לוח צף אחד סוגרת את האחר. פעולות כותרת השיחה עוברות לתפריט הנוסף שלה כשהמקום מוגבל.

שדה הקלט משאיר את הסוכן, המודל והחשיבה בשורה התחתונה שלו. גודל השדה משתנה עם השיחה הנראית, לרבות המקלדת שעל המסך; טיוטות ארוכות נשארות נגללות. פתיחת בקשה מצמצמת זמנית את הקלט בלי לשנות את הגובה השמור או את הטיוטה. ענו לאישורים/שאלות באזור שמעליו, ושמרו את שורת הפעולות התחתונה נגישה. ראו [שיחות](conversations.md) ו־[אישורים](permissions.md).

## מגבלות יכולת וקישוריות {#limits}

| יכולת | דפדפן נייד / PWA |
| --- | --- |
| פרויקטים, שיחות, קבצים ואישורים | פועלים במארח שרת הקצה המחובר, בכפוף לבקרות הגישה שלו. קבצים מצורפים מהמכשיר מועלים מהטלפון; הפניות לפרויקט נפתרות במארח. |
| חלונות שולחן עבודה מקוריים, תפריטי מערכת הפעלה ואוטומציה מקורית במארח | אינם ניתנים באמצעות התקנת PWA. |
| תצוגת דפדפן | אינה מקבלת יכולות של דפדפן אורח מקורי; תצוגת הגיבוי נשארת מוגבלת ליכולות הדפדפן. |
| תוכן SideCar ו־WebSockets | תלויים בנתיב החיבור; שליטה מרחוק חוסמת את מתווך תוכן ה־SideCar, תוכן התצוגה המקדימה ושדרוגי WebSocket. ראו את [המגבלות המדויקות](remote-control.md). |
| מיקרופון, לוח, התראות ובקשת התקנה | תלויים בתמיכת הדפדפן/מערכת ההפעלה, בהקשר מאובטח ובהרשאות המשתמש. |
| עבודה לא מקוונת | אין שרת קצה לא מקוון או היסטוריית API במטמון. נכסי ממשק סטטיים עשויים להישמר במטמון, אך מסמכים ותשובות API אינם סביבת עבודה לא מקוונת. |

שמרו על נגישות שרת הקצה. השהיה בידי מערכת ההפעלה הניידת או החלפת רשת עשויות לנתק את זרם האירועים; החזרה מחברת מחדש וקוראת את המצב הנוכחי, ללא הבטחת שחזור אירועים. בדקו אם פעולה הושלמה לפני ניסיון חוזר. סגירת PWA אינה עוצרת שרת קצה עצמאי; יציאה מיישום שולחן העבודה במארח ומשרת הקצה שלו הופכת את השליטה מרחוק ללא זמינה עד ההפעלה הבאה.
