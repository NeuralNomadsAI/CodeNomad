# עזרה ל־CodeNomad

מדריך זה מסביר כיצד להשתמש בסביבת העבודה הנוכחית של CodeNomad בשולחן העבודה או בדפדפן עם שירות OpenCode שלכם. הוא מתמקד בפקדים, בגבולות ההרצה ובהתאוששות של CodeNomad — לא בהדרכות להגדרת OpenCode או בארכיון גרסאות.

## קראו תחילה {#read-this-first}

CodeNomad מחבר את סביבת העבודה לשירות רקע משותף אחד של OpenCode. הסשנים וההודעות שייכים ל־OpenCode; הלשוניות, טיוטות הקלט והפריסה שייכים ללקוח CodeNomad. סגירת לשונית סוגרת את הפרויקט ב־CodeNomad, אך הסשנים ממשיכים ב־OpenCode ונמצאים שוב בפתיחת הפרויקט מחדש. סגירת CodeNomad אינה עצירת OpenCode.

1. בדקו את [דרישות המארח](install.md#requirements) ואת [הגדרת OpenCode](opencode.md).
2. [פתחו פרויקט](projects.md), ואז בחרו בפקדי הסוכן, המודל והחשיבה של השיחה.
3. בדקו את היקף ההשפעה לפני שינוי פרטי התחברות, הפעלה מחדש של שירות או מחיקת היסטוריה. לקוחות אחרים עשויים להשתמש באותו שירות מקורי.

אתר העזרה הציבורי פועל ללא CodeNomad, שרת הקצה שלו או התחברות. **עזרה → עזרה של CodeNomad** בשולחן העבודה ו־**פתיחת עזרה** בלוח הפקודות פותחים אותו בנפרד בשפת הממשק הנוכחית. שינוי שפה אינו מתרגם שיחות שמורות.

**הגדרות** פותח את חלון **העדפות** המקורי בלקוח מקומי לשולחן העבודה; לקוחות דפדפן ולקוחות מרוחקים משתמשים בהגדרות מוטמעות. נתיבים כגון **הגדרות → ספקים** מציינים אותו סעיף הגדרות בשני הממשקים.

לסביבת עבודה עצמאית בדפדפן על מארח מוכן, [מדריך השרת](server.md) מסביר את ההפעלה הבאה ואת דרישות האימות ו־TLS שלה:

```sh
npx @neuralnomads/codenomad --generate-token --launch
```

למגבלות המדויקות ראו [תצוגות דפדפן ו־SideCars](browser-sidecars.md), [שליטה מרחוק](remote-control.md) ו־[נייד/PWA](mobile.md). חלון מרוחק אינו הופך את מערכת הקבצים של המכשיר לסביבת העבודה של השרת.

## למי שייך המצב {#state-and-scope}

| מונח | משמעות ב־CodeNomad |
| --- | --- |
| לשונית פרויקט / סביבת עבודה / מופע | חיבור CodeNomad לתיקייה שנפתחה במפורש; מספר לשוניות יכולות להשתמש בשירות המשותף. |
| שיחה / סשן | היסטוריה והרצה מקוריות של OpenCode המשויכות לתיקייה שלהן. |
| משפחה | שיחה ותת־הסשנים שלה בכל העומקים; רלוונטית להעברות, לפעילות, ל־Yolo ולפקדי משימות. |
| Worktree | עותק עבודה של מאגר בבעלות הסביבה, שנבחר לעיון או למיקום סשן. עיון בו אינו מעביר שיחה. |
| Location | הקשר זמן הריצה המקורי של OpenCode ברמת תיקייה; סגירת לשונית פרויקט אינה פורקת אותו או עוצרת את הסשנים שלו. |
| שרת הקצה של CodeNomad | השרת המספק פקדי סביבת עבודה, Git, אימות וחיבור לקוחות. החשבון והסביבה שלו קובעים את גישתו למערכת הקבצים. |
| תצורה | הגדרות CodeNomad בתיקיית התצורה של השרת; להגדרות OpenCode כלליות/של פרויקט יש היקף מקורי משלהן. |
| חלון | לשוניות, ניווט, טיוטות ותצוגה משוחזרת משלו. ההיסטוריה המקורית משותפת ואינה מועתקת לכל חלון. |
| פרופיל נתונים לשולחן העבודה | אחסון מקורי/לקוח שנבחר בהגדרות; אינו מבודד אוטומטית סשנים של OpenCode או כל תצורה משותפת. |

שורש סביבת העבודה מגביל אילו תיקיות CodeNomad פותח; הוא אינו ארגז חול לסוכן. עיינו ב־[אבטחה](security.md) לפני חשיפת מארח או מתן גישה רחבה לכלים.

## ניטור עבודה בלי לשנותה {#monitor-work}

לוח הסטטוס מציג את השימוש אצל הספק ואת מעטפות הרקע המקוריות של הסשן הפעיל. מצב השיחה ופעילות הצאצאים מזהים סשנים שעובדים, מסכמים או ממתינים לקלט. ניטור מעטפת רקע שונה משליחת בקשת מעטפת משדה הקלט או משימוש ב־SideCar של מסוף המתארח בנפרד.

1. פתחו **סטטוס → מעטפות רקע** עבור ה־Location של השיחה שנבחרה (או סביבת העבודה הפתוחה כשלא נבחרה שיחה).
2. בדקו את הפקודה, המעטפת, התיקייה, המצב, ה־PID וקוד היציאה כשהם מוצגים; בחרו **הצגת פלט** לפלט המקורי הזמין.
3. לסילוק מעטפת, השתמשו ב־**עצור והסר** בזמן פעולתה או ב־**הסר** לאחר יציאה, ואשרו את היעד.

הסרת מעטפת פועלת עוצרת את התהליך; סגירת חלון הפלט אינה עוצרת אותו. רענון/חיבור מחדש קוראים את המצב המקורי הנוכחי במקום לשחזר אירועי פלט שהוחמצו.

תמונות מצב של התצוגה מתרעננות לאחר שינויים מקוריים, חיבור מחדש ודרישת תצוגה. הן אינן יומנים המבטיחים שחזור אירועים. אם תוצאה אינה ודאית, רעננו את המצב המוסמך לפני ניסיון חוזר לשינוי; אל תשלחו שוב רק מפני שהתראה או אירוע הוחמצו.
