# שרת עצמאי

הריצו את CodeNomad במקום שבו נמצאים הפרויקטים והכלים, ואז השתמשו בממשק הדפדפן שלו מקומית או מרחוק. שרת הקצה מספק גישה למערכת הקבצים, פעולות Git, אימות ומסירת אירועים. השירות המשותף של OpenCode הוא הבעלים של השיחות וההרצה; הוא אינו שרת־בן שיש לעצור כשהדפדפן מתנתק.

אותו ממשק תומך ב־[מספר לשוניות פרויקט ו־worktrees](projects.md), ב־[משפחות שיחה ופעילות רקע](conversations.md), ב־[טעינת היסטוריה תחומה, חיפוש וניווט בציר הזמן](history.md), וב־[לוח פקודות וקיצורים](shortcuts.md). גישה מדפדפן ומטאבלט אינה מעבירה את ההרצה מהמארח.

## הכנת המארח {#prerequisites}

1. התקינו Node.js 24 LTS ו־npm; סביבת הבנייה המקובעת במאגר היא 24.20.0. חבילות שולחן העבודה כוללות Node/npm.
2. הוסיפו Git ל־**PATH של תהליך שרת הקצה**. Git בתוך WSL בלבד אינו מספיק לשרת קצה ב־Windows.
3. התקינו או בחרו OpenCode: המינימום הנדרש הוא **2.1.2**, ו־**2.1.2** היא הגרסה המומלצת לבדיקה. בניות חדשות או מותאמות עוברות בדיקות תאימות, לא רשימת היתר של גרסאות שנבדקו. ראו [הגדרת OpenCode](opencode.md).
4. בחרו את התיקייה שממנה תפעילו את השרת, או העבירו `--workspace-root` במפורש.

ללא Git, שיחות נשארות זמינות רק בתיקייה הפיזית שנפתחה במפורש; פעולות Git ו־worktree נכשלות. התקינו Git והפעילו מחדש את שרת הקצה לאחר שינוי PATH. שורש סביבת עבודה מגביל פתיחה/עיון, לא הרצת סוכן: ראו [אבטחה](security.md).

## הרצה או התקנה {#run}

בחרו שיטת התקנה אחת. דוגמאות הפעלה ראשונה אלה משתמשות באתחול מקומי במקום להכניס סיסמה להיסטוריית המעטפת:

### הרצה עם npx {#npx}

```sh
npx @neuralnomads/codenomad --generate-token --launch
```

### התקנה גלובלית {#global-install}

```sh
npm install -g @neuralnomads/codenomad
codenomad --generate-token --launch
```

### התקנה בפרויקט {#local-install}

```sh
npm install @neuralnomads/codenomad
npx codenomad --generate-token --launch
```

`npx codenomad` משתמש בקובץ ההרצה המותקן בפרויקט כשיש כזה. פעולה זו מתקינה את החבילה בפרויקט; היא **אינה** הופכת את התצורה או את אחסון OpenCode למקומיים לפרויקט.

1. פתחו במארח את **Local Connection URL** המודפס. השלימו [אתחול מקומי](security.md), ואז שמרו סיסמת שרת קבועה. הנוהל כולל אפשרות הגדרת HTTP ל־loopback בלבד אם עדיין לא הגדרתם אמון ב־HTTPS.
2. בהפעלות הבאות השמיטו `--generate-token`; לחלופין, ספקו `CODENOMAD_SERVER_PASSWORD` בכל הפעלה.
3. השתמשו ב־`codenomad --help` לעיון באפשרויות ה־CLI המותקן.

הפקודות פועלות בחזית. סגירת המסוף או שליחת Ctrl+C עוצרות את שרת הקצה הזה ואת חיבור השליטה מרחוק שלו. `--launch` רק פותח דפדפן; הוא אינו הופך את השרת לדמון. לזמינות ללא השגחה, הריצו אותה פקודה במנהל תהליכים/שירותים של מערכת ההפעלה עם תצורה, תיקיית עבודה, סביבה ומדיניות הפעלה מחדש מפורשות. אל תכניסו סודות ליומני שירות או לקובץ יחידת שירות ציבורי.

סגירת דפדפן אינה עוצרת שרת קצה עצמאי הפועל בנפרד. סגירת לשונית פרויקט סוגרת את הפרויקט ב־CodeNomad ומפסיקה את המעקב אחריו; הסשנים ממשיכים ב־OpenCode ונמצאים שוב בפתיחת הפרויקט מחדש. ה־Location אינו נפרק. גם כיבוי שרת הקצה משאיר את שירות OpenCode פועל. תכונות התלויות בשרת הקצה אינן זמינות עד חזרת CodeNomad; ראו [משימות](missions.md) למשך החיים הנפרד של תזמון מקורי.

## כתובות ויציאות {#addresses}

בהפעלה מודפסים **Local Connection URL**, ו־**Remote Connection URL** כשזמין, וכן **Other Accessible URLs** כשמתאים. השתמשו בסכמה וביציאה המודפסות, לא בכתובת מנוחשת. כתובת loopback נגישה רק באותו מחשב; כתובת LAN מודפסת עדיין דורשת ניתוב וגישה דרך חומת האש.

HTTPS מעדיף את יציאה **9898** ו־HTTP את **9899**. ללא דריסת יציאה, אם היציאה המועדפת תפוסה נבחרת יציאה שמערכת ההפעלה מקצה. יציאה מפורשת שאינה אפס אינה עוברת לחלופה; `0` מבקש יציאה בהקצאת מערכת ההפעלה. יציאות מקבלות מספרים שלמים מ־0 עד 65535.

לחשיפת מאזין, תעודות, VPN/SSH ומתווכים הפוכים, ראו [גישה ישירה מרחוק](remote-access.md). לגישה ללא יציאה נכנסת, השתמשו ב־[שליטה מרחוק](remote-control.md).

## מדריך CLI ציבורי {#cli-reference}

דגלים גוברים על משתני הסביבה המקבילים. דגלים המקבלים ערך משתמשים בארגומנט המוצג; מתגים אינם מקבלים ערך. ערכי HTTPS/HTTP מזהים `1`, `true`, `yes`, `y` ו־`on` כמופעלים, ללא תלות ברישיות; השתמשו ב־`true`/`false` מפורשים לבהירות. עדכון ממשק אוטומטי מזהה `1`, `true` ו־`yes`.

**משתני סביבה בוליאניים מחמירים** (`CLI_UNRESTRICTED_ROOT`, `CLI_UI_NO_UPDATE`, `CLI_LAUNCH`, `CODENOMAD_GENERATE_TOKEN` ו־`CODENOMAD_SKIP_AUTH`) מפעילים את המתגים שלהם עם `1`,‏ `true`,‏ `yes` או `on`, ללא תלות ברישיות ובהתעלמות מרווחים בתחילת הערך ובסופו. `0`,‏ `false`,‏ `no`,‏ `off`, ערכים ריקים או המכילים רק רווחים ומשתנים שאינם מוגדרים משאירים את המתגים כבויים. כל ערך אחר מונע את הפעלת השרת, גם עם דגל ה־CLI המתאים. דגל CLI מפעיל את המתג גם מול ערך כיבוי תקין; אחרת חלות ברירות המחדל `false` שלהלן.

| דגל | סביבה | ברירת מחדל והשפעה |
| --- | --- | --- |
| `-h, --help` | — | הדפסת עזרה ויציאה. |
| `-v, --version` | — | הדפסת גרסת החבילה המותקנת ויציאה. |
| `--host <host>` | `CLI_HOST` | `127.0.0.1`; `localhost` מנורמל ל־loopback של IPv4. מזהי אזור IPv6 נדחים. ראו [טבלת האזנה](remote-access.md). |
| `--https <enabled>` | `CLI_HTTPS` | `true`; מאזין HTTPS. |
| `--http <enabled>` | `CLI_HTTP` | `false`; מאזין HTTP. חייב להיות לפחות מאזין פעיל אחד. |
| `--https-port <number>` | `CLI_HTTPS_PORT` | `9898` מועדפת; `0` אוטומטית. |
| `--http-port <number>` | `CLI_HTTP_PORT` | `9899` מועדפת; `0` אוטומטית. |
| `--tls-key <path>` | `CLI_TLS_KEY` | לא מוגדר; מפתח PEM פרטי, דורש `--tls-cert`. |
| `--tls-cert <path>` | `CLI_TLS_CERT` | לא מוגדר; תעודת PEM, דורשת `--tls-key`. |
| `--tls-ca <path>` | `CLI_TLS_CA` | לא מוגדר; שרשרת CA ב־PEM אופציונלית לתעודות שסופקו. |
| `--tlsSANs <list>` | `CLI_TLS_SANS` | לא מוגדר; שמות DNS/כתובות IP נוספים, מופרדים בפסיקים, לתעודות שנוצרות. |
| `--workspace-root <path>` | `CLI_WORKSPACE_ROOT` | תיקיית העבודה של התהליך; שורש לפתיחת סביבות עבודה. |
| `--unrestricted-root` | `CLI_UNRESTRICTED_ROOT` | `false`; מאפשר עיון בכל מערכת הקבצים. אינו הגדרת ארגז חול לסוכן. |
| `--config <path>` | `CLI_CONFIG` | ברירת מחדל פעילה פתורה: `~/.config/codenomad/config.yaml`. מקבל תיקייה או קובץ YAML למיקום מפורש. |
| `--log-level <level>` | `CLI_LOG_LEVEL` | `info`; רמות מתועדות: `trace`, `debug`, `info`, `warn`, `error`. |
| `--log-destination <path>` | `CLI_LOG_DESTINATION` | `stdout`; אחרת כותב לקובץ שנבחר. |
| `--username <username>` | `CODENOMAD_SERVER_USERNAME` | `codenomad`; שם משתמש לאימות בזמן ריצה. קובץ אימות שמור שומר את שם המשתמש שלו כשאין סיסמת זמן ריצה שדורסת אותו. |
| `--password <password>` | `CODENOMAD_SERVER_PASSWORD` | לא מוגדר; סיסמה לזמן ריצה בלבד, גוברת על קובץ האימות המנוהל. |
| `--auth-cookie-name <name>` | `CODENOMAD_AUTH_COOKIE_NAME` | `codenomad_session`; תווים שאינם אותיות, ספרות, `_` ו־`-` הופכים ל־`_`. |
| `--generate-token` | `CODENOMAD_GENERATE_TOKEN` | `false`; מדפיס אסימון אתחול מקומי לשימוש יחיד, ל־60 שניות. |
| `--dangerously-skip-auth` | `CODENOMAD_SKIP_AUTH` | `false`; משבית אימות במאזין הישיר. מסוכן: ראו [אבטחה](security.md). שליטה מרחוק עדיין דורשת צימוד מכשיר. |
| `--ui-dir <path>` | `CLI_UI_DIR` | תיקיית `public` של החבילה; דריסה מפורשת מגישה את הממשק הזה במקום פתרון ממשק מרוחק. |
| `--ui-dev-server <url>` | `CLI_UI_DEV_SERVER` | לא מוגדר; מתווך ממשק דרך מאזין HTTP. לפיתוח, השתמשו ב־`--https=false --http=true`; מאזין HTTPS אינו מתווך את ממשק הפיתוח. |
| `--ui-no-update` | `CLI_UI_NO_UPDATE` | `false`; גובר על עדכון אוטומטי ומשתמש בממשק זמין מהמטמון/מהחבילה. |
| `--ui-auto-update <enabled>` | `CLI_UI_AUTO_UPDATE` | `true`; בודק ממשק מרוחק תואם בהפעלה. |
| `--ui-manifest-url <url>` | `CLI_UI_MANIFEST_URL` | `https://ui.codenomad.neuralnomads.ai/version.json`; מניפסט ממשק מרוחק. |
| `--launch` | `CLI_LAUNCH` | `false`; פותח את הממשק המקומי בדפדפן לאחר ההפעלה. |
| `--upgrade [version]` | — | אין שדרוג כברירת מחדל. כשמתבקש, מתקין גלובלית `@neuralnomads/codenomad@latest`, או את הגרסה שסופקה, ויוצא. |

המדריך הציבורי מפרט אפשרויות למשתמש; מארחי שולחן העבודה מנהלים בעצמם את תיאום ההפעלה הפרטי שלהם.

### משתני פריסה נוספים {#deployment-environment}

| משתנה | ברירת מחדל והיקף |
| --- | --- |
| `CODENOMAD_GITHUB_REPO` | `NeuralNomadsAI/CodeNomad`; המאגר שנשאל לגבי הצעות גרסאות. |
| `CODENOMAD_REMOTE_CONTROL_API` | לא מוגדר: API של OpenTunnel המתארח בשירות. הגדירו מקור API לפריסת ממסר באירוח עצמי. |
| `NODE_EXTRA_CA_CERTS` | קובץ CA נוסף אופציונלי של Node; מועבר עם סביבת ההפעלה המותרת כשמפעילים דמון OpenCode חסר. אינו משנה דמון שכבר פועל. |

פרטי התחברות לשימוש אצל ספקים מכוסים ב־[ספקים](providers.md). בחירת פרופיל נתונים לשולחן העבודה מכוסה ב־[שולחן עבודה](desktop.md), ואינה נשלטת בידי ערוץ העדכונים.

## בעלות על תצורה ואחסון {#storage}

נתיבי ברירת המחדל להלן משתמשים בתיקיית הבית של משתמש שרת הקצה. תיקיית `--config` מפורשת משנה את בסיס התצורה; שם קובץ YAML בוחר אותו עם מצב/אחסון לצדו. השתמשו בזהות תצורה מכוונת אחת לפריסה והגנו על כל התיקייה בהרשאות מערכת ההפעלה.

| בעלים/נתונים | מיקום ברירת מחדל או כלל |
| --- | --- |
| העדפות CodeNomad קבועות | `~/.config/codenomad/config.yaml` |
| מצב CodeNomad משתנה | `~/.config/codenomad/state.yaml` |
| מטא־נתוני מופעי CodeNomad | `~/.config/codenomad/instances/` |
| גיבוב סיסמה | `auth.json` לצד תצורת YAML הפעילה; מנוהל בידי היישום. |
| תעודות TLS ומפתחות פרטיים שנוצרו | `tls/` תחת בסיס התצורה. |
| נתיב שליטה מרחוק, בחירת הפעלה וגיבובי מכשירים | `remote-control-devices.json` תחת בסיס התצורה. |
| מרשם ותיקיות של סביבות עבודה זמניות | `temporary-workspaces.json` ו־`temporary-workspaces/` תחת אותו בסיס. |
| הרחבות לוח מותקנות וקבלות הרשאה | `panel-extensions/` ו־`permission-receipts/` תחת אותו בסיס. |
| מטמון ממשק שהורד | `~/.config/codenomad/ui/`; פותר הממשק של ה־CLI משתמש במטמון זה בתיקיית הבית גם עם `--config` מותאם. |
| שיחות OpenCode, הודעות, רישום שירות וחיבורי ספקים | האחסון הגלובלי של OpenCode עצמו במארח ההרצה, לא תיקיית מופע CodeNomad. |
| מצב שחזור שולחן עבודה | ברירת מחדל `~/.codenomad/client-state/v2/`; ראו [שולחן עבודה](desktop.md) להיקף פרופיל/חלון. |

CodeNomad מתחבר לדמון המשותף הקיים או מפעיל אותו אם חסר. סביבת ההפעלה משפיעה רק על דמון שזה עתה הופעל. בנפרד, סביבת הסשן המלאה המוגדרת מוחלת לפני כל קלט, פקודה מותאמת או בקשת מעטפת של סשן, לא כשמציגים או עורכים העדפות בלבד. ראו [הגדרת OpenCode](opencode.md).

## אירועים וחיבורים מחדש {#events}

שרת הקצה צורך זרם אירועי OpenCode מקורי משותף ומנתב אירועי סביבת עבודה ו־CodeNomad ללקוחות דפדפן באמצעות Server-Sent Events. המסירה חיה וארעית: **אין הבטחה לשחזור אירועים**.

לאחר חיבור מחדש, הממשק קורא מחדש מצב סשנים ובקשות ממתינות ממקור מוסמך; גם ביטולי תוקף של קבצים/תצורה מפעילים קריאות חדשות. חיבור מחדש אינו היתר לחזור על שליחה, מחיקה, תשובה או שינוי אחר שתשובתו אבדה. בדקו תחילה את המצב שנוצר. בקשות ממתינות ידועות וטיוטות נשמרות כשההתאוששות חלקית; ראו [אישורים](permissions.md) ו־[פתרון בעיות](troubleshooting.md).

## חבילות תצוגה מקדימה ותחזוקה {#maintenance}

לניסיון מפורש של חבילת CLI לתצוגה מקדימה:

```sh
npx @neuralnomads/codenomad-dev --generate-token --launch
```

השתמשו בתצורה נפרדת במכוון אם דרושות הגדרות CodeNomad מבודדות; בחירת חבילה אינה מבודדת אחסון OpenCode משותף. **הגדרות → מידע → עדכונים → ערוץ עדכונים** שולט בגרסאות המוצעות, לא בזהות נתוני שרת הקצה או בחבילה המותקנת.

`codenomad --upgrade` מעדכן את חבילת ה־CLI היציבה הגלובלית באמצעות מנהל npm/pnpm/bun שזוהה (npm אם לא זוהה מנהל). הוא אינו מפעיל מחדש שרת פועל ואינו מעדכן OpenCode. להתקנה מקומית לפרויקט או לתצוגה מקדימה, עדכנו במפורש את אותה חבילת npm מדויקת. הפעילו מחדש במכוון את תהליך CodeNomad המנוהל לאחר עדכון; בדקו שוב את כתובותיו המודפסות.

ראו [עדכונים](updates.md) לתחזוקת שולחן העבודה, [תמיכה](support.md) לפקודות בנייה מקוד מקור, ו־[ספקים](providers.md) לשימוש בתוכניות ספקים.
