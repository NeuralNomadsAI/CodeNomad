# קיצורי מקלדת

## גילוי פקודות ופתיחת עזרה {#discover-commands}

1. פתחו **לוח פקודות** עם `Ctrl+Shift+P` ב־Windows/Linux או `Cmd+Shift+P` ב־macOS, או השתמשו בכפתור/פריט התפריט הגלוי שלו.
2. הקלידו שם פעולה. הלוח כולל פעולות יישום ופקודות מותאמות של ה־Location הנוכחי; הזמינות תלויה בתצוגה הפעילה.
3. הפעילו **פתיחת עזרה** לפתיחת מדריך זה בשפת הממשק הנוכחית בהקשר דפדפן חיצוני. התפריט המקורי **עזרה → עזרה של CodeNomad** פותח אותו מדריך.

העזרה משאירה את תצוגת היישום והטיוטה ללא שינוי. אם הפתיחה נכשלת, בקרו ישירות ב־[עזרת CodeNomad](https://neuralnomadsai.github.io/CodeNomad/). היכולת למצוא פקודה אינה אומרת שיש לה קיצור שניתן להתאמה: מנהל הקיצורים מכסה קטלוג קבוע של 49 פקודות בתהליך התצוגה, לא כל פעולת לוח או תפריט מקורי.

## הקלטה, השבתה ואיפוס {#customize}

1. פתחו **הגדרות → קיצורי מקלדת** והשתמשו ב־**סינון קיצורים** לאיתור הפעולה.
2. בחרו **עריכה**, ואז לחצו על הצירוף הרצוי ב־**לחצו על צירוף מקשים**. ההקלטה שומרת את השיוך.
3. השתמשו ב־**השבתה** להסרת השיוך של הפעולה בתהליך התצוגה, ב־**איפוס** לשחזור ברירת המחדל, או ב־**איפוס הכול** לכל השיוכים בתהליך התצוגה.
4. פתרו אזהרות בכל שורה עם התנגשות; התנגשויות מדווחות ואינן מושבתות בשקט.

שיוכים נשמרים בתצורת ממשק CodeNomad ומשפיעים על לקוחות החולקים אותה. הם אינם עורכים שיוכי CLI/TUI של OpenCode או קיצורי תפריטים מקוריים. ההקלטה מדכאת קיצורי תהליך תצוגה של היישום, אך אינה יכולה לדכא את מערכת ההפעלה או התפריט המקורי. **ביטול**, אובדן מיקוד, סגירת הסעיף או יציאה מהחלון מסיימים הקלטה. מקשי שינוי לבדם והרכבת IME אינם נחשבים; Tab/Shift+Tab רגילים מעבירים מיקוד.

אם השמירה נכשלת, השאירו את הקיצור הקודם זמין ונסו שוב לאחר בדיקת השיוך המוצג. איפוס הוא ההתאוששות הבטוחה משיוך מקרי.

## ברירות מחדל של תהליך התצוגה {#renderer-defaults}

`Mod` פירושו `Ctrl` ב־Windows/Linux ו־`Cmd` ב־macOS. אלו ברירות מחדל, לא הבטחה שמערכת ההפעלה/המארח המקורי יעבירו את המקש. ההיקף חשוב: אותו מקש יכול לשמש פעולה אחרת בדף הבית, בשדה קלט או בחיפוש.

| פעולה | ברירת מחדל |
| --- | --- |
| פתיחת לוח פקודות | `Mod+Shift+P` |
| מופע חדש / עיון בתיקייה בדף הבית | `Mod+N` |
| סגירת לשונית יישום | `Mod+W` |
| לשונית יישום קודמת / הבאה | `Mod+[` / `Mod+]` |
| לשונית יישום 1–9 | `Mod+1` עד `Mod+9` |
| שינוי שם מופע (בהקשר לשונית) | `F2` |
| סשן חדש | `Mod+Shift+N` |
| סגירת סשן | `Mod+Shift+W` |
| סשן קודם / הבא | `Mod+Shift+[` / `Mod+Shift+]` |
| לשונית סשן 1–9 | `Mod+Shift+1` עד `Mod+Shift+9` |
| מידע על מופע | `Mod+Shift+L` |
| חיפוש בהיסטוריית סשן | `Mod+F` |
| תוצאת חיפוש הבאה / קודמת (כשהחיפוש ממוקד) | `Enter` / `Shift+Enter` |
| מיקוד קלט / ניקוי קלט | `Mod+P` / `Mod+K` |
| פתיחת בורר מודל / סוכן | `Mod+Shift+M` / `Mod+Shift+A` |
| בחירת וריאנט מודל | `Mod+Shift+T` |
| העברת כלים חוסמים לרקע (בשדה הקלט) | `Mod+B` |
| שליחת הקלט | `Enter` |
| שליחה עם התנהגות הודעת המשך חלופית | `Alt+Enter` או `Mod+Shift+Enter` |
| הוספת שורה חדשה | `Shift+Enter` או `Mod+Enter` |
| קלט קודם / הבא (בשדה הקלט) | `ArrowUp` / `ArrowDown` |
| הסרת מיקוד מהקלט / יציאה ממצב מעטפת | `Escape`, בהתאם להקשר הקלט |
| עצירת סשן | לחצו `Escape` פעמיים; הלחיצה הראשונה מציגה אישור |
| שליחת שאלת צד (חלון `/btw`) | `Mod+Enter` |
| שמירת קובץ (עורך סביבת עבודה) | `Mod+S` |

בתצורה שבה שליחה ב־Enter כבויה, ברירת המחדל של **שליחת הקלט** היא `Mod+Enter` ושל **הוספת שורה חדשה** היא `Enter` או `Shift+Enter`. דריסת קיצור מפורשת מחליפה ברירת מחדל זו. השתמשו במנהל להצגת השיוך בפועל. סשן קודם/הבא עובר במחזור ברשימת הסשנים; הוא אינו היסטוריית **אחורה**/**קדימה** דמוית הדפדפן בסרגל הצד, שאין לה קיצור.

## מקשים מקוריים ויירוט בפלטפורמה {#native-keys}

מקשים מקוריים קבועים ונשארים פעילים גם לאחר שינוי או השבתת השיוך המקביל בתהליך התצוגה. בפרט, **New Window** המקורי משתמש ב־`Mod+Shift+N`, ברירת המחדל של סשן חדש בתהליך התצוגה. השתמשו בפקד סשן חדש גלוי או שנו את שיוך פעולת תהליך התצוגה אם התפריט המקורי מיירט אותה. בדומה, `Mod+W` מקורי עשוי לסגור את החלון ולא רק לשונית יישום.

| פעולה מקורית | Electron | Tauri |
| --- | --- | --- |
| New Window | `Mod+Shift+N` | `Mod+Shift+N` |
| New Instance / Command Palette | `Mod+N` / `Mod+Shift+P` | `Mod+N` / `Mod+Shift+P` |
| Reload / Force Reload | `Mod+R` / `Mod+Shift+R` | `Mod+R` / `Mod+Shift+R` |
| Actual Size | `Mod+0` | `Mod+0` |
| Zoom | `Mod+Plus` / `Mod+-` | פקדי תפריט View וקלט זום של webview בפלטפורמה |
| Full Screen | `F11` ב־Windows/Linux; `Ctrl+Cmd+F` ב־macOS | קיצור התפריט `Ctrl+Cmd+F` ב־macOS; השתמשו בתפריט בפלטפורמות אחרות |
| Developer Tools | `Ctrl+Shift+I` ב־Windows/Linux; `Alt+Cmd+I` ב־macOS | `Alt+Mod+I` |

גם חלונות דפדפן רגילים שומרים את קיצורי הדפדפן. אם שיוך לעולם אינו מגיע ל־CodeNomad, בחרו צירוף אחר במקום להשבית אבטחה או לשנות מקשים ברמת מערכת ההפעלה.

## פריסות מקלדת והזנת טקסט {#layouts-ime}

קיצורי שורת הספרות והסוגריים המרובעים משתמשים במיקומי המקשים הפיזיים להקלטה, לביצוע ולבדיקת התנגשויות, לרבות בפריסות AZERTY/QWERTZ. מקשים אחרים משתמשים בערכים הלוגיים שלהם. הקליטו במקלדת שבה בכוונתכם להשתמש, ואז בדקו את התוצאה המוצגת.

במהלך הרכבת IME, הזנת טקסט מקבלת קדימות. גם היסטוריית קלט ופעולות Escape תלויות במיקוד, במצב הבורר/המעטפת ובפעולה הנוכחית; אל תניחו שכל ArrowUp או Escape הם פעולה גלובלית ללא תנאי. עצות ריחוף ומנהל הקיצורים מציגים את השיוכים הנוכחיים בלי להוסיף פס עזרה קבוע למקלדת.
