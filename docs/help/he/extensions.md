# הרחבות לוח

## עיון בהרחבות מותקנות ומקוונות {#browse}

1. פתחו **התאמת הלוח הימני** בסרגל הלשוניות של הלוח הימני.
2. הרחיבו **הרחבות** מתחת לקו ההפרדה.
3. השתמשו ב־**חיפוש הרחבות** לחיפוש ברשימה המאוחדת של תוספים מותקנים והקטלוג המקוון הרשמי. רחפו מעל רשומה או מקדו אותה להצגת המטא־נתונים שלה.

הסעיף מתחיל מכווץ בכל פתיחה של חלונית ההתאמה. רשומות מותקנות ומקוונות מאוחדות לפי מזהה ההרחבה; אין חלון ניהול נפרד או מצב מותקן/מקוון. עיון במטא־נתוני הקטלוג אינו מוריד או מריץ את קוד הלוח של המחבר. הקטלוג מתוחזק ב־[CodeNomad Extensions](https://github.com/NeuralNomadsAI/CodeNomad-Extensions); הכללה בו ושמות מחברים מוצהרים אינם חתימות או הוכחת אמינות.

אם הקטלוג אינו זמין, ההרחבות המותקנות ו־**התקנה מקובץ ZIP…** נשארות זמינות. רעננו כדי לנסות שוב לגלות רשומות. כיווץ החלונית או סגירתה זונחים את ממשק הבדיקה/האישור הממתין; הם אינם מתקינים דבר בשקט.

## בדיקה והתקנה ללא הפעלה {#install}

1. בחרו **התקנה…** ברשומת קטלוג, או **התקנה מקובץ ZIP…** עבור חבילה שהשגתם בנפרד.
2. בדקו את מזהה החבילה, המחבר, המאגר, הגרסה, ה־API/ההרשאות ותקציר SHA-256. הרחיבו פרטים טכניים לפי הצורך.
3. אמתו את המפרסם, וכשאפשר השוו את התקציר בערוץ מהימן.
4. רק אם אתם נותנים אמון בקוד, סמנו **אני סומך על החבילה ועל המחבר שלה**, ואז **התקנה ללא הפעלה**.

הבדיקה מורידה/מאמתת מחדש את החבילה שנבחרה; קוד המחבר אינו מורץ בבדיקה. תקציר מזהה בתים מדויקים, לא את זהות המחבר. חבילות הקטלוג מגיעות מנכס ההפצה המדויק שהוצהר ב־GitHub, לא מכתובת שרירותית. חבילות ידניות הן קובצי ZIP המכילים רק `manifest.json` ו־`panel.html` עצמאי; חבילות לא תקינות או לא נתמכות נדחות.

ההתקנה אינה דורשת הפעלה מחדש של OpenCode ולעולם אינה מעניקה הפעלה אוטומטית. כשל באימות, התנגשות או כשל אחסון אינם מתירים ניסיון חוזר עם בתים אחרים. בדקו מחדש את החבילה לפני ניסיון התקנה חדש.

## הפעלה והבנת ההיקף {#activate-scope}

1. חזרו לשורת התוסף מעל הסעיף **הרחבות** ב־**התאמת הלוח הימני**. תוספים מותקנים ומושבתים נשארים ברשימה.
2. סמנו את תיבת הסימון שלו כדי להפעילו. נקו את אותה תיבה כדי להשביתו.

תיבת סימון זו היא פקד ההפעלה היחיד: אין מתג ניהול נוסף או תנאי נראות לכל חלון. ההפעלה חלה על כל הפרויקטים בתצורה, לא על תיקייה בודדת. בחיבור מרוחק היא משפיעה על מאגר ההרחבות המותקנות של השרת, לא רק על המכשיר שבו אתם צופים.

מאגר ההרחבות הוא `panel-extensions/` לצד תצורת CodeNomad שנבחרה. פרופילי נתונים נפרדים לשולחן העבודה **אינם** מבודדים הרחבות כאשר הפרופילים משתמשים באותה תיקיית תצורה. מנגד, פתיחת תצורה אחרת אינה מעניקה רשות להריץ תוסף שהותקן במקום אחר. ראו [חלונות ונתונים בשולחן העבודה](desktop.md) להבחנה.

לוח שהופעל יכול להיטען כשנבחר; הסתרתו יכולה לסלק את מצב הממשק הזמני שלו. השבתה מבטלת את אישור הפעלתו. **איפוס** בהתאמה רק משחזר פריסה מובנית ואינו מפעיל, משבית או מסיר הרחבות.

## החלפה או הסרה {#replace-remove}

1. השתמשו ב־**שינוי גרסה…** או בדקו ZIP אחר בעל אותו מזהה כדי להחליף חבילה מותקנת.
2. בדקו את התקציר וההרשאות החדשים, אשרו אמון והתקינו ללא הפעלה.
3. הפעילו מחדש בתיבת הסימון הרגילה רק לאחר שהחלטתם לתת אמון בתחליף.
4. להסרה, השתמשו ב־**הסרה…** וב־**אישור הסרה** לאחר בדיקת היעד.

כל החלפה מבטלת הפעלה בכל הפרויקטים, גם אם רשימת ההרשאות לא השתנתה, ומוחקת את ההגדרות השמורות של הלוח עצמו. כשל אימות/התנגשות/אחסון משמר את החבילה המותקנת. אין עדכוני הרחבות שקטים. הסרה מוחקת את החבילה, את הגדרות ההפעלה שלה ואת הגדרות הלוח השמורות שלה, לא סשנים של OpenCode או קובצי פרויקט. להתאוששות מקוד לא רצוי, השביתו אותו תחילה; התקינו מחדש רק חבילה מאומתת ומהימנה.

## הקשר, הסכמה לנכסים ומגבלות ארגז החול {#permissions-sandbox}

| חוזה | מה ההפעלה מתירה |
| --- | --- |
| API 1 / `session.context` | מזהה הסשן הנוכחי (או ללא מזהה), שפת הממשק והמראה. ללא טקסט תמליל או גישה למערכת הקבצים. |
| API 2 / `session.assets.read` נוסף על ההקשר | הרשאה שנבדקה במפורש לרשימה מוגבלת של מטא־נתוני תמונות/קבצים מצורפים מתוצאות כלים בסשן הנוכחי ולקריאת בתים מוטמעים נתמכים. זו אינה גישה כללית לתמליל, לקבצים או לכתובות URL. |
| API 3 / `repository.workItems.read` בתוספת הקשר | הרשאה שנבדקה במפורש להצגת עמודים מוגבלים של issues ו-pull requests של מאגר הפרויקט ב-GitHub, ‏GitLab או Gitea/Forgejo, ולפתיחת אחד מהם בדפדפן. אין בה גישה לקבצים, לפרטי התחברות או לרשת באופן כללי. |
| API 4 / הקשר בתוספת הרשאה אחת או יותר מההרשאות שלהלן | הבדיקה מציגה משפט אחד לכל הרשאה מוצהרת; ההפעלה מעניקה את כולן יחד, והחלפה מבטלת את כולן. |
| `session.images.read` | קריאת התמונות שהוחזרו על ידי הכלי read בשיחה המוצגת, עם מצב היצירה והשושלת כאשר ניתן לאמת אותם. |
| `session.images.prompts` (דורשת `session.images.read`) | קריאת ההנחיה והמודל של כל תמונה שנוצרה בשיחת התמונות של הפרויקט. |
| `composer.prefill` | הוספת טקסט לשדה הקלט של השיחה המוצגת. אף פעם אינה שולחת הודעה. |
| `images.conversation` | פתיחה או התחלה של שיחת התמונות של פרויקט זה. |
| `opencode.designAgent` | מוסיפה ל-OpenCode את סוכן Design של CodeNomad ואת מיומנויות התמונה שלו כל עוד הרחבה זו מופעלת. |
| `panel.preferences` | זכירת ההגדרות הייחודיות של לוח זה. |

גישה לנכסים עוקבת אחר המארח/הסשן המוצג כעת, לא אחר סשן שהמחבר בחר. הפניות מקומיות/מרוחקות עשויות להופיע כלא זמינות; API הנכסים אינו מאחזר כתובות מרוחקות שרירותיות או פותח קבצים מקומיים. החלפת סשן, ניתוק או ביטול הסכמה מבטלים גישה ישנה.

ב-API 4, קריאת תמונות עוקבת באותו אופן אחר השיחה המוצגת, ומציגה רק את התמונות שהסוכן קרא בחזרה לתוכה. הרחבה עם `session.images.prompts` יכולה לקרוא את ההנחיות שאתם או הסוכן כתבתם לתמונות בשיחת תמונות, ועלולה להעביר אותן הלאה למרות ארגז החול, לכן העניקו אותה רק למחברים שאתם סומכים עליהם בנוגע להן. טקסט שנוסף על ידי `composer.prefill` נשאר בשדה הקלט עד שתערכו אותו או תבחרו **שלח הודעה**; הוא אף פעם אינו מתחיל בפקודה, אף פעם אינו מסתיים באזכור `@` פתוח, ומציין נתיבי תמונות כטקסט רגיל. ביטול עם Ctrl+Z (Cmd+Z ב-macOS) בשדה הקלט אינו מסיר אותו. הגדרות לוח שמורות שייכות לפרופיל CodeNomad זה, לכל היותר 4 KiB לכל הרחבה; השבתת הרחבה שומרת אותן.

הפריטים מגיעים מה-remote ‏`upstream` של תיקיית הפרויקט, ואם אין כזה מ-`origin`. ‏CodeNomad קורא אותם באמצעות ה-CLI של GitHub, ‏GitLab או Gitea שאליו כבר התחברתם (`gh`, ‏`glab`, ‏`tea`), או באופן אנונימי למאגרים ציבוריים, ואינו שומר טוקן; ההרחבה רואה רק את שם המאגר ואת הפריטים. קריאה אנונימית זמינה ל-github.com, ‏gitlab.com, ‏codeberg.org ו-gitea.com; פלטפורמה באירוח עצמי נקראת רק דרך ה-CLI המחובר אליה. פתיחת פריט מבקשת מ-CodeNomad לפתוח את דף הפריט באותה פלטפורמה בדפדפן, לכל היותר פעם בשנייה; ההרחבה אינה יכולה לפתוח כתובות אחרות.

קוד המחבר רץ ב־iframe מוגבל, לא בתהליך התצוגה המהימן של היישום. הוא אינו מקבל גשר מקורי/ל־OpenCode, גישה לפרטי התחברות, RPC כללי, טפסים, חלונות קופצים או הורדות; ממשקי רשת ומשאבים חיצוניים מוגבלים. הרחבות הן תוספי ממשק, לא [תוספי OpenCode](integrations.md).

ארגז החול אינו בידוד תהליך/מעבד או הבטחה שקוד שאושר אינו מזיק. הרחבה עוינת יכולה לשבש את תהליך התצוגה שלה. התקינו רק ממחברים מהימנים, אל תמסרו סודות והשביתו/הסירו תוסף שמתנהג באופן בלתי צפוי.
