# אימות ואבטחה

גישה ל־CodeNomad יכולה להריץ עבודה במארח שרת הקצה באמצעות OpenCode. התייחסו לסיסמאות שרת, לסשנים בדפדפן ולמכשירים מצומדים כאל אישורי גישה רבי עוצמה. CodeNomad אינו ארגז חול להרצה מרובת דיירים.

## בחירת אופן אימות השרת {#authentication}

| שיטה | משך חיים והיקף |
| --- | --- |
| `--password` או `CODENOMAD_SERVER_PASSWORD` | דריסה בזמן ריצה עבור תהליך שרת הקצה. נדרשת שוב בכל הפעלה; אינה נשמרת. גוברת על קובץ הסיסמה המנוהל. |
| סיסמה שהוגדרה בהגדרות | שומרת גיבוב scrypt עם מלח ב־`auth.json` לצד קובץ YAML של התצורה הפעילה. משמשת בהפעלות הבאות ללא דריסה בזמן ריצה. |
| `--generate-token` | מאפשר אתחול מקומי חד־פעמי; האסימון המודפס תקף ל־60 שניות. הוא אינו אסימון API לשימוש חוזר או קישור לשליטה מרחוק. |
| צימוד לשליטה מרחוק | אימות נפרד באמצעות עוגיית מכשיר, המנוהל מהמארח; ראו [שליטה מרחוק](remote-control.md). |

שם המשתמש כברירת מחדל הוא `codenomad`. קובץ אימות שמור שומר את שם המשתמש שלו; שינוי `--username` בלבד אינו משנה את שם הזהות השמורה. ללא סיסמה מוגדרת, מצב אתחול או דילוג מפורש על אימות, השרת מסרב לעלות.

העדיפו סוד מוגן בסביבה/בשירות על פני הטמעת סיסמה בארגומנטים לפקודה או בהיסטוריית המעטפת. מי שיכול לעיין בסביבת התהליך או בתיקיית התצורה עדיין עשוי להשתלט על ההתקנה.

## אתחול סיסמה קבועה {#bootstrap}

1. הפעילו מקומית ללא דריסת סיסמה בזמן ריצה. לאתחול ב־loopback בלי להגדיר תעודה תחילה, השתמשו ב־`codenomad --host 127.0.0.1 --https=false --http=true --generate-token --launch`.
2. במחשב שרת הקצה, פתחו `/auth/token` ב־**Local Connection URL** המודפס, ושלחו את הערך המודפס אחרי `CODENOMAD_BOOTSTRAP_TOKEN:`. אל תשתפו פלט זה.
3. פתחו **הגדרות → גישה מרוחקת → גישה ישירה (רשת מקומית, מתקדם) → סיסמת שרת**.
4. בחרו **הגדר סיסמה**, מלאו **סיסמה חדשה** ו־**אשר סיסמה** בלפחות שמונה תווים, ואז בחרו **שמור סיסמה**.
5. בהפעלה הבאה השמיטו `--generate-token` והשתמשו בסיסמה השמורה לחיבורים ישירים. לפני הפעלת גישה מרחוק, הגדירו [HTTPS מהימן](remote-access.md); פקודת הגדרת HTTP ב־loopback אינה פקודת פריסה מרוחקת.

אתחול מתקבל רק ממאזין ה־loopback של המארח עצמו, לא מלקוח ברשת המקומית או מכניסה של שליטה מרחוק. השאירו את ההאזנה כברירת מחדל ב־loopback לצורך ההגדרה. אסימון שפג או נוצל דורש הפעלת אתחול חדשה. אם סיסמה קבועה כבר קיימת, סשן האתחול מאפשר לבחור **שנה סיסמה** במקום זאת.

`auth.json` מנוהל בידי היישום; אל תערכו גיבוב ידנית ואל תפרסמו את הקובץ. אם הסיסמה הגיעה מה־CLI/מהסביבה, ההגדרות מסרבות להחליפה: הפעילו מחדש ללא הדריסה כדי להשתמש בסיסמה מנוהלת קיימת, או השתמשו באתחול מקומי להגדרת אחת. קובץ אימות שאי אפשר לקרוא או לכתוב דורש תיקון הרשאות/נתיב במערכת ההפעלה, לא השבתת אימות.

## סשנים בדפדפן וביטול גישה {#sessions}

התחברות ישירה יוצרת סשן אטום בזיכרון שרת הקצה ועוגיית `codenomad_session` (או בשם העוגייה שהוגדר). העוגיות הן `HttpOnly`, `SameSite=Lax`, תחומות ל־`/`, ומסומנות `Secure` כשמונפקות ב־HTTPS. אלו עוגיות סשן דפדפן; הפעלה מחדש של שרת הקצה מבטלת את הסשנים בזיכרון. התחברו מחדש במקום כשמתבקשים, במקום לשלוח שוב פעולות שינוי שנכשלו.

שינוי סיסמה משנה בדיקות אישורים עתידיות; הוא **אינו** מבטל סשנים ישירים או מכשירי שליטה מרחוק שכבר אושרו. בחשד לפריצה:

1. הגבילו חשיפה לרשת והגדירו סיסמה חדשה במארח, או שנו את סוד זמן הריצה והפעילו מחדש.
2. הפעילו מחדש את שרת הקצה כדי לבטל את הסשנים הישירים הקיימים שלו.
3. תחת **שליטה מרחוק → מכשירים מצומדים**, השתמשו ב־**בטל גישה** למכשירים לא מוכרים בנפרד. עצרו שליטה מרחוק אם עליכם לנתק מיד את כל נתיב הגישה הזה.
4. בדקו קבצים, חשבונות ספקים ופעילות OpenCode מקורית שהושפעו. עצירת גישה אינה ביטול עבודה שכבר התקבלה להרצה.

ראו [שליטה מרחוק](remote-control.md) לגבי תפוגה נפרדת לאחר 30 ימי חוסר פעילות וקישורי צימוד לחמש דקות. שינוי סיסמה אינו ביטול מכשיר, ועצירת מנהרה אינה מחיקת מכשיר.

## הגנת התעבורה וחשיפת המאזין {#transport}

השתמשו ב־HTTPS מהימן לגישה ישירה מרחוק. HTTP גלוי חושף סיסמאות, עוגיות סשן ותוכן עבודה לכל מי שיכול לצפות במקטע הרשת הזה. אם TLS מסתיים במתווך הפוך, השאירו את המקטע לשרת הקצה ב־loopback או ברשת מוגנת אחרת; TLS במתווך אינו מצפין חיבור HTTP חשוף לשרת שמאחוריו.

`--dangerously-skip-auth` / `CODENOMAD_SKIP_AUTH` משבית את ההתחברות למאזין הישיר של CodeNomad ומתייחס לבקשות כמאומתות. הוא **אינו** הופך את חשיפת השרת לבטוחה. מאזין נגיש ללא מעטפת הגנה אוכפת מעניק גישה לכל מי שיכול להגיע אליו; חיבור VPN לבדו אינו מבחין בין משתמשי VPN מהימנים ולא מהימנים. השאירו אימות פעיל אלא אם תכננתם ואימתתם באופן עצמאי כל נתיב גישה. שליטה מרחוק עדיין דורשת מכשיר מצומד, גם עם דגל זה.

בדקו את [טבלת ההאזנה ונוהלי TLS](remote-access.md), במיוחד במצב עצמאי של HTTP בלבד: הוא מכבד את `--host` ועשוי לחשוף טקסט גלוי מעבר ל־loopback. לעולם אל תפתרו שגיאות תעודה בהשבתת אימות התעודה.

**`CODENOMAD_SKIP_AUTH=false` משאיר את האימות פעיל, אלא אם מעבירים `--dangerously-skip-auth`.** `1`,‏ `true`,‏ `yes` או `on` מפעילים את עקיפת האימות, ללא תלות ברישיות ובהתעלמות מרווחים בתחילת הערך ובסופו; `0`,‏ `false`,‏ `no`,‏ `off`, ערך ריק או המכיל רק רווחים ומשתנה שאינו מוגדר משאירים אותה כבויה. כל ערך אחר מונע את הפעלת השרת, גם עם דגל ה־CLI. הדגל גובר על ערך כיבוי תקין; ראו [מדריך CLI](server.md#cli-reference).

## הבנת גבול המארח {#host-boundary}

`--workspace-root` מגביל אילו סביבות עבודה אפשר לפתוח, ו־`--unrestricted-root` מרחיב את העיון. אף אחד מהם אינו כלא של מערכת ההפעלה, מכל, ארגז חול למערכת הקבצים או מגבלה על מה שכלי מקורי מורשה יכול לעשות. סוכנים, פקודות מעטפת, תוספים וכלי MCP פועלים בהרשאות מארח ההרצה ובפרטי ההתחברות המוגדרים שלהם.

[SideCars](browser-sidecars.md) הם תוספות מהימנות. CodeNomad מונע משירות ה־SideCar את עוגיות ההתחברות והמכשיר המצומד שלו, אך דף ה־SideCar נטען באותו מקור (origin) כמו CodeNomad, והסקריפטים שלו יכולים לפעול באמצעות הסשן המחובר שלכם. רשמו רק שירותים שאתם סומכים עליהם כמו על CodeNomad עצמו.

השתמשו בחשבונות מערכת הפעלה, במכלים/מכונות וירטואליות ובהגדרות האישורים של OpenCode כשנדרש בידוד ממשי. אל תעניקו גישה למכשיר רק מפני שאתם מצפים שיראה לשונית אחת בלבד. תצורת השרת ושירות OpenCode המשותף יכולים להשפיע על שיחות/פרויקטים אחרים; ראו [הגדרת OpenCode](opencode.md), [אישורים](permissions.md) ו־[הרחבות](extensions.md) לגבולות הנפרדים שלהם.

## שמירה על פרטיות אישורים ונתוני אבחון {#privacy}

OpenCode הוא הבעלים של חיבורי הספקים ואחסון השיחות הגלובלי שלו. CodeNomad קורא מטא־נתוני חיבור ופרטי התחברות נבחרים בצד השרת לשילובי שימוש נתמכים; ממשקי API בדפדפן אינם מחזירים ערכי סוד של ספקים. רענון התחברות OAuth בבעלות חיצונית שייך לבעליו; CodeNomad אינו מחליף את אסימוני הרענון האלה. ראו [ספקים](providers.md).

| חומר | טיפול |
| --- | --- |
| סיסמאות, אסימוני אתחול, קישורי צימוד, עוגיות | לעולם אל תדביקו בדיווחי תקלות, בצילומי מסך, בתמלילי מעטפת או ביומנים משותפים. |
| `auth.json`, מפתחות TLS פרטיים, זהות מנהרה, סודות תצורה | הגנו בהרשאות מערכת הפעלה ובגיבויים מוצפנים; אל תעלו תיקיות שלמות לתמיכה. |
| טקסט שיחה, קבצים מצורפים, נתיבי סביבת עבודה וכתובות מרוחקות | בדקו/השחירו לפני שיתוף; הם עלולים לזהות אנשים, פרויקטים או תשתיות. |
| מפתחות ספקים ואישורי שירותי קול | הזינו רק בהגדרות/אצל בעל האישורים המיועד; בדקו איזה ספק מקבל נתונים. ראו [קול](voice.md). |
| יומני debug/trace ולכידות רשת | אספו רק את הנדרש, בדקו מקומית והשחירו לפני דיווח. אל תניחו שפלט של כל כלי בהמשך השרשרת נקי מסודות. |

**הגדרות → מידע → דווח על באג** מכין אבחון מוגבל בלי למלא מראש מאזינים, כתובות, נתיבים, פרטי התחברות או תוכן שיחות. בדקו כל דבר שאתם מוסיפים בעצמכם לפני השליחה. ראו [תמיכה](support.md).
