# קלט קולי והשמעה

## הגדרת קול {#configure}

1. פתחו **הגדרות → קול**. כרטיס **קול** משתמש במתאם בצד השרת התואם ל־OpenAI, בנפרד מספק המודל של השיחה.
2. הזינו **מפתח API**, ואפשר גם **כתובת בסיס**, **מודל תמלול**, **מודל קול** ו־**קול ברירת מחדל**.
3. אם לקלט ולפלט נחוצים שירותים שונים, הפעילו **ספקים נפרדים לקלט ולפלט**, ואז מלאו את שדות המפתח, כתובת הבסיס והמודל לקלט/לפלט.
4. בחרו **מצב ניגון** ו־**פורמט פלט**, ואז **שמור**. בדקו שמופיע **נשמר**, **מוגדר** או **מוגדר חלקית** לפני בדיקה.

הגדרות הקול והמפתחות שייכים לתצורת שרת CodeNomad המחובר, לא לפרויקט שנבחר או לחיבור ספק OpenCode. לקוחות אחרים החולקים אותה משתמשים בהגדרות האלה. מפתחות שמורים מוסתרים: שדה מפתח ריק שומר את הערך השמור; **נקה מפתח שמור** מתזמן את הסרתו בשמירה. כיוון שאין לו נקודת קצה או מפתח משלו יכול להשתמש בהגדרות המשותפות; נקודת קצה נפרדת דורשת מפתח משלה, ומפתח נפרד דורש את נקודת הקצה שלו. בשינוי נקודת קצה, ספקו במפורש את המפתח הרצוי ואמתו את התצורה השמורה; שינויים בנקודת הקצה מנקים את המפתח השמור לאותו מקום במקום לשלוח אותו למארח אחר.

שרת הקצה יכול להשתמש גם ב־`OPENAI_API_KEY` וב־`OPENAI_BASE_URL` כברירות מחדל משותפות. ניקוי מפתח שמור אינו מסיר אישור שסופק מהסביבה; שנו את הסביבה בשרת הקצה והפעילו אותו מחדש אם בכוונתכם להסיר את החלופה הזו.

| הגדרה | משמעות / ברירת מחדל |
| --- | --- |
| כתובת בסיס | שורש API תואם OpenAI, כברירת מחדל `https://api.openai.com/v1`. הקלט משתמש ב־`audio/transcriptions`; הפלט ב־`audio/speech`. |
| מודל תמלול / מודל קלט | מודל שנקודת הקצה STT מקבלת; ברירת מחדל `gpt-4o-mini-transcribe`. |
| מודל קול / מודל פלט | מודל שנקודת הקצה TTS מקבלת; ברירת מחדל `gpt-4o-mini-tts`. |
| קול ברירת מחדל | מזהה קול של הספק; ברירת מחדל `alloy`. זה אינו בורר קולות של מערכת ההפעלה. |
| הזרמה | מתחילה השמעה עם הגעת השמע, כשהספק והדפדפן תומכים בפורמט שנבחר. |
| באפר מלא | ממתין לתשובת השמע המלאה לפני השמעה. |
| פורמט פלט | `mp3`, `wav`, `opus` או `aac`; ברירת מחדל `mp3`. התאימות משתנה לפי דפדפן/ספק. |

אלו בקשות לשירות המוגדר, לא הבטחה שכל נקודת קצה תואמת מממשת כל מודל, קול או פורמט. כשל שמירה משאיר שגיאה; בדקו את התצורה לפני שינוי נוסף.

## בדיקת קלט ופלט {#test}

1. שמרו תחילה שינויי נקודת קצה, מפתח, מודל וקול.
2. בחרו **בדיקת קלט**, אשרו גישה למיקרופון, דברו ואז **עצור הקלטה**. בדקו את התמלול שהוחזר.
3. בחרו **בדוק ניגון** לשמיעת הדוגמה; **עצור דוגמה** מסיים אותה.

בדיקת ההשמעה משתמשת מיד במצב/פורמט ההשמעה שנבחרו, אך נקודת הקצה, המפתח, המודל והקול מגיעים מההגדרות השמורות. בדיקת קלט אינה שולחת קלט לשיחה. הבדיקות עדיין שולחות שמע/טקסט לספק הקול המוגדר ועשויות לגרור חיובים שלו.

אם הזרמה נכשלת, בחרו **באפר מלא**, נסו `mp3`, שמרו ובדקו שוב. "מוגדר" מאשר הגדרות, לא אימות מוצלח מול הספק או השמעת codec. בדקו זמינות נקודת קצה ממארח השרת, שמות מודל/קול אצל הספק ומכסה לפני ניסיון חוזר.

## הכתבת קלט {#dictate}

1. הפעילו **קלט קולי לפרומפט** ב־**קול**.
2. בשדה הקלט, לחצו והחזיקו את פקד המיקרופון (**התחל קלט קולי**) ואפשרו גישה למיקרופון במכשיר זה.
3. שחררו כדי לעצור ולתמלל. בשימוש ברשומה מתפריט הפעולות במקום זאת, בחרו **התחל קלט קולי**, ואז **עצור הקלטה ותמלל**.
4. בדקו וערכו את הטקסט שהוכנס לפני שליחת הקלט כרגיל.

התמלול מכניס טקסט בבחירה הנוכחית; הוא אינו שולח אותו אוטומטית ל־OpenCode. פקד המיקרופון מופיע רק כאשר STT מוגדר והלקוח תומך בהקלטה. ההקלטה משתמשת במיקרופון של מכשיר הלקוח, גם כש־CodeNomad פועל בשרת מרוחק.

אם הפקד חסר, בדקו את המתג ואת תצורת STT. לשגיאות הרשאה, אפשרו את המיקרופון הן בדפדפן והן בהגדרות הפרטיות של מערכת ההפעלה. הקלטה בדפדפן מרוחק דורשת הקשר מאובטח, לרוב HTTPS מהימן; ראו [גישה מנייד](mobile.md) ו־[גישה ישירה מרחוק](remote-access.md). מעבר מהקלט או סגירתו מסיימים את מחזור חיי ההקלטה; אל תסתמכו על האפשרות לשחזר שמע שלא נשלח. הטיוטה המוקלדת נשארת המקום לבדיקת התוצאה.

## הקראת הודעות {#playback}

1. השתמשו ב־**השמע הודעה** בהודעה כש־TTS זמין.
2. השתמשו ב־**עצור ניגון** באותו פקד פעיל לפני תחילת הקראה אחרת.
3. שנו את הקול, המודל, המצב או הפורמט השמורים ב־**קול** לבקשות הבאות.

ההשמעה משתמשת בהיטל הטקסט של CodeNomad, לא בהקראת צילום מסך: בתים בינאריים/של תמונות וקבלות הרשאה אינם תוכן להקראה. היא אינה מריצה קלט או משנה את מודל OpenCode שנבחר. תמיכת השמע בדפדפן ותשובות הספק עדיין עשויות למנוע השמעה גם אם אפשר לבחור פורמט.

לדיבור שיחה אוטומטי, השתמשו ב־**הפעל מצב שיחה** בפעולות שדה הקלט. הוא מקריא טקסט עוזר שמתחיל בבלוק `spoken` מגודר שהושלם בסשן הראשי הפעיל; זו אינה הקראה אוטומטית של כל תשובה או תת־סוכן. בקשו פורמט פלט זה לפי הצורך. **כבה מצב שיחה** עוצר את התור שלו. תחילת קלט מיקרופון עוצרת גם דיבור שיחה פעיל. המתג מופיע עם קלט קולי, או כל עוד מצב שיחה כבר מופעל, ונדרש TTS תקין להפעלתו.

## זרימת נתונים ופרטיות {#privacy}

שמע המיקרופון עובר מהלקוח לשרת הקצה של CodeNomad, ומשם לנקודת הקצה STT המוגדרת. טקסט שנבחר להפקת דיבור עובר דרך אותו שרת קצה לנקודת הקצה TTS המוגדרת; השמע המוחזר מושמע בלקוח. מפתחות API נשארים בצד השרת ואינם מוחזרים כערכים שמורים לטופס ההגדרות.

השתמשו בנקודת קצה שאתם נותנים בה אמון עם החומר המוכתב או המוקרא. אין זו הבטחה לתמלול לא מקוון, ופרטי התחברות של OpenCode אינם מאשרים שימוש בקול אוטומטית. עצרו הקלטה/השמעה בסיום; שינוי מפתח או נקודת קצה משפיע על בקשות עתידיות, לא על נתונים שכבר נשלחו לספק. ראו [אבטחה](security.md) לפני חשיפת שרת למשתמשים אחרים.
