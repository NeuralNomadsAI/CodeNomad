# הכתבה, ניגון ושיחה קולית

## הגדרת קול {#configure}

פתחו **הגדרות → קול**. הכרטיסים **הכתבה**, **ניגון** ו־**שיחה** מציגים כל אחד את מצבו.

1. ביישום שולחן העבודה המקומי בחרו ב־**הכתבה** את [המנוע במכשיר](#desktop-dictation). בדפדפן ובנייד אפשר להשתמש רק ב־API.
2. להכתבה דרך API ולניגון, פתחו **פרטי גישה ל־API** מאחד משני הכרטיסים. הזינו **מפתח API** ולפי הצורך **כתובת בסיס**, **מודל תמלול** ו־**מודל קול**. כדי להשתמש בשני שירותים, הפעילו **ספקים נפרדים לקלט ולפלט**, מלאו את השדות ובחרו **שמור**.
3. הכרטיס **ניגון** מציג את ה־**ספק**. הגדירו **קול ברירת מחדל**, **מצב ניגון** ו־**פורמט פלט** ובחרו **שמור**.

הגדרות הקול והמפתחות שייכים לתצורת שרת CodeNomad המחובר, לא לפרויקט שנבחר או לחיבור ספק OpenCode. לקוחות אחרים החולקים אותה משתמשים בהגדרות האלה. מפתחות שמורים מוסתרים: שדה מפתח ריק שומר את הערך השמור; **נקה מפתח שמור** מתזמן את הסרתו בשמירה. כיוון שאין לו נקודת קצה או מפתח משלו יכול להשתמש בהגדרות המשותפות; נקודת קצה נפרדת דורשת מפתח משלה, ומפתח נפרד דורש את נקודת הקצה שלו. בשינוי נקודת קצה, ספקו במפורש את המפתח הרצוי ואמתו את התצורה השמורה; שינויים בנקודת הקצה מנקים את המפתח השמור לאותו מקום במקום לשלוח אותו למארח אחר.

שרת הקצה יכול להשתמש גם ב־`OPENAI_API_KEY` וב־`OPENAI_BASE_URL` כברירות מחדל משותפות. ניקוי מפתח שמור אינו מסיר אישור שסופק מהסביבה; שנו את הסביבה בשרת הקצה והפעילו אותו מחדש אם בכוונתכם להסיר את החלופה הזו.

| הגדרה | משמעות / ברירת מחדל |
| --- | --- |
| כתובת בסיס | שורש API תואם OpenAI, כברירת מחדל `https://api.openai.com/v1`. הקלט משתמש ב־`audio/transcriptions`; הפלט ב־`audio/speech`. |
| מודל תמלול / מודל קלט | מודל שנקודת הקצה STT מקבלת; ברירת מחדל `gpt-4o-mini-transcribe`. |
| מודל קול / מודל פלט | מודל שנקודת הקצה TTS מקבלת; ברירת מחדל `gpt-4o-mini-tts`. |
| קול ברירת מחדל | מזהה קול של הספק; ברירת מחדל `alloy`. זה אינו בורר קולות של מערכת ההפעלה. |
| הזרמה | ברירת מחדל. מתחילה השמעה עם הגעת השמע, כשהספק והדפדפן תומכים בפורמט שנבחר. |
| באפר מלא | ממתין לתשובת השמע המלאה לפני השמעה. |
| פורמט פלט | `mp3`, `wav`, `opus` או `aac`; ברירת מחדל `mp3`. התאימות משתנה לפי דפדפן/ספק. |

אלו בקשות לשירות המוגדר, לא הבטחה שכל נקודת קצה תואמת מממשת כל מודל, קול או פורמט.

## בדיקת קלט ופלט {#test}

1. שמרו תחילה שינויי נקודת קצה, מפתח, מודל וקול.
2. בחרו **בדיקת קלט דרך API**, אשרו גישה למיקרופון, דברו ואז **עצור הקלטה**. בדקו את התמלול שהוחזר.
3. בחרו **בדוק ניגון** לשמיעת הדוגמה; **עצור דוגמה** מסיים אותה.

בדיקת ההשמעה משתמשת מיד במצב ובפורמט שנבחרו, אך נקודת הקצה, המפתח, המודל והקול מגיעים מההגדרות השמורות. **בדיקת קלט דרך API** שולחת שמע לספק ה־API שהוגדר, בלי קשר למנוע ההכתבה. היא אינה שולחת הודעה לשיחה. הספק עשוי לגבות תשלום על הבדיקות.

## הכתבת קלט {#dictate}

1. השאירו את **קלט קולי לפרומפט** מופעל ב־**קול** (הוא מופעל כברירת מחדל).
2. בתפריט **פעולות נוספות**, סמנו **מצב הכתבה**. בטלו את הסימון של המצב הפעיל לפני בחירת המצב האחר.
3. לחצו לחיצה ממושכת על המיקרופון ליד **פעולות נוספות**, דברו ושחררו כדי לתמלל. אפשרו גישה למיקרופון לפי הצורך. בחלון מרוחק תואם, לחיצה פותחת את פקדי ההכתבה המקומיים.
4. בדקו את הטקסט. הוא מחליף את הבחירה המקורית רק אם הטיוטה והבחירה לא השתנו. אחרת בחרו **הוספת התמלול** במצב רגיל או **מחיקת התמלול** לפני שתתחילו להכתיב שוב. הכתבה אינה שולחת את הטיוטה.

אם ה-API משתמש בהקלטת WAV כחלופה ב-Tauri על לינוקס, ההכתבה ובדיקת הקלט מפסיקות להקליט אחרי 24 שניות. הקטע נשאר במכשיר עד לבחירה ב־**תמלול** כדי לשלוח אותו לספק שירותי הקול, או ב־**ביטול** כדי למחוק אותו.

גם הקלטות דחוסות דרך ה־API נעצרות כשהן מגיעות למגבלת הגודל ומציעות **תמלול** או **ביטול**.

### בחירת מנוע הכתבה במחשב {#desktop-dictation}

ביישום שולחן העבודה המקומי, פתחו **הגדרות → קול → הכתבה** ובחרו **מנוע הכתבה במכשיר זה**. הבחירה חלה על כל הפרויקטים במכשיר. **ספק API** משתמש בהגדרות השרת המחובר ודורש הקשר מאובטח לגישה למיקרופון.

- אם המנוע השמור אינו זמין, בחרו כאן **Hex (מקומי)** אם הוא מוצע, או **ספק API**. במחשבי Mac עם Intel או עם גרסת macOS קודמת ל־15, השתמשו ב־**ספק API**.
- בקטע קול מוצגים הרכיבים החסרים ל־Hex ונפח ההורדה לכל רכיב ובסך הכול. לחיצה אחת על **הפעלת Hex** בודקת קבצים תואמים, משתמשת בהם מחדש, מורידה את החסר ובוחרת ב־Hex כשהוא מוכן. אפשר לעקוב אחר ההתקדמות, לבחור **ביטול הפעלת Hex** ולעבור ל־**המשך הפעלת Hex** כשהאפשרות מוצגת. בכשל או בביטול נשמר המנוע הקודם. פתיחת ההגדרות, בחירת **Hex (מקומי)** כשהוא מוכן או הכתבה באמצעותו אינן מתחילות הורדה.
- Hex מוצע במכשירים תואמים: Windows ‏x64/arm64, ‏Apple Silicon עם macOS 15 ומעלה, ו־Linux ‏x64/arm64 עם glibc 2.36 ומעלה והספריות ש־Hex דורש. מחשבי Mac עם Intel ומערכות Linux עם glibc ישנה יותר או musl אינם תואמים. המנוע והמודלים נפרדים ממתקין CodeNomad; אין צורך במסוף או במפתח API.

Ubuntu 24.04 עומדת בדרישת glibc, בניגוד ל־Ubuntu 22.04. ‏Hex מזהה את שפת הדיבור מבין [השפות הנתמכות ב־Parakeet](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3), ובהן אנגלית וצרפתית. הרשימה אינה תלויה בשפת היישום.

Hex טוען את המודל שלו ברקע עם תחילת ההקלטה ומשאיר אותו זמין למשך שלוש דקות לאחר ההכתבה האחרונה.

הזיהוי המקומי פועל ללא אינטרנט, גם בפרויקטי WSL שנפתחים ביישום המקומי. בחלון מרוחק תואם, לחצו על המיקרופון כדי לפתוח את **הכתבה במכשיר הזה**. בדקו את היעד והשתמשו בפקדי ההקלטה וההוספה בחלון הזה. רק הטקסט חוזר לטיוטה. הפרויקט המרוחק עדיין זקוק לחיבור לשרת.

בחלון Tauri מרוחק ב־Linux, **בדיקת קלט דרך API** בודקת את ממשק ה־API הקולי של השרת בלי לשנות את מנוע ההכתבה. לפני אישור כל הקלטה ל־API, יש לבדוק את כתובת השרת בתיבת הדו־שיח המובנית של המיקרופון. ההקלטה משתמשת ב־PulseAudio או בשירות PulseAudio של PipeWire, ומגבלת 24 השניות לקובץ WAV שתוארה לעיל חלה תמיד.

Gemini Live ו־OpenAI Realtime אינם זמינים בחלונות Tauri מרוחקים ב־Linux: חלונות אלה משתמשים במקליט המובנה להכתבה ולבדיקות קלט, ו־WebKit חוסם גישה ישירה למיקרופון.

## הקראת הודעות {#playback}

1. השתמשו ב־**השמע הודעה** בהודעה, או באותה פעולה בקריאת כלי, כש־TTS זמין.
2. השתמשו ב־**עצור ניגון** באותו פקד כדי לסיים אותה; התחלת הקראה אחרת עוצרת את הנוכחית.
3. שנו את הקול, המצב או הפורמט ב־**ניגון**, או את המודל ב־**פרטי גישה ל־API**, ושמרו.

ההשמעה משתמשת בהיטל הטקסט של CodeNomad, לא בהקראת צילום מסך: בתים בינאריים/של תמונות וקבלות הרשאה אינם תוכן להקראה. היא אינה מריצה קלט או משנה את מודל OpenCode שנבחר.

## שיחה קולית {#conversation}

Gemini Live ו־OpenAI Realtime זמינים רק בסשנים בשרת שפתח את החלון הזה.

בכרטיס **שיחה**, בחרו **מנוע שיחה**:

- **קלאסי** דורש רק ניגון בפורמט נתמך. סמנו **מצב שיחה** בתפריט **פעולות נוספות**. CodeNomad מקריא את סיכום ה־`spoken` השלם של התשובה בשיחה הראשית הפעילה. המצב חל על לשונית הפרויקט עד לביטול הסימון או לטעינה מחדש.
- ל־**Gemini Live** ול־**OpenAI Realtime** יש **מפתח API** ו־**מודל** נפרדים ואפשר לבחור גם **קול**. שמרו את הגדרות הספק שנבחר. פתחו את שיחת היעד, בחרו **מצב שיחה** ב־**פעולות נוספות** ובתיבת ההסכמה לספק בחרו **הסכמה והתחלה**. אפשרו גישה למיקרופון.

אם הספק אינו זמין בזמן שתיבת ההסכמה פתוחה, בחרו **הגדרות קול** כדי לפתוח את כרטיס השיחה.

מודל הקול יכול לקרוא את מצב השיחה שנקבעה בתחילת ההפעלה, את התשובה האחרונה שמוצגת ואת השגיאות האחרונות. אין לו גישה לקבצים. כשתבקשו ממנו לשלוח בקשה לסוכן, הוא שולח אותה ישירות כהודעה מכם, ללא אישור במסך. [מצב ההרשאות של השיחה](permissions.md#conversation-mode) והשאלות של הסוכן חלים כרגיל.

השרת מאפשר שיחה חיה אחת בכל פעם לכל משתמש מחובר, או לכל מכשיר שמקושר באמצעות שליטה מרחוק. **עצירה** מסיימת את השמע ומשאירה את התמלול פתוח. התמלול נשאר בזיכרון עד לסגירת החלון; בקשות שנשלחו לסוכן נשארות כהודעות בשיחה. השיחה מסתיימת גם אחרי שתי דקות בלי דיבור, אחרי שמונה דקות בסך הכול, בשינוי היעד, בסגירת החלון או בניתוק. אין התחברות חוזרת אוטומטית או מעבר לספק אחר.

ב־OpenAI Realtime, **קטיעת התשובה** עוצרת את הניגון ומבקשת לבטל את התשובה הנוכחית. ב־Gemini Live, **עצור ניגון** רק משתיק את התשובה במכשיר הזה; Gemini יכול להמשיך ליצור אותה ולשלוח בקשות לסוכן.

## זרימת נתונים ופרטיות {#privacy}

בהכתבה מקומית השמע נשאר במכשיר, ללא מעבר לספק API. עם **ספק API**, השמע עובר דרך שרת CodeNomad לנקודת הקצה לתמלול. טקסט לסינתזה עובר דרך אותו שרת לנקודת הקצה TTS והשמע המוחזר מושמע בלקוח. מפתחות API נשארים בשרת.

ב־**Gemini Live** או **OpenAI Realtime**, ‏Google או OpenAI מקבלים את שמע המיקרופון, שם הפרויקט, הענף, עץ העבודה, הכותרת ומצב השיחה. הספק יכול גם לקבל את הטקסט של התשובה האחרונה שמוצגת ואת השגיאות האחרונות. הספק שנבחר עשוי לחייב את החשבון שלכם על השימוש.

בחרו ספק שאתם סומכים עליו עם התוכן שאתם מכתיבים, מקריאים או משתפים. פרטי ההתחברות של OpenCode אינם מעניקים גישה אוטומטית לשירותי קול. ראו [אבטחה](security.md) לפני חשיפת שרת למשתמשים אחרים.
