# קלט קולי והשמעה

## הגדרת API לקול {#configure}

1. פתחו **הגדרות → קול**. כרטיס **קול** משתמש במתאם בצד השרת התואם ל־OpenAI, בנפרד מספק המודל של השיחה.
2. הזינו **מפתח API**, ואפשר גם **כתובת בסיס**, **מודל תמלול**, **מודל קול** ו־**קול ברירת מחדל**.
3. אם לקלט ולפלט נחוצים שירותים שונים, הפעילו **ספקים נפרדים לקלט ולפלט**, ואז מלאו את שדות המפתח, כתובת הבסיס והמודל לקלט/לפלט.
4. בחרו **מצב ניגון** ו־**פורמט פלט**, ואז **שמור** (זמין כל עוד יש שינויים שלא נשמרו). לפני בדיקה, בדקו את הסטטוס שליד כפתורי הבדיקה: **מוגדר**, **מוגדר חלקית** או **חסר מפתח API**; שמירה שנכשלה מציגה **השמירה נכשלה**.

הגדרות הקול והמפתחות שייכים לתצורת שרת CodeNomad המחובר, לא לפרויקט שנבחר או לחיבור ספק OpenCode. לקוחות אחרים החולקים אותה משתמשים בהגדרות האלה. מפתחות שמורים מוסתרים: שדה מפתח ריק שומר את הערך השמור; **נקה מפתח שמור** מתזמן את הסרתו בשמירה. כיוון שאין לו נקודת קצה או מפתח משלו יכול להשתמש בהגדרות המשותפות; נקודת קצה נפרדת דורשת מפתח משלה, ומפתח נפרד דורש את נקודת הקצה שלו. בשינוי נקודת קצה, ספקו במפורש את המפתח הרצוי ואמתו את התצורה השמורה; שינויים בנקודת הקצה מנקים את המפתח השמור לאותו מקום במקום לשלוח אותו למארח אחר.

שרת הקצה יכול להשתמש גם ב־`OPENAI_API_KEY` וב־`OPENAI_BASE_URL` כברירות מחדל משותפות. ניקוי מפתח שמור אינו מסיר אישור שסופק מהסביבה; שנו את הסביבה בשרת הקצה והפעילו אותו מחדש אם בכוונתכם להסיר את החלופה הזו.

| הגדרה | משמעות / ברירת מחדל |
| --- | --- |
| כתובת בסיס | שורש API תואם OpenAI, כברירת מחדל `https://api.openai.com/v1`. הקלט משתמש ב־`audio/transcriptions`; הפלט ב־`audio/speech`. |
| מודל תמלול / מודל קלט | מודל שנקודת הקצה STT מקבלת; ברירת מחדל `gpt-4o-mini-transcribe`. |
| מודל קול / מודל פלט | מודל שנקודת הקצה TTS מקבלת; ברירת מחדל `gpt-4o-mini-tts`. |
| קול ברירת מחדל | מזהה קול של הספק; ברירת מחדל `alloy`. זה אינו בורר קולות של מערכת ההפעלה. |
| הזרמה | ברירת מחדל. מתחילה השמעה עם הגעת השמע, כשהספק והדפדפן תומכים בפורמט שנבחר. |
| באפר מלא | ממתין לתשובת השמע המלאה לפני השמעה. |
| פורמט פלט | `mp3`, `wav`, `opus` או `aac`; ברירת מחדל `mp3`. התאימות משתנה לפי דפדפן/ספק. |

אלו בקשות לשירות המוגדר, לא הבטחה שכל נקודת קצה תואמת מממשת כל מודל, קול או פורמט.

## בדיקת קלט ופלט {#test}

1. שמרו תחילה שינויי נקודת קצה, מפתח, מודל וקול.
2. בחרו **בדיקת קלט**, אשרו גישה למיקרופון, דברו ואז **עצור הקלטה**. בדקו את התמלול שהוחזר.
3. בחרו **בדוק ניגון** לשמיעת הדוגמה; **עצור דוגמה** מסיים אותה.

בדיקת ההשמעה משתמשת מיד במצב/פורמט ההשמעה שנבחרו, אך נקודת הקצה, המפתח, המודל והקול מגיעים מההגדרות השמורות. בדיקת קלט אינה שולחת קלט לשיחה. הבדיקות עדיין שולחות שמע/טקסט לספק הקול המוגדר ועשויות לגרור חיובים שלו.

## הכתבת קלט {#dictate}

1. השאירו את **קלט קולי לפרומפט** מופעל ב־**קול** (הוא מופעל כברירת מחדל).
2. בשדה הקלט, בחרו **פעולות נוספות → הכתבה** ואפשרו גישה למיקרופון. אם מופיע **הכתבה: פתיחת הגדרות קול**, בחרו או הגדירו שם את המנוע וחזרו לטיוטה.
3. בחרו **עצור הקלטה ותמלל** לקבלת הטקסט או **ביטול הכתבה** להשלכת ההקלטה. גם מעבר לשיחה אחרת או סגירת עורך הקלט מבטלים את ההכתבה.
4. בדקו את הטקסט. הוא מחליף את הבחירה המקורית רק אם הטיוטה והבחירה לא השתנו. אחרת בחרו **הוספת התמלול** או **מחיקת התמלול**. הכתבה אינה שולחת את הטיוטה.

אם ה-API משתמש בהקלטת WAV כחלופה ב-Tauri על לינוקס, ההכתבה ובדיקת הקלט מפסיקות להקליט אחרי 24 שניות. הקטע נשאר במכשיר עד לבחירה ב־**תמלול** כדי לשלוח אותו לספק שירותי הקול, או ב־**ביטול** כדי למחוק אותו.

### בחירת מנוע הכתבה במחשב {#desktop-dictation}

ביישום שולחן העבודה המקומי, פתחו **הגדרות → קול** ובחרו **מנוע הכתבה במכשיר זה**. הבחירה חלה על כל הפרויקטים במכשיר; כרטיס **קול** עדיין מגדיר את ה־API של השרת המחובר. הדפדפן והנייד משתמשים בספק ה־API שהוגדר וזקוקים להקשר מאובטח לגישה למיקרופון.

- **זיהוי דיבור מקומי של המערכת** פועל בתוך CodeNomad בלי לפתוח את לוח ההכתבה של מערכת ההפעלה. נדרש מנוע מקומי מותקן לשפת היישום ב־Windows או ב־macOS. ב־Linux, או אם המנוע או השפה חסרים, נסו את Hex אם הוא מוצע.
- בקטע קול מוצגים הרכיבים החסרים ל־Hex ונפח ההורדה לכל רכיב ובסך הכול. לחיצה אחת על **הפעלת Hex** בודקת קבצים תואמים, משתמשת בהם מחדש, מורידה את החסר ובוחרת ב־Hex כשהוא מוכן. אפשר לעקוב אחר ההתקדמות, לבחור **ביטול הפעלת Hex** ולעבור ל־**המשך הפעלת Hex** כשהאפשרות מוצגת. בכשל או בביטול נשמר המנוע הקודם. פתיחת ההגדרות, בחירת **Hex (מקומי)** כשהוא מוכן או הכתבה באמצעותו אינן מתחילות הורדה.
- Hex מוצע במכשירים תואמים: Windows ‏x64/arm64, ‏Apple Silicon עם macOS 15 ומעלה, ו־Linux ‏x64/arm64 עם glibc 2.36 ומעלה והספריות ש־Hex דורש. מחשבי Mac עם Intel ומערכות Linux עם glibc ישנה יותר או musl אינם תואמים. המנוע והמודלים נפרדים ממתקין CodeNomad; אין צורך במסוף או במפתח API.

Ubuntu 24.04 עומדת בדרישת glibc, בניגוד ל־Ubuntu 22.04. ‏Hex מזהה את שפת הדיבור מבין [השפות הנתמכות ב־Parakeet](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3), ובהן אנגלית וצרפתית. הרשימה אינה תלויה בשפת היישום.

הזיהוי המקומי משתמש במיקרופון של המכשיר ופועל ללא אינטרנט, גם בפרויקטי WSL שנפתחים ביישום המקומי. בחלון מרוחק תואם, **הכתבה** פותחת את החלון המקומי **הכתבה במכשיר הזה**. בדקו את היעד המוצג ובחרו **התחל קלט קולי**, **עצור הקלטה ותמלל** ואז **הוספת התמלול** כדי להחזיר רק את הטקסט לטיוטה. הפרויקט המרוחק עדיין זקוק לחיבור לשרת.

בחלון Tauri מרוחק ב־Linux, **בדיקת קלט** בודקת את ממשק ה־API הקולי של השרת בלי לשנות את מנוע ההכתבה. לפני אישור כל הקלטה ל־API, יש לבדוק את כתובת השרת בתיבת הדו־שיח המובנית של המיקרופון. ההקלטה משתמשת ב־PulseAudio או בשירות PulseAudio של PipeWire, ומגבלת 24 השניות לקובץ WAV שתוארה לעיל חלה תמיד.

## הקראת הודעות {#playback}

1. השתמשו ב־**השמע הודעה** בהודעה, או באותה פעולה בקריאת כלי, כש־TTS זמין.
2. השתמשו ב־**עצור ניגון** באותו פקד כדי לסיים אותה; התחלת הקראה אחרת עוצרת את הנוכחית.
3. שנו את הקול, המודל, המצב או הפורמט השמורים ב־**קול** לבקשות הבאות.

ההשמעה משתמשת בהיטל הטקסט של CodeNomad, לא בהקראת צילום מסך: בתים בינאריים/של תמונות וקבלות הרשאה אינם תוכן להקראה. היא אינה מריצה קלט או משנה את מודל OpenCode שנבחר.

לדיבור שיחה אוטומטי, השתמשו ב־**הפעל מצב שיחה** בתפריט **פעולות נוספות** של שדה הקלט; הוא חל על אותה לשונית פרויקט ואינו נשמר לאחר טעינה מחדש. כל עוד הוא פעיל, CodeNomad מבקש מהסוכן, עם כל קלט שאתם שולחים, לפתוח את תשובתו בסיכום קצר בבלוק `spoken` מגודר. רק הבלוק שהושלם מוקרא, בסשן הראשי הפעיל; זו אינה הקראה אוטומטית של כל תשובה או תת־סוכן. **כבה מצב שיחה** עוצר את התור שלו ומפסיק לבקש את הסיכום. תחילת קלט מיקרופון עוצרת גם דיבור שיחה פעיל. מצב שיחה דורש השמעה מוגדרת בפורמט נתמך.

## זרימת נתונים ופרטיות {#privacy}

בהכתבה מקומית השמע נשאר במכשיר, ללא מעבר לספק API. עם **ספק API**, השמע עובר דרך שרת CodeNomad לנקודת הקצה לתמלול. טקסט לסינתזה עובר דרך אותו שרת לנקודת הקצה TTS והשמע המוחזר מושמע בלקוח. מפתחות API נשארים בשרת.

השתמשו בנקודת קצה שאתם סומכים עליה עם חומר מוכתב או מוקרא. פרטי ההתחברות של OpenCode אינם מאשרים שימוש בקול אוטומטית. שינוי מפתח או נקודת קצה משפיע על בקשות עתידיות בלבד. ראו [אבטחה](security.md) לפני חשיפת שרת למשתמשים אחרים.
