# モバイルと PWA

スマートフォンやタブレットのブラウザー UI から、バックエンドホスト上の作業を続けられます。PWA のインストールで変わるのは UI の開き方であり、プロジェクト、認証情報、エージェント実行の場所ではありません。

## スマートフォンやタブレットから接続する {#connect}

1. ホストで **設定 → リモートアクセス → リモートコントロール** を開き、**リモートコントロールを開始** を選びます。
2. モバイル端末でペアリング QR コードを読み取り、今後も使う予定のブラウザーでリンクを開きます。
3. または、[直接アクセス](remote-access.md)を設定し、ホストの到達可能な信頼済み HTTPS URL を開き、サーバーパスワードでログインします。

リモートコントロールには端末のペアリングが、直接接続には経路、到達可能なリスナー、認証が必要です。スマートフォンからワークステーションに接続するために `localhost` を使わないでください。サイトデータの消失やブラウザープロファイルの変更では、再ログインや再ペアリングが必要になる場合があります。[リモートコントロール](remote-control.md)を参照してください。

## PWA をインストールする {#install-pwa}

1. インストールに対応したブラウザーで、動作する CodeNomad URL を信頼された HTTPS で開きます。
2. Chrome/Edge などでは、アドレスバーのインストール操作や、表示された場合はブラウザーの **Install CodeNomad** を使用します。iPhone/iPad の Safari では **Share → Add to Home Screen** を使用します。正確な表記は OS／ブラウザーによって異なります。
3. 新しいランチャーを開き、ブラウザーストレージが別の場合は、そこでログインやペアリングを完了します。

インストールは、端末／ブラウザーとオリジンごとです。スマートフォンに Node、Git、OpenCode をインストールしたり、バックエンドを起動したり、ネイティブデスクトップ連携を許可したりはしません。ランチャーを削除してもホストの会話は削除されません。アクセスを解除するときは、別途ペアリング済み端末を取り消してください。

### 安全なコンテキストと証明書 {#secure-context}

リモートの PWA インストールとマイクアクセスには、ブラウザーが認める安全なコンテキストが必要です。正確なホスト名／IP に合う、信頼された HTTPS 証明書を使用してください。生成されたローカル証明書は、クライアント端末／ブラウザーで明示的に信頼する必要があります。警告ページやその回避は、確実なインストール環境ではありません。ブラウザーの localhost 例外はその端末に適用され、別ホストの HTTP LAN アドレスには適用されません。

インストール操作が見つからない場合は、まず HTTPS の信頼とブラウザーの対応を確認し、QR／アプリ内の埋め込みブラウザーではなく、通常のブラウザーで開き直します。マイクの失敗では、ブラウザー／OS のサイト権限と[音声](voice.md)を確認します。インストールを直すために認証や TLS 検証をオフにしないでください。

## タッチ向けレイアウトで作業する {#touch-layout}

**左パネル** と **右パネル** のコントロールで、ナビゲーションとツールを開きます。狭いレイアウトでは、デスクトップ幅のキャンバスを強制せず、パネルは会話の上に重なります。一方のフローティングパネルを開くと、他方は閉じます。会話ヘッダーの操作は、領域が限られるとオーバーフローメニューに移ります。

入力欄ではエージェント、モデル、思考をフッターに保ちます。フィールドは画面キーボードを含む可視の会話領域に合わせてサイズが変わり、長い下書きはスクロールできます。タッチ操作のみの端末では、送信しても画面キーボードは再表示されないため、応答を読めます。続けるには入力欄をタップします。セッションの実行中は、入力欄の **その他の操作** メニューに、通常の送信とは異なる方の **メッセージをキューに追加** または **今すぐ割り込む** が表示され、ハードウェアキーボードのショートカットは不要です。割り込みを開くと、保存した高さや下書きを変えずに入力欄を一時的に縮めます。その上のドックで権限／質問に回答し、ドックの操作フッターに届くようにしてください。[会話](conversations.md)と[権限](permissions.md)を参照してください。

## 機能と接続の制限 {#limits}

| 機能 | モバイルブラウザー／PWA |
| --- | --- |
| プロジェクト、会話、ファイル、権限 | 接続先バックエンドホスト上で、そのアクセス制御に従って操作します。端末添付はスマートフォンからアップロードし、プロジェクト参照はホストで解決します。 |
| ネイティブデスクトップウィンドウ、OS メニュー、ホストのネイティブ自動操作 | PWA をインストールしても提供されません。 |
| ブラウザープレビュー | ネイティブのゲストブラウザー機能は獲得しません。代替描画はブラウザーの制限を受けます。 |
| SideCar のコンテンツと WebSocket | 接続経路に依存します。リモートコントロールは SideCar コンテンツプロキシをブロックし、ホストが許可している間は Web プレビューとその WebSocket を提供します。[正確な制限](remote-control.md)を参照してください。 |
| マイク、クリップボード、通知、インストール案内 | ブラウザー／OS の対応、安全なコンテキスト、ユーザー権限に依存します。 |
| オフライン作業 | オフラインのバックエンドや API 履歴キャッシュはありません。静的 UI 資産はキャッシュされる場合がありますが、文書と API 応答はオフラインのワークスペースではありません。 |

バックエンドを到達可能に保ってください。モバイル OS の一時停止やネットワーク切り替えは、イベントストリームを切断する場合があります。戻ると再接続して現在の状態を取得しますが、イベントの再生は保証されません。再試行前に操作が完了したか確認してください。PWA を閉じてもスタンドアロンバックエンドは停止しません。ホストのデスクトップアプリとバックエンドを終了すると、次の起動までリモートコントロールは利用できなくなります。
