# ブラウザープレビューと SideCar

iframe プレビューと SideCar は、DNS エイリアスを含め、CodeNomad 自身の待ち受けアドレスとポートへの接続を拒否します。アプリケーション用サーバーの別のポートを使用してください。

## セッションのブラウザーを開く {#session-browser}

1. 会話のツールバーで **Web プレビューを開く** を選びます。
2. 認証情報を含まない `http://` または `https://` の **プレビュー URL** を入力し、**プレビューを開く** を選びます。ツールバーで移動、更新、戻る／進むを行います。
3. プレビューの閉じるボタンでチャットに戻ります。同じタブと会話で開き直すと続行できます。

リモートプレビューでは Service Worker を無効にしています。

会話内の `localhost` または `127.0.0.1` リンクをクリックすると、プレビューが利用できるクライアントではそのセッションの Web プレビューで開きます。Remote Control でホストが Web プレビューをオフにしている場合や、プレビューがそれ以外の理由で利用できないクライアントでは、こうしたリンクは通常のブラウザー動作のままです。Ctrl+クリック（macOS では ⌘+クリック）または中クリックで、代わりにブラウザーで開きます。

チャットに戻ったり、同じウィンドウ内の別のタブに移したりしても、ネイティブプレビューのページは保持されます。

各タブはチャット／プレビューの選択を保存し、セッションは共有 URL、ビューポートテンプレート、履歴を保存します。保存したページはセッションブラウザーを明示的に開き直したときだけ読み込まれます。URL とカーソルを保存し、入力中のフォーム、DOM、POST 本文、JavaScript メモリは文書とともに終了します。履歴はセッションごとに 32 URL までで、ウィンドウの保存容量を共有します。古い項目は削られる場合があり、URL の復元でページが再読み込みされることがあります。

リモートプレビューはプロジェクトのサーバーを使い、アプリの URL を表示します。プレビューやタブを閉じる、サーバーを切断する、または終了するとページが閉じます。再度開くと保存済みのアドレスと履歴が読み込まれますが、未保存の作業は失われます。内部の読み込みアドレスは公開しないでください。

ネイティブのリモートプレビューでは、内部読み込みアドレスを保護するため、コンテキストメニュー、クリップボードへの書き出し、リンクのドラッグ、印刷、ポップアップ、ダウンロード、ページのダイアログ、権限要求を無効にします。閉じる前にページの作業を保存してください。

ホストとリモートプロジェクトのサーバーの両方でプレビューが利用できると確認できた時点で、プレビューの操作ボタンが表示されます。

リモートコントロールの **Web プレビュー** は、ホストの **設定 → リモートアクセス → リモートコントロール** で既定でオンです。オフにするとプレビューと WebSocket が停止し、再読み込み後に **Web プレビューを開く** が非表示になります。サインアウトするか端末のペアリングを解除すると、その端末のプレビューと WebSocket が終了します。

## 共有ログインと自動操作の境界 {#signins-automation}

Electron と Windows 版 Tauri では、自動再起動（`codenomad.act` の `restart`）は検査したプロファイル、設定、ビルドを再起動します。元のウィンドウが復元されれば再検査し、復元されなければ別のウィンドウを検査せず、元のウィンドウがないと報告します。再接続中に別の検査が成功した場合は、その検査が優先されます。

再起動が取り消された場合は、`codenomad.inspect` に `targets: true` を指定して開いているウィンドウを一覧表示し、目的のウィンドウを `target` で指定して検査します。

ネイティブプレビューは、同じデスクトップエンジンとプロファイル／設定範囲のプロジェクト／セッション間で、Cookie、ログイン、サイトストレージを共有します。信頼された CodeNomad レンダラーとは分離されています。1 つのプレビューでサイトからログアウトすると、同じストアを使う他のプレビューにも影響します。文書、フォーム、セッションストレージ、移動履歴、自動操作の接続は各セッションに属します。

ネイティブプレビューはセッションごとに 1 つです。複製したタブに **プレビューは別のタブで開いています** と表示されたら、**タブに移動** するか、同じウィンドウ内で移すには **ここで開く** を選びます。移した後は元のタブに同じメッセージが表示されます。プレビューのあるタブを閉じると、別のタブで開けます。

デスクトップウィンドウに会話が表示されている間、その会話のエージェントは OpenCode のブラウザーツール（OpenCode 2.4 以降）でプレビューを操作できます。ページでのスクリプト実行は拒否され、macOS と Linux の Tauri アプリでは戻る・進む・再読み込みはできません。Electron と Windows の Tauri アプリでは、プレビューのコンソールメッセージとネットワークリクエストも読み取れます。プレビューが保持している間は、リクエストとレスポンスのヘッダーとテキスト本文を参照できますが、Cookie と認証ヘッダーの値は非表示です。エージェントはプレビューを保持しているタブで開きます。なければ、そのセッションで最後に使用したタブで開きます。ページ操作は表示中のネイティブプレビューが対象です。ページは表示中のプレビューと同じくこのコンピューターのネットワークで読み込まれるため、OpenCode が WSL で動作していても `localhost` はこのコンピューターを指します。

エージェントはプレビューを操作または撮影する前にスナップショットを取得します。プレビューが切り替わると、別のプレビューを使わずにコマンドを中止します。

| クライアント | プレビューの実装 | エージェントのブラウザー自動操作 | モバイルテンプレート |
| --- | --- | --- | --- |
| 対応デスクトップ環境の Electron | ネイティブ Chromium ゲスト。OAuth ポップアップ、ダウンロード、ダイアログに対応 | 所有する表示中のセッションプレビューで対応 | Android/Chromium の識別、タッチ、密度のエミュレーション |
| Windows Tauri | ネイティブ WebView2 子。OAuth ポップアップ、ダウンロード、ダイアログに対応 | 所有する表示中のセッションプレビューで対応 | Android/Chromium の識別、タッチ、密度のエミュレーション |
| macOS Tauri (14+) | ネイティブ WKWebView 子。OAuth ポップアップ、ダウンロード、ダイアログに対応 | 所有する表示中のセッションプレビューで対応 | WebKit モバイル識別と CSS ビューポート。入力はネイティブ環境の制約あり |
| Linux Tauri | ネイティブ WebKitGTK 子。OAuth ポップアップ、ダウンロード、ダイアログに対応 | 所有する表示中のセッションプレビューで対応 | WebKit モバイル識別と CSS ビューポート。密度と入力はネイティブ環境の制約あり |
| 通常のブラウザー／リモート表示 | 代替 iframe | ローカルのネイティブプレビュー対象なし | 寸法のみ |

ネイティブモードでは要素コメントは利用できません。GTK のクリップボード読取は明示的な Ctrl+V で行い、書込とネイティブのコピー／貼付は動作します。iframe を禁止するサイトは外部ブラウザーで開いてください。

ネイティブポップアップはプレビューのログイン状態を共有し、`opener`/`postMessage` を保持し、元のページとともに閉じます。入力・復元するアドレスは認証情報のない HTTP(S) のみで、サイトは空白文書や同一オリジンの blob 文書も開けます。ファイル・アプリのスキームは拒否されます。ダウンロードは安全な一意の名前でダウンロードフォルダーに保存され、上書き・自動実行しません。カメラ、マイク、位置情報、通知は拒否され、分類済み権限には同意が必要です。不明な要求はエラーを表示します。Tauri と Electron は `alert`/`confirm`/`prompt` に対応し、Electron の prompt ダイアログはプレビューのトップレベルページ、ポップアップ、サブフレームで利用できます。

サイトはネイティブポップアップを閉じる際に確認を求めることがあります。2.52.6 など [WebKit 323277](https://bugs.webkit.org/show_bug.cgi?id=323277) の影響を受ける WebKitGTK では、セキュリティ上ドロップされたファイルへのアクセスがブロックされるため、アップロードにはページのファイル選択を使ってください。ページを含む CodeNomad ウィンドウを閉じる、または再読み込みする前に、ページの作業を保存してください。

Tauri macOS/Linux では、プレビューにフォーカスして ⌘/Ctrl と +、−、0、またはアプリのズームメニューでプレビューを拡大・縮小できます。ほかの場所にフォーカスがある場合、これらのメニュー操作はアプリのズームを変更します。

## 6 種類のビューポートテンプレートから選ぶ {#templates}

1. プレビューのビューポートメニューを開きます。
2. 下表から選びます。縦／横の項目を直接使い、独立した回転コントロールはありません。
3. Electron と Windows Tauri では、モバイルエミュレーションの開始／変更や、寸法のみのテンプレートへ戻る際は、ネイティブの再読み込みが行われます。

| テンプレート | CSS ビューポート |
| --- | --- |
| レスポンシブビューポート | 利用可能なプレビュー領域 |
| デスクトップビューポート | 1440 × 900 |
| タブレットビューポート | 768 × 1024 |
| タブレット横向き | 1024 × 768 |
| モバイルビューポート | 390 × 844 |
| モバイル横向き | 844 × 390 |

Electron と Windows Tauri では、モバイルテンプレートは、所有するゲストにだけ Android/Chromium の識別、向き、タッチ、DPR 2.75 を設定します。レスポンシブ／デスクトップ／タブレットへ戻ると上書きを解除し再読み込みします。macOS/Linux Tauri は HTTP と JavaScript に汎用 WebKit モバイル識別を適用し、アプリのズームや DPI に依存せず CSS ビューポートを合わせ、テンプレートの変更やリセットで再読み込みします。代替 iframe はサイズのみ変更します。これらはレイアウトの基準で、携帯のキーボード、システムバー、モバイルの文字設定は対象外です。再読み込みで未送信のページ状態を失う場合があるため、テンプレート変更前にページ上の作業を保存してください。

## SideCar を登録する {#register-sidecar}

1. CodeNomad バックエンドホストで、ウェブツールを別途起動し、`127.0.0.1:<port>` で待ち受けます。
2. **設定 → SideCar** を開き、**名前** と **ポート** を入力し、算出された **ベースパス**（`/sidecars/<id>`）を確認します。
3. 上流サービスに合わせて **プロトコル** を設定し、**プレフィックスモード** を選びます。
4. **SideCar を追加** を選び、**参照** から開きます。 [プロジェクトタブ](projects.md#open-project).

実行中の SideCar は、タブを閉じても最近のタブに残ります。

| 選択 | 正確な効果 |
| --- | --- |
| HTTPS（フォームの既定） | CodeNomad は `https://127.0.0.1:<port>` として上流に接続します。 |
| HTTP | CodeNomad は `http://127.0.0.1:<port>` として上流に接続します。公開側の CodeNomad 接続の TLS 設定は変えません。 |
| プレフィックスを削除（既定） | `/sidecars/<id>/path` を `/path` として上流に転送します。 |
| プレフィックスを保持 | `/sidecars/<id>/path` を変更せずに上流へ転送します。サービス自体のベースパスを一致させてください。 |

登録はクライアント間で共有されるサーバー設定であり、サービスのインストールや起動はしません。ポートはバックエンドホスト上にあり、閲覧中のノートパソコンやスマートフォン上ではありません。登録を削除しても、別に起動したプロセスは停止しません。タブを閉じても停止しません。

到達できない場合はバックエンドのプロセスとポートを確認します。HTML は読めても資産／WebSocket が失敗する場合は、ツールのベースパスとプレフィックスモードを確認します。 誤った登録は目的の設定で作り直してください。プロキシエラーの回避だけのために上流を公開しないでください。SideCar アプリは、サーバーアカウントの権限でターミナルやファイルを公開できるため、利用者と設定を信頼する必要があります。

SideCar はサンドボックス化されたプレビューではなく、CodeNomad の信頼された拡張です。そのページは CodeNomad 自身のオリジンで動作するため、スクリプトはサインイン済みのアクセス権で CodeNomad を利用できます。コードを信頼できるサービスだけを登録してください。CodeNomad は自身のサインイン Cookie をサービスへ転送しませんが、サービス自身の Cookie は保持されます。

SideCar のコンテンツ（`/sidecars/`）と WebSocket には、ホスト上のループバック接続が必要です。他の端末からも開くには、ホストで **設定 → SideCar** の **HTTPS で SideCar を開く** をオンにします。このサーバーの HTTPS アドレス、または TLS リバースプロキシなど `CODENOMAD_ALLOWED_ORIGINS` の HTTPS オリジンからサインインしたブラウザーが SideCar を開けるようになります。通常の HTTP、`localhost` のアドレス、リモートコントロールはホスト専用のままです。`/api/sidecars` による登録は、ペアリング済み端末と認証済みの LAN 直接接続クライアントで利用できます。有効なケイパビリティトークンがあれば、アクティブなプレビューのコンテンツ（`/previews/`）は LAN からの直接アクセスで利用できます。[リモートコントロール](remote-control.md#remote-surface)の Web プレビューは、有効な間、ケイパビリティトークンで利用できます。直接アクセスの要件は[許可するオリジン](remote-access.md#upgrading)を参照してください。

## OpenVSCode Server の例 {#openvscode}

1. バックエンドホストで、サービスをループバックにバインドして Docker を実行します。

```sh
docker run -it --init -p 127.0.0.1:8000:3000 -v "${HOME}:${HOME}:cached" -e HOME=${HOME} gitpod/openvscode-server --server-base-path /sidecars/vscode
```

2. **名前** `VSCode`、**ポート** `8000`、**プロトコル** `HTTP`、**プレフィックスモード** **プレフィックスを保持** で登録します。
3. 表示されたベースパスが `/sidecars/vscode` であることを確認し、SideCar を開きます。

このシェルの例は、ホームディレクトリをコンテナーにマウントします。エディターのアクセス範囲を絞るなら、より狭いマウントを使用してください。サービスの `--server-base-path` は、登録と正確に一致する必要があります。終わったらコンテナーを別途停止してください。SideCar の削除ではコンテナーやそのファイルは削除されません。

## ttyd ターミナルの例 {#ttyd}

1. バックエンドホストで、書き込み可能なシェルターミナルをループバックにバインドして起動します。

```sh
ttyd --interface 127.0.0.1 --writable zsh
```

2. **名前** `Terminal`、**ポート** `7681`、**プロトコル** `HTTP`、**プレフィックスモード** **プレフィックスを削除** で登録します。
3. 表示された `/sidecars/terminal` ベースパスで SideCar を開きます。

ターミナルは ttyd を起動したアカウントの権限で実行します。`zsh` がなければ別のシェルを選びます。ttyd の既定ポートを変えた場合は実際のポートを使い、終了時は ttyd を別途停止してください。CodeNomad へのアクセスを認証・保護してください。書き込み可能なターミナルはサンドボックスではありません。
