# プロバイダーとアカウント

プロバイダー認証は、ブラウザー端末や 1 つの CodeNomad プロジェクトではなく、接続先の OpenCode サービスに属します。モデルの表示設定、サブスクリプションの割り当て量、ウェブ検索の選択は、それぞれ適用範囲が異なります。

## モデルまたは検索プロバイダーを接続する {#connect}

1. ワークスペースを開き、**設定 → プロバイダー** を開きます。**モデル** は展開された状態で始まります。検索プロバイダーには **ウェブ検索** を展開します。**画像** には画像の設定があります。
2. そのグループで **プロバイダーを選択**、続けて **接続** を選びます。下の一覧にあるモデルプロバイダーでは、初回の接続もその行の **アカウントを追加** (+) を使用します。
3. モデルプロバイダーでは、提供されたネイティブの **認証方法**（API キー、OAuth、コマンド）を完了します。OAuth では **認可ページを開く** を使用し、求められた場合にのみ認可コードを送信します。検索プロバイダーは API キーで接続します。
4. 完了後、設定済みプロバイダーの行を確認します。**モデル** は接続、アカウント変更、再接続の後に読み直します。**ウェブ検索** には **更新** もあります。

検索専用の連携は **モデル** ではなく **ウェブ検索** に表示されます。認証を保存しても、モデルの選択や既定の検索プロバイダーの変更は行いません。API キーと OAuth 認証情報は、アクティブな OpenCode サーバーが保存します。ブラウザーが受け取るのは接続のメタデータであり、保存済みの秘密情報ではありません。環境変数由来の接続は、この UI では読み取り専用です。ここで切断しようとせず、管理元の環境を変更してください。

認可ウィンドウがブロックされた場合は、フロー内の **認可ページを開く**、**このタブで開く**、**リンクをコピー** を使用します。認可リンクやコードを診断情報に公開しないでください。

## アカウントを選択・管理する {#accounts}

1. プロバイダーの行で **有効なアカウント** を使用し、保存済み認証情報を選びます。
2. 別の接続を認証するには **アカウントを追加** を使用します。
3. 別の保存済みアカウントを管理するには、先に選択してから **アカウント名を変更** または **アカウントを削除** を使用します。名前変更では **アカウント名** と **保存** を使用します。**アカウントを削除** は確認なしで直ちに実行されます。

選択、名前変更、削除は、他のプロジェクトやクライアントを含む OpenCode サービス全体のその連携に影響します。認証情報を削除すると、それらのクライアントが認証できなくなる場合があります。会話履歴の削除や、プロバイダーのリモートアカウントの失効は行いません。環境由来の接続を、書き込み可能な保存済み認証情報として選択したり、ここで削除したりはできません。操作に失敗すると CodeNomad はアカウントを読み直すので、再操作の前に **有効なアカウント** をもう一度確認してください。

### 自動選択の制限 {#automatic-selection}

対応する連携に保存済み認証情報が複数ある場合、**アカウントを自動選択** で、CodeNomad 経由の次のプロンプト／カスタムコマンド受け付け前に、割り当て量に基づく選択を有効にできます。設定は CodeNomad 設定内の連携ごとですが、結果のアカウント選択はサービス全体に適用されます。

| 対象の連携 | 対象のアカウント種別 |
| --- | --- |
| OpenAI / Codex | Codex のブラウザー／デバイス OAuth サブスクリプションアカウント。OpenAI の従量課金キーや、OpenAI が使用量を提供しない ChatGPT のサインイン方式は対象外です。 |
| OpenCode Go | Go キー、または **Go プロバイダーのみ** に使う OpenCode Console のログイン／キー。Console の有料モデルは手動選択です。 |
| Anthropic | OpenCode の Claude Pro/Max OAuth ログイン。Claude Code のログイン **ではありません**。 |
| GitHub Copilot | プレミアムリクエストの割り当て量を読み取れる OAuth。エンタープライズエンドポイントの認証情報は読み取り可能な候補ではありません。 |
| コーディングプラン | キー方式の `zai-coding-plan`、`zhipuai-coding-plan`、`kimi-for-coding`、`minimax-coding-plan`、`minimax-cn-coding-plan`。 |

現在のアカウントが上限に達した場合にのみ切り替えます。別のアカウントの余裕が大きいだけでは切り替えません。候補を有効化したり更新トークンを交換したりせず、明示的な保存済み認証情報を読み取ります。Codex、Copilot、コーディングプランは、利用可能と実証された候補が必要です。Go、Console、Claude は、最近のネイティブな割り当て量エラーで使い切ったと記録されていない限り、割り当て量不明の候補を使用する場合があります。OpenCode Go の読み取りは利用可能な API と認証情報の権限に依存します。

これは **実行途中のフェイルオーバーではありません**。失敗したリクエストの再試行や、プロンプト、コマンド、変更操作の再実行はしません。環境由来の接続、任意のプロバイダー、従量課金残高、外部の Claude Code ログインはローテーションしません。選択準備中の手動アカウント変更を尊重しますが、クライアント間のアカウントロックはありません。割り当て量／認証エラー時は、**有効なアカウント** を確認し、使用量を更新し、必要に応じて認証情報の管理元でログインしてから、意識的に再送信します。

## モデルの表示、お気に入り、思考 {#models}

1. モデルプロバイダー横の **モデルを管理** を選びます。
2. 名前／ID で検索して表示を変更します。**すべて表示** と **すべて非表示** は、そのプロバイダーのセレクター一覧に影響します。チェックボックスの上をドラッグすると、複数のモデルをまとめて変更できます。
3. 会話の **モデル** セレクターで **お気に入りに追加** または **お気に入りから削除** を使用します。**すべてのモデルを表示** は、お気に入りのみの絞り込みを解除します。
4. 選択したモデルのバリアントには、入力欄の **思考** を使用します。

表示とお気に入りは CodeNomad のセレクターを整理するもので、モデルのアンインストール、認証情報の削除、他の OpenCode クライアントによる利用の禁止は行いません。モデルを隠すことは、アカウントの切断ではありません。思考は、次の送信のモデルバリアントを選ぶもので、会話欄に既にある推論の表示設定ではありません。隠したモデルは **モデルを管理 → すべて表示** で戻せます。

## 使用量、トークン数、ログイン期限切れ {#usage}

右パネルの **使用量** で、アクティブな会話のプロバイダープランの期間、リセット時刻、対応する残高を確認します。これらのプロバイダー測定値は、メッセージごとの **トークン** や費用見積もりとは異なります。サブスクリプションの割り当て量は、表示中の会話から計算した請求額ではありません。欠落、古い、不明な測定値は、使用量ゼロや残容量の証拠ではありません。**設定 → 詳細設定** の **プロバイダーのクレジット残高** は、補足残高の表示を制御します。

OpenCode の Gemini CLI 認証方式を使用する Google 接続では、**使用量** にモデル別の上限を表示します。Antigravity 接続では **5時間** と **週間** の上限を表示し、提供される場合はモデルファミリーごとの枠を分けて表示します。割り当て量を取得できない場合は「使用量は一時的に利用できません。」と表示します。これらの接続のアカウント選択は手動です。

Google の [Antigravity FAQ](https://antigravity.google/docs/faq/) は、Antigravity のログインでサードパーティ製ソフトウェアを使用すると利用規約に違反し、アカウントの停止または終了につながる可能性があると説明しています。

`opencode` 連携の有料モデルでは、**OpenCode Console** に **リクエスト数** が **今日（UTC）**、**7日間（UTC）**、**30日間（UTC）** ごとに表示されます。期間は今日を含む UTC の暦日で、それぞれ今日、6日前、29日前の UTC 00:00 から始まります。**モデル別リクエスト数 · 30日間** には各モデルとプロバイダーが表示されます。集計対象は接続中の Console アカウントで、数値はアプリの言語に合わせて表示されます。**サービスアカウントの予算** には **予算を取得できません。** と表示されます。OpenCode Go は専用の使用枠リーダーを使います。

リーダーは保存済みの `opencode` API キーを使い、Console の OAuth 接続があればそちらを優先します。OAuth には `https://opencode.ai/console` と接続の組織 ID が必要で、Console へのアクセスには **Usage › Read** 権限が必要です。CodeNomad はこの認証情報を更新しません。OAuth 接続が無効または期限切れの場合、API キーも保存されていても、その認証情報を管理する側で接続を修復してください。

Console のエラーは、接続なし、認証情報が無効または期限切れ（401）、アクセス拒否（403）、無効な使用量応答、ネットワーク障害を区別します。接続エラーでは **設定 → プロバイダー** でログインと権限を確認し、**使用量** を更新してください。サマリーまたはモデル一覧の1ページでも取得に失敗すると、Console の集計全体が利用不可になります。

OpenCode の無料モデル（`big-pickle` と ID が `-free` で終わるモデル）では、**使用量** に **推定** と表示されます。このサービスが UTC 00:00 以降に記録したステップ数を1日200件の参考値と比較し、次の UTC 午前0時を推定リセット時刻とします。ステップ数はリクエスト数の近似で、他のクライアントの通信や変動する IP 制限により実際の使用枠は異なります。無料モデルのステップで使用枠エラーが発生すると、その OpenCode 接続の無料モデルすべてが UTC 00:00 まで **上限到達** になります。ゲージは100%になり、既知の件数は変わらず、不明な件数は不明のままです。この印は接続ごとにバックエンドのメモリに保存され、再起動で消去されます。

OpenCode Console に接続している場合、無料推定値にはローカルのステップ数と Console が UTC 00:00 以降に集計した無料モデルのリクエスト数の大きい方を使い、**推定**の表示を維持します。利用可能な接続がない場合や Console の読み取りに失敗した場合は、ローカルの推定値を保持します。Console の集計は他のクライアントや IP アドレスを含むアカウント全体が対象であり、IP ごとの上限とは異なる場合があります。推定値、上限到達の印、有料 Console カウンターは表示専用です。アカウントの自動選択は別の使用枠リーダーとルールを使います。

OpenAI は、ChatGPT のサインイン方式の 1 つについて使用量を提供していません。その場合、**使用量** は割り当て量の期間を表示する代わりにその旨を示します。[ChatGPT の使用状況を確認](https://chatgpt.com/settings/usage) を選ぶと、ChatGPT でアプリの使用状況を確認し、プランやクレジットへのアクセスを管理できます。チャットは引き続き利用でき、同じログインで再接続しても測定値は戻りません。

使用量の認証情報の取得元はプロバイダーによって異なります。`anthropic`／`claude` 経由の Claude は OpenCode の Anthropic OAuth を使用します。OpenCode の **Claude Agent** プロバイダー（`claude-agent`）と `claude-code` プロバイダーは、WSL ディストリビューションを含むデーモンホストの Claude Code ログインを使用します。`CLAUDE_CODE_OAUTH_TOKEN`、次に保存済みログインの順で、`CLAUDE_SECURESTORAGE_CONFIG_DIR`／`CLAUDE_CONFIG_DIR` または `~/.claude` がファイル保存場所を決めます。ローカル macOS では Keychain を使用できます。CodeNomad は、一方の Claude ログインを他方の代わりにしません。

使用量リーダーがアクセストークンを更新できるのは、使用のたびに更新トークンが変わらないプロバイダーに限り、サーバーメモリ内だけです。Gemini CLI と Antigravity が該当します。保存済み接続の管理は OpenCode が担います。その他のプロバイダーログインの期限が切れたら、管理元である OpenCode、Claude Code、Codex CLI で更新／ログインし、その後 CodeNomad を更新します。CodeNomad のサーバーログイン期限切れは別です。失敗したプロバイダーリクエストが再送されると思わず、CodeNomad へ再接続／ログインしてください。[トラブルシューティング](troubleshooting.md)を参照してください。

MiniMax が正常に応答しても上限を返さない場合、**使用量**にはクォータ値の代わりに **MiniMax は上限を公開していません** と表示されます。

OpenRouter の **キーの上限** は、キーの支出上限に対する USD の残額を表示します。上限のないキーにはこの行は表示されません。アカウントのクレジットは、API がアクセスを許可した場合に別途表示されます。使用量には、パスのプレフィックスを含むプロバイダーの設定済み `baseURL` を使用し、未設定時は `https://openrouter.ai/api/v1` を使用します。認証情報、明示的なポート、クエリ、フラグメントのない公開 HTTPS ホスト名を指定してください。IP アドレスと localhost は拒否されます。無効な URL や `/key` のないゲートウェイでは使用量を取得できません。キーは設定先だけに送信され、リダイレクトは拒否されます。

z.ai と Zhipu では、使用量は設定された `apiKey` を優先します。OpenCode がホスト上で解決した `{env:…}` と `{file:…}` の値も使用し、そのキーが利用できない場合は保存済みの認証情報を使用します。キーも保存済みの認証情報もない場合は未設定と表示されます。業務エラーでは、割り当て値の代わりに翻訳されたプロバイダーエラーと、取得できる場合は数値コードを表示します。プランのクレジットには 5 時間と週単位の枠があり、MCP ツールには別の割り当てがあります。

GitHub Copilot の **使用量** は **使用済み量 / 上限 使用済み** の形式で消費量を表示します。無制限の枠について GitHub が消費クレジットを返す場合はその値を表示し、それ以外は **無制限** と表示します。プレミアムリクエストのラベルは維持されます。下部には認識されたプラン名が表示されます。Enterprise 接続では、保存された接続のホスト名または HTTPS ルート URL を使い、`https://api.<host>/copilot_internal/user` にアクセスします。認証情報、明示的なポート（`:443` も含む）、`/` 以外のパス、クエリ、フラグメントのない完全修飾ホスト名を使用してください。IP アドレスと localhost はトークン送信前に拒否されます。リダイレクトは拒否されます。無効な宛先やこの API のないサーバーでは使用量を取得できません。Enterprise 接続は引き続きアカウントの自動選択の対象外です。

Kimi は `kimi-code-plan-cn`（kimi.com）、`kimi-code-plan-global`（kimi.ai）、`kimi-for-coding`、`kimi` に対応しています。**使用量**は会話のインテグレーションを優先し、各インテグレーションで有効な保存済みキーを共通の制限時間内で順に試します。利用可能な5時間、週間、**月間**、**月間コーディング**の上限は使用率で表示されます。月間上限はプロバイダーのリセット日時に従います。いずれかの月間上限を使い切った `kimi-for-coding` アカウントは、短い期間の枠に余裕があっても自動選択の候補にはなりません。

OpenCode Go の API キーでは、取得できる使用率とリセット時刻を表示します。OpenCode Console ログインでは、請求の閲覧権限があればウォレット残高も USD で取得します。独立した残高を表示するには **プロバイダーのクレジット残高** を有効にします（既定はオフ）。Go の割り当て量と Extra Usage は別です。残高だけでは自動選択の割り当て量は不明のままです。**OpenCode Go キーの有効期限が切れています。** と表示されたら、[OpenCode Console で新しいキーを作成して置き換える](https://opencode.ai/console/login) を選びます。**Account → Personal API keys** でキーを作成し（または管理者にサービスアカウント用キーを依頼し）、プロバイダーの接続手順で保存済みキーを置き換えてください。期限切れキーは交換が必要です。

### 任意の使用量用環境変数 {#usage-environment}

Cursor Enterprise は非公開のダッシュボード API をベストエフォートで使用します。プロファイルにチーム所属とチーム ID がある場合、**使用量**には識別できる `gpt-4` のリクエスト枠と、提供された **ユーザーごとの上限** / **チームの上限**が USD で個別に表示されます。支出が不明な場合は上限のみ、リクエスト上限が不明な場合は使用数のみを表示します。不明な枠やリセット日時は未取得のままです。チーム不明、アクセス拒否、トークン期限切れには別々のメッセージが表示され、確認済みの部分データは表示されます。

以下の変数で有効な Cursor アクセストークンを指定してください。Enterprise の読み取りにはチームのダッシュボードデータの閲覧権限が必要です。[管理 API](https://cursor.com/docs/account/teams/admin-api) は別の管理キーを使用します。期限切れのトークンを更新し、更新した環境でバックエンドを再起動してください。

起動前に、**CodeNomad バックエンドプロセス** の環境に設定します。使用量リーダーの認証情報であり、ブラウザー設定やモデル選択コントロールではありません。セッションの **環境変数** エディターを変更しても、これらのリーダーが使う稼働中バックエンドの `process.env` は更新されません。変更時は意図した環境でバックエンドを再起動します。使用量リーダーの変数だけのために共有 OpenCode サービスを再起動しないでください。

| 使用量の連携 | 環境変数 |
| --- | --- |
| Cursor | `CURSOR_ACCESS_TOKEN`、なければ `CURSOR_TOKEN` |
| Ollama Cloud | `OLLAMA_CLOUD_COOKIE` |
| OpenCode Go の補足使用量 | `OPENCODE_GO_WORKSPACE_ID` と `OPENCODE_GO_AUTH_COOKIE` を両方指定 |
| ZenMux | `ZENMUX_PLATFORM_API_KEY` — 推論キーとは別のプラットフォームキー |
| exe.dev | `EXE_DEV_USAGE_TOKEN` |
| Command Code | ネイティブ認証情報がない場合の `COMMAND_CODE_API_KEY` |

トークン／Cookie をシェル履歴、スクリーンショット、レポートに残さないでください。任意のリーダーはプロバイダー API と認証情報の有効性に依存します。変数の設定は、使用可能な割り当て量データを保証しません。

## ウェブ検索の既定値とプロジェクト上書き {#web-search}

1. **設定 → プロバイダー** で **ウェブ検索** を展開し、必要なら API キーで検索連携を接続します。
2. グローバル設定には **既定の検索** を選びます。
3. **現在のプロジェクト用** で、アクティブな Location の設定を上書きします。そのセレクターにカーソルを合わせるかフォーカスすると、実効結果を示す **このプロジェクトの検索** が表示されます。

変更は自動保存されます。**既定 / 継承** は継承設定または保存済みネイティブ選択を使用し、プロジェクトの上書きはグローバルより優先します。**無効** は選択範囲の検索をオフにし、**自動プロバイダー** はネイティブの自動プロバイダー選択を要求します。**ウェブ検索** は、展開している間だけ接続と選択を読み込みます。**切断** は保存済みの検索キーを削除します。環境変数で提供される接続は読み取り専用と表示され、**切断** はありません。

プロバイダー選択がプロジェクト範囲でも、検索の認証情報はサービス全体で共有されます。キーを保存しても検索の既定には選ばれません。読み取り／保存に失敗したら、無条件で設定を置き換えず、更新してから再試行します。ネイティブ設定の詳細は、[OpenCode ドキュメント](https://opencode.ai/v2/docs/)と [OpenCode のセットアップ](opencode.md)を参照してください。

## 画像の生成と保存 {#images}

1. **設定 → プロバイダー** で **画像** を展開します。
2. **画像生成** は、変更しない限り **オン（モデルは自動）** です。代わりに接続済みプロバイダーが提供する画像モデルのいずれかを選ぶか、**オフ** を選んでグローバル設定で無効にします。
3. **画像を一度だけ保存** をオンにすると、添付または生成された画像を、それを使う各メッセージ内ではなく一度だけ保存します。

変更は自動的にグローバルの OpenCode 設定に保存され、すべてのプロジェクトに適用されます。どちらも OpenCode の実験的機能です。**画像** には接続中の OpenCode バージョンが対応する設定だけが表示されます。エージェントが画像ツールを使えるのは、接続済みプロバイダーが画像モデルを提供している間だけです。画像はバックグラウンドで生成され、ファイルとして保存されます。エージェントがそのパスを伝えます。**画像を一度だけ保存** は新しいメッセージに適用されます。プロジェクト独自の OpenCode 設定ファイルが **画像を一度だけ保存** を決めている場合、チェックボックスにはそこで適用される値が表示され、保存するとそのファイルにも書き込まれます。それ以外で、プロジェクト独自の設定など、別の OpenCode 設定が代わりに設定を決めている場合、**画像** はその設定の下にそれを表示します。保存すると別の OpenCode 設定ファイルの実験的設定が隠れてしまう場合、**画像** は読み取り専用になり、その旨を表示します。代わりにそのファイルでオプションを変更してください。

専用の会話で画像を作成、比較、改良するには、[Design 拡張機能で画像を作成する](extensions.md#design) を参照してください。
