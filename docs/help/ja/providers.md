# プロバイダーとアカウント

プロバイダー認証は、ブラウザー端末や 1 つの CodeNomad プロジェクトではなく、接続先の OpenCode サービスに属します。モデルの表示設定、サブスクリプションの割り当て量、ウェブ検索の選択は、それぞれ適用範囲が異なります。

## モデルまたは検索プロバイダーを接続する {#connect}

1. ワークスペースを開き、**設定 → プロバイダー** を開きます。**モデル** は展開された状態で始まります。検索プロバイダーには **ウェブ検索** を展開します。**画像** には画像の設定があります。
2. そのグループで **プロバイダーを選択**、続けて **接続** を選びます。下の一覧にあるモデルプロバイダーでは、初回の接続もその行の **アカウントを追加** (+) を使用します。
3. モデルプロバイダーでは、提供されたネイティブの **認証方法**（API キー、OAuth、コマンド）を完了します。OAuth では **認可ページを開く** を使用し、求められた場合にのみ認可コードを送信します。検索プロバイダーは API キーで接続します。
4. 完了後、設定済みプロバイダーの行を確認します。

検索専用の連携は **モデル** ではなく **ウェブ検索** に表示されます。認証を保存しても、モデルの選択や既定の検索プロバイダーの変更は行いません。API キーと OAuth 認証情報は、アクティブな OpenCode サーバーが保存します。ブラウザーが受け取るのは接続のメタデータであり、保存済みの秘密情報ではありません。環境変数由来の接続は、この UI では読み取り専用です。ここで切断しようとせず、管理元の環境を変更してください。

認可リンクやコードを診断情報に公開しないでください。

## アカウントを選択・管理する {#accounts}

1. プロバイダーの行で **有効なアカウント** を使用し、保存済み認証情報を選びます。
2. 別の接続を認証するには **アカウントを追加** を使用します。
3. 別の保存済みアカウントを管理するには、先に選択してから **アカウント名を変更** または **アカウントを削除** を使用します。名前変更では **アカウント名** と **保存** を使用します。**アカウントを削除** は確認なしで直ちに実行されます。

選択、名前変更、削除は、他のプロジェクトやクライアントを含む OpenCode サービス全体のその連携に影響します。認証情報を削除すると、それらのクライアントが認証できなくなる場合があります。会話履歴の削除や、プロバイダーのリモートアカウントの失効は行いません。環境由来の接続を、書き込み可能な保存済み認証情報として選択したり、ここで削除したりはできません。

### 自動選択の制限 {#automatic-selection}

対応する連携に保存済み認証情報が複数ある場合、**アカウントを自動選択** で、CodeNomad 経由の次のプロンプト／カスタムコマンド受け付け前に、割り当て量に基づく選択を有効にできます。設定は CodeNomad 設定内の連携ごとですが、結果のアカウント選択はサービス全体に適用されます。

| 対象の連携 | 対象のアカウント種別 |
| --- | --- |
| OpenAI / Codex | Codex のブラウザー／デバイス OAuth サブスクリプションアカウント。OpenAI の従量課金キーや、OpenAI が使用量を提供しない ChatGPT のサインイン方式は対象外です。 |
| OpenCode Go | Go キー、または **Go プロバイダーのみ** に使う OpenCode Console のログイン／キー。Console の有料モデルは手動選択です。 |
| Anthropic | OpenCode の Claude Pro/Max OAuth ログイン。Claude Code のログイン **ではありません**。 |
| GitHub Copilot | プレミアムリクエストの割り当て量を読み取れる OAuth。エンタープライズエンドポイントの認証情報は読み取り可能な候補ではありません。 |
| コーディングプラン | キー方式の `zai-coding-plan`、`zhipuai-coding-plan`、`kimi-for-coding`、`minimax-coding-plan`、`minimax-cn-coding-plan`。 |

現在のアカウントが上限に達した場合にのみ切り替えます。別のアカウントの余裕が大きいだけでは切り替えません。Codex、Copilot、コーディングプランは、利用可能と実証された候補が必要です。Go、Console、Claude は、最近のネイティブな割り当て量エラーで使い切ったと記録されていない限り、割り当て量不明の候補を使用する場合があります。

これは **実行途中のフェイルオーバーではありません**。失敗したリクエストの再試行や、プロンプト、コマンド、変更操作の再実行はしません。環境由来の接続、任意のプロバイダー、従量課金残高、外部の Claude Code ログインはローテーションしません。

## モデルの表示、お気に入り、思考 {#models}

1. モデルプロバイダー横の **モデルを管理** を選びます。
2. 名前／ID で検索して表示を変更します。**すべて表示** と **すべて非表示** は、そのプロバイダーのセレクター一覧に影響します。チェックボックスの上をドラッグすると、複数のモデルをまとめて変更できます。
3. 会話の **モデル** セレクターで **お気に入りに追加** または **お気に入りから削除** を使用します。**すべてのモデルを表示** は、お気に入りのみの絞り込みを解除します。
4. 選択したモデルのバリアントには、入力欄の **思考** を使用します。

表示とお気に入りは CodeNomad のセレクターを整理するもので、モデルのアンインストール、認証情報の削除、他の OpenCode クライアントによる利用の禁止は行いません。思考は、次の送信のモデルバリアントを選ぶもので、会話欄に既にある推論の表示設定ではありません。隠したモデルは **モデルを管理 → すべて表示** で戻せます。

## 使用量、トークン数、ログイン期限切れ {#usage}

右パネルの **使用量** で、アクティブな会話のプロバイダープランの期間、リセット時刻、対応する残高を確認します。これらのプロバイダー測定値は、メッセージごとの **トークン** や費用見積もりとは異なります。サブスクリプションの割り当て量は、表示中の会話から計算した請求額ではありません。欠落、古い、不明な測定値は、使用量ゼロや残容量の証拠ではありません。**設定 → 詳細設定** の **プロバイダーのクレジット残高** は、補足残高の表示を制御します。

Google の [Antigravity FAQ](https://antigravity.google/docs/faq/) は、Antigravity のログインでサードパーティ製ソフトウェアを使用すると利用規約に違反し、アカウントの停止または終了につながる可能性があると説明しています。

`opencode` 連携の有料モデルでは、**OpenCode Console** に Console が報告する **24時間**、**7日間**、**30日間** の **リクエスト数** が表示されます。**モデル別リクエスト数 · 30日間** には各モデルとプロバイダーが表示されます。集計対象は接続中の Console アカウントで、数値はアプリの言語に合わせて表示されます。**サービスアカウントの予算** には **予算を取得できません。** と表示されます。**プロバイダーのクレジット残高** を有効にすると、Console のクレジット残高が **クレジット** として表示されます。OpenCode Go は専用の使用枠リーダーを使います。

Console の OAuth 接続が無効または期限切れの場合、API キーも保存されていても、その認証情報を管理する側で接続を修復してください。

Console の接続エラー（401 または 403）では、**設定 → プロバイダー**でログイン、組織 ID、**Usage › Read** 権限を確認し、**使用量**を更新してください。OAuth には `https://opencode.ai/console` が必要です。

OpenCode の無料モデル（`big-pickle` と ID が `-free` で終わるモデル）では、**使用量** に 1 本のバーが表示されます。接続中の Console アカウントの、Console が報告する直近 24 時間の無料リクエスト数を **800** 件の基準値と比較します。実際の上限は異なる場合があります。件数には同じアカウントの他のクライアントも含まれ、リセット時刻はありません。**プロバイダーのクレジット残高** を有効にすると、Console のクレジット残高が **クレジット** として表示されます。無料モデルのリクエスト数を確認するには、**設定 → プロバイダー** で OpenCode Console に接続してください。

無料使用量と有料 Console カウンターは表示専用です。アカウントの自動選択は別のリーダーとルールを使います。

OpenAI は、ChatGPT のサインイン方式の 1 つについて使用量を提供していません。その場合、**使用量** は割り当て量の期間を表示する代わりにその旨を示します。[ChatGPT の使用状況を確認](https://chatgpt.com/settings/usage) を選ぶと、ChatGPT でアプリの使用状況を確認し、プランやクレジットへのアクセスを管理できます。

`anthropic`／`claude` 経由の Claude は OpenCode の Anthropic OAuth を使用します。OpenCode の **Claude Agent** プロバイダー（`claude-agent`）と `claude-code` プロバイダーは、WSL ディストリビューションを含むデーモンホストの Claude Code ログインを使用します。`CLAUDE_CODE_OAUTH_TOKEN`、次に保存済みログインの順で、`CLAUDE_SECURESTORAGE_CONFIG_DIR`／`CLAUDE_CONFIG_DIR` または `~/.claude` がファイル保存場所を決めます。ローカル macOS では Keychain を使用できます。

OpenRouter の **キーの上限** は、キーの支出上限に対する USD の残額を表示します。上限のないキーにはこの行は表示されません。使用量には、パスのプレフィックスを含むプロバイダーの設定済み `baseURL` を使用し、未設定時は `https://openrouter.ai/api/v1` を使用します。認証情報、明示的なポート、クエリ、フラグメントのない公開 HTTPS ホスト名を指定してください。IP アドレスと localhost は拒否されます。キーは設定先だけに送信され、リダイレクトは拒否されます。

GitHub Copilot の **使用量** は **使用済み量 / 上限 使用済み** の形式で消費量を表示します。無制限の枠について GitHub が消費クレジットを返す場合はその値を表示し、それ以外は **無制限** と表示します。Enterprise 接続では、保存された接続のホスト名または HTTPS ルート URL を使い、`https://api.<host>/copilot_internal/user` にアクセスします。認証情報、明示的なポート（`:443` も含む）、`/` 以外のパス、クエリ、フラグメントのない完全修飾ホスト名を使用してください。IP アドレスと localhost はトークン送信前に拒否されます。リダイレクトは拒否されます。Enterprise 接続は引き続きアカウントの自動選択の対象外です。

Kimi は `kimi-code-plan-cn`、`kimi-code-plan-global`、`kimi-for-coding`、`kimi` に対応しています。利用可能な5時間、週間、**月間**、**月間コーディング**の上限は使用率で表示されます。

月間上限はプロバイダーのリセット日時に従います。いずれかの月間上限を使い切った `kimi-for-coding` アカウントは、短い期間の枠に余裕があっても自動選択の候補にはなりません。

OpenCode Go の API キーでは、取得できる使用率とリセット時刻を表示します。OpenCode Console ログインでは、請求の閲覧権限があればウォレット残高も USD で取得します。独立した残高を表示するには **プロバイダーのクレジット残高** を有効にします（既定はオフ）。Go の割り当て量と Extra Usage は別です。残高だけでは自動選択の割り当て量は不明のままです。

**使用量は一時的に利用できません。** または **OpenCode Console に接続できません。** では、ネットワーク接続を確認して **使用量** を更新してください。

OpenCode Go キーの期限が切れた場合は、[OpenCode Console](https://opencode.ai/console/login) の **Account → Personal API keys** で新しいキーを作成し、プロバイダーの接続手順で保存済みキーを置き換えてください。

### 任意の使用量用環境変数 {#usage-environment}

以下の変数で有効な Cursor アクセストークンを指定してください。Enterprise の読み取りにはチームのダッシュボードデータの閲覧権限が必要です。[管理 API](https://cursor.com/docs/account/teams/admin-api) は別の管理キーを使用します。期限切れのトークンを更新し、更新した環境でバックエンドを再起動してください。

起動前に、**CodeNomad バックエンドプロセス** の環境に設定します。セッションの **環境変数** エディターを変更しても、これらのリーダーが使う稼働中バックエンドの `process.env` は更新されません。変更時は意図した環境でバックエンドを再起動します。使用量リーダーの変数だけのために共有 OpenCode サービスを再起動しないでください。

| 使用量の連携 | 環境変数 |
| --- | --- |
| Cursor | `CURSOR_ACCESS_TOKEN`、なければ `CURSOR_TOKEN` |
| Ollama Cloud | `OLLAMA_CLOUD_COOKIE` |
| OpenCode Go の補足使用量 | `OPENCODE_GO_WORKSPACE_ID` と `OPENCODE_GO_AUTH_COOKIE` を両方指定 |
| ZenMux | `ZENMUX_PLATFORM_API_KEY` — 推論キーとは別のプラットフォームキー |
| exe.dev | `EXE_DEV_USAGE_TOKEN` |
| Command Code | ネイティブ認証情報がない場合の `COMMAND_CODE_API_KEY` |

トークン／Cookie をシェル履歴、スクリーンショット、レポートに残さないでください。

## ウェブ検索の既定値とプロジェクト上書き {#web-search}

1. **設定 → プロバイダー** で **ウェブ検索** を展開し、必要なら API キーで検索連携を接続します。
2. グローバル設定には **既定の検索** を選びます。
3. **現在のプロジェクト用** で、アクティブな Location の設定を上書きします。そのセレクターにカーソルを合わせるかフォーカスすると、実効結果を示す **このプロジェクトの検索** が表示されます。

変更は自動保存されます。**既定 / 継承** は継承設定または保存済みネイティブ選択を使用し、プロジェクトの上書きはグローバルより優先します。**無効** は選択範囲の検索をオフにし、**自動プロバイダー** はネイティブの自動プロバイダー選択を要求します。**切断** は保存済みの検索キーを削除します。環境変数で提供される接続は読み取り専用と表示され、**切断** はありません。

プロバイダー選択がプロジェクト範囲でも、検索の認証情報はサービス全体で共有されます。キーを保存しても検索の既定には選ばれません。ネイティブ設定の詳細は、[OpenCode ドキュメント](https://opencode.ai/v2/docs/)と [OpenCode のセットアップ](opencode.md)を参照してください。

## 画像の生成と保存 {#images}

1. **設定 → プロバイダー** で **画像** を展開します。
2. **画像生成** は、変更しない限り **オン（モデルは自動）** です。代わりに接続済みプロバイダーが提供する画像モデルのいずれかを選ぶか、**オフ** を選んでグローバル設定で無効にします。
3. **画像を一度だけ保存** をオンにすると、添付または生成された画像を、それを使う各メッセージ内ではなく一度だけ保存します。

変更は自動的にグローバルの OpenCode 設定に保存され、すべてのプロジェクトに適用されます。どちらも OpenCode の実験的機能です。**画像** には接続中の OpenCode バージョンが対応する設定だけが表示されます。エージェントが画像ツールを使えるのは、接続済みプロバイダーが画像モデルを提供している間だけです。**画像を一度だけ保存** は新しいメッセージに適用されます。プロジェクト独自の OpenCode 設定ファイルが **画像を一度だけ保存** を決めている場合、チェックボックスにはそこで適用される値が表示され、保存するとそのファイルにも書き込まれます。保存すると他の OpenCode 設定が隠れる場合、**画像** は読み取り専用になります。警告のツールチップに表示される設定ファイルで変更してください。

専用の会話で画像を作成、比較、改良するには、[Design 拡張機能で画像を作成する](extensions.md#design) を参照してください。
