# キーボードショートカット

## コマンドを探してヘルプを開く {#discover-commands}

1. Windows/Linux の `Ctrl+Shift+P`、macOS の `Cmd+Shift+P`、または表示中のボタン／メニュー項目で **コマンドパレット** を開きます。
2. 操作名を入力します。パレットにはアプリ操作と現在の Location のカスタムコマンドが含まれ、利用可否はアクティブな表示に依存します。
3. **ヘルプを開く** を実行すると、現在の UI 言語のガイドを外部ブラウザーのコンテキストで開きます。ネイティブの **ヘルプ → CodeNomad ヘルプ** も同じガイドを開きます。

ヘルプを開いても、アプリの表示と下書きはそのままです。開けない場合は [CodeNomad Help](https://neuralnomadsai.github.io/CodeNomad/) に直接アクセスしてください。コマンドが見つかることは、ショートカットをカスタマイズできることを意味しません。ショートカット管理の対象は、74 個のレンダラー操作からなる固定のカタログであり、すべてのパレット／ネイティブメニュー操作ではありません。カタログには、**ショートカットなし** で始まる **セッションをコンパクト化**、**直前のメッセージを取り消す**、**ヘルプを開く** などのパレットコマンドも含まれます。プロジェクトフォルダー、ターミナル、エディターの操作は、ローカルのデスクトップウィンドウでのみ実行されます。

## 記録、無効化、リセット {#customize}

1. **設定 → キーボードショートカット** を開き、**ショートカットを絞り込む** で操作またはキーの組み合わせを探します。
2. **編集** を選び、**キーの組み合わせを押してください** で目的の組み合わせを押します。記録すると割り当てが保存されます。
3. **ショートカットを消去**（×）でその操作のレンダラー割り当てを削除し、**リセット** で既定に戻します。**すべてリセット** は全レンダラー割り当てを戻します。
4. 競合するすべての行の警告を解消します。競合は報告され、無断で無効化されません。

割り当ては CodeNomad の UI 設定に保存され、その設定を共有するクライアントに影響します。OpenCode の CLI/TUI の割り当てや、ネイティブメニューのアクセラレーターは編集しません。記録中はアプリのレンダラーショートカットを抑止しますが、OS やネイティブメニューは抑止できません。**キャンセル**、フォーカスの喪失、セクションを閉じる操作、ウィンドウからの移動で記録を終了します。修飾キーだけの入力と IME 変換中の入力は無視し、通常の Tab/Shift+Tab はフォーカスを移動します。

保存に失敗した場合は古いショートカットを使える状態にし、表示された割り当てを確認してから再試行します。誤って割り当てた場合は、リセットが安全な復旧方法です。

## レンダラーの既定値 {#renderer-defaults}

`Mod` は Windows/Linux では `Ctrl`、macOS では `Cmd` です。これらは既定値であり、OS／ネイティブホストからキーが届く保証ではありません。範囲が重要です。同じキーでも、ホームページ、入力欄、検索では別の操作になる場合があります。

| 操作 | 既定値 |
| --- | --- |
| コマンドパレットを開く | `Mod+Shift+P` |
| 新しいインスタンス／ホームページでフォルダーを参照 | `Mod+N` |
| アプリタブを閉じる | `Mod+W` |
| 前／次のアプリタブ | `Mod+[` / `Mod+]` |
| アプリタブ 1〜9 | `Mod+1` から `Mod+9` |
| インスタンス名を変更（タブのコンテキスト） | `F2` |
| 新しいセッション | `Mod+Shift+N` |
| セッションを閉じる | `Mod+Shift+W` |
| 前／次のセッション | `Mod+Shift+[` / `Mod+Shift+]` |
| セッションタブ 1〜9 | `Mod+Shift+1` から `Mod+Shift+9` |
| インスタンス情報 | `Mod+Shift+L` |
| セッション履歴を検索 | `Mod+F` |
| 前 / 次のユーザーメッセージ（会話内、テキスト入力欄の外） | `Shift+ArrowUp` / `Shift+ArrowDown` |
| 次／前の検索結果（検索にフォーカス中） | `Enter` / `Shift+Enter` |
| 入力欄にフォーカス／入力を消去 | `Mod+P` / `Mod+K` |
| モデル／エージェントセレクターを開く | `Mod+Shift+M` / `Mod+Shift+A` |
| モデルバリアントを選ぶ | `Mod+Shift+T` |
| ブロック中のツールをバックグラウンドへ移す（入力欄） | `Mod+B` |
| 入力を送信 | `Enter` |
| 別のフォローアップ動作で送信 | `Alt+Enter` (Windows, Linux) または `Mod+Shift+Enter` |
| 改行を挿入 | `Shift+Enter` または `Mod+Enter` |
| 前／次のプロンプト（入力欄） | `ArrowUp` / `ArrowDown` |
| 入力欄のフォーカス解除／シェルモード終了 | 入力欄の文脈に応じて `Escape` |
| セッションを停止 | `Escape` を 2 回。1 回目で確認を表示 |
| 補足質問を送信（`/btw` ウィンドウ） | `Mod+Enter` |
| ファイルを保存（ワークスペースエディター） | `Mod+S` |

Enter で送信しない設定の場合、**入力を送信** の既定は `Mod+Enter`、**改行を挿入** は `Enter` または `Shift+Enter` です。明示的なショートカット上書きはその既定値を置き換えます。実効の割り当ては管理画面で確認してください。macOS では `Option+Return` は改行のままなので、別の動作で送信するのは `Cmd+Shift+Return` だけです。セッションの作業中は、入力欄の **その他の操作** メニューでも同じ選択（**メッセージをキューに追加** または **今すぐ割り込む**）ができます。**入力を消去** は、新しい会話の最初の下書きを含め、入力欄自身のクリア操作を実行します。前／次のセッションはセッション一覧を巡回するもので、ショートカットのない、サイドバーのブラウザー風の **戻る**／**進む** 履歴とは異なります。

## ネイティブキーとプラットフォームの割り込み {#native-keys}

ネイティブキーは固定で、対応するレンダラー割り当てを変更／無効化しても有効です。特にネイティブの **新規ウィンドウ** は、レンダラーの新しいセッションの既定と同じ `Mod+Shift+N` を使います。ネイティブメニューに先取りされる場合は、表示された新しいセッションのコントロールを使うか、レンダラー操作の割り当てを変更します。同様に、ネイティブの `Mod+W` はアプリタブだけでなくウィンドウを閉じる場合があります。

| ネイティブ操作 | Electron | Tauri |
| --- | --- | --- |
| 新規ウィンドウ | `Mod+Shift+N` | `Mod+Shift+N` |
| 新しいインスタンス / コマンドパレット | `Mod+N` / `Mod+Shift+P` | `Mod+N` / `Mod+Shift+P` |
| 再読み込み / 強制再読み込み | `Mod+R` / `Mod+Shift+R` | `Mod+R` / `Mod+Shift+R` |
| 実際のサイズ | `Mod+0` | `Mod+0` |
| 拡大 / 縮小 | `Mod+Plus` / `Mod+-` | 表示メニューの操作とプラットフォームの webview ズーム入力 |
| フルスクリーン | Windows/Linux は `F11`、macOS は `Ctrl+Cmd+F` | macOS はメニューアクセラレーターの `Ctrl+Cmd+F`、他の環境はメニューを使用 |
| 開発者ツール | Windows/Linux は `Ctrl+Shift+I`、macOS は `Alt+Cmd+I` | `Alt+Mod+I` |

通常のブラウザーウィンドウにも、ブラウザーのショートカットが残ります。割り当てが CodeNomad に届かない場合は、セキュリティを無効にしたり OS 全体のキーを変更したりせず、別の組み合わせを選んでください。

## キーボード配列と文字入力 {#layouts-ime}

数字列と角括弧のショートカットは、AZERTY/QWERTZ 配列を含め、記録、実行、競合確認に物理キー位置を使用します。他のキーは論理値を使います。使用する予定のキーボードで記録し、表示結果を確認してください。

IME 変換中は文字入力を優先します。プロンプト履歴と Escape 操作も、フォーカス、ピッカー／シェルの状態、現在の操作に依存します。ArrowUp や Escape が常に無条件のグローバル操作だとは想定しないでください。デスクトップでは、送信するとフォーカスが会話に移るため、矢印、ページ送りキー、Space で会話をスクロールできます。文字を入力すると、その文字とともに入力欄に戻ります。プロンプト履歴を使う前には **入力にフォーカス** で入力欄に戻ります。コマンドパレット、検索、新しいセッション、情報、入力欄のセレクターなどのコントロールでは、ツールチップに現在のショートカットが表示されます。ショートカット管理画面とあわせて、常設のキーボードヘルプ欄を追加せずに割り当てを確認できます。
