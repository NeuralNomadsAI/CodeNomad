# 設定とレイアウト

## 設定を開き、範囲を確認する {#open-settings}

1. ホームページまたはコマンドパレットから **設定** を開きます。
2. セクションを選びます。ローカルの Electron／Tauri ウィンドウは、単一のネイティブ設定ウィンドウを開くかフォーカスします。ブラウザー／リモート表示は埋め込み設定画面を使います。
3. 離れる前に、設定の範囲と **保存** 操作の有無を確認します。

ほとんどのスイッチは直ちに適用されます。音声、パレット、ミッション設定などのエディターには、明示的な保存操作があります。保存失敗は変更が反映された確認ではありません。再試行前に該当セクションを開き直すか更新してください。

| 状態 | 制御するもの |
| --- | --- |
| CodeNomad 設定 | その設定を使用するクライアントの UI 設定、音声、SideCar、サーバー設定。UI の「このデバイス」バッジは、同じ設定を共有する他クライアントからの分離を保証しません。 |
| ウィンドウ／プロジェクトタブのレイアウト | 開いているパネル、選択タブ、リーダー状態、復元可能な下書き／レイアウト。OpenCode 設定ではありません。 |
| グローバル／プロジェクトの OpenCode 設定 | 表示範囲のネイティブなプラグイン／設定変更。プロジェクト操作にはアクティブなプロジェクト／Location が必要です。 |
| デスクトップデータプロファイル | 設定ファイルや共有 OpenCode サービスとは独立した、ネイティブウィンドウ、復元状態、ブラウザーストレージ。[デスクトップのウィンドウとデータ](desktop.md)を参照してください。 |

表示設定を変更しても、OpenCode の再起動やプロンプトの再実行は行いません。ネイティブ設定、サービス保守、認証情報の影響は別です。[OpenCode のセットアップ](opencode.md)、[プロバイダー](providers.md)、[連携](integrations.md)を参照してください。

## 言語と外観 {#language-appearance}

1. **一般** の **言語** で、英語、スペイン語、フランス語、ロシア語、日本語、簡体字中国語、ヘブライ語、ドイツ語、ネパール語、トルコ語を選びます。
2. **外観モード** に **自動**、**ライト**、**ダーク** を選びます。自動は OS に従います。
3. 表示中の外観のパレットを選びます。ライトとダークの選択は独立して保存され、自動では対応するものを使います。
4. 色をカスタマイズするには、色見本と **保存** を使います。**リセット** はそのパレットの色を復元します。別のパレットに名前を付けるには **新規** を使用します。

UI は会話を再起動せずに更新されます。ヘブライ語では右から左のレイアウトを使い、コードや技術値はそれぞれの方向で読みやすく保ちます。言語選択はインターフェースのテキストを変えますが、既存メッセージやエージェント指示の言語は変えません。OS ネイティブのメニューは英語のままの場合があります。

色が読みにくくなったら、組み込みパレットを選ぶか編集したものをリセットします。パレットを切り替えると未保存の色編集を破棄するか確認する場合がありますが、会話の下書きは破棄しません。

## パネルとステータスのセクション {#panels-status}

1. 外側のヘッダー隅の **左パネル** と **右パネル**、または **View** メニュー内の項目で、それぞれを表示／非表示にします。
2. 右パネルの **右パネルをカスタマイズ** を開きます。チェックボックスで組み込みタブとステータスのセクションを選びます。ステータスの最低 1 セクションは表示されます。
3. 右パネルのタブをドラッグして並べ替えます。**リセット** で組み込みレイアウトの選択を復元します。

ステータスには、トークン情報、Yolo モード、プロバイダーの使用量、バックグラウンドプロセス、MCP、プラグインがあります。セクションを隠しても、サービスの無効化や権限の取り消しはしません。狭いレイアウトでは、会話を圧迫せずパネルが上に浮かび、一方のフローティングパネルを開くと他方は閉じます。

組み込みレイアウトはウィンドウのレイアウトであり、プロジェクトの変更操作ではありません。拡張機能のチェックボックスは異なり、その設定を使う全プロジェクトでコードを有効化します。**リセット** は拡張機能の同意を変更しません。[パネル拡張機能](extensions.md)を参照してください。

## 会話表示の詳細と入力欄のサイズ {#transcript-composer}

1. **チャット** を開いて会話表示の詳細の既定値を選びます。プリセットは **Minimal**、**Balanced**、**Detailed**、**Everything** です。個別変更では **Custom** になります。
2. 思考、ツールの入出力、診断、トークン詳細を調整するか、会話の **メッセージの内容** ポップアップで共通の表示コントロールを使います。
3. **一般** で、必要に応じて **メッセージタイムライン**、**タイムラインのツール呼び出し**、**差分表示**、**フォローアップの動作** を調整します。
4. サイズ変更コントロールで入力欄を調整します。長い下書きはフィールド内でスクロールします。

表示と展開の設定は、見せ方だけを変えます。保存済みのツール／推論の削除や、モデルコンテキストのコンパクト化はしません。破壊的な操作は、[履歴とクリーンアップ](history.md)を参照してください。

入力欄の高さは、ソフトウェアキーボードを含む可視の会話領域に従います。最小 8%（下限 44 px）、最大 60% です。手動の高さは比率として記憶され、狭い幅や長いテキストでも上限は上がりません。権限／質問を展開すると、保存した高さや下書きを変えずに入力欄を一時的に最小化します。リクエストを折りたたむか処理すると、サイズ変更を再開できます。

## 通知とバッジ {#notifications}

1. **通知** を開き、未許可なら **リクエスト** を選びます。
2. **通知を有効化** を有効にします。
3. **セッションに入力が必要**、**セッションが待機状態になる**、**アプリにフォーカスがあるときも通知** するかを選びます。

ブラウザー／OS の権限は端末とアプリのオリジンに属し、保存した設定で拒否を上書きすることはできません。ブロックされている場合はブラウザーまたは OS の設定で通知を許可し、ここに戻ってください。未対応環境ではコントロールは無効のままです。

ベル／履歴の未読件数が、ブラウザーのファビコンの点とネイティブアプリのバッジに反映されます。ネイティブバッジは稼働中のメインウィンドウを集計します。実行中セッションの件数でも、OS 通知が配信された証拠でもありません。この機能は PWA ランチャーのバッジを提供しません。

## 詳細オプション {#advanced}

1. **詳細設定** を開きます。
2. 必要な動作だけを変更します。スイッチは CodeNomad 設定に保存されます。セッション実行環境を変える場合は、別途 **環境変数** を編集します。
3. 推測で共有サービスを再起動せず、表示結果や次の送信を確認します。

| オプション | 効果と注意 |
| --- | --- |
| 空のセッションを自動クリーンアップ | 新しいセッションの作成時に空のセッションを整理します。残したい場合はオフにします。 |
| サブエージェントの idle マーカーを保持 | 未確認の待機マーカーを 5 秒で隠さず、確認するまで保持します。 |
| 2 回目の起動で既存ウィンドウをフォーカス | ネイティブデスクトップのみ。アプリが起動中に再度起動したときのウィンドウ動作を変え、タブ作成は変えません。 |
| プロバイダーのクレジット残高 | 使用量に補足残高を表示します。クレジット購入やアカウント切り替えはしません。 |
| 空白のみの変更を非表示 | 空白／改行のみの未ステージファイルを変更一覧と一括操作から除外します。ステージ済みファイルは表示します。[ファイル](files.md)を参照してください。 |
| 長いアシスタント応答を保持 | ストリーミング返信が表示領域を超えると、自動追従を止めます。 |
| 環境変数 | 各プロンプトやセッションコマンドの前にサーバー側で適用します。読み取りだけで実行中の処理を更新しません。[OpenCode のセットアップ](opencode.md)を参照してください。 |

キーボード設定は[キーボードショートカット](shortcuts.md)、音声操作は[音声入力と再生](voice.md)を参照してください。起動時復元と保存済みデスクトッププロファイルの削除は、[デスクトップのウィンドウとデータ](desktop.md)で説明しています。
