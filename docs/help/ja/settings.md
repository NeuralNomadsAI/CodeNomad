# 設定とレイアウト

環境設定では選択したプロジェクトのサーバーを使い、プロジェクト設定、プロバイダー、統計、メモリとその整理を扱います。サーバーが利用できない間、プロジェクトの操作は無効になります。デバイス設定と SideCars はローカルのままです。 画像と Web 検索の設定は、グローバル既定値も含めてプロジェクトのサーバーに適用されます。

## 設定を開き、範囲を確認する {#open-settings}

1. タブバーの **設定を開く** の歯車で **設定** を開きます。モデルセレクターの **プロバイダーを管理**、ミッションパネルの歯車、通知履歴の **設定** の歯車などのショートカットは、該当するセクションを直接開きます。
2. セクションを選びます。ローカルの Electron／Tauri ウィンドウは、単一のネイティブ設定ウィンドウを開くかフォーカスします。ブラウザー／リモート表示は埋め込み設定画面を使います。
3. 離れる前に、設定の範囲と **保存** 操作の有無を確認します。

ほとんどの選択は直ちに適用されます。ミッション設定も、変更するたびにその変更を保存します。音声 API の設定、パレットのカスタム色、設定ファイルには **保存** が必要です。設定のタイトル横の **i** にカーソルを合わせるかフォーカスすると短い説明が表示されます。ヘルプへのリンクがある場合は、クリック、Enter、タップで、インターフェースの言語の該当セクションをシステムのブラウザーまたは別のタブで開きます。説明のみのアイコンはタップで説明を表示します。**設定 → 情報** には **CodeNomad を支援する** カードもあり、**スポンサーになる・貢献する** で [CodeNomad を支援する](sponsor.md) ページを開きます。

| 状態 | 制御するもの |
| --- | --- |
| CodeNomad 設定 | 共有 UI 設定と、音声 API、SideCar、リモートコントロール、環境変数などの **サーバー設定**。 |
| 音声エンジン | [デスクトップの音声入力エンジン](voice.md#desktop-dictation)は、このデバイスの全プロジェクトに適用されます。[会話エンジン](voice.md#conversation)は、デスクトップのプロファイル、またはブラウザーのプロファイルと接続先サーバーごとに選びます。 |
| ウィンドウ／プロジェクトタブのレイアウト | 開いているパネル、選択タブ、リーダー状態、復元可能な下書き／レイアウト。OpenCode 設定ではありません。 |
| グローバル／プロジェクトの OpenCode 設定 | 表示範囲のネイティブなプラグイン／設定変更。プロジェクト操作にはアクティブなプロジェクト／Location が必要です。 |
| デスクトップデータプロファイル | 設定ファイルや共有 OpenCode サービスとは独立した、ネイティブウィンドウ、復元状態、ブラウザーストレージ。[デスクトップのウィンドウとデータ](desktop.md)を参照してください。 |

右パネルの選択タブとファイルのモードは、プロジェクトタブごとに保存されます。最後に明示的に選んだ内容が新しいタブの既定値になります。パネルのサイズ、タブの順序、カスタマイズ、外観は共有のレイアウト／設定として保持されます。

**統計** は、開いたフォルダーだけでなく、接続先の OpenCode サービス全体（すべてのプロジェクト、独立したクローン、サブセッション）を対象とし、過去 7、30、90、365 日を集計します。開いているプロジェクトが必要で、表示するのは OpenCode が記録したトークンとコストであり、プロバイダーの請求書やサブスクリプションの利用枠ではありません。プランの割り当て量は、ステータスの **使用量** セクションで確認します。

## 言語と外観 {#language-appearance}

1. **一般** の **言語** で、英語、スペイン語、フランス語、ロシア語、日本語、簡体字中国語、ヘブライ語、ドイツ語、ネパール語、トルコ語を選びます。
2. **カラースキーム** で、**モード** に **自動**、**ダーク**、**ライト** を選びます。自動は OS に従います。
3. **モード** の横で **コントラスト** を選びます。**自動**（既定）はシステムのコントラスト設定に従い、**オン** はすべてのパレットのコントラストを高め、**オフ** は通常のコントラストを使います。
4. 表示中の外観のパレットを選びます。ライトとダークの選択は独立して保存され、自動では対応するものを使います。
5. 色をカスタマイズするには、色見本と **保存** を使います。**リセット** は組み込みパレットの色を復元します。別のパレットに名前を付けるには **新規**、自分で作成したパレットを削除するには **削除** を使用します。

コントラストは色の **保存** とは独立して、すぐに適用・保存されます。選択したパレット、編集可能な色、会話の下書きを保持したまま表示を調整します。**i** は自動モードでの現在のコントラスト状態を示します。

UI は会話を再起動せずに更新されます。ヘブライ語では右から左のレイアウトを使い、コードや技術値はそれぞれの方向で読みやすく保ちます。言語選択はインターフェースのテキストを変えますが、既存メッセージやエージェント指示の言語は変えません。デスクトップのネイティブメニューは、CodeNomad のウィンドウが読み込まれるとインターフェースの言語に切り替わります。

色が読みにくくなったら、**コントラスト → オン** を選びます。組み込みパレットを選ぶか、編集したものをリセットすることもできます。パレットを切り替えると未保存の色編集を破棄するか確認する場合があります。会話の下書きは保持されます。

## コンピューターをスリープさせない {#keep-computer-awake}

**設定 → 一般** の **CodeNomad の実行中はコンピューターをスリープさせない** は、既定で無効です。有効にすると、作業中のセッションがなくても、ローカルの CodeNomad ウィンドウが開いている間（最小化中も含む）はシステムのスリープを防ぎます。画面は引き続きオフになることがあります。無効の場合、セッションが作業中の間だけコンピューターをスリープさせません。この設定はローカルのデスクトップアプリウィンドウとネイティブ設定ウィンドウにのみ表示され、ブラウザー表示とリモート表示では非表示です。

## 新しい会話の権限 {#new-conversation-permissions}

**設定 → 一般 → 新しい会話の権限** で、CodeNomad で作成する新しい親なし会話の初期モードを **自律**（既定）または **監督付き** から選びます。既存の会話には影響しません。既存の会話のモードを変えるには、その会話で [ステータス → 権限](permissions.md#conversation-mode) を開きます。

## エージェントの永続メモリ {#agent-memory}

リモートコントロール、検証済み HTTPS、LAN、インストール済み PWA で認証されたユーザーは、選択したローカルまたはリモートのプロジェクトのメモリを確認・編集し、**整理** を実行できます。

CodeNomad はセッションの古いメモリ指示の削除を試みますが、削除にも失敗した場合、次の更新が成功するまで以前の指示が残ることがあります。

**設定 → 一般 → メモリ** を開きます（ブラウザーでも **設定 → 一般**）。メモリは初期状態で無効です。有効にすると、エージェントが有用な事実や好みを会話間で保持します。スイッチは接続先の CodeNomad 設定全体に適用され、無効にしても保存済みの項目と履歴は保持されます。 無効の間、エージェントにはメモリツールが提供されません。切り替えは再起動なしで、進行中の会話にも数秒以内に反映されます。

- **あなたについて**：同じ設定を使うプロジェクト間で共有される、最大60項目。
- **プロジェクト**：最大200項目。この画面では環境設定で選択したプロジェクトを使い、埋め込みの設定ではメインウィンドウのアクティブなプロジェクトを使います。サーバーは正規化した Git リモートアドレスでリポジトリを識別し、取得できない場合はローカルのリポジトリパスを使います。ワークツリー間で同じメモリを共有します。この範囲を選ぶにはプロジェクトを開きます。

1. 範囲を選び、そのエントリ数(例: **7/200**)を展開して項目を選びます。**新規** と **変更済み** は、このブラウザーまたはデスクトップ表示で、その範囲のエントリを最後に表示してからの変更を示します。折りたたまれた件数の行にも表示され、現在の閲覧中は表示が維持されます。
2. **タイトル**、**種類**（**事実**、**好み・設定**、**参照**）、**本文** を編集し、**保存** します。タイトルは60文字、本文は2,000文字までです。**キャンセル** で保存済みの内容に戻します。他で変更されていたら **再読み込み** して確認してから保存してください。
3. 削除するには項目の操作メニューを開き、**忘れる** を確認します。項目は有効なメモリから外れますが、古い本文を含むローカルの Git 履歴は保持されます。「忘れる」はエージェントによる利用の停止であり、安全なデータ消去ではありません。
4. メモリがいっぱいの場合は、項目を統合するか忘れてから再試行します。同じタイトルや大きく重複する本文は既存項目を置き換え、以前の本文は Git に残ります。

**要確認** は、安全対策の回避や認証情報の公開につながる指示の疑いを示します。これらの項目はここで編集でき、上限に数えられますが、エージェントのタイトル一覧と読み取りから除外されます。読み取りのたびに確認されるため、内容を修正して保存するか **忘れる** を選びます。

**整理** は確認後、設定に表示されたプロジェクトで新しい会話を開き、選択範囲を検証・統合します。確認できない項目や外部参照を保持し、変更を報告します。開いているプロジェクトと、有効・読み書き可能で警告のない項目を1つ以上含むメモリが必要です。

メモリはエージェントが管理します。すでに `.claude/…/MEMORY.md` などで管理している場合は、そのファイルへの **参照** を記録します。外部メモリファイルはそれぞれの管理下に置かれます。保存はローカルのみで、リモート同期は行いません。設定とプロファイルの範囲は [デスクトップのウィンドウとデータ](desktop.md) を参照してください。

## パネルとステータスのセクション {#panels-status}

**ステータス**は既定で先頭に表示されます。保存済みのタブ順序がある場合はそちらが優先されます。このタブは常に利用できます。**右パネルをカスタマイズ**では、矢印でセクションのチェックボックス一覧を折りたたんだり展開したりできます。セクション自体の表示設定は変わりません。

固定されたパネルの内側の端をドラッグすると、サイズを変更できます。

1. 外側のヘッダー隅の **左パネル** と **右パネル**、または **表示** メニュー内の項目で、それぞれを表示／非表示にします。
2. 右パネルの **右パネルをカスタマイズ** を開きます。チェックボックスで組み込みタブとステータスのセクションを選びます。ステータスの最低 1 セクションは表示されます。これらのチェックボックスの上をドラッグすると、まとめて設定できます。
3. 右パネルのタブをドラッグして並べ替えます。**リセット** で組み込みレイアウトの選択を復元します。

すべてのステータスセクションをグリップのドラッグまたは上下キーで並べ替えられます。表示設定と順序は再読み込み後も保持されます。

ステータスには、トークン情報、権限、プロバイダーの使用量、バックグラウンドシェル、MCP、プラグインがあります。会話に[目標](conversations.md#goal)がある間は、これらのセクションの上に目標の行が表示されます。この行はセクションではないため、非表示にも移動もできません。セクションを隠しても、サービスの無効化や権限の取り消しはしません。狭いレイアウトでは、会話を圧迫せず、収まらなくなったパネルを閉じます。そこで開いたパネルは会話の上に浮かび、一方のフローティングパネルを開くと他方は閉じます。

組み込みレイアウトはウィンドウごとの設定です。[ミッションのチェックボックス](missions.md#activation)はプラグインのグローバル設定も変更します。複数のチェックボックスをドラッグで切り替えるときはスキップされます。拡張機能のチェックボックスは、その設定を使う全プロジェクトでコードを有効化します。**リセット** は拡張機能の同意を変更しません。[パネル拡張機能](extensions.md)を参照してください。

## 会話表示の詳細と入力欄のサイズ {#transcript-composer}

1. **チャット** を開いて会話表示の詳細の既定値を選びます。プリセットは **なし**、**最小**、**バランス**、**すべて** です。個別変更では **カスタム** になります。
2. 行ごとの **既定の状態**（**非表示**、**折りたたみ**、**展開**）を設定するか、同じ設定を使う会話の **メッセージの内容** ポップアップを開きます。**ツールグループ** を **無効** にすると呼び出しごとにカードが表示され、**折りたたみ** と **展開** はグループの初期状態を設定します。
3. **一般** で、必要に応じて **メッセージのタイムラインを表示**、**最初／最新のメッセージの矢印をタイムラインの下に配置**、**ツール呼び出しの差分を分割表示**、**送信したプロンプトをキューに入れる**（セッションの作業中に送信したプロンプトを、割り込ませずにキューに入れる）をオンにします。
4. サイズ変更コントロールで入力欄を調整します。長い下書きはフィールド内でスクロールします。

タイムラインには、会話に表示される返答・推論・ツール・コンパクト化・システムコンテキストごとに 1 つのマーカーが同じ順序で並びます。マーカーは **メッセージの内容** に従います。そこでツールの種類、推論、システムメッセージを非表示にするとそのマーカーも非表示になり（保留中の権限があるツールを除く）、**なし** ではすべてのツールマーカーが非表示になります。表示と展開の設定は、見せ方だけを変えます。保存済みのツール／推論の削除や、モデルコンテキストのコンパクト化はしません。破壊的な操作は、[履歴とクリーンアップ](history.md)を参照してください。

入力欄の高さを手動で調整する際は、画面キーボードがないときの会話領域の高さが基準です。最小 8%（下限 44 px）、最大 60% です。画面幅が狭くても、テキストが長くても、この制限は変わりません。キーボードを開くと、操作ボタンやメッセージの領域を確保するため、保存された高さの比率はそのままで、入力欄が一時的に縮むことがあります。権限／質問を展開すると、保存した高さや下書きを変えずに入力欄を一時的に最小化します。リクエストを折りたたむか処理すると、サイズ変更を再開できます。

## 通知とバッジ {#notifications}

別の CodeNomad サーバーのプロジェクトタブでは、通知にサーバー名が表示されます。 **会話を表示**で該当するプロジェクトと会話を開きます。 サーバーを切り離すと、その通知は消去されます。

ミッションの内部セッションをコンパクト化しても、通知は表示されません。

1. **通知** を開きます。通知の種類ごとに、表示先をチェックします。**画面**（一時的なバブル）、**履歴**（タブバーにあるベルの通知履歴に保持）、**システム**（OS の通知）です。ボックスの行または列の上をドラッグすると、まとめて設定できます。
2. **システム** のチェックボックスをオンにすると、必要に応じて許可を求めます。許可がない間は、**システム通知** の **権限をリクエスト** で再度求められます。
3. このウィンドウにフォーカスがある間もシステム通知を受け取るには、**アプリにフォーカスがあるときも通知** を有効にします。無効のときは、ウィンドウが画面に開いたままでも、フォーカスがなければ通知が表示されます。

既定では、**セッションが応答を待っています** と **セッションが終了しました** はシステムにのみ送られるため、一時的なセッション状態が履歴にたまりません。これらはサブエージェントではなくメインセッションが対象で、自分で停止したセッションは通知されません。エラーは表の設定にかかわらず常に画面と履歴に表示され、短い進捗メッセージは画面にだけ表示されます。

ブラウザー／OS の権限は端末とアプリのオリジンに属し、保存した設定で拒否を上書きすることはできません。ブロックされている場合はブラウザーまたは OS の設定で通知を許可し、ここに戻ってください。未対応環境ではシステムの列は無効のままです。

ベル／履歴の未読件数（履歴に送られた通知だけを数えます）が、ブラウザーのファビコンの点とネイティブアプリのバッジに反映されます。

システムが通知アクションに対応していれば、通知をクリックすると、まだ開いている会話が表示されます。ウィンドウが前面に出るかどうかはデスクトップ環境によります。

## 詳細オプション {#advanced}

1. **詳細設定** を開きます。
2. 必要なオプションだけをオンまたはオフにします。各変更は CodeNomad 設定に保存されます。セッション実行環境を変える場合は、末尾の折りたたまれた **環境変数** グループを展開します。

| オプション | 効果と注意 |
| --- | --- |
| 空のセッションを自動クリーンアップ | 新しいセッションの作成時に空のセッションを整理します。残したい場合はオフにします。 |
| サブエージェントの idle マーカーを保持 | 未確認の待機マーカーを 5 秒で隠さず、確認するまで保持します。 |
| 2 回目の起動で既存ウィンドウをフォーカス | ネイティブデスクトップのみ。アプリが起動中に再度起動したときのウィンドウ動作を変え、タブ作成は変えません。 |
| プロバイダーのクレジット残高 | 使用量に補足残高を表示します。クレジット購入やアカウント切り替えはしません。 |
| 空白のみの変更を非表示 | 空白／改行のみの未ステージファイルを変更一覧と一括操作から除外します。ステージ済みファイルは表示します。[ファイル](files.md)を参照してください。 |
| 長いアシスタント応答を保持 | ストリーミング返信が表示領域を超えると、自動追従を止めます。 |
| 環境変数 | 各プロンプトやセッションコマンドの前にサーバー側で適用します。読み取りだけで実行中の処理を更新しません。[OpenCode のセットアップ](opencode.md)を参照してください。 |

キーボード設定は[キーボードショートカット](shortcuts.md)を参照してください。**音声** には[音声入力・再生・会話](voice.md)があります。起動時復元とデスクトップデータプロファイルは、[デスクトップのウィンドウとデータ](desktop.md)で説明しています。
