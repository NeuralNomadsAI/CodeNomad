# CodeNomad を支援する

{{funding}}

私は CodeNomad をフルタイムで開発・保守しています。CodeNomad は無料のオープンソースです。実際の仕事で使われるツールにふさわしい手間を、これからもかけ続けたいと考えています。

私のバックグラウンドは 3D と VFX です。30 年にわたり、制作し、制作現場の問題を解決し、ソフトウェアを使う人たちと一緒にソフトウェアを作ってきました。その経験が CodeNomad への向き合い方を形づくっています。ツールは最初のデモを超えて、長いセッションでも、複雑なプロジェクトでも、日々の思わぬ出来事の中でも持ちこたえなければなりません。

フィードバック、バグ報告、コードのコントリビューションが CodeNomad を良くしてくれます。寄付は、それらを信頼できる形にし、OpenCode の進化に合わせて保守していくための時間を支えてくれます。

これをフルタイムで続けるには、経済的な支援が必要です。CodeNomad があなたの仕事の一部になっているなら、スポンサーになっていただくことで、誰もが使えるツールを開発・保守しながら生計を立てることができます。

Pascal André

## その他の協力方法 {#other-ways}

- [リポジトリ](https://github.com/NeuralNomadsAI/CodeNomad)にスターを付け、OpenCode を使っている人に CodeNomad を紹介してください。
- 最小の再現手順を添えて[不具合を報告](support.md#report-a-bug)してください。
- どのヘルプページでも下部にある **このページを編集** リンクから、ヘルプページや翻訳を修正できます。
- `dev` 宛ての範囲を絞ったプルリクエストで[コードを貢献](support.md#contribute)してください。
