# Расширения панели

## Просмотр установленных и онлайн-расширений {#browse}

1. Откройте **Настроить правую панель** в полосе вкладок правой панели.
2. Раскройте **Расширения** под разделителем.
3. Используйте **Поиск расширений** для поиска в едином списке установленных дополнений и официального онлайн-каталога. Наведите указатель на запись или установите фокус для метаданных.

Раздел изначально свёрнут при каждом открытии настройки. Установленные и онлайн-записи объединяются по ID расширения; отдельного окна управления или режима установленных/онлайн нет. Просмотр метаданных каталога не загружает и не выполняет код панели автора. Каталог поддерживается в [CodeNomad Extensions](https://github.com/NeuralNomadsAI/CodeNomad-Extensions); включение в него и заявленные имена авторов — не подписи и не доказательство доверия.

Если каталог недоступен, установленные расширения и **Установить из ZIP…** остаются доступны. Обновите для повторного обнаружения. Сворачивание или закрытие окна прекращает текущий просмотр/подтверждение в интерфейсе; оно ничего не устанавливает незаметно.

## Проверка и установка без активации {#install}

1. Выберите **Установить…** у записи каталога или **Установить из ZIP…** для отдельно полученного пакета.
2. Проверьте ID пакета, автора, репозиторий, версию, API/разрешения и дайджест SHA-256. При необходимости раскройте технические подробности.
3. Проверьте издателя и, где возможно, сравните дайджест по доверенному каналу.
4. Только если доверяете коду, отметьте **Я доверяю этому пакету и его автору**, затем **Установить без активации**.

Инспекция загружает/перепроверяет выбранный пакет; код автора при этом не выполняется. Дайджест идентифицирует точные байты, не личность автора. Пакеты каталога поступают из точно объявленного ресурса релиза GitHub, не произвольного URL. Ручные пакеты — ZIP только с `manifest.json` и самодостаточным `panel.html`; неверные или неподдерживаемые пакеты отклоняются.

Установка не требует перезапуска OpenCode и никогда автоматически не даёт активацию. Сбой проверки, конфликт или ошибка хранения не разрешают повтор с другими байтами. Заново проверьте пакет перед новой попыткой установки.

## Активация и область действия {#activate-scope}

1. Вернитесь к строке дополнения над разделом **Расширения** в **Настроить правую панель**. Установленные отключённые дополнения остаются в списке.
2. Отметьте флажок для активации. Снимите тот же флажок для отключения.

Этот флажок — единственное управление активацией: нет дополнительного переключателя менеджера или отдельного допуска видимости окна. Активация действует на всю конфигурацию во всех проектах, не на папку. При удалённом подключении влияет на хранилище расширений сервера, не только устройство просмотра.

Хранилище расширений — `panel-extensions/` рядом с выбранной конфигурацией CodeNomad. Отдельные настольные профили данных **не** изолируют расширения, если используют тот же каталог конфигурации. И наоборот, открытие другой конфигурации не разрешает запуск дополнения, установленного в другом месте. Различия см. в разделе [Настольные окна и данные](desktop.md).

Включённая панель может монтироваться при выборе; скрытие может уничтожить временное состояние интерфейса. Отключение отзывает активацию. **Сбросить** в настройке восстанавливает только встроенную раскладку и не включает, не отключает и не удаляет расширения.

## Замена или удаление {#replace-remove}

1. Используйте **Сменить версию…** или проверьте другой ZIP с тем же ID для замены установленного пакета.
2. Проверьте новый дайджест и разрешения, подтвердите доверие, затем установите без активации.
3. Снова активируйте обычным флажком только после решения доверять замене.
4. Для удаления используйте **Удалить…** и **Подтвердить удаление** после проверки цели.

Каждая замена отзывает активацию во всех проектах, даже при неизменном списке разрешений, и очищает сохранённые собственные настройки панели. Сбой проверки/конфликта/хранения сохраняет установленный пакет. Скрытых обновлений расширений нет. Удаление убирает пакет, настройки активации и сохранённые настройки панели, не сессии OpenCode или файлы проекта. Для восстановления после нежелательного кода сначала отключите его; переустанавливайте только проверенный доверенный пакет.

## Контекст, согласие на ресурсы и ограничения песочницы {#permissions-sandbox}

| Контракт | Что разрешает активация |
| --- | --- |
| API 1 / `session.context` | Идентификатор текущей сессии (или его отсутствие), язык и оформление интерфейса. Без текста переписки и доступа к файловой системе. |
| API 2 / `session.assets.read` плюс контекст | Явно проверенное разрешение перечислять ограниченные метаданные изображений/вложений результатов инструментов текущей сессии и читать поддерживаемые встроенные байты. Не общий доступ к переписке, файлам или URL. |
| API 3 / `repository.workItems.read` и контекст | Явно проверенное разрешение показывать ограниченные страницы issues и pull requests репозитория проекта на GitHub, GitLab или Gitea/Forgejo и открывать один из них в браузере. Это не доступ к файлам, учётным данным или сети в целом. |
| API 4 / контекст плюс одно или несколько разрешений ниже | При проверке показывается по одному предложению на каждое объявленное разрешение; активация предоставляет их все вместе, а замена отзывает их все. |
| `session.images.read` | Читать изображения, возвращённые инструментом read в отображаемом разговоре, со статусом генерации и происхождением, когда их можно проверить. |
| `session.images.prompts` (требует `session.images.read`) | Читать промпт и модель каждого изображения, созданного в разговоре «Изображения» проекта. |
| `composer.prefill` | Добавлять текст в поле ввода отображаемого разговора. Никогда не отправляет сообщение. |
| `images.conversation` | Открывать или начинать разговор «Изображения» этого проекта. |
| `opencode.designAgent` | Добавляет в OpenCode агент Design от CodeNomad и его навыки работы с изображениями, пока это расширение включено. |
| `panel.preferences` | Запоминать собственные настройки этой панели. |

Доступ к ресурсам следует текущему смонтированному хосту/сессии, не выбранной автором сессии. Локальные/удалённые ссылки могут перечисляться как недоступные; API ресурсов не загружает произвольные удалённые URL и не открывает локальные файлы. Смена сессии, отключение или отзыв согласия аннулируют старый доступ.

В API 4 чтение изображений так же следует отображаемому разговору и показывает только изображения, которые агент прочитал обратно в него. Расширение с `session.images.prompts` может читать промпты, написанные вами или агентом для изображений в разговоре «Изображения», и может передать их дальше, несмотря на песочницу, поэтому предоставляйте его только авторам, которым вы их доверяете. Текст, добавленный через `composer.prefill`, остаётся в поле ввода, пока вы не измените его или не выберете **Отправить сообщение**; он никогда не начинается с команды, никогда не заканчивается незавершённым упоминанием `@` и приводит пути к изображениям обычным текстом. Отмена через Ctrl+Z (Cmd+Z в macOS) в поле ввода его не удаляет. Сохранённые настройки панели принадлежат этому профилю CodeNomad, не более 4 КиБ на расширение; при отключении расширения они сохраняются.

Элементы берутся из удалённого репозитория `upstream` папки проекта, иначе из `origin`. CodeNomad читает их через CLI GitHub, GitLab или Gitea, в который вы уже вошли (`gh`, `glab`, `tea`), либо анонимно для публичных репозиториев, и не хранит токенов; расширение видит только имя репозитория и элементы. Анонимное чтение доступно для github.com, gitlab.com, codeberg.org и gitea.com; самостоятельно размещённая платформа читается только через CLI, в который выполнен вход на ней. Открытие элемента просит CodeNomad открыть его страницу на той же платформе в браузере, не чаще раза в секунду; другие адреса расширение открыть не может.

Код автора работает в ограниченном iframe, не в доверенном процессе отображения приложения. Он не получает мост к нативному окружению/OpenCode, учётные данные, общий RPC, формы, всплывающие окна или загрузки; сетевые API и внешние ресурсы ограничены. Расширения — дополнения интерфейса, не [плагины OpenCode](integrations.md).

Песочница не изолирует процесс/CPU и не обещает безвредность одобренного кода. Враждебное расширение может нарушить работу своего процесса отображения. Устанавливайте только доверенных авторов, не передавайте секреты и отключите/удалите дополнение при неожиданном поведении.
