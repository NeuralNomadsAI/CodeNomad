# Горячие клавиши

## Поиск команд и открытие справки {#discover-commands}

1. Откройте **Палитра команд** через `Ctrl+Shift+P` в Windows/Linux или `Cmd+Shift+P` в macOS либо видимой кнопкой/пунктом меню.
2. Введите название действия. Палитра включает действия приложения и пользовательские команды текущей Location; доступность зависит от активного вида.
3. Выполните **Открыть справку** для открытия этого руководства на текущем языке интерфейса во внешнем браузерном контексте. Нативное **Справка → Справка CodeNomad** открывает то же руководство.

Справка не меняет вид приложения и черновик. При сбое открытия посетите [справку CodeNomad](https://neuralnomadsai.github.io/CodeNomad/) напрямую. Наличие команды в поиске не означает настраиваемое сочетание: менеджер охватывает фиксированный каталог из 74 действий интерфейса, не все действия палитры или нативного меню. В него входят команды палитры, например **Компактировать сессию**, **Отменить последнее сообщение** или **Открыть справку**, у которых изначально **Нет сочетания**; действия с папкой проекта, терминалом и редактором работают только в локальных настольных окнах.

## Запись, отключение и сброс {#customize}

1. Откройте **Настройки → Горячие клавиши** и найдите действие или сочетание клавиш через **Фильтр сочетаний**.
2. Выберите **Изменить**, затем нажмите нужное сочетание в **Нажмите сочетание клавиш**. Запись сохраняет привязку.
3. Используйте **Очистить сочетание** (×) для удаления привязки интерфейса этого действия, **Сбросить** для восстановления по умолчанию или **Сбросить все** для всех привязок интерфейса.
4. Разрешите предупреждения каждой конфликтующей строки; конфликты сообщаются, не отключаются незаметно.

Привязки сохраняются в конфигурации интерфейса CodeNomad и влияют на клиентов с общей конфигурацией. Не меняют CLI/TUI-привязки OpenCode и ускорители нативного меню. Запись подавляет сочетания интерфейса приложения, но не может подавить ОС или нативное меню. **Отмена**, потеря фокуса, закрытие раздела или уход из окна завершает запись. Отдельные модификаторы и композиция IME игнорируются; обычные Tab/Shift+Tab перемещают фокус.

При сбое сохранения держите старое сочетание доступным и повторите после проверки показанной привязки. Сброс — безопасное восстановление после случайного назначения.

## Значения интерфейса по умолчанию {#renderer-defaults}

`Mod` означает `Ctrl` в Windows/Linux и `Cmd` в macOS. Это значения по умолчанию, не гарантия доставки клавиши ОС/нативным хостом. Область важна: одна клавиша может выполнять разные действия на главной странице, в поле ввода или поиске.

| Действие | По умолчанию |
| --- | --- |
| Открыть палитру команд | `Mod+Shift+P` |
| Новый экземпляр / обзор папки на главной странице | `Mod+N` |
| Закрыть вкладку приложения | `Mod+W` |
| Предыдущая / следующая вкладка приложения | `Mod+[` / `Mod+]` |
| Вкладка приложения 1–9 | От `Mod+1` до `Mod+9` |
| Переименовать экземпляр (контекст вкладки) | `F2` |
| Новая сессия | `Mod+Shift+N` |
| Закрыть сессию | `Mod+Shift+W` |
| Предыдущая / следующая сессия | `Mod+Shift+[` / `Mod+Shift+]` |
| Вкладка сессии 1–9 | От `Mod+Shift+1` до `Mod+Shift+9` |
| Информация об экземпляре | `Mod+Shift+L` |
| Поиск по истории сессии | `Mod+F` |
| Предыдущее / следующее сообщение пользователя | `Alt+ArrowUp` / `Alt+ArrowDown` (Windows, Linux) или `Mod+Alt+ArrowUp` / `Mod+Alt+ArrowDown` (macOS) |
| Следующий / предыдущий результат (фокус в поиске) | `Enter` / `Shift+Enter` |
| Фокус на запрос / очистить запрос | `Mod+P` / `Mod+K` |
| Открыть выбор модели / агента | `Mod+Shift+M` / `Mod+Shift+A` |
| Выбрать вариант модели | `Mod+Shift+T` |
| Переместить блокирующие инструменты в фон (поле ввода) | `Mod+B` |
| Отправить запрос | `Enter` |
| Отправить с альтернативным поведением последующего запроса | `Alt+Enter` (Windows, Linux) или `Mod+Shift+Enter` |
| Вставить новую строку | `Shift+Enter` или `Mod+Enter` |
| Предыдущий / следующий запрос (поле ввода) | `ArrowUp` / `ArrowDown` |
| Убрать фокус с запроса / выйти из режима Shell | `Escape`, по контексту поля ввода |
| Остановить сессию | Дважды `Escape`; первое нажатие показывает подтверждение |
| Отправить побочный вопрос (окно `/btw`) | `Mod+Enter` |
| Сохранить файл (редактор рабочей области) | `Mod+S` |

Если отправка по Enter отключена, **Отправить запрос** по умолчанию — `Mod+Enter`, **Вставить новую строку** — `Enter` или `Shift+Enter`. Явное переопределение заменяет это значение. Смотрите фактическую привязку в менеджере. В macOS `Option+Return` остаётся переводом строки, поэтому с альтернативным поведением отправляет только `Cmd+Shift+Return`; меню **Больше действий** поля ввода предлагает тот же выбор (**Поставить сообщение в очередь** или **Направить сейчас**), пока сессия работает. **Очистить ввод** выполняет собственное действие очистки поля ввода, в том числе в первом черновике нового разговора. Предыдущая/следующая сессия перебирает список; это не браузерная история **Назад**/**Вперёд** боковой панели, у которой нет сочетания.

## Нативные клавиши и перехват платформой {#native-keys}

Нативные клавиши фиксированы и остаются активными после изменения или отключения соответствующей привязки интерфейса. В частности, нативное **Новое окно** использует `Mod+Shift+N` — значение интерфейса для новой сессии. Используйте видимый элемент новой сессии или переназначьте действие, если нативное меню перехватывает его. Аналогично нативное `Mod+W` может закрыть окно вместо вкладки приложения.

| Нативное действие | Electron | Tauri |
| --- | --- | --- |
| New Window | `Mod+Shift+N` | `Mod+Shift+N` |
| New Instance / Command Palette | `Mod+N` / `Mod+Shift+P` | `Mod+N` / `Mod+Shift+P` |
| Reload / Force Reload | `Mod+R` / `Mod+Shift+R` | `Mod+R` / `Mod+Shift+R` |
| Actual Size | `Mod+0` | `Mod+0` |
| Zoom | `Mod+Plus` / `Mod+-` | Управление меню «Вид» и масштабирование webview платформы |
| Full Screen | `F11` в Windows/Linux; `Ctrl+Cmd+F` в macOS | Ускоритель меню `Ctrl+Cmd+F` в macOS; на других платформах используйте меню |
| Developer Tools | `Ctrl+Shift+I` в Windows/Linux; `Alt+Cmd+I` в macOS | `Alt+Mod+I` |

Обычные окна браузера тоже сохраняют свои сочетания. Если привязка не достигает CodeNomad, выберите другую комбинацию вместо отключения защиты или изменения системных клавиш.

## Раскладки клавиатуры и ввод текста {#layouts-ime}

Сочетания цифрового ряда и квадратных скобок используют физические позиции клавиш для записи, выполнения и проверки конфликтов, включая AZERTY/QWERTZ. Другие клавиши используют логические значения. Записывайте на нужной клавиатуре, затем проверьте результат.

Во время композиции IME ввод текста приоритетен. История запросов и Escape тоже зависят от фокуса, состояния выбора/оболочки и текущей операции; не считайте каждый ArrowUp или Escape безусловным глобальным действием. На настольных устройствах отправка переводит фокус на разговор, чтобы стрелки, клавиши листания и пробел прокручивали его; ввод символа возвращает в поле ввода вместе с этим символом, а **Перейти к вводу** возвращает туда перед использованием истории запросов. Подсказки называют текущее сочетание таких элементов, как палитра команд, поиск, новая сессия, информация и переключатели поля ввода; вместе с менеджером сочетаний они показывают назначения без постоянной полосы клавиатурной справки.
