# Провайдеры и аккаунты

Аутентификация провайдеров принадлежит подключённой службе OpenCode, а не устройству браузера или отдельному проекту CodeNomad. Настройки отображения моделей, квоты подписок и выбор веб-поиска имеют разные области действия.

## Подключение провайдера моделей или поиска {#connect}

1. Откройте рабочее пространство, затем **Настройки → Провайдеры**. **Модели** изначально раскрыты; для поисковых провайдеров раскройте **Поиск в интернете**. В **Изображения** собраны настройки изображений.
2. В этой группе нажмите **Выберите провайдера**, затем **Подключить**. Для провайдера моделей, уже указанного ниже, используйте **Добавить аккаунт** (+) в его строке, в том числе для первого подключения.
3. Для провайдера моделей выполните предложенный нативный **Способ аутентификации**: API-ключ, OAuth или команду. Для OAuth используйте **Открыть страницу авторизации** и отправляйте код авторизации только по запросу. Поисковые провайдеры подключаются по API-ключу.
4. После завершения проверьте строку настроенного провайдера. **Модели** перечитываются после подключений, смены аккаунтов и переподключений; у **Поиск в интернете** есть также **Обновить**.

Интеграции только для поиска находятся в **Поиск в интернете**, не в **Модели**. Сохранение аутентификации не выбирает модель и не меняет провайдера поиска по умолчанию. API-ключи и учётные данные OAuth сохраняет активный сервер OpenCode. Браузер получает метаданные подключения, не сохранённые секреты. Подключение из переменных окружения доступно здесь только для чтения: измените окружение-владельца, а не пытайтесь отключить его здесь.

Если окно авторизации заблокировано, используйте **Открыть страницу авторизации**, **Открыть в этой вкладке** или **Скопировать ссылку** в процедуре. Не публикуйте ссылку или код авторизации в диагностике.

## Выбор аккаунтов и управление ими {#accounts}

1. В строке провайдера используйте **Активный аккаунт** для выбора сохранённых учётных данных.
2. Нажмите **Добавить аккаунт**, чтобы авторизовать другое подключение.
3. Для управления другим сохранённым аккаунтом сначала выберите его, затем используйте **Переименовать аккаунт** или **Удалить аккаунт**. Для переименования служат **Имя аккаунта** и **Сохранить**; **Удалить аккаунт** действует сразу, без подтверждения.

Выбор, переименование и удаление влияют на интеграцию во всей службе OpenCode, включая другие проекты и клиенты. Удаление учётных данных может лишить эти клиенты аутентификации; оно не удаляет историю разговоров и не отзывает удалённый аккаунт провайдера. Подключения из окружения нельзя выбрать как изменяемые сохранённые данные или удалить здесь. При ошибке CodeNomad перечитывает аккаунты: снова проверьте **Активный аккаунт** перед действием.

### Ограничения автоматического выбора {#automatic-selection}

При нескольких сохранённых учётных данных поддерживаемой интеграции **Автоматически выбирать аккаунт** включает выбор по квоте перед допуском следующего запроса/пользовательской команды через CodeNomad. Настройка хранится для каждой интеграции в конфигурации CodeNomad; итоговый выбор аккаунта действует во всей службе.

| Подходящая интеграция | Подходящий тип аккаунта |
| --- | --- |
| OpenAI / Codex | Аккаунты подписки Codex с OAuth через браузер/устройство, не ключи OpenAI с оплатой по использованию и не способ входа ChatGPT, использование которого OpenAI не предоставляет. |
| OpenCode Go | Ключ Go или вход/ключ OpenCode Console **только для провайдера Go**; платные модели Console выбираются вручную. |
| Anthropic | Вход Claude Pro/Max OAuth в OpenCode, **не** вход Claude Code. |
| GitHub Copilot | OAuth с читаемой квотой премиум-запросов; учётные данные корпоративного эндпоинта не являются читаемыми кандидатами. |
| Планы для программирования | Аккаунты с API-ключами: `zai-coding-plan`, `zhipuai-coding-plan`, `kimi-for-coding`, `minimax-coding-plan`, `minimax-cn-coding-plan`. |

Переключение вызывает только исчерпание текущего аккаунта; более свободная альтернатива сама по себе не причина. Чтения проверяют явные сохранённые учётные данные без активации кандидатов и обмена токенов обновления. Codex, Copilot и планы программирования требуют доказанно доступного кандидата. Go, Console и Claude могут использовать кандидата с неизвестной квотой, если недавняя нативная ошибка квоты не пометила его исчерпанным. Показания OpenCode Go зависят от доступного API и прав учётных данных.

Это **не переключение во время выполнения при сбое**. Оно не повторяет неудачные запросы, запросы модели, команды или изменения. Оно не ротирует подключения из окружения, произвольных провайдеров, балансы с оплатой по использованию или внешние входы Claude Code. Ручные изменения аккаунта учитываются при подготовке выбора; межклиентской блокировки нет. При ошибках квоты/аутентификации проверьте **Активный аккаунт**, обновите использование и при необходимости войдите через владельца учётных данных перед осознанной повторной отправкой.

## Видимость моделей, избранное и мышление {#models}

1. Выберите **Управление моделями** рядом с провайдером моделей.
2. Найдите по имени/ID и измените видимость; **Показать все** и **Скрыть все** влияют на список выбора этого провайдера. Проведите с зажатой кнопкой по флажкам, чтобы изменить несколько моделей сразу.
3. В переключателе **Модель** разговора используйте **Добавить в избранное** или **Удалить из избранного**; **Показать все модели** отключает фильтрацию только по избранному.
4. Используйте **Мышление** в поле ввода для вариантов выбранной модели.

Видимость и избранное организуют переключатели CodeNomad; они не удаляют модели, учётные данные и не мешают другим клиентам OpenCode использовать их. Скрытие модели не отключает аккаунт. Мышление выбирает вариант модели для следующих отправок, а не видимость уже имеющихся рассуждений в переписке. Верните скрытые модели через **Управление моделями → Показать все**.

## Использование, счётчики токенов и истёкшие входы {#usage}

Используйте **Использование** на правой панели для окон плана провайдера активного разговора, времени сброса и поддерживаемых балансов. Эти показания отличаются от **Токены** сообщений и оценки стоимости: квота подписки — не счёт по видимой переписке. Отсутствующее, устаревшее или неизвестное показание не означает нулевое использование или доказанный остаток. **Баланс кредитов провайдера** в **Настройки → Расширенные** управляет отображением дополнительных балансов.

Для подключений Google, использующих способ аутентификации Gemini CLI в OpenCode, раздел **Использование** показывает лимиты по моделям; для подключений Antigravity — лимиты **5 часов** и **За неделю**, с отдельными квотами по семействам моделей, если они предоставлены. Если квота недоступна, отображается «Данные об использовании временно недоступны.» Выбор аккаунта для этих подключений остаётся ручным.

В [FAQ Antigravity](https://antigravity.google/docs/faq/) Google указывает, что использование стороннего ПО со входом Antigravity нарушает условия сервиса и может привести к приостановке или закрытию аккаунта.

Для платных моделей интеграции `opencode` раздел **OpenCode Console** показывает **Запросы** за **Сегодня (UTC)**, **7 дней (UTC)** и **30 дней (UTC)**. Это календарные периоды UTC, включая сегодня; они начинаются в 00:00 UTC сегодня, шесть дней назад и 29 дней назад соответственно. **Запросы по моделям · 30 дней** перечисляет каждую модель и её провайдера. Счётчики относятся к подключённому аккаунту Console, формат чисел соответствует языку приложения. В разделе **Бюджеты сервисных аккаунтов** отображается **Бюджеты недоступны.** OpenCode Go использует отдельный механизм чтения квоты.

Чтение использует сохранённый API-ключ `opencode` или, с приоритетом, подключение Console через OAuth. Для OAuth требуются `https://opencode.ai/console` и ID организации подключения; для доступа к Console нужно разрешение **Usage › Read**. CodeNomad никогда не обновляет эти учётные данные. Недействительное или просроченное OAuth-подключение нужно восстановить через его владельца, даже если также сохранён API-ключ.

Ошибки Console различают отсутствие подключения, недействительные или просроченные данные (401), запрет доступа (403), некорректный ответ об использовании и сетевой сбой. При ошибках подключения откройте **Настройки → Провайдеры**, проверьте вход и разрешения, затем обновите **Использование**. Ошибка сводки или одной страницы моделей делает всё чтение Console недоступным.

Для бесплатных моделей OpenCode (`big-pickle` и ID с окончанием `-free`) раздел **Использование** показывает **Оценка**: шаги этого сервиса с 00:00 UTC относительно ориентира 200 запросов в день с предполагаемым сбросом в следующую полночь UTC. Шаги приблизительно отражают запросы; трафик других клиентов и меняющиеся IP-лимиты могут влиять на реальную квоту. Ошибка квоты на шаге бесплатной модели помечает все бесплатные модели этого подключения OpenCode как **Лимит исчерпан** до 00:00 UTC. Индикатор показывает 100%, сохраняя известное число запросов; неизвестное число остаётся неизвестным. Отметка хранится в памяти бэкенда для каждого подключения и очищается при перезапуске.

При активном подключении OpenCode Console бесплатная оценка использует большее из числа локальных шагов и числа запросов бесплатных моделей, учтённых Console с 00:00 UTC, сохраняя отметку **Оценка**. Без доступного подключения или при ошибке чтения Console сохраняется локальная оценка. Счётчики Console охватывают аккаунт, включая другие клиенты и IP-адреса; ограничение по IP может отличаться. Оценка, отметка исчерпания и платные счётчики Console служат только для отображения; автоматический выбор аккаунта использует отдельные механизмы чтения квот и правила.

Для одного способа входа ChatGPT OpenAI не предоставляет данные об использовании: панель «Использование» сообщает об этом вместо окон квоты. Выберите [Посмотреть использование ChatGPT](https://chatgpt.com/settings/usage), чтобы проверить использование приложений и управлять их доступом к вашему тарифу и кредитам в ChatGPT. Общение в чате продолжает работать, а повторное подключение того же входа не возвращает показания.

Источники учётных данных для использования зависят от провайдера. Claude через `anthropic`/`claude` использует Anthropic OAuth OpenCode. Провайдер OpenCode **Claude Agent** (`claude-agent`) и провайдер `claude-code` используют вход Claude Code на хосте демона, включая его дистрибутив WSL: `CLAUDE_CODE_OAUTH_TOKEN`, затем сохранённый вход; `CLAUDE_SECURESTORAGE_CONFIG_DIR` / `CLAUDE_CONFIG_DIR` или `~/.claude` определяют файловое хранилище; локальная macOS может использовать Keychain. CodeNomad не подменяет один вход Claude другим.

Средства чтения использования могут обновлять токены доступа только в памяти сервера и только для провайдеров, чей токен обновления остаётся неизменным при каждом использовании, включая Gemini CLI и Antigravity. Сохранённым подключением по-прежнему управляет OpenCode. Для других истёкших входов провайдера обновите/войдите через владельца — OpenCode, Claude Code или Codex CLI — затем обновите CodeNomad. Истечение входа на сервер CodeNomad — отдельный случай: переподключитесь/войдите в CodeNomad, не предполагая повторной отправки неудачного запроса провайдера. См. [устранение неполадок](troubleshooting.md).

Если MiniMax успешно отвечает без лимитов, панель **Использование** показывает **MiniMax не сообщает свои лимиты** вместо значений квоты.

Для OpenRouter строка **Лимит ключа** показывает остаток в USD относительно лимита расходов ключа; у ключа без лимита этой строки нет. Кредиты аккаунта отображаются отдельно, если API разрешает доступ. Используется настроенный `baseURL` провайдера с префиксом пути, а при его отсутствии — `https://openrouter.ai/api/v1`. Укажите публичное имя хоста HTTPS без учётных данных, явного порта, запроса или фрагмента; IP-адреса и localhost отклоняются. При недопустимом URL или шлюзе без `/key` данные недоступны; ключ остаётся на настроенном адресе, перенаправления отклоняются.

Для z.ai и Zhipu панель использования отдаёт приоритет настроенному `apiKey`, включая значения `{env:…}` и `{file:…}`, раскрываемые OpenCode на своём хосте, а при отсутствии ключа использует сохранённые учётные данные. Без ключа и сохранённых данных провайдер отображается как ненастроенный. Ошибки бизнес-логики показываются переведённым сообщением об ошибке провайдера и числовым кодом, если он доступен, вместо значений квоты. Кредиты плана используют пятичасовое и недельное окна; у инструментов MCP отдельная квота.

Для GitHub Copilot панель **Использование** показывает расход в виде **израсходовано / лимит использовано** или потраченные кредиты безлимитного пула, если GitHub их сообщает; иначе — **Без ограничений**. Премиальные запросы сохраняют свою подпись. Внизу указан распознанный тариф. Подключения Enterprise используют `https://api.<host>/copilot_internal/user` с именем хоста или корневым HTTPS URL сохранённого подключения. Укажите полное имя хоста без учётных данных, явного порта (включая `:443`), пути за пределами `/`, запроса или фрагмента; IP-адреса и localhost отклоняются до отправки токена. Перенаправления отклоняются. При недопустимом адресе или отсутствии этого API данные недоступны. Подключения Enterprise остаются вне автоматического выбора аккаунта.

Kimi поддерживает `kimi-code-plan-cn` (kimi.com), `kimi-code-plan-global` (kimi.ai), `kimi-for-coding` и `kimi`. **Использование** последовательно пробует активный сохранённый ключ каждой интеграции, начиная с интеграции беседы, в пределах общего срока ожидания. Доступные пятичасовые, недельные, **За месяц** и **Код за месяц** лимиты показывают использованный процент. Месячные лимиты следуют дате сброса провайдера; аккаунт `kimi-for-coding` с исчерпанным месячным лимитом недоступен для автоматического выбора, даже если в более коротком окне ещё есть ресурс.

API-ключи OpenCode Go показывают доступные проценты использования и время сброса. Вход через OpenCode Console также читает баланс кошелька в USD при наличии прав на просмотр биллинга. Включите **Баланс кредитов провайдера**, чтобы видеть этот отдельный баланс (по умолчанию выключен); квоты Go и Extra Usage остаются отдельными. Один баланс оставляет квоту неизвестной для автоматического выбора. При сообщении **Срок действия ключа OpenCode Go истёк.** выберите [Создать новый ключ в OpenCode Console и заменить старый](https://opencode.ai/console/login). Создайте ключ в **Account → Personal API keys** (или запросите у администратора ключ сервисного аккаунта), затем замените сохранённый ключ через подключение провайдера. Истёкший ключ требует замены.

### Необязательные переменные окружения использования {#usage-environment}

Cursor Enterprise использует частные API панели по мере их доступности. При наличии членства и ID команды в профиле **Использование** показывает распознанный счётчик запросов `gpt-4` и отдельные суммы **Лимит на пользователя** / **Лимит команды** в USD, если они предоставлены. При неизвестных расходах отображается только лимит; при неизвестном лимите запросов — только использованное количество. Неизвестные категории и даты сброса остаются недоступными. Отсутствие команды, отказ в доступе и истёкший токен имеют отдельные сообщения; проверенные частичные данные остаются видимыми.

Задайте действующий токен доступа Cursor в переменных ниже. Для чтения Enterprise нужны права доступа к данным панели команды; [Admin API](https://cursor.com/docs/account/teams/admin-api) использует отдельный административный ключ. Обновите истёкший токен и перезапустите сервер с обновлённым окружением.

Задайте их в окружении **процесса серверной части CodeNomad** до запуска. Это учётные данные чтения использования, а не настройки браузера или выбора модели. Изменение редактора **Переменные окружения** сессии не обновляет `process.env` работающей серверной части для этих читателей. При изменении перезапустите серверную часть с нужным окружением; не перезапускайте общую службу OpenCode лишь ради переменной чтения использования.

| Интеграция использования | Переменная окружения |
| --- | --- |
| Cursor | `CURSOR_ACCESS_TOKEN`, с резервным `CURSOR_TOKEN` |
| Ollama Cloud | `OLLAMA_CLOUD_COOKIE` |
| Дополнительное использование OpenCode Go | `OPENCODE_GO_WORKSPACE_ID` и `OPENCODE_GO_AUTH_COOKIE` вместе |
| ZenMux | `ZENMUX_PLATFORM_API_KEY` — ключ платформы, отличный от ключа инференса |
| exe.dev | `EXE_DEV_USAGE_TOKEN` |
| Command Code | Резервный `COMMAND_CODE_API_KEY`, когда нативные учётные данные недоступны |

Не допускайте токены/cookies в историю оболочки, снимки экрана и отчёты. Необязательные читатели зависят от API провайдера и действительности данных; настройка переменной не гарантирует полезные данные квоты.

## Поиск по умолчанию и проектное переопределение {#web-search}

1. В **Настройки → Провайдеры** раскройте **Поиск в интернете** и подключите поисковую интеграцию по её API-ключу, если он нужен.
2. Выберите **Поиск по умолчанию** для глобальной конфигурации.
3. Используйте **Для текущего проекта** для переопределения активной Location. Наведите указатель на этот переключатель или установите на него фокус, чтобы увидеть **Поиск в этом проекте** с фактическим результатом.

Изменения сохраняются автоматически. **По умолчанию / наследуется** использует унаследованную конфигурацию или сохранённый нативный выбор; проектное переопределение важнее глобального. **Отключено** выключает поиск в выбранной области; **Автоматический провайдер** запрашивает нативный автоматический выбор. **Поиск в интернете** загружает свои подключения и варианты, только пока группа раскрыта. **Отключить** удаляет сохранённый ключ поиска; подключение из переменной окружения помечено как доступное только для чтения и не имеет **Отключить**.

Учётные данные поиска остаются глобальными для службы, даже если выбор провайдера проектный. Сохранение ключа не выбирает его поиском по умолчанию. При ошибке чтения/сохранения обновите перед повтором; не заменяйте конфигурацию вслепую. Подробности нативной конфигурации см. в [документации OpenCode](https://opencode.ai/v2/docs/) и [настройке OpenCode](opencode.md).

## Генерация и хранение изображений {#images}

1. В **Настройки → Провайдеры** разверните **Изображения**.
2. **Генерация изображений** стоит на **Включена, модель автоматически**, пока вы её не измените: вместо этого выберите одну из моделей изображений подключённых провайдеров или **Выключена**, чтобы отключить её в глобальной конфигурации.
3. Отметьте **Хранить изображения один раз**, чтобы каждое вложенное или созданное изображение хранилось один раз, а не внутри каждого сообщения, где оно используется.

Изменения сохраняются автоматически в глобальной конфигурации OpenCode и применяются ко всем проектам. Это экспериментальные функции OpenCode: **Изображения** показывает только настройки, которые поддерживает подключённая версия OpenCode. Агенты получают инструмент изображений, только пока подключённый провайдер предлагает модель изображений. Каждое изображение создаётся в фоне и сохраняется в файл; агент сообщает его путь. **Хранить изображения один раз** применяется к новым сообщениям. Если параметр **Хранить изображения один раз** определяет собственный файл конфигурации OpenCode проекта, флажок показывает действующее там значение, а сохранение записывает его и в этот файл. В остальных случаях, если настройку вместо этого определяет другая конфигурация OpenCode, например собственная конфигурация проекта, **Изображения** сообщает об этом под настройкой. Если сохранение скрыло бы экспериментальные настройки другого файла конфигурации OpenCode, **Изображения** остаётся только для чтения и сообщает об этом; измените параметры в том файле.

Чтобы создавать, сравнивать и дорабатывать изображения в отдельной беседе, см. [Создание изображений с расширением Design](extensions.md#design).
