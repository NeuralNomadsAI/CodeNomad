# Провайдеры и аккаунты

Аутентификация провайдеров принадлежит подключённой службе OpenCode, а не устройству браузера или отдельному проекту CodeNomad. Настройки отображения моделей, квоты подписок и выбор веб-поиска имеют разные области действия.

## Подключение провайдера моделей или поиска {#connect}

1. Откройте рабочее пространство, затем **Настройки → Провайдеры**. **Модели** изначально раскрыты; для поисковых провайдеров раскройте **Поиск в интернете**.
2. В этой группе нажмите **Выберите провайдера**, затем **Подключить**.
3. Для провайдера моделей выполните предложенный нативный **Способ аутентификации**: API-ключ, OAuth или команду. Для OAuth используйте **Открыть страницу авторизации** и отправляйте код авторизации только по запросу. Поисковые провайдеры подключаются по API-ключу.
4. После завершения проверьте строку настроенного провайдера. **Модели** перечитываются после подключений, смены аккаунтов и переподключений; у **Поиск в интернете** есть также **Обновить**.

Интеграции только для поиска находятся в **Поиск в интернете**, не в **Модели**. Сохранение аутентификации не выбирает модель и не меняет провайдера поиска по умолчанию. API-ключи и учётные данные OAuth сохраняет активный сервер OpenCode. Браузер получает метаданные подключения, не сохранённые секреты. Подключение из переменных окружения доступно здесь только для чтения: измените окружение-владельца, а не пытайтесь отключить его здесь.

Если окно авторизации заблокировано, используйте **Открыть страницу авторизации**, **Открыть в этой вкладке** или **Скопировать ссылку** в процедуре. Не публикуйте ссылку или код авторизации в диагностике.

## Выбор аккаунтов и управление ими {#accounts}

1. В строке провайдера используйте **Активный аккаунт** для выбора сохранённых учётных данных.
2. Нажмите **Добавить аккаунт**, чтобы авторизовать другое подключение.
3. Для управления другим сохранённым аккаунтом сначала выберите его, затем используйте **Переименовать аккаунт** или **Удалить аккаунт**. Для переименования служат **Имя аккаунта** и **Сохранить**; **Удалить аккаунт** действует сразу, без подтверждения.

Выбор, переименование и удаление влияют на интеграцию во всей службе OpenCode, включая другие проекты и клиенты. Удаление учётных данных может лишить эти клиенты аутентификации; оно не удаляет историю разговоров и не отзывает удалённый аккаунт провайдера. Подключения из окружения нельзя выбрать как изменяемые сохранённые данные или удалить здесь. При ошибке CodeNomad перечитывает аккаунты: снова проверьте **Активный аккаунт** перед действием.

### Ограничения автоматического выбора {#automatic-selection}

При нескольких сохранённых учётных данных поддерживаемой интеграции **Автоматически выбирать аккаунт** включает выбор по квоте перед допуском следующего запроса/пользовательской команды через CodeNomad. Настройка хранится для каждой интеграции в конфигурации CodeNomad; итоговый выбор аккаунта действует во всей службе.

| Подходящая интеграция | Подходящий тип аккаунта |
| --- | --- |
| OpenAI / Codex | Аккаунты подписки Codex с OAuth через браузер/устройство, не ключи OpenAI с оплатой по использованию и не способ входа ChatGPT, использование которого OpenAI не предоставляет. |
| OpenCode Go | Ключ Go или вход/ключ OpenCode Console **только для провайдера Go**, не кредиты Zen с оплатой по использованию. |
| Anthropic | Вход Claude Pro/Max OAuth в OpenCode, **не** вход Claude Code. |
| GitHub Copilot | OAuth с читаемой квотой премиум-запросов; учётные данные корпоративного эндпоинта не являются читаемыми кандидатами. |
| Планы для программирования | Аккаунты с API-ключами: `zai-coding-plan`, `zhipuai-coding-plan`, `kimi-for-coding`, `minimax-coding-plan`, `minimax-cn-coding-plan`. |

Переключение вызывает только исчерпание текущего аккаунта; более свободная альтернатива сама по себе не причина. Чтения проверяют явные сохранённые учётные данные без активации кандидатов и обмена токенов обновления. Codex, Copilot и планы программирования требуют доказанно доступного кандидата. Go, Console и Claude могут использовать кандидата с неизвестной квотой, если недавняя нативная ошибка квоты не пометила его исчерпанным. Эндпоинт использования OpenCode Go и использование Console OAuth остаются непроверенными у поставщика, поэтому доступность не гарантируется.

Это **не переключение во время выполнения при сбое**. Оно не повторяет неудачные запросы, запросы модели, команды или изменения. Оно не ротирует подключения из окружения, произвольных провайдеров, балансы с оплатой по использованию или внешние входы Claude Code. Ручные изменения аккаунта учитываются при подготовке выбора; межклиентской блокировки нет. При ошибках квоты/аутентификации проверьте **Активный аккаунт**, обновите использование и при необходимости войдите через владельца учётных данных перед осознанной повторной отправкой.

## Видимость моделей, избранное и мышление {#models}

1. Выберите **Управление моделями** рядом с провайдером моделей.
2. Найдите по имени/ID и измените видимость; **Показать все** и **Скрыть все** влияют на список выбора этого провайдера.
3. В переключателе **Модель** разговора используйте **Добавить в избранное** или **Удалить из избранного**; **Показать все модели** отключает фильтрацию только по избранному.
4. Используйте **Мышление** в поле ввода для вариантов выбранной модели.

Видимость и избранное организуют переключатели CodeNomad; они не удаляют модели, учётные данные и не мешают другим клиентам OpenCode использовать их. Скрытие модели не отключает аккаунт. Мышление выбирает вариант модели для следующих отправок, а не видимость уже имеющихся рассуждений в переписке. Верните скрытые модели через **Управление моделями → Показать все**.

## Использование, счётчики токенов и истёкшие входы {#usage}

Используйте **Использование** на правой панели для окон плана провайдера активного разговора, времени сброса и поддерживаемых балансов. Эти показания отличаются от **Токены** сообщений и оценки стоимости: квота подписки — не счёт по видимой переписке. Отсутствующее, устаревшее или неизвестное показание не означает нулевое использование или доказанный остаток. **Баланс кредитов провайдера** в **Настройки → Расширенные** управляет отображением дополнительных балансов.

Для одного способа входа ChatGPT OpenAI не предоставляет данные об использовании: панель «Использование» сообщает об этом вместо окон квоты. Общение в чате продолжает работать, а повторное подключение того же входа не возвращает показания.

Использование следует выбранным нативным учётным данным. Claude через `anthropic`/`claude` использует Anthropic OAuth OpenCode. Провайдер `claude-code` использует вход Claude Code на хосте демона, включая его дистрибутив WSL: `CLAUDE_CODE_OAUTH_TOKEN`, затем сохранённый вход; `CLAUDE_SECURESTORAGE_CONFIG_DIR` / `CLAUDE_CONFIG_DIR` или `~/.claude` определяют файловое хранилище; локальная macOS может использовать Keychain. CodeNomad не подменяет один вход Claude другим.

При истёкшем входе провайдера обновите/войдите через владельца — OpenCode, Claude Code или Codex CLI — затем обновите CodeNomad. CodeNomad не обменивает чужие токены обновления. Истечение входа на сервер CodeNomad — отдельный случай: переподключитесь/войдите в CodeNomad, не предполагая повторной отправки неудачного запроса провайдера. См. [устранение неполадок](troubleshooting.md).

### Необязательные переменные окружения использования {#usage-environment}

Задайте их в окружении **процесса серверной части CodeNomad** до запуска. Это учётные данные чтения использования, а не настройки браузера или выбора модели. Изменение редактора **Переменные окружения** сессии не обновляет `process.env` работающей серверной части для этих читателей. При изменении перезапустите серверную часть с нужным окружением; не перезапускайте общую службу OpenCode лишь ради переменной чтения использования.

| Интеграция использования | Переменная окружения |
| --- | --- |
| Cursor | `CURSOR_ACCESS_TOKEN`, с резервным `CURSOR_TOKEN` |
| Ollama Cloud | `OLLAMA_CLOUD_COOKIE` |
| Дополнительное использование OpenCode Go | `OPENCODE_GO_WORKSPACE_ID` и `OPENCODE_GO_AUTH_COOKIE` вместе |
| ZenMux | `ZENMUX_PLATFORM_API_KEY` — ключ платформы, отличный от ключа инференса |
| exe.dev | `EXE_DEV_USAGE_TOKEN` |
| Command Code | Резервный `COMMAND_CODE_API_KEY`, когда нативные учётные данные недоступны |

Не допускайте токены/cookies в историю оболочки, снимки экрана и отчёты. Необязательные читатели зависят от API провайдера и действительности данных; настройка переменной не гарантирует полезные данные квоты.

## Поиск по умолчанию и проектное переопределение {#web-search}

1. В **Настройки → Провайдеры** раскройте **Поиск в интернете** и подключите поисковую интеграцию по её API-ключу, если он нужен.
2. Выберите **Поиск по умолчанию** для глобальной конфигурации.
3. Используйте **Для текущего проекта** для переопределения активной Location. Наведите указатель на этот переключатель или установите на него фокус, чтобы увидеть **Поиск в этом проекте** с фактическим результатом.

Изменения сохраняются автоматически. **По умолчанию / наследуется** использует унаследованную конфигурацию или сохранённый нативный выбор; проектное переопределение важнее глобального. **Отключено** выключает поиск в выбранной области; **Автоматический провайдер** запрашивает нативный автоматический выбор. **Поиск в интернете** загружает свои подключения и варианты, только пока группа раскрыта. **Отключить** удаляет сохранённый ключ поиска; подключение из переменной окружения помечено как доступное только для чтения и не имеет **Отключить**.

Учётные данные поиска остаются глобальными для службы, даже если выбор провайдера проектный. Сохранение ключа не выбирает его поиском по умолчанию. При ошибке чтения/сохранения обновите перед повтором; не заменяйте конфигурацию вслепую. Подробности нативной конфигурации см. в [документации OpenCode](https://opencode.ai/v2/docs/) и [настройке OpenCode](opencode.md).
