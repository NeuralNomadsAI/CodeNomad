# Настройки и раскладка

Окно настроек использует сервер выбранного проекта для настроек проекта, провайдеров, статистики и памяти, включая её упорядочивание. Если сервер недоступен, элементы управления проектом остаются неактивными. Настройки устройства и SideCars остаются локальными. Настройки изображений и веб-поиска относятся к серверу проекта, включая его глобальные значения.

## Открытие настроек и проверка области {#open-settings}

1. Откройте **Настройки** шестерёнкой **Открыть настройки** на панели вкладок. Ярлыки вроде **Управление провайдерами** в переключателе модели, шестерёнки панели миссий или шестерёнки **Настройки** в истории уведомлений сразу открывают нужный раздел.
2. Выберите раздел. Локальные окна Electron и Tauri открывают или фокусируют одно нативное окно настроек; браузерные и удалённые виды используют встроенный экран.
3. Перед уходом проверьте область настройки и наличие действия **Сохранить**.

Большинство вариантов применяется сразу, включая настройки миссий, которые сохраняют каждое изменение по мере ввода. Для настроек голосовых API, своих цветов палитры и файлов конфигурации нужно нажать **Сохранить**. Наведите указатель на **i** рядом с названием настройки или установите на него фокус для краткого пояснения. Если значок ведёт к справке, щелчок, Enter или касание открывают нужный раздел на языке интерфейса в системном браузере или отдельной вкладке. Значки только с подсказкой показывают её при касании. В разделе **Настройки → Информация** есть также карточка **Поддержать CodeNomad**: кнопка **Спонсировать или помочь** открывает страницу [Поддержать CodeNomad](sponsor.md).

| Состояние | Чем управляет |
| --- | --- |
| Конфигурация CodeNomad | Общие настройки интерфейса и параметры с меткой **Настройка сервера**, включая API речи, SideCars, удалённое управление и переменные окружения. |
| Голосовые движки | [Движок диктовки настольного приложения](voice.md#desktop-dictation) действует для всех проектов на устройстве. [Движок разговора](voice.md#conversation) выбирается для профиля настольного приложения либо для профиля браузера и подключённого сервера. |
| Раскладка окна/вкладки проекта | Открытые панели, выбранные вкладки, состояние просмотрщика и восстанавливаемые черновики/раскладка. Это не конфигурация OpenCode. |
| Глобальные/проектные настройки OpenCode | Нативные изменения плагинов/конфигурации в показанной области. Для проектных элементов нужен активный проект/Location. |
| Профиль настольных данных | Нативные окна, состояние восстановления и хранилище браузера независимо от файла конфигурации и общей службы OpenCode. См. [Настольные окна и данные](desktop.md). |

Выбранная вкладка правой панели и режим «Файлы» сохраняются отдельно для каждой вкладки проекта. Ваши последние явные действия задают значения по умолчанию для новых вкладок; размеры панелей, порядок вкладок, настройка состава и внешний вид остаются общей раскладкой и настройками.

**Статистика** охватывает всю подключённую службу OpenCode (все проекты, независимые клоны и подсессии), а не только открытую папку, за последние 7, 30, 90 или 365 дней. Ей нужен открытый проект; она показывает записанные OpenCode токены и стоимость, а не счета провайдеров или лимиты подписок; во время обновления могут показываться прежние сохранённые итоги. Квоты планов относятся к разделу статуса **Использование**.

## Язык и оформление {#language-appearance}

1. В **Общие** выберите **Язык**: английский, испанский, французский, русский, японский, упрощённый китайский, иврит, немецкий, непальский или турецкий.
2. В **Цветовая схема** выберите **Режим**: **Авто**, **Тёмная** или **Светлая**. Авто следует операционной системе.
3. Рядом с **Режим** выберите **Контраст**: **Авто** (по умолчанию) следует системным настройкам контраста; **Вкл.** повышает контраст любой палитры; **Выкл.** использует обычный контраст.
4. Выберите палитру показанного оформления. Светлый и тёмный выбор сохраняются независимо; авто использует соответствующий.
5. Для своих цветов используйте образцы и **Сохранить**; **Сбросить** восстанавливает цвета встроенной палитры. **Новая** позволяет назвать отдельную палитру, а **Удалить** — удалить созданную вами.

Контраст применяется и сохраняется сразу, независимо от действия **Сохранить** для цветов. Он адаптирует отображение, сохраняя выбранную палитру, редактируемые цвета и черновик разговора. Значок **i** показывает текущее состояние контраста в режиме Авто.

Интерфейс обновляется без перезапуска разговора. Иврит использует раскладку справа налево; код и технические значения остаются читаемыми в своём направлении. Выбор языка меняет интерфейс, не язык существующих сообщений или инструкций агента. Нативные меню настольного приложения переключаются на язык интерфейса после загрузки окна CodeNomad.

Если цвета плохо читаются, выберите **Контраст → Вкл.** Можно также выбрать встроенную палитру или сбросить изменённую. При смене палитры может запрашиваться отказ от несохранённых правок цветов; черновик разговора сохраняется.

## Предотвращение перехода в спящий режим {#keep-computer-awake}

В разделе **Настройки → Общие** параметр **Не переводить компьютер в спящий режим, пока работает CodeNomad** по умолчанию отключён. Включите его, чтобы предотвращать переход системы в спящий режим, пока открыто локальное окно CodeNomad (в том числе свёрнутое), даже если ни одна сессия не работает; экран по-прежнему может выключаться. Если параметр отключён, CodeNomad предотвращает переход в спящий режим только во время работы сессии. Параметр отображается только в локальных окнах настольного приложения и в нативном окне настроек; в браузерных и удалённых видах он скрыт.

## Разрешения для новых разговоров {#new-conversation-permissions}

В разделе **Настройки → Общие → Разрешения для новых разговоров** выберите **Автономный** (по умолчанию) или **Под наблюдением** для новых основных разговоров, которые вы создаёте в CodeNomad. Существующие разговоры не изменятся. Чтобы изменить режим одного из них, откройте в нём [Статус → Разрешения](permissions.md#conversation-mode).

## Постоянная память агента {#agent-memory}

Пользователи, прошедшие аутентификацию через Удалённое управление, проверенный HTTPS, LAN или установленную PWA, могут просматривать и редактировать память выбранного локального или удалённого проекта и выполнять **Упорядочить**.

CodeNomad пытается удалить устаревшие инструкции памяти сеанса; если очистка тоже не удастся, прежние инструкции могут сохраниться до успешного обновления.

Откройте **Настройки → Общие → Память** (в браузере также **Настройки → Общие**). По умолчанию память отключена. Включите её, чтобы агент сохранял полезные факты и предпочтения между беседами. Переключатель относится к подключённой конфигурации CodeNomad; отключение сохраняет записи и их историю. Пока память отключена, агенты не получают инструмент памяти; переключение применяется к текущим беседам в течение нескольких секунд, без перезапуска.

- **О вас**: до 60 записей, общих для проектов этой конфигурации.
- **Проект**: до 200 записей. Этот интерфейс использует проект, выбранный в настройках, а встроенные настройки — активный проект главного окна. Сервер определяет репозиторий по нормализованному адресу Git remote, а при его отсутствии — по локальному пути репозитория; рабочие деревья используют общую память. Для выбора этой области откройте проект.

1. Выберите область, разверните счётчик её записей (например, **7/200**) и выберите запись. **Новое** и **Изменено** отмечают изменения с последнего показа записей этой области в данном браузере или настольном представлении; свёрнутая строка счётчика тоже их показывает, и отметки сохраняются в течение текущего посещения.
2. Измените **Заголовок**, **Тип** (**Факт**, **Предпочтение** или **Ссылка**) и **Текст**, затем нажмите **Сохранить**. Заголовок вмещает 60 символов, текст — 2000. **Отмена** восстанавливает сохранённое содержимое. Если запись изменена другим участником, нажмите **Перезагрузить** и проверьте её перед повторным сохранением.
3. Для удаления откройте меню действий записи и подтвердите **Забыть**. Запись уходит из активной памяти; локальный Git сохраняет историю, включая старый текст. Забывание прекращает использование агентом, но не является безопасным стиранием данных.
4. При заполнении памяти объедините или забудьте записи перед повторной попыткой. Совпадающие заголовки или сильно пересекающиеся тексты заменяют существующую запись; Git хранит предыдущий текст.

**Требует проверки** отмечает подозрительные инструкции, способные обойти защиту или раскрыть учётные данные. Эти записи доступны для редактирования здесь, учитываются в лимите и исключены из заголовков и чтений агента. Проверка выполняется при каждом чтении; исправьте и сохраните содержимое либо выберите **Забыть**.

**Упорядочить** запрашивает подтверждение, затем открывает новую беседу в проекте, показанном в настройках, для проверки и объединения выбранной области. Непроверяемые записи и внешние ссылки сохраняются, агент сообщает об изменениях. Требуются открытый проект и включённая, читаемая и доступная для записи память хотя бы с одной непомеченной записью.

Память ведёт агент. Если он уже хранит её в другом месте, например `.claude/…/MEMORY.md`, он сохраняет **Ссылку** на этот файл; внешние файлы памяти остаются под собственным управлением. Хранение только локальное, без удалённой синхронизации. Границы конфигурации и профилей описаны в разделе [Окна и данные настольного приложения](desktop.md).

## Панели и разделы статуса {#panels-status}

**Статус** по умолчанию расположен первым; сохранённый порядок вкладок имеет приоритет. Вкладка остаётся доступной. В **Настроить правую панель** её стрелка сворачивает или разворачивает список флажков разделов, не скрывая сами разделы.

Перетащите внутренний край закреплённой панели, чтобы изменить её ширину.

1. Используйте **Левая панель** и **Правая панель** во внешних углах заголовка или их пункты меню **Вид** для показа/скрытия.
2. Откройте **Настроить правую панель** в правой панели. Флажками выберите встроенные вкладки и разделы статуса; хотя бы один раздел статуса остаётся видимым. Проведите с зажатой кнопкой по этим флажкам, чтобы настроить несколько сразу.
3. Перетаскивайте вкладки правой панели для изменения порядка. **Сбросить** восстанавливает встроенные варианты раскладки.

Меняйте порядок любого раздела Статуса перетаскиванием за ручку или клавишами Вверх/Вниз. Видимость и порядок сохраняются при перезагрузке.

Статус включает информацию о токенах, Разрешения, использование провайдера, фоновые оболочки, MCP и плагины. Пока у разговора есть [цель](conversations.md#goal), её показывает строка цели над этими разделами; эта строка не является разделом, её нельзя скрыть или переместить. Скрытие раздела не отключает службу и не отзывает разрешения. Узкие раскладки закрывают панели, которые больше не помещаются, вместо сжатия разговора; панель, открытая в такой раскладке, плавает поверх него, а открытие одной плавающей панели закрывает другую.

Встроенная раскладка относится к окну. [Флажок «Миссии»](missions.md#activation) также меняет глобальную активацию плагина и пропускается при перетаскивании указателя по флажкам. Флажки расширений активируют код во всех проектах этой конфигурации. **Сбросить** не меняет согласие на расширения. См. [расширения панели](extensions.md).

## Детализация переписки и размер поля ввода {#transcript-composer}

1. Откройте **Чат** для выбора детализации переписки по умолчанию. Предустановки — **Ничего**, **Минимальный**, **Сбалансированный** и **Всё**; отдельные изменения дают **Пользовательский**.
2. Задайте для каждой строки **Состояние по умолчанию** (**Скрыто**, **Свернуто** или **Развернуто**) либо используйте окно **Содержимое сообщений** разговора с теми же настройками. В строке **Группы инструментов** вариант **Выключено** показывает каждый вызов в отдельной карточке, а **Свернуто** и **Развернуто** задают начальное состояние групп.
3. В **Общие** при необходимости отметьте **Показывать хронологию сообщений**, **Размещать стрелки первого/последнего сообщения под хронологией**, **Разделять diff вызовов инструментов** и **Ставить отправленные промпты в очередь** (ставить в очередь промпты, отправленные во время работы сессии, вместо направления её).
4. Меняйте размер поля ввода его регулятором; длинные черновики прокручиваются внутри.

На таймлайне по одному маркеру на каждый ответ, блок рассуждений, инструмент, сжатие и системный контекст, показанные в беседе, в том же порядке. Маркеры следуют **Содержимое сообщений**: скрытие там типа инструмента, рассуждений или системных сообщений скрывает и их маркеры, кроме инструмента с ожидающим разрешением, а **Ничего** скрывает все маркеры инструментов. Настройки видимости и раскрытия меняют только представление. Они не удаляют сохранённые инструменты/рассуждения и не компактируют контекст модели. Разрушительные операции см. в разделе [История и очистка](history.md).

При ручной настройке высоты поля ввода за основу берётся высота области разговора без экранной клавиатуры: минимум 8% с нижней границей 44 px, максимум 60%. Узкая область или длинный текст не повышают эти пределы. Когда клавиатура открыта, поле может временно уменьшиться, чтобы оставить место для элементов управления и сообщений. Сохранённая доля высоты при этом не меняется. Раскрытое разрешение/вопрос временно минимизирует поле без изменения сохранённой высоты или черновика. Сверните или завершите запрос для возобновления изменения размера.

## Уведомления и значки {#notifications}

Для вкладки проекта на другом сервере CodeNomad уведомления содержат имя сервера. **Открыть разговор** открывает именно этот проект и разговор; отключение сервера удаляет его уведомления.

Свёртывание контекста служебных сессий миссий проходит без уведомлений.

1. Откройте **Уведомления**. Для каждого вида уведомлений отметьте, где оно появляется: **На экране** (временное всплывающее сообщение), **История** (сохраняется в истории уведомлений колокольчика на панели вкладок) и **Система** (уведомление операционной системы). Проведите с зажатой кнопкой по строке или столбцу флажков, чтобы настроить несколько сразу.
2. Отметка в столбце **Система** при необходимости запрашивает разрешение. В **Системные уведомления** кнопка **Запросить разрешение** запрашивает его снова, пока разрешения нет.
3. Включите **Уведомлять, когда приложение в фокусе**, чтобы получать системные уведомления, пока это окно в фокусе. Иначе они появляются, как только окно теряет фокус, даже если оно остаётся открытым на экране.

По умолчанию **Сессия ждёт вашего ответа** и **Сессия завершена** отправляются только в систему, чтобы преходящие состояния сессий не накапливались в истории; они касаются основных сессий, а не субагентов, и о сессии, которую вы остановили сами, не сообщается. Ошибки всегда показываются на экране и в истории, что бы ни было в таблице, а короткие сообщения о ходе работы остаются только на экране.

Разрешение браузера/ОС принадлежит устройству и origin приложения; сохранённая настройка не может обойти отказ. При блокировке включите уведомления в браузере или ОС, затем вернитесь сюда. В неподдерживаемых средах столбец **Система** отключён.

Счётчик непрочитанного колокольчика/истории, учитывающий только уведомления, направленные в историю, управляет точкой favicon браузера и нативным значком приложения.

Если система поддерживает действия с уведомлениями, нажатие на уведомление покажет беседу, пока она открыта. Переход окна на передний план зависит от среды рабочего стола.

## Расширенные параметры {#advanced}

В Rune переведите фокус на **i** рядом с недоступным переключателем, чтобы узнать причину. Редактор конфигурации показывает строки с ошибками синтаксиса JSON/JSONC и позволяет сохранить файл.

1. Откройте **Расширенные**.
2. Отмечайте или снимайте только нужные параметры; каждое изменение сохраняется через настройки CodeNomad. Чтобы изменить окружение выполнения сессии, раскройте свёрнутую группу **Переменные окружения** в конце.

| Параметр | Эффект и предостережение |
| --- | --- |
| Автоочистка пустых сессий | Очищает пустые сессии при создании новых; оставьте выключенным, если хотите сохранять их. |
| Оставлять idle-маркеры субагентов | Сохраняет непросмотренные маркеры простоя до просмотра вместо скрытия через пять секунд. |
| Фокусировать существующее окно при втором запуске | Только нативное приложение; меняет поведение окна повторного запуска, не создание вкладок. |
| Баланс кредитов провайдера | Показывает дополнительные балансы в разделе «Использование»; не покупает кредиты и не переключает аккаунты. |
| Скрывать изменения только пробелов | Убирает неиндексированные файлы только с пробелами/окончаниями строк из изменений и массовых действий; подготовленные остаются видимыми. См. [файлы](files.md). |
| Удерживать длинные ответы ассистента | Останавливает автоматическое следование, когда потоковый ответ перерастает окно. |
| Переменные окружения | Применяются серверной стороной перед каждым запросом или командой сессии; чтения не обновляют уже запущенное выполнение. См. [настройку OpenCode](opencode.md). |
