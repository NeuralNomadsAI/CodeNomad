# Проекты и worktree

Вкладка проекта подключает CodeNomad к папке на компьютере серверной части. Открытие вкладки, просмотр рабочей копии и перемещение семейства разговоров — разные операции.

## Открытие проекта {#open-project}

Нажмите **Новый экземпляр** (`+`) или `Ctrl/Cmd+N`, чтобы открыть новую пустую вкладку. Выберите проект через **Недавние вкладки** или **Обзор**. Если восстанавливать нечего или закрыта последняя вкладка, CodeNomad показывает пустую вкладку. Клонирование и временные вкладки используют локальный сервер.

В списке недавних вкладок кнопка **Открыта** переключает на вкладку этого окна. Зелёная точка **Открыто в другом окне** обозначает подключение к серверу проекта за пределами этого окна. Нажатие на строку открывает отдельную вкладку.

[Открыть удалённый проект во вкладке](remote-access.md#remote-project-tabs) · [SideCars](browser-sidecars.md#register-sidecar)

Для копирования репозитория выберите **Клонировать Git-репозиторий**, заполните **URL репозитория** и **Папка назначения**, затем нажмите **Клонировать**. **Папка назначения** заполняется заранее: папка с именем репозитория в папке, где лежит последний клон, а без него — рядом с последним проектом. **Обзор** выбирает папку, в которой будет клон; путь, включая имя папки клона, можно изменить и вручную.

Просмотр удалённого сервера означает просмотр его файловой системы, а не телефона или ноутбука. Открытие проекта не создаёт отдельный демон OpenCode для каждой вкладки. Разговоры — нативные сессии OpenCode; их время жизни не совпадает со временем жизни вкладки.

Клонирование записывает репозиторий в папку назначения. Параметр **Сначала удалить папку назначения, если она уже существует.** разрушителен: включайте его, только если всё уже находящееся там можно удалить. Если не уверены, используйте новую папку. Неудачное клонирование не повод удалять существующий проект; перед повтором проверьте указанные папку назначения и ошибку.

Недавние записи — ярлыки. Меню действий пустой вкладки предлагает **Переименовать рабочее пространство** и **Убрать из недавних**, когда применимо; файлы и разговоры сохраняются. В пустой вкладке и в быстром меню нажатие на локальный или удалённый проект либо SideCar создаёт новый экземпляр, даже если он уже открыт. Отдельное действие **Открыта** (**Перейти к открытому проекту**) выбирает существующий экземпляр.

Действие перехода выбирает и вкладку, ожидающую сервер, а исходная пустая вкладка закрывается.

## Меню нового экземпляра {#new-instance-launcher}

Удерживайте `+` или щёлкните правой кнопкой; когда на ней фокус, используйте **Alt+Down**, **Shift+F10** или клавишу Menu.
Tab открывает поиск, стрелки и Enter выбирают, Escape возвращает фокус на `+`.

## Закрытие вкладки проекта {#close-stop}

1. Нажмите кнопку закрытия вкладки или выполните **Закрыть вкладку** в палитре команд (`Ctrl/Cmd+W` в интерфейсе).
2. Закрытие вкладки закрывает этот проект в CodeNomad: он перестаёт следить за его событиями и запросами. Сессии продолжают работать в OpenCode.
3. Снова откройте папку через обзор или недавние записи, чтобы найти эти разговоры.

| Действие | Область и эффект | Чего не делает |
| --- | --- | --- |
| Закрыть вкладку | Убирает подключение CodeNomad к проекту этой вкладки; отдельно открытая вкладка той же папки не затрагивается | Не удаляет файлы проекта или нативную историю, не останавливает сессии и не выгружает Location из OpenCode |
| Остановить сессию | Выполнение выбранного разговора | Не закрывает проект и не удаляет историю |

Неотправленные черновики и вложения закрытой вкладки возвращаются, когда вы снова открываете ту же папку в этом окне; окно хранит их для 16 последних закрытых проектов, пока его не перезагрузят или не закроют. В восстановление при запуске они не входят.

При закрытии или перезагрузке окна или вкладки браузера, а также при выходе из приложения CodeNomad просит серверы освободить соответствующие подключения проектов. Если сервер недоступен, записи могут остаться на нём. Вкладки в других окнах остаются открытыми. Восстановление при запуске повторно подключает сохранённые вкладки и сохраняет открытые временные папки. Чтобы завершить выполнение, остановите его явно; об обслуживании общей службы см. [настройку OpenCode](opencode.md).

При включённом восстановлении при запуске каждая оставшаяся вкладка восстанавливает свои настройки панелей, выбор миссии и просмотрщик, а также выбор чата или веб-предпросмотра. URL и история браузера общие для каждой сессии; сохранённые страницы загружаются только при явном повторном открытии веб-предпросмотра. Закрытие одного экземпляра папки удаляет только его сохранённый вид; повторное открытие папки создаёт новый экземпляр.

Дубликат вкладки браузера открывает собственные подключения к проектам. Ещё открытое подключение можно использовать повторно только при восстановлении той же вкладки после того, как браузер выгрузил её из памяти.

## Восстановление удалённых вкладок {#restore-remote-tabs}

При перезагрузке с включённым восстановлением удалённые вкладки сохраняют порядок, выбор и черновики. Недоступный сервер оставляет ожидающую вкладку: выберите **Повторить**, когда он вернётся, или **Подключиться** с именем пользователя и паролем либо новой ссылкой в поле **Новая ссылка сопряжения**. Другие серверы остаются доступны. **Сервер не найден** означает, что сохранённый сервер отсутствует.

**Повторить** подключает проект на сохранённом сервере и при необходимости создаёт подключение заново.

**Повторить** восстанавливает ожидающие вкладки и при отключённом автоматическом восстановлении при запуске. Уведомления выбирают существующую ожидающую вкладку. Проверьте результат неподтверждённого действия в разговоре перед повторной отправкой.

## Временные рабочие пространства {#temporary-workspaces}

1. Выберите **Временная вкладка** в верхней части пустой вкладки.
2. Работайте в пустой папке под управлением CodeNomad; Git автоматически не инициализируется.
3. При закрытии вкладки выберите **Сохранить**, **Удалить** или **Отмена**. В меню вкладки также есть **Сохранить как проект**.

| Выбор | Эффект | Восстановление |
| --- | --- | --- |
| Сохранить | Закрывает проект в CodeNomad, сохраняет папку и разговоры, убирает временный статус и добавляет недавний проект | Откройте из недавних; папка не перемещается |
| Удалить | Удаляет разговоры, файлы и неотправленные черновики временного рабочего пространства | Отмены нет; сначала сохраните нужное в другом месте |
| Отмена | Оставляет временное рабочее пространство открытым | Продолжайте работу или решите позже |

Нетронутая временная вкладка без разговора, файлов и неотправленного черновика при закрытии удаляется без вопроса. Открытые временные вкладки участвуют в обычном восстановлении при запуске.

Удаление запрещено, пока разговор выполняется или папка открыта в другой вкладке/окне. Сначала остановите запуск и закройте другие виды. При неудачном удалении пространство остаётся временным: устраните указанную проблему и повторите, а не удаляйте родительский каталог вручную.

## Выбор или создание worktree {#select-create-worktree}

1. Откройте родительский разговор и используйте переключатель worktree в поле ввода. На узких экранах это элемент только со стрелкой.
2. Выберите найденный worktree или **+ Создать worktree**.
3. Для создания заполните **Имя** и выберите **Создать и использовать worktree**.

Если проект — папка внутри репозитория, показываются только worktree, содержащие эту папку. Чтобы создать worktree из такой папки, Git должен её отслеживать. Новая ветка начинается с HEAD выбранной рабочей копии. Имя существующей ветки использует её текущую ревизию; Git может отказать, если ветка уже открыта в другом месте. По умолчанию worktree размещаются в `.codenomad/worktrees`. Незакоммиченные изменения остаются в исходной рабочей копии; создание не копирует их в новый worktree.

Переключатель в поле ввода перемещает родительский разговор и всех его рекурсивных потомков как проверенное семейство. Подсессия не может менять этот переключатель независимо. Активные сессии блокируют операцию: дождитесь завершения семейства или сначала остановите его выполнение. Дождитесь завершения перемещения перед следующим; при ошибке проверьте обновлённое состояние разговора/worktree перед повтором.

Напротив, **Просматриваемое рабочее дерево** в разделе [Файлы](files.md) меняет только рабочую копию, читаемую панелью. Это не перемещает разговор, не переключает ветку и не меняет место выполнения следующей команды оболочки.

## Удаление worktree {#remove-worktree}

1. В списке worktree поля ввода используйте **Удалить worktree** для удаляемого worktree ветки.
2. Проверьте целевую папку. Не включайте **Удалить принудительно (отбросить локальные изменения)**, если потеря локальных изменений недопустима.
3. Подтвердите удаление и проверьте итоговый список.

Удаление убирает локальную папку worktree. Основная рабочая копия Git не подлежит такому удалению. CodeNomad возвращает затронутые семейства разговоров в корневую рабочую копию и проверяет их размещение перед удалением worktree; активные сессии могут блокировать удаление. Это не архив и не резервная копия незакоммиченных файлов.

Если Git отказывает из-за изменённых/неотслеживаемых файлов, сохраните или очистите их перед повтором. Принудительное удаление явно отбрасывает их. При блокировке каталога закройте использующие его терминалы, редакторы, наблюдатели и фоновые процессы. Для передачи диагностики в окне ошибки есть **Копировать обезличенную**; сначала проверьте даже обезличенный текст.

## Инициализация Git и работа без него {#initialize-git}

1. Для обычной папки при доступном Git откройте **Файлы → Изменения** или **Коммиты**.
2. Выберите **Инициализировать Git**. Действие выполняется сразу, без дополнительного подтверждения.
3. Дождитесь обновления метаданных проекта и разговоров; используйте **Обновить**, если Git инициализирован вне CodeNomad.

Инициализация создаёт репозиторий в явно открытой папке, а не в родительской. Коммит не создаётся.

Если серверная часть не может запустить Git, разговоры и ограниченный просмотр файлов остаются доступны для явно открытой папки в режиме только каталога. Операции worktree и инициализация Git требуют Git в этой серверной части. См. [установку](install.md) и [файлы](files.md).
