# 桌面窗口与数据

## 窗口、标签页和共享服务 {#windows-tabs}

1. 使用**新建实例**在当前窗口打开另一个项目/主页标签页。
2. 使用原生 **窗口 → 新建窗口**（`Ctrl+Shift+N` 或 `Cmd+Shift+N`）打开独立应用窗口。
3. 在**设置 → 高级**中，若希望再次启动时聚焦最近使用的窗口而非新开窗口，请启用**再次启动时聚焦现有窗口**。

项目标签页、所选对话和布局属于窗口。OpenCode 会话/消息属于共享原生 OpenCode 服务：另一个窗口可以看到同一对话。关闭项目标签页会在 CodeNomad 中关闭该项目，但不会关闭其 OpenCode 会话；重新打开项目即可再次找到它们。显示同一项目连接的其他窗口也会关闭其标签页并显示通知；单独打开的同一文件夹标签页不受影响。关闭整个窗口、退出或重新加载会保留项目连接以便恢复；参阅[项目](projects.md)。不要以关闭窗口证明智能体或计划任务已停止。

窗口加载完成后，原生应用菜单会使用 CodeNomad 的界面语言；在此之前显示英文。**帮助 → 关于 CodeNomad**（也位于 macOS 应用菜单中）会打开**设置 → 信息**，其中包含版本、更新和诊断信息。

## 偏好设置和启动恢复 {#preferences-startup}

1. 从想配置的窗口打开设置。本地桌面入口会聚焦唯一的原生偏好设置窗口，并使用打开它的窗口的项目/Location。
2. 在**常规**中开启或关闭**恢复上次状态**。
3. 要忘记该窗口保存的布局，请使用**清除已保存的启动状态**。它会立即生效，无需确认。

恢复可重新打开工作区/SideCar 标签页和活动会话、未发送文本、滚动位置、面板、窗口位置和缩放。这是按窗口保存的客户端状态，而非原生对话数据库副本。清除会移除保存的标签页、草稿和布局；不会删除 CodeNomad 配置或 OpenCode 对话。请先将重要未发送草稿另存。

偏好设置窗口没有自己的独立恢复状态：这些控件针对打开它的窗口。如果该窗口已关闭，或因启动时重新打开偏好设置而未知，这些控件会改为跟随最近使用的窗口；为其他窗口准备的更改绝不会被应用，控件会先显示新窗口的值。要配置特定窗口，请从该窗口打开偏好设置。项目范围设置同样使用打开者的 Location；没有 Location 时保持不可用。启动时重新打开偏好设置后，这些设置会在该项目完成打开后重新连接；若文件夹仍在启动中，或在多个标签页中打开，它们会保持不可用，直到你从目标窗口打开偏好设置。

浏览器和远程设置采用内嵌界面，而非第二个原生偏好设置所有者。原生偏好设置打开失败会报告错误；不要因此假定已打开隐藏的内嵌设置界面。

## 桌面数据配置文件 {#data-profiles}

1. 在原生**设置 → 常规**中，于**恢复上次状态**下方展开**数据配置文件**。它列出这台计算机上的所有配置文件及其大小、创建日期和上次使用时间，当前打开的排在最前。
2. 选择下次启动要打开的配置文件，或选择**新建配置文件**并输入名称：1 到 64 个小写字母、数字、点、短横线或下划线，并以字母或数字开头。
3. 选择**在 … 中重启**可立即切换；否则所选配置文件会在下次启动时打开。再次选择当前打开的配置文件会取消此更改。

其他配置下的配置文件也会列出，但无法在此选择。没有记住的选择时，打包应用启动会检查默认、`dev` 和 `dev-v2` 配置文件中的可恢复工作，并打开其中最近使用的一个；都没有时使用默认配置文件。选择配置文件不会移动、合并或删除配置文件数据。

启动可执行文件前设置的 `CODENOMAD_PROFILE` 优先于此选择；此时**数据配置文件**会显示各配置文件，但不允许选择。`default` 或 `stable` 选择默认配置文件，名称无效会阻止启动，而非选择其他配置文件。例如，在 PowerShell 中启动目标桌面可执行文件之前：

```powershell
$env:CODENOMAD_PROFILE = "review"
```

若需独立服务器配置，也请在启动前将 `CLI_CONFIG` 设为单独配置文件。默认值为 `~/.config/codenomad/config.yaml`。仅指定桌面数据配置的名称，不会更改上述服务器配置文件或共享 OpenCode 服务。

| 桌面数据配置文件隔离的内容 | 不会自动隔离的内容 |
| --- | --- |
| 窗口/标签页恢复状态、未发送草稿和桌面单实例/后端范围 | OpenCode 会话、消息、提供商凭据和执行 |
| 关联于该配置文件的原生 Chromium/WebView 存储，受平台限制 | 共享配置时的 CodeNomad 配置/偏好、语音密钥、SideCar 和扩展激活 |
| 宿主/配置文件内的原生预览存储 | 已打开项目中的文件；远程服务器数据 |

macOS Tauri 上，分范围的配置文件共享系统 WebKit 存储、登录和缓存；不要将配置文件名用作账户安全隔离。Electron 将网页数据存储在其配置文件中。已安装版本和**更新通道**绝不会选择另一数据配置文件。未打包的开发启动默认使用 `dev`，除非显式选择。

## 删除已保存的配置文件 {#delete-profiles}

1. 按上述方式展开**数据配置文件**，按需刷新列表。
2. 选择要移除的配置文件上的删除按钮。当前打开的配置文件没有删除按钮。
3. 保留所需草稿/登录后才确认。重试前检查任何未完整移除报告。

删除会移除该配置文件保存的标签页、草稿、布局以及其拥有的网页存储/缓存/登录，列出的其他配置下的配置文件也是如此。会保留当前打开的配置文件、OpenCode 对话和项目文件。打开或状态未知的配置文件无法删除；请关闭相关 CodeNomad 窗口，刷新列表后重试。无法识别的内容会保留并报告，而非宽泛删除。

macOS Tauri 的共享 WebKit 存储会保留，因为删除会影响其他配置文件。这不是可撤销清理：幸存的原生对话无法恢复已删除的未发送草稿。若仅想重置当前窗口，**清除已保存的启动状态**是范围更小的操作。

## 缩放和面板几何布局 {#zoom-panels}

1. 使用原生 **视图 → 放大**、**缩小** 或 **实际大小**；键盘/滚轮输入也取决于宿主支持。
2. 使用标题栏固定外角的**左侧面板**和**右侧面板**切换面板。布局允许时固定/取消固定抽屉。
3. 控件放不下时，降低缩放或加宽窗口；窄布局会将控件移入菜单、将面板变为覆盖层。

本地和远程桌面主窗口至少保留 390 × 600 CSS 像素，按应用缩放调整并受显示器工作区限制。放大可扩大过小窗口；缩小不会缩小已较大的窗口。偏好设置和浏览器预览子窗口有单独尺寸规则。

面板会先保留最小对话宽度，再改为浮动。对话宽度小于 420 CSS 像素时，时间线隐藏，标题栏操作移入溢出菜单；保存的时间线偏好会保留。这些几何变化不会更改提示词草稿或原生会话。参阅[设置与布局](settings.md)和[浏览器预览与 SideCar](browser-sidecars.md)。
