# 桌面窗口与数据

## 窗口、标签页和共享服务 {#windows-tabs}

1. 使用**新建实例**在当前窗口打开另一个项目/主页标签页。
2. 使用原生 **窗口 → 新建窗口**（`Ctrl+Shift+N` 或 `Cmd+Shift+N`）打开独立应用窗口。
3. 在**设置 → 高级**中，若希望再次启动时聚焦最近使用的窗口而非新开窗口，请启用**再次启动时聚焦现有窗口**。

项目标签页、所选对话和布局属于窗口。OpenCode 会话/消息属于共享原生 OpenCode 服务：另一个窗口可以看到同一对话。关闭窗口或应用标签页不会停止服务。**停止工作区**是另一项共享操作；参阅[项目](projects.md)。不要以关闭窗口证明智能体或计划任务已停止。

## 偏好设置和启动恢复 {#preferences-startup}

1. 从想配置的窗口打开设置。本地桌面入口会聚焦唯一的原生偏好设置窗口，并使用打开它的窗口的项目/Location。
2. 在**常规 → 启动**中启用或禁用**恢复上次状态**。
3. 要忘记该窗口保存的布局，阅读后果后使用**清除已保存状态**。

恢复可重新打开工作区/SideCar 标签页和活动会话、未发送文本、滚动位置、面板、窗口位置和缩放。这是按窗口保存的客户端状态，而非原生对话数据库副本。清除会移除保存的标签页、草稿和布局；不会删除 CodeNomad 配置或 OpenCode 对话。请先将重要未发送草稿另存。

偏好设置窗口没有自己的独立恢复状态：启动设置针对打开它的确切窗口。如果该窗口关闭或更改，不可用/过时控件不会静默写入其他窗口状态。请从目标窗口重新打开偏好设置。项目范围设置同样使用打开者的 Location；没有 Location 时保持不可用。

浏览器和远程设置采用内嵌界面，而非第二个原生偏好设置所有者。原生偏好设置打开失败会报告错误；不要因此假定已打开隐藏的内嵌设置界面。

## 显式桌面数据配置文件 {#data-profiles}

未显式指定配置文件时，打包应用启动会复用为该配置记住的数据配置文件。若没有记住选择，应用检查默认、`dev` 和 `dev-v2` 配置文件中的可恢复工作：只有一个候选时选择它，有多个时询问，没有时使用默认值。选择不会移动、合并或删除配置文件数据。使用 `CODENOMAD_PROFILE` 可显式打开其他配置文件。

1. 若需有意隔离桌面数据，请在启动可执行文件前设置 `CODENOMAD_PROFILE`。
2. 名称为 1-64 个 ASCII 字母/数字、点、下划线或连字符，并以字母或数字开头。名称会转为小写；`default` 或 `stable` 选择默认配置文件。
3. 对命名配置文件，请查看**设置 → 信息 → 数据配置文件**。名称无效会阻止启动，而非选择其他配置文件。

例如，在 PowerShell 中启动目标桌面可执行文件之前：

```powershell
$env:CODENOMAD_PROFILE = "review"
```

若需独立服务器配置，也请在启动前将 `CLI_CONFIG` 设为单独配置文件。默认值为 `~/.config/codenomad/config.yaml`。仅指定桌面数据配置的名称，不会更改上述服务器配置文件或共享 OpenCode 服务。

| 桌面数据配置文件隔离的内容 | 不会自动隔离的内容 |
| --- | --- |
| 窗口/标签页恢复状态、未发送草稿和桌面单实例/后端范围 | OpenCode 会话、消息、提供商凭据和执行 |
| 关联于该配置文件的原生 Chromium/WebView 存储，受平台限制 | 共享配置时的 CodeNomad 配置/偏好、语音密钥、SideCar 和扩展激活 |
| 宿主/配置文件内的原生预览存储 | 已打开项目中的文件；远程服务器数据 |

macOS Tauri 上，分范围的配置文件共享系统 WebKit 存储、登录和缓存；不要将配置文件名用作账户安全隔离。Electron 将网页数据存储在其配置文件中。已安装版本和**更新通道**绝不会选择另一数据配置文件。未打包的开发启动默认使用 `dev`，除非显式选择。

## 删除其他已保存配置文件 {#delete-profiles}

1. 在原生**设置 → 常规 → 启动**中找到**其他已保存的配置文件**。只有机器上存在其他配置文件时才显示。
2. 按需刷新列表，选择**删除…**，阅读列出的目标和跳过的配置文件。
3. 保留所需草稿/登录后才确认。重试前检查任何未完整移除报告。

删除会移除其他配置文件保存的标签页、草稿、布局以及其拥有的网页存储/缓存/登录，包括列出的其他配置下的配置文件。会保留当前打开的配置文件、OpenCode 对话和项目文件。打开或状态未知的配置文件会跳过；请关闭相关 CodeNomad 窗口后，显式刷新并重试。无法识别的内容会保留并报告，而非宽泛删除。

macOS Tauri 的共享 WebKit 存储会保留，因为删除会影响其他配置文件。这不是可撤销清理：幸存的原生对话无法恢复已删除的未发送草稿。若仅想重置当前窗口，**清除已保存状态**是范围更小的操作。

## 缩放和面板几何布局 {#zoom-panels}

1. 使用原生 **视图 → 放大**、**缩小** 或 **实际大小**；键盘/滚轮输入也取决于宿主支持。
2. 使用标题栏固定外角的**左侧面板**和**右侧面板**切换面板。布局允许时固定/取消固定抽屉。
3. 控件放不下时，降低缩放或加宽窗口；窄布局会将控件移入菜单、将面板变为覆盖层。

本地和远程桌面主窗口至少保留 390 × 600 CSS 像素，按应用缩放调整并受显示器工作区限制。放大可扩大过小窗口；缩小不会缩小已较大的窗口。偏好设置和浏览器预览子窗口有单独尺寸规则。

面板会先保留最小对话宽度，再改为浮动。对话宽度小于 420 CSS 像素时，时间线隐藏，标题栏操作移入溢出菜单；保存的时间线偏好会保留。这些几何变化不会更改提示词草稿或原生会话。参阅[设置与布局](settings.md)和[浏览器预览与 SideCar](browser-sidecars.md)。
