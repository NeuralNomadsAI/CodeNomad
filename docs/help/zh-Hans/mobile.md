# 移动设备与 PWA

使用手机或平板浏览器界面，继续在后端主机上工作。安装 PWA 只改变界面打开方式，不改变项目、凭据或智能体执行的位置。

## 从手机或平板连接 {#connect}

1. 在主机打开**设置 → 远程访问 → 远程控制**，然后选择**启动远程控制**。
2. 用移动设备扫描配对二维码，在打算持续使用的浏览器中打开链接。
3. 或者配置[直接访问](remote-access.md)，打开主机可达且受信任的 HTTPS URL，使用服务器密码登录。

远程控制需要设备配对；直接连接需要路由、可达监听器和认证。不要在手机上使用 `localhost` 访问工作站。丢失站点数据或切换浏览器配置文件可能需要重新登录或配对；参阅[远程控制](remote-control.md)。

## 安装 PWA {#install-pwa}

1. 在支持安装的浏览器中，通过受信任 HTTPS 打开可正常使用的 CodeNomad URL。
2. 在 Chrome/Edge 等浏览器中，使用地址栏安装操作或出现时的 **Install CodeNomad** 浏览器操作。在 iPhone/iPad Safari 上使用 **Share → Add to Home Screen**；具体措辞取决于操作系统/浏览器。
3. 打开新启动入口，如果其浏览器存储独立，请在其中完成登录或配对。

安装按设备/浏览器和来源生效。不会在手机上安装 Node、Git 或 OpenCode，不会启动后端，也不会授予原生桌面集成。移除启动入口不会删除主机对话；移除访问权限时请单独撤销配对设备。

### 安全上下文与证书 {#secure-context}

远程 PWA 安装和麦克风访问需要浏览器认可的安全上下文。请使用与精确主机名/IP 匹配的可信 HTTPS 证书。生成的本地证书必须由客户端设备/浏览器显式信任；警告页面或绕过警告不是可靠的安装环境。浏览器 localhost 例外只适用于该设备，而非另一主机的 HTTP 局域网地址。

没有安装操作时，先确认 HTTPS 信任和浏览器支持，然后在完整浏览器中重新打开页面，而非内嵌二维码/应用内浏览器。麦克风失败时，检查浏览器/操作系统站点权限和[语音](voice.md)。不要为修复安装而关闭认证或 TLS 验证。

## 使用触摸布局 {#touch-layout}

使用**左侧面板**和**右侧面板**控件打开导航和工具。窄布局下，面板覆盖对话，而非强制使用桌面宽画布；打开一个浮动面板会关闭另一个。空间不足时，对话标题栏操作移入溢出菜单。

输入框底栏保留智能体、模型和思考。字段随可见对话调整尺寸，包括屏幕键盘；长草稿仍可滚动。打开中断会暂时压缩输入框，不改变保存高度或草稿。在其上方停靠区回答权限/问题，确保停靠区操作底栏可达。参阅[对话](conversations.md)和[权限](permissions.md)。

## 能力与连接限制 {#limits}

| 能力 | 移动浏览器 / PWA |
| --- | --- |
| 项目、对话、文件和权限 | 在所连接后端主机上操作，受其访问控制约束。设备附件从手机上传；项目引用在主机上解析。 |
| 原生桌面窗口、操作系统菜单和主机原生自动化 | 安装 PWA 不会提供这些能力。 |
| 浏览器预览 | 不会获得原生访客浏览器能力；后备渲染仍受浏览器限制。 |
| SideCar 内容与 WebSocket | 取决于连接路径；远程控制阻止 SideCar 内容代理、预览内容和 WebSocket 升级。参阅其[精确限制](remote-control.md)。 |
| 麦克风、剪贴板、通知和安装提示 | 取决于浏览器/操作系统支持、安全上下文和用户权限。 |
| 离线工作 | 无离线后端或缓存 API 历史。静态界面资源可能缓存，但文档和 API 响应不是离线工作区。 |

请保持后端可达。移动操作系统挂起或网络切换可能断开事件流；返回后会重新连接并重新获取当前状态，不保证事件重放。重试操作前检查是否已完成。关闭 PWA 不会停止独立后端；退出主机桌面应用及其后端会使远程控制不可用，直到下次启动。
