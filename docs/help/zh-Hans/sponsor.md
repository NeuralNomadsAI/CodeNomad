# 赞助 CodeNomad

{{funding}}

我全职开发和维护 CodeNomad。它免费且开源，我希望继续给予它一款用于真实工作的工具应得的投入。

我来自 3D 和视觉特效领域：三十年来，我一直在创作、解决制作中的问题，并与使用软件的人一起开发软件。这段经历决定了我对待 CodeNomad 的方式：一个工具必须经得起首次演示之后的考验，经得起长时间的会话、复杂的项目，以及日常使用中的各种意外。

反馈、错误报告和代码贡献让 CodeNomad 变得更好。捐赠支持我投入时间，把这些意见变成可靠的改进，并随着 OpenCode 的发展持续维护它。

要继续全职做这件事，我需要这份经济支持。如果 CodeNomad 已经成为你工作的一部分，赞助能帮助我以开发和维护一款人人可用的工具为生。

Pascal André

## 其他帮助方式 {#other-ways}

- 为[仓库](https://github.com/NeuralNomadsAI/CodeNomad)点星标，并向使用 OpenCode 的人介绍 CodeNomad。
- 附上最小复现来[报告错误](support.md#report-a-bug)。
- 通过任一帮助页面底部的**编辑此页**链接修正帮助页面或翻译。
- 通过面向 `dev` 的聚焦拉取请求[贡献代码](support.md#contribute)。
