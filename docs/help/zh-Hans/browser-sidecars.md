# 浏览器预览与 SideCar

## 打开会话浏览器 {#session-browser}

1. 在对话工具栏中选择**打开网页预览**。
2. 输入不含凭据的 `http://` 或 `https://` **预览 URL**，然后选择**打开预览**。使用工具栏导航、刷新和后退/前进。
3. 使用预览关闭按钮返回聊天。在该对话中重新打开即可继续。

远程预览禁用 Service Worker。

点击对话中的 `localhost` 或 `127.0.0.1` 链接时，会在预览可用的客户端上于该会话的网页预览中打开。通过 Remote Control 且主机关闭网页预览时，或在预览因其他原因不可用的客户端上，此类链接保持正常的浏览器行为。Ctrl+点击（macOS 上为 ⌘+点击）或鼠标中键点击可改为在浏览器中打开该链接。在无法使用真实存储的沙盒预览框架内，页面会获得仅限当前页面加载的内存版 `localStorage`、`sessionStorage` 和 `document.cookie`；单独打开的按令牌预览主机保留其真实存储。

每个预览属于其项目文件夹和会话。切换对话、项目、信息或聊天会隐藏已显式打开的原生访客页面，但不丢弃活动文档/历史。隐藏页面不是自动化目标。关闭项目/窗口或重启渲染器会结束活动文档。

保存的历史只在显式重新打开该会话浏览器时恢复，而非启动/选择会话时。它保存 URL 和游标，不保存未发送表单、DOM、POST 正文或 JavaScript 内存。历史受每会话 32 个 URL 和共享布局预算限制；旧条目可能被裁剪。恢复 URL 可能重新加载页面；不是事务重放。

远程项目标签页通过该项目的 CodeNomad 服务器加载预览。地址栏和保存的历史记录显示应用 URL。关闭预览或项目标签页、断开连接或移除服务器、退出应用，都会结束当前页面及其连接；重新打开时会根据保存的地址和历史记录重新加载。服务器登录凭据保留在后端，代理传输的应用 Cookie 会被过滤。请仅在 CodeNomad 内部使用预览的内部加载地址。

原生远程预览禁用上下文菜单、链接拖出、打印、弹出窗口、下载、页面对话框和权限提示，以保护内部加载地址。关闭前请保存页面中的工作。

## 共享登录与自动化边界 {#signins-automation}

在同一桌面引擎和配置文件/配置范围内，原生预览跨项目/会话共享 cookie、登录和站点存储，与可信 CodeNomad 渲染器分开。在一个预览中退出站点会影响使用该存储的其他预览。文档、表单、会话存储、导航历史和自动化附件仍归各会话所有。iframe 预览不是完整共享原生浏览器配置文件。

| 客户端 | 预览实现 | 智能体浏览器自动化 | 移动模板 |
| --- | --- | --- | --- |
| 支持的桌面平台上的 Electron | 原生 Chromium 访客页面；支持 OAuth 弹窗、下载和对话框 | 支持可见且归属已确认的会话预览 | Android/Chromium 身份、触摸和像素密度仿真 |
| Windows Tauri | 原生 WebView2 子窗口；支持 OAuth 弹窗、下载和对话框 | 支持可见且归属已确认的会话预览 | Android/Chromium 身份、触摸和像素密度仿真 |
| macOS Tauri (14+) | 原生 WKWebView 子窗口；支持 OAuth 弹窗、下载和对话框 | 支持可见且归属已确认的会话预览 | WebKit 移动标识和 CSS 视口；输入受原生限制 |
| Linux Tauri | 原生 WebKitGTK 子窗口；支持 OAuth 弹窗、下载和对话框 | 支持可见且归属已确认的会话预览 | WebKit 移动标识和 CSS 视口；密度和输入受原生限制 |
| 普通浏览器/远程视图 | iframe 后备实现 | 无本地原生预览目标 | 仅尺寸 |

在所有原生桌面宿主上，会话绑定的 `codenomad.browser` 都可打开、导航、快照和截图预览，并执行点击、输入、选择、悬停、拖动、滚动、按键和等待文本操作。执行时会检查所属后端、原生能力、会话和可见目标。隐藏、替换或导航后的目标会被拒绝；操作绝不自动重试。页面内容仍不可信。对于阻止 iframe 嵌入的网站，请使用外部浏览器。

原生预览可手动或由智能体打开，重启后保留登录，并使用原生后退/前进历史。本地菜单和对话框会隐藏预览。原生模式不支持元素评论。WebKit 可读取脚本创建的封闭 shadow root；声明式封闭根保持不透明。macOS 首次悬停可能省略 pointerenter；⌘A 通过原生响应器选择，不产生 A keydown。GTK 剪贴板读取需显式 Ctrl+V；写入和原生复制/粘贴可用。

原生弹窗共享预览登录状态，保留 `opener`/`postMessage`，并随打开它的页面关闭。输入或恢复的地址仅允许无凭据的 HTTP(S)；网站还可打开空白文档和同源 blob 文档。文件及应用协议被阻止。下载使用清理后的唯一名称保存到“下载”文件夹，不覆盖文件，也不自动打开。摄像头、麦克风、位置和通知始终被拒绝；已分类权限需要同意，未知请求显示错误。Tauri 和 Electron 支持 `alert`/`confirm`/`prompt`；Electron 的 prompt 对话框适用于预览顶层页面、弹窗和子框架。设备及屏幕选择列表可滚动查看可用项目。其他 API 取决于引擎和硬件。

网站可在关闭原生弹窗时要求确认。Linux 的指针锁定同意控件显示在所属窗口顶部。受 [WebKit 323277](https://bugs.webkit.org/show_bug.cgi?id=323277) 影响的 WebKitGTK 版本（包括 2.52.6）因安全措施阻止访问拖放的文件，上传时请使用页面的文件选择器。关闭或重新加载所属 CodeNomad 窗口前，请保存页面中的工作。

在 Tauri macOS/Linux 中，聚焦预览后，可用 ⌘/Ctrl 配合 +、− 或 0，或使用应用的缩放菜单来缩放预览。焦点在其他位置时，这些菜单操作会缩放应用。

## 选择六种视口模板之一 {#templates}

1. 打开预览视口菜单。
2. 选择下列模板。直接使用纵向/横向条目；没有单独旋转控件。
3. 在 Electron 和 Windows Tauri 中，进入/更改移动仿真或返回仅尺寸模板时，预期会发生原生重新加载。

| 模板 | CSS 视口 |
| --- | --- |
| 响应式视口 | 可用预览空间 |
| 桌面视口 | 1440 × 900 |
| 平板视口 | 768 × 1024 |
| 平板横向 | 1024 × 768 |
| 手机视口 | 390 × 844 |
| 手机横向 | 844 × 390 |

在 Electron 和 Windows Tauri 上，移动模板仅对所属访客页面设置 Android/Chromium 身份、方向、触摸和 DPR 2.75。返回响应式/桌面/平板会清除覆盖值并重新加载。Tauri macOS/Linux 在 HTTP 和 JavaScript 中应用通用 WebKit 移动标识，并独立于应用缩放/DPI 调整 CSS 视口；切换模板和重置会重新加载。macOS 在可用时使用原生 DPR 2.75；GTK 密度取决于适配缩放和显示器。屏幕、平台、指针/悬停媒体和最大触点数保留原生桌面值。GTK 移动点击产生原生触摸和兼容鼠标事件；macOS 保留鼠标输入。iframe 后备实现只调整尺寸。这些配置提供布局参考；手机键盘、系统栏和移动文字设置不在其范围内。切换模板前请保存页面工作，因为重新加载可能丢弃未发送页面状态。

## 注册 SideCar {#register-sidecar}

1. 在 CodeNomad 后端主机上单独启动网页工具，监听 `127.0.0.1:<port>`。
2. 打开**设置 → SideCars**。输入**名称**和**端口**；检查推导出的**基础路径**（`/sidecars/<id>`）。
3. 将**协议**设为匹配上游服务，并选择**前缀模式**。
4. 选择**添加 SideCar**，然后从主页选择**打开 SideCar**打开其标签页。

| 选择 | 精确影响 |
| --- | --- |
| HTTPS（表单默认） | CodeNomad 以上游 `https://127.0.0.1:<port>` 连接。 |
| HTTP | CodeNomad 以上游 `http://127.0.0.1:<port>` 连接。不改变公共 CodeNomad 连接的 TLS 设置。 |
| 移除前缀（默认） | `/sidecars/<id>/path` 转发到上游时变为 `/path`。 |
| 保留前缀 | `/sidecars/<id>/path` 原样转发到上游。请相应配置服务自身基础路径。 |

注册是服务器配置，由客户端共享；既不安装也不启动服务。端口位于后端主机，而非查看用的笔记本电脑或手机。**运行中**表示可达，不表示工具应用/认证正常。移除注册不会停止单独启动的进程。关闭标签页也不会停止它。

不可达时，检查后端进程和端口。HTML 可加载但资源/WebSocket 失败时，检查工具基础路径和前缀模式。以目标设置重新创建错误注册；不要仅为绕过代理错误而公开上游。SideCar 应用可能以服务器账户权限提供终端或文件；请信任其用户和配置。

SideCar 是 CodeNomad 的可信扩展，而不是沙箱预览：其页面以 CodeNomad 自身的源运行，因此其脚本可以凭借你的登录访问权限使用 CodeNomad。只注册你信任其代码的服务。CodeNomad 不会将自身的登录 cookie 转发给该服务，但会保留该服务自己的 cookie。

SideCar 内容（`/sidecars/`）和 SideCar WebSocket 要求在主机上使用回环连接。通过 `/api/sidecars` 注册可供已配对设备和已认证的局域网直连客户端使用。持有有效能力令牌时，活动预览内容（`/previews/`）可通过局域网直接访问；[远程控制](remote-control.md#remote-surface)网页预览在启用时仍可通过其能力令牌访问。直接访问的要求请参阅[升级](remote-access.md#upgrading)。

## OpenVSCode Server 示例 {#openvscode}

1. 在后端主机运行 Docker，将服务绑定到回环地址：

```sh
docker run -it --init -p 127.0.0.1:8000:3000 -v "${HOME}:${HOME}:cached" -e HOME=${HOME} gitpod/openvscode-server --server-base-path /sidecars/vscode
```

2. 注册**名称** `VSCode`、**端口** `8000`、**协议** `HTTP`、**前缀模式** **保留前缀**。
3. 验证显示基础路径为 `/sidecars/vscode`，然后打开 SideCar。

此 Shell 示例将主目录挂载到容器中；如果编辑器只应访问更小范围，请缩小挂载。服务的 `--server-base-path` 必须与注册精确匹配。完成后单独停止容器；删除 SideCar 不会移除容器或其文件。

## ttyd 终端示例 {#ttyd}

1. 在后端主机上启动绑定回环地址的可写 Shell 终端：

```sh
ttyd --interface 127.0.0.1 --writable zsh
```

2. 注册**名称** `Terminal`、**端口** `7681`、**协议** `HTTP`、**前缀模式** **移除前缀**。
3. 在显示的 `/sidecars/terminal` 基础路径打开 SideCar。

终端以启动 ttyd 的账户权限运行。`zsh` 不可用时选择其他 Shell。若更改 ttyd 默认端口，请使用实际端口，并在完成后单独停止 ttyd。为 CodeNomad 访问启用认证并加以保护；可写终端不是沙箱。
