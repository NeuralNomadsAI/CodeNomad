# 浏览器预览与 SideCar

iframe 预览和 SideCar 会拒绝连接到 CodeNomad 自身的监听地址和端口，包括通过 DNS 别名的连接。请使用应用服务器的独立端口。

## 打开会话浏览器 {#session-browser}

1. 在对话工具栏中选择**打开网页预览**。
2. 输入不含凭据的 `http://` 或 `https://` **预览 URL**，然后选择**打开预览**。使用工具栏导航、刷新和后退/前进。
3. 使用预览关闭按钮返回聊天。在同一标签页和对话中重新打开即可继续。

远程预览禁用 Service Worker。

点击对话中的 `localhost` 或 `127.0.0.1` 链接时，会在预览可用的客户端上于该会话的网页预览中打开。通过 Remote Control 且主机关闭网页预览时，或在预览因其他原因不可用的客户端上，此类链接保持正常的浏览器行为。Ctrl+点击（macOS 上为 ⌘+点击）或鼠标中键点击可改为在浏览器中打开该链接。

返回聊天或将原生预览移到同一窗口中的其他标签页时，当前页面会保留。

每个标签页保存聊天或预览的选择；会话保存共享 URL、视口模板和历史。已保存的页面只在显式重新打开会话浏览器时加载。持久化保存 URL 和游标；活动表单、DOM、POST 正文和 JavaScript 内存随文档结束。历史受每个会话 32 个 URL 及窗口共享预算限制，旧条目可能被裁剪。恢复 URL 可能重新加载页面。

远程预览使用项目所在的服务器，并显示应用 URL。关闭预览或标签页、断开服务器或退出应用都会结束实时页面。重新打开时会加载已保存的地址与历史记录，未保存的更改会丢失。请勿公开内部加载地址。

原生远程预览禁用上下文菜单、剪贴板导出、链接拖出、打印、弹出窗口、下载、页面对话框和权限提示，以保护内部加载地址。关闭前请保存页面中的工作。

主机和远程项目服务器均确认预览可用后，才会显示预览控件。

远程控制的**网页预览**默认开启，位于主机的**设置 → 远程访问 → 远程控制**。关闭后会结束预览及其 WebSocket 连接；重新加载后将隐藏**打开网页预览**。退出登录或撤销配对设备的访问权限会结束该设备的预览及其 WebSocket 连接。

## 共享登录与自动化边界 {#signins-automation}

在 Electron 和 Windows 版 Tauri 上，自动重启（`codenomad.act` 的 `restart`）会重新启动已检查窗口所用的配置档、配置和构建。如果原窗口已恢复，工具会再次检查它；否则会报告原窗口未恢复，不会检查其他窗口。重新连接期间成功完成的检查优先。

如果重启被取消，请使用 `codenomad.inspect` 并指定 `targets: true` 列出打开的窗口，再用 `target` 指定要检查的窗口。

在同一桌面引擎和配置文件/配置范围内，原生预览跨项目/会话共享 cookie、登录和站点存储，与可信 CodeNomad 渲染器分开。在一个预览中退出站点会影响使用该存储的其他预览。文档、表单、会话存储、导航历史和自动化附件归各个会话所有。

每个会话只有一个原生预览。如果重复的标签页显示**预览已在另一个标签页中打开**，请选择**转到该标签页**查看，或选择**在此打开**在同一窗口内移动预览。移动后，原标签页会显示相同的提示。关闭预览所在的标签页后，可在其他标签页中打开预览。

桌面窗口显示某个会话时，该会话的智能体可以使用 OpenCode 的浏览器工具（OpenCode 2.4 或更高版本）控制其预览；在页面中运行脚本会被拒绝，并且在 macOS 和 Linux 上的 Tauri 应用中无法后退、前进或重新加载。在 Electron 和 Windows 版 Tauri 应用中，它们还可以读取预览的控制台消息和网络请求；在预览仍保留时，它们可以看到请求和响应的标头与文本正文，但 Cookie 和授权标头的值除外。智能体在预览所在的标签页中打开预览；如果预览尚未打开，则使用该会话最近用过的标签页。页面操作针对可见的原生预览。页面与你看到的预览一样通过这台电脑的网络加载，因此即使 OpenCode 在 WSL 中运行，`localhost` 也是指这台电脑。

智能体在操作预览或截屏之前会先获取快照。如果预览发生变化，命令会停止，不会改为操作其他预览。

| 客户端 | 预览实现 | 智能体浏览器自动化 | 移动模板 |
| --- | --- | --- | --- |
| 支持的桌面平台上的 Electron | 原生 Chromium 访客页面；支持 OAuth 弹窗、下载和对话框 | 支持可见且归属已确认的会话预览 | Android/Chromium 身份、触摸和像素密度仿真 |
| Windows Tauri | 原生 WebView2 子窗口；支持 OAuth 弹窗、下载和对话框 | 支持可见且归属已确认的会话预览 | Android/Chromium 身份、触摸和像素密度仿真 |
| macOS Tauri (14+) | 原生 WKWebView 子窗口；支持 OAuth 弹窗、下载和对话框 | 支持可见且归属已确认的会话预览 | WebKit 移动标识和 CSS 视口；输入受原生限制 |
| Linux Tauri | 原生 WebKitGTK 子窗口；支持 OAuth 弹窗、下载和对话框 | 支持可见且归属已确认的会话预览 | WebKit 移动标识和 CSS 视口；密度和输入受原生限制 |
| 普通浏览器/远程视图 | iframe 后备实现 | 无本地原生预览目标 | 仅尺寸 |

原生模式不支持元素评论。GTK 剪贴板读取需显式 Ctrl+V；写入和原生复制/粘贴可用。对于阻止 iframe 嵌入的网站，请使用外部浏览器。

原生弹窗共享预览登录状态，保留 `opener`/`postMessage`，并随打开它的页面关闭。输入或恢复的地址仅允许无凭据的 HTTP(S)；网站还可打开空白文档和同源 blob 文档。文件及应用协议被阻止。下载使用清理后的唯一名称保存到“下载”文件夹，不覆盖文件，也不自动打开。摄像头、麦克风、位置和通知始终被拒绝；已分类权限需要同意，未知请求显示错误。Tauri 和 Electron 支持 `alert`/`confirm`/`prompt`；Electron 的 prompt 对话框适用于预览顶层页面、弹窗和子框架。

网站可在关闭原生弹窗时要求确认。受 [WebKit 323277](https://bugs.webkit.org/show_bug.cgi?id=323277) 影响的 WebKitGTK 版本（包括 2.52.6）因安全措施阻止访问拖放的文件，上传时请使用页面的文件选择器。关闭或重新加载所属 CodeNomad 窗口前，请保存页面中的工作。

在 Tauri macOS/Linux 中，聚焦预览后，可用 ⌘/Ctrl 配合 +、− 或 0，或使用应用的缩放菜单来缩放预览。焦点在其他位置时，这些菜单操作会缩放应用。

## 选择六种视口模板之一 {#templates}

1. 打开预览视口菜单。
2. 选择下列模板。直接使用纵向/横向条目；没有单独旋转控件。
3. 在 Electron 和 Windows Tauri 中，进入/更改移动仿真或返回仅尺寸模板时，预期会发生原生重新加载。

| 模板 | CSS 视口 |
| --- | --- |
| 响应式视口 | 可用预览空间 |
| 桌面视口 | 1440 × 900 |
| 平板视口 | 768 × 1024 |
| 平板横向 | 1024 × 768 |
| 手机视口 | 390 × 844 |
| 手机横向 | 844 × 390 |

在 Electron 和 Windows Tauri 上，移动模板仅对所属访客页面设置 Android/Chromium 身份、方向、触摸和 DPR 2.75。返回响应式/桌面/平板会清除覆盖值并重新加载。Tauri macOS/Linux 在 HTTP 和 JavaScript 中应用通用 WebKit 移动标识，并独立于应用缩放/DPI 调整 CSS 视口；切换模板和重置会重新加载。iframe 后备实现只调整尺寸。这些配置提供布局参考；手机键盘、系统栏和移动文字设置不在其范围内。切换模板前请保存页面工作，因为重新加载可能丢弃未发送页面状态。

## 注册 SideCar {#register-sidecar}

1. 在 CodeNomad 后端主机上单独启动网页工具，监听 `127.0.0.1:<port>`。
2. 打开**设置 → SideCars**。输入**名称**和**端口**；检查推导出的**基础路径**（`/sidecars/<id>`）。
3. 将**协议**设为匹配上游服务，并选择**前缀模式**。
4. 选择 **添加 SideCar**，然后从 **浏览** 打开。 [项目标签页](projects.md#open-project).

关闭标签页后，仍在运行的 SideCar 会留在最近标签页列表中。

| 选择 | 精确影响 |
| --- | --- |
| HTTPS（表单默认） | CodeNomad 以上游 `https://127.0.0.1:<port>` 连接。 |
| HTTP | CodeNomad 以上游 `http://127.0.0.1:<port>` 连接。不改变公共 CodeNomad 连接的 TLS 设置。 |
| 移除前缀（默认） | `/sidecars/<id>/path` 转发到上游时变为 `/path`。 |
| 保留前缀 | `/sidecars/<id>/path` 原样转发到上游。请相应配置服务自身基础路径。 |

注册是服务器配置，由客户端共享；既不安装也不启动服务。端口位于后端主机，而非查看用的笔记本电脑或手机。移除注册不会停止单独启动的进程。关闭标签页也不会停止它。

不可达时，检查后端进程和端口。HTML 可加载但资源/WebSocket 失败时，检查工具基础路径和前缀模式。 以目标设置重新创建错误注册；不要仅为绕过代理错误而公开上游。SideCar 应用可能以服务器账户权限提供终端或文件；请信任其用户和配置。

SideCar 是 CodeNomad 的可信扩展，而不是沙箱预览：其页面以 CodeNomad 自身的源运行，因此其脚本可以凭借你的登录访问权限使用 CodeNomad。只注册你信任其代码的服务。CodeNomad 不会将自身的登录 cookie 转发给该服务，但会保留该服务自己的 cookie。

SideCar 内容（`/sidecars/`）和 SideCar WebSocket 要求在主机上使用回环连接。如需从其他设备打开，请在主机的**设置 → SideCars**中开启**通过 HTTPS 打开 SideCars**：通过此服务器的 HTTPS 地址或 `CODENOMAD_ALLOWED_ORIGINS` 中的 HTTPS 来源（例如 TLS 反向代理）登录的浏览器即可打开 SideCars。普通 HTTP、`localhost` 地址和远程控制仍仅限主机使用。通过 `/api/sidecars` 注册可供已配对设备和已认证的局域网直连客户端使用。持有有效能力令牌时，活动预览内容（`/previews/`）可通过局域网直接访问；[远程控制](remote-control.md#remote-surface)网页预览在启用时仍可通过其能力令牌访问。直接访问的要求请参阅[允许的来源](remote-access.md#upgrading)。

## OpenVSCode Server 示例 {#openvscode}

1. 在后端主机运行 Docker，将服务绑定到回环地址：

```sh
docker run -it --init -p 127.0.0.1:8000:3000 -v "${HOME}:${HOME}:cached" -e HOME=${HOME} gitpod/openvscode-server --server-base-path /sidecars/vscode
```

2. 注册**名称** `VSCode`、**端口** `8000`、**协议** `HTTP`、**前缀模式** **保留前缀**。
3. 验证显示基础路径为 `/sidecars/vscode`，然后打开 SideCar。

此 Shell 示例将主目录挂载到容器中；如果编辑器只应访问更小范围，请缩小挂载。服务的 `--server-base-path` 必须与注册精确匹配。完成后单独停止容器；删除 SideCar 不会移除容器或其文件。

## ttyd 终端示例 {#ttyd}

1. 在后端主机上启动绑定回环地址的可写 Shell 终端：

```sh
ttyd --interface 127.0.0.1 --writable zsh
```

2. 注册**名称** `Terminal`、**端口** `7681`、**协议** `HTTP`、**前缀模式** **移除前缀**。
3. 在显示的 `/sidecars/terminal` 基础路径打开 SideCar。

终端以启动 ttyd 的账户权限运行。`zsh` 不可用时选择其他 Shell。若更改 ttyd 默认端口，请使用实际端口，并在完成后单独停止 ttyd。为 CodeNomad 访问启用认证并加以保护；可写终端不是沙箱。
