# 远程控制

远程控制让已配对浏览器或桌面客户端无需开放入站网络端口即可使用运行中的 CodeNomad 后端。无需服务器密码、非回环 `--host` 或 VPN。它是独立于[直接连接](remote-access.md)的访问路径。

## 启动和配对 {#start-and-pair}

1. 在主机打开**设置 → 远程访问**。
2. 选择**启动远程控制**。等待**已准备好远程连接**；首次使用可能需要时间配置隧道身份和证书。
3. 在**连接其他设备**下扫描二维码或选择**复制链接**，然后在目标设备打开该一次性链接。
4. 保留已配对浏览器的站点数据。后端运行时重新打开隧道地址即可重连。

链接有效期为**五分钟**，只能成功使用**一次**。请将其视为凭据：任何消费它的人都能成为配对设备。配对码位于 URL 片段，而非查询字符串。**创建新的配对链接**会立即使上一个未使用链接失效。后端关闭会取消未使用的配对链接；停止和隧道失败会取消隧道链接。

在另一台电脑上的 CodeNomad 中，将配对链接粘贴到**设置 → 服务器 → 服务器地址或链接**。

如需重新配对，请将新链接粘贴到服务器或项目的连接表单中。

## 通过直接 HTTPS 配对 {#direct-https}

当隧道被阻断、但后端可通过可信 HTTPS 访问时（例如使用正式证书的反向代理），设备可以改在该地址配对。可用地址为此后端自身的 HTTPS 地址和 `CODENOMAD_ALLOWED_ORIGINS` 中的 HTTPS 来源（参阅[允许的来源](remote-access.md#upgrading)）；环回名称和明文 HTTP 永远不能配对。无需启动远程控制。

1. 在主机打开**设置 → 远程访问 → 远程控制**。
2. 在**HTTPS 直接配对**下，如有多个地址先选择**HTTPS 地址**，然后选择**创建 HTTPS 配对链接**。
3. 像隧道链接一样在设备上打开该链接。也可以从其他页面点击打开。

该链接遵循相同的五分钟、一次性规则，并替换任何未使用的链接；反复输入错误代码会被限流。反向代理必须终止可信 TLS，传递原始 `Host` 和 `Origin` 请求头，并通过环回或受保护的网络访问后端。

此类设备只能通过其 HTTPS 地址连接，永远不能通过隧道连接；**已配对设备**会在其名称下显示该地址。停止远程控制既不会取消链接，也不会断开这些设备；**撤销**、30 天未使用、32 台设备上限或从配置中移除该地址会结束其访问。在该地址出示已撤销或过期设备凭据的浏览器不能回退到服务器密码：请重新配对，或清除站点数据后用密码登录。

参阅[可用功能](#remote-surface)，其中包括 SideCar 内容的 HTTPS 直连例外。即使经由主机上的代理，配对也不授予环回权限。

## 管理配对设备 {#paired-devices}

1. 在主机返回**设置 → 远程访问 → 远程控制**。
2. 检查**已配对设备**及其**上次活动**时间。每台设备以配对时所用的平台和浏览器命名，例如 `iPhone · Safari`。
3. 对不应继续连接的设备选择**撤销**。如果显示**撤销待保存**，请在重启主机前再次选择**撤销**。

撤销会终止该设备当前的 HTTP/SSE 连接及未来访问。使用新链接重新配对即可恢复访问。设备**连续 30 天未使用**后过期。达到 **32 台设备上限**时，新配对会替换最久未见的设备并关闭其连接。

清除站点数据、切换浏览器配置文件或使用隐私浏览可能需要重新配对。

更改直接访问密码**不会**撤销设备。**停止远程控制**会断开隧道，但保留已配对设备列表；要移除授权请使用**撤销**。

### 不丢失当前位置地重新配对 {#re-pair}

1. 如果客户端显示**重新配对此设备**，请保持该页面打开。
2. 在主机上为原连接创建新链接：若使用隧道，选择**创建新的配对链接**；若使用 HTTPS 直连，在**HTTPS 直接配对**中选择原来的**HTTPS 地址**，再选择**创建 HTTPS 配对链接**。在同一客户端浏览器或配置文件中打开链接。独立的远程窗口会复用其存储。
3. 返回等待页面并选择**检查连接**；页面重新获得焦点时也会再次检查。

恢复会保留打开页面和草稿；不会重放失败操作。重试发送、回答或删除之前，请检查是否已生效。直接访问密码无法恢复远程控制配对。

## 可用性与生命周期 {#lifetime}

| 操作/状态 | 影响 |
| --- | --- |
| 启动远程控制 | 连接此后端并记住选择，供后续启动使用。 |
| 关闭远程浏览器 | 不停止主机后端，也不撤销设备。 |
| 停止远程控制 | 断开隧道访问并清除自动启动恢复；保留设备记录。 |
| 后端关闭 / 最后一个桌面窗口关闭且应用退出 | 远程控制离线。OpenCode 共享服务可继续运行，但无法通过已停止后端提供此界面。 |
| 保持远程控制启动状态后再次启动 | 后台重连，不签发新配对链接。从未启动过的安装不会自行启用。 |

自动启动恢复限制为每个配置目录一个后端。不要用同一配置启动相互竞争的主机来增加隧道容量。若桌面退出后主机仍须可达，请部署单独管理的[独立服务器](server.md)；远程控制不是独立守护进程。

## 可用和不可用界面 {#remote-surface}

配对设备可以使用普通项目/对话 API、发送提示词、检查文件和回答权限/Form，并受相同归属检查约束。配对是强大访问权限，而非只读共享链接。即使隧道在主机内部转发流量，也绝不授予回环特权。

| 界面 | 通过远程控制 |
| --- | --- |
| 普通已认证界面、工作区、对话和 SSE | 配对设备可用。 |
| 密码登录/退出、密码更改、本地令牌初始化 | 不可用；即使禁用直接认证，仍需要设备凭据。 |
| 远程控制状态 | 配对设备可读；管理不可用。启动/停止、创建配对、设备列表和撤销保留在主机访问路径上。 |
| 已保存的服务器和后端中继 | 功能已启用且主机能力允许时，已认证的远程客户端可以使用和管理主机保存的所有服务器。新的服务器密码或配对链接需要远程控制或 HTTPS，不能通过普通 LAN HTTP 输入。请参阅[已保存服务器](remote-access.md#saved-servers)。 |
| 桌面远程窗口及窗口代理 | 仅限主机（`/api/remote-proxy/`）。 |
| SideCar 内容和 WebSocket（`/sidecars/`） | 隧道不可用。请使用环回连接，或在主机上启用 [SideCar 的 HTTPS 直连访问](browser-sidecars.md#register-sidecar)。 |
| SideCar 注册（`/api/sidecars`） | 已配对设备和已认证的直连客户端均可使用。 |
| 网页预览内容 | [打开会话浏览器](browser-sidecars.md#session-browser) |
| 自动化桥接 | 不可用（`/api/opencode-plugin/`）。原生桌面能力不会变成浏览器能力。 |
| WebSocket 升级 | 适用于网页预览，以及已配对设备上的[实时语音对话](voice.md#conversation)。 |

仅限主机的代理/WebSocket 功能和远程控制管理（`/api/remote-control/`）需要在主机上使用回环连接。通过局域网直接访问时，这些操作也要求回环连接；请参阅[允许的来源](remote-access.md#upgrading)。

## 中继与隐私 {#relay-privacy}

CodeNomad 使用 [OpenTunnel](https://github.com/anomalyco/opentunnel)，在机器共享的默认隧道身份上申请一条随机路由。

TLS 在 CodeNomad 后端终止。中继转发密文，无法读取应用内容，但可观察主机名、连接时间和流量大小。隧道证书/私钥保留在主机上。请将主机隧道存储和 CodeNomad 配置作为凭据保护；难以猜测的地址不等于授权。

`CODENOMAD_REMOTE_CONTROL_API` 选择自托管 OpenTunnel API；未设置则使用托管服务。这改变隧道部署，而非配对要求或被阻止的界面。凭据和诊断信息处理请参阅[安全](security.md)。

## 管理员策略 {#administrator-policy}

管理员可以为一台计算机上的所有用户关闭远程控制：在系统范围设置环境变量 `CODENOMAD_REMOTE_CONTROL=disabled`，然后重启 CodeNomad。后端将不会连接隧道，会拒绝 **启动远程控制** 和配对链接，启动时也不会重新连接；设置中显示 **已被管理员禁用**。之前配对的设备无法连接，并保留在列表中以便撤销。未设置或为空时不应用任何策略；任何其他值（包括仅含空格）都会阻止后端启动。
