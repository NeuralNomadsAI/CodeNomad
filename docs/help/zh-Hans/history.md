# 历史记录、搜索与清理

已存储历史、对话当前显示的内容和模型压缩后的上下文彼此独立。删除任何内容前，先考虑导航或筛选。

## 搜索完整历史 {#full-history-search}

1. 在对话标题栏打开**搜索聊天历史**，或使用其配置的快捷键（默认 **Ctrl/Cmd+F**）。
2. 选择**整个会话**或**整个工作区**并输入搜索词。
3. 若除可读文本外还需要技术内容，请启用**包含工具和思考**。
4. 选择摘要片段。在**整个会话**中使用**下一页结果**浏览按时间排列的结果页。

**整个会话**在已存储历史中按字面短语搜索，不区分大小写。**整个工作区**使用最多六个词元对所打开项目的授权目录树和工作树进行相关性排序，并在一个列表中显示最多40个最佳结果。每个对话的最佳匹配优先显示，标题和当前工作树标签保持排名顺序。搜索词在摘要及通过**在会话中打开**跳转后的目标对话中高亮。搜索内容包括可读文本及按需启用的工具和思考内容。

会话结果页随着批次到达显示**本页：… 个结果 · 已搜索 … 条消息**。项目搜索显示**最佳结果：…**，并简要提示部分扫描或排除的目录。运行环境不支持排序搜索时，请使用**整个会话**。跳过的消息会有提示；请重新搜索以包含新消息。

项目扫描从每个位置最新存储的最多16,384条消息开始。**搜索更早记录**会用下一个较旧窗口的最佳结果替换列表。提示会显示已检查的范围，各项目位置均从新到旧扫描。排名仅适用于该窗口。更改查询、范围或技术内容选项，关闭搜索或离开会话都会重置窗口。新搜索会包含新消息。

如果搜索窗口已过期或历史记录已更改，**开始新搜索**会使用相同查询和选项从最新消息重新开始。

## 打开结果并使用时间线 {#timeline-navigation}

1. 选择当前会话搜索结果，跳转到其周围片段。
2. 选择其他会话的结果，单独预览该消息；使用**在会话中打开**可转到该对话中的命中位置。
3. 在**消息时间线**中悬停或聚焦标记查看摘要，再选择它导航：对应内容块会移到顶部，标记保持高亮直到你滚动；之后高亮会跟随对话顶部的内容块。使用首条/最新消息箭头返回已存储历史的两端。箭头悬浮在对话上方；在**常规**中启用**将首条/最新消息箭头放在时间线下方**后，它们会位于时间线下方、**发送消息**右侧的角落，你所在一端的箭头会变暗。

即使对话只保留有界片段，时间线仍表示完整会话结构。跳转会加载目标位置，而非获取所有中间消息。其他会话搜索预览不会加载该会话的完整对话或选择它；只有**在会话中打开**会切换对话。

工具标记遵循**消息内容**：在其中隐藏的工具类型没有标记（选择**无**时全部没有），等待权限的工具除外。仅运行了工具的步骤只显示其工具标记，不会出现空的智能体标记。

对话过窄时（小于 420 CSS 像素），时间线会隐藏；此时使用搜索和对话控件。此响应式更改不会清除已保存的可见性偏好。

## 选择正确的历史操作 {#operation-reference}

| 操作 | 位置 | 范围与后果 |
| --- | --- | --- |
| 显示筛选 | **消息内容**或**设置 → 聊天** | 共享对话显示偏好；隐藏/折叠内容而不删除 |
| 压缩 | 命令面板**压缩会话** | 所选会话的原生摘要/上下文压缩，而非删除技术输出 |
| 单回复清理 | 消息**更多操作 → 从此回复中删除工具和推理** | 永久移除符合条件的已完成技术部分；保留最终文本 |
| 会话技术清理 | 命令面板**删除会话工具和推理** | 对完整已存储会话历史规划，包括压缩前消息；保留最终文本及消息/会话元数据 |
| 删除会话 | 会话行**删除会话**，或删除所选会话 | 确认后递归删除原生对话及其后代子会话/历史；无法撤销 |
| 清理会话 | 命令面板 | 更广泛的会话删除，而非显示或上下文大小设置 |

**消息内容**适用于所有对话。在其顶部或**设置 → 聊天**中选择预设（**无**、**精简**、**均衡**或**全部**），再调整各行；之后**消息内容**的预设菜单会显示**自定义**。选择其他预设会保留这些行：再次选择**自定义**即可恢复。隐藏工具不会禁用工具、更改权限或移除已存储输出。为保持渲染响应，超大消息会在省略间隙显示**再显示 … 项**，超长文本或工具输出会在**已隐藏其余 … 个字符**一行处截止，并提供**全部显示**；剩余内容很多时则提供**再显示 … 个字符**，可能需要分几步展开。两者的展开都只影响显示，无法恢复已删除内容。在其眼睛或箭头按钮上拖动可一次设置多行：最先离开的按钮会切换，同一列中划过的每个按钮都会采用它的新状态。松开按钮时对话才会更新。

在**工具分组**一行中，关闭眼睛按钮可单独显示每次调用，使用箭头按钮可让分组默认展开。每种工具仍有独立的可见性设置。**全部**会默认展开分组，其他预设则保持折叠。

## 压缩会话 {#compact-session}

1. 选择目标对话。
2. 从命令面板运行**压缩会话**。
3. 等待原生压缩结果，或检查**压缩失败**后再决定是否重试。

压缩会改变 OpenCode 继续会话所用的上下文。它不保证擦除先前存储的消息：完整历史搜索和技术清理仍可访问压缩前内容。不要用压缩代替删除敏感的已存储历史。

## 移除工具和推理 {#technical-cleanup}

1. 选择单回复操作，或针对所选会话运行**删除会话工具和推理**。
2. 检查计划的工具/推理数量及所有跳过内容警告。
3. 确认**删除**。对于整个会话的操作，查看对话上方进度，必要时使用取消控件。

只移除符合条件的已完成工具和推理。活动/未完成内容不会被裁剪，按 OpenCode 读取的大小（含附件）超过 16 MB 的消息也不会被裁剪，并计为跳过内容；内容已更改时会拒绝操作，而非静默扩大你确认的范围。最终文本和消息/会话元数据保留，但移除的技术输出无法撤销。确认前请保留所需内容。

会话清理并非对整个会话原子执行。即使后续消息冲突或失败，先前成功移除的内容仍保持移除。**取消会停止后续批次；不会回滚已派发批次**，该批次仍可能提交。

## 删除与清理会话 {#delete-scrub}

删除父会话也会删除其后代子会话及其历史。确认前请检查对话族。任务专家清理不同：它会保留有子会话的会话。

1. 明确要删除哪个对话时，优先使用具体行的**删除会话**。
2. 更广泛的维护请运行**清理会话**，并阅读**深度清理会话**确认内容。

两种清理方式都只删除经确认没有消息、不活跃且没有子会话的会话。即使在其他文件夹中标记，收藏的会话及其上级会话也会保留。

如果对话在清理期间消失，可以在项目的新对话输入框中找到未发送的文字和附件。 使用**切换草稿**打开已保存的草稿，不会覆盖当前草稿。 重新打开项目时也可以恢复草稿。

删除移除的是对话，而非 Git 提交，也不会回滚文件系统/外部影响。部分清理成功时，已删除会话仍保持删除。重试前请检查剩余列表和错误。分叉/撤销参阅[对话](conversations.md)；删除临时文件夹或工作树参阅[项目](projects.md)。
