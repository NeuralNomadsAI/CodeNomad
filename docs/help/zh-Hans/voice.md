# 语音输入与播放

## 配置语音 API {#configure}

1. 打开**设置 → 语音**。**语音**卡片使用兼容 OpenAI 的服务器端适配器，独立于对话模型提供商。
2. 输入 **API 密钥**，以及可选的**基础 URL**、**转写模型**、**语音模型**和**默认语音**。
3. 若输入和输出需要不同服务，启用**为输入和输出使用不同供应商**，然后填写输入/输出密钥、基础 URL 和模型字段。
4. 选择**播放模式**和**输出格式**，然后**保存**（存在未保存更改时可用）。测试前检查测试按钮旁的状态：**已配置**、**部分已配置**或**缺少 API 密钥**；保存失败时会显示**保存失败**。

语音设置和密钥属于所连接 CodeNomad 服务器配置，而非所选项目或 OpenCode 提供商连接。共享配置的其他客户端使用这些设置。保存的密钥会隐藏：空密钥字段保留已保存值；**清除已保存的密钥**会在保存时安排移除。某一方向既无自身端点也无密钥时可使用共享设置；单独端点需要自己的密钥，单独密钥也需要对应端点。更改端点时，请显式提供目标密钥并验证保存配置；端点变化会清除该槽位已保存密钥，而非发送到另一主机。

后端也可使用 `OPENAI_API_KEY` 和 `OPENAI_BASE_URL` 作为共享默认值。清除已保存密钥不会移除环境提供的凭据；若想移除后备凭据，请更改后端环境并重启。

| 设置 | 含义 / 默认值 |
| --- | --- |
| 基础 URL | 兼容 OpenAI 的 API 根地址，默认 `https://api.openai.com/v1`。输入使用 `audio/transcriptions`；输出使用 `audio/speech`。 |
| 转写模型 / 输入模型 | STT 端点接受的模型；默认 `gpt-4o-mini-transcribe`。 |
| 语音模型 / 输出模型 | TTS 端点接受的模型；默认 `gpt-4o-mini-tts`。 |
| 默认语音 | 提供商语音标识符；默认 `alloy`。不是操作系统语音选择器。 |
| 流式 | 默认值。提供商和浏览器支持所选格式时，音频到达即开始播放。 |
| 缓冲后播放 | 等待完整音频响应后播放。 |
| 输出格式 | `mp3`、`wav`、`opus` 或 `aac`；默认 `mp3`。兼容性取决于浏览器/提供商。 |

这些是向配置服务发出的请求，不保证每个兼容端点都实现每个模型、语音或格式。

## 测试输入和输出 {#test}

1. 先保存端点、密钥、模型和语音更改。
2. 选择**测试输入**，授予麦克风权限，讲话后选择**停止录音**。检查返回转写。
3. 选择**测试播放**听示例；**停止示例**结束播放。

播放测试立即使用所选播放模式/格式，但端点、密钥、模型和语音来自已保存设置。测试输入不会发送对话提示词。测试仍会向配置的语音提供商发送音频/文本，可能产生费用。

## 口述提示词 {#dictate}

1. 在**语音**中保持**提示词语音输入**为启用状态（默认开启）。
2. 在输入框中选择**更多操作 → 听写**，并允许访问麦克风。如果显示**听写：打开语音设置**，请在那里选择或配置听写引擎，再返回草稿。
3. 选择**停止录音并转写**以获取文字，或选择**取消听写**以丢弃录音。切换对话或关闭输入框也会取消听写。
4. 检查文字。只有草稿和选区均未更改时，转写文字才会替换原选区；否则，选择**插入转写文本**或**丢弃转写文本**。听写不会发送草稿。

Linux 上的 Tauri 如果通过 API 使用备用 WAV 模式，听写和输入测试会在 24 秒时停止录音。录音会保留在此设备上，直到选择**转写**将其发送给语音服务商，或选择**取消**将其丢弃。

### 选择桌面听写引擎 {#desktop-dictation}

在本地桌面应用的**偏好设置 → 语音**中，选择**此设备的听写引擎**。此选择适用于该设备上的所有项目；**语音**卡片仍用于配置已连接服务器的 API。浏览器和移动端使用已配置的 API 提供商，访问麦克风需要安全上下文。

- **系统本地语音识别**在 CodeNomad 内运行，不打开系统听写面板。Windows 或 macOS 上必须安装与应用语言匹配的本地识别引擎。在 Linux 上，或缺少引擎或语言时，如果界面提供 Hex，可尝试使用它。
- 语音设置会列出 Hex 尚缺的组件，以及各组件和总下载大小。点击一次**启用 Hex**即可验证、复用兼容文件，下载缺少的内容，并在准备好后选中 Hex。可以在语音设置查看进度，点击**取消启用 Hex**停止，或在出现**继续启用 Hex**时恢复。失败或取消后保留原引擎。重新打开偏好设置、选择已就绪的 **Hex（本地）** 或用它听写，都不会启动下载。
- Hex 可在符合条件的设备上使用：Windows x64/arm64、运行 macOS 15 或更高版本的 Apple Silicon，以及具备 glibc 2.36 或更高版本和所需库的 Linux x64/arm64。Intel Mac 以及使用较旧 glibc 或 musl 的 Linux 系统不兼容。引擎和模型不包含在 CodeNomad 安装程序中，无需使用终端或 API 密钥。

Ubuntu 24.04 满足 glibc 要求，Ubuntu 22.04 则不满足。Hex 会在 [Parakeet 支持的语言](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3)中自动识别所说的语言，其中包括英语和法语。此列表与应用的显示语言无关。

本地识别使用此设备的麦克风，可离线运行，包括在本地应用中打开 WSL 项目时。在兼容的远程窗口中选择**听写**会另开本地窗口**在此设备上听写**。检查显示的目标后，依次选择**开始语音输入**、**停止录音并转写**和**插入转写文本**。只有文字会返回草稿。远程项目仍需连接服务器。

在 Linux 的远程 Tauri 窗口中，**测试输入**可测试服务器的语音 API，无需更改听写引擎。每次确认 API 录音前，请在原生麦克风对话框中核对服务器地址。录音使用 PulseAudio 或 PipeWire 的 PulseAudio 服务，并始终遵守上文所述的 WAV 录音 24 秒限制。

Linux 上的远程 Tauri 窗口不支持 Gemini Live 和 OpenAI Realtime：这些窗口使用原生录音功能进行听写和输入测试，WebKit 会阻止直接访问麦克风。

## 朗读消息 {#playback}

1. TTS 可用时，在消息上使用**朗读消息**，或在工具调用上使用同一操作。
2. 在同一控件上使用**停止播放**结束朗读；开始另一段朗读会停止当前朗读。
3. 在**语音**中更改保存的语音、模型、模式或格式，供后续请求使用。

播放使用 CodeNomad 文本投影，而非对截图进行旁白：二进制/图片字节和权限回执不是语音内容。不会运行提示词或更改所选 OpenCode 模型。

自动对话语音使用输入框**更多操作**菜单中的**开启对话模式**；它作用于该项目标签页，重新加载后不会保留。开启期间，CodeNomad 会在你发送的每条提示词中要求智能体以简短的 `spoken` 围栏摘要开始回复。只有该完整块会被朗读，且仅限活动主会话；不会自动朗读每条回复或子智能体。**关闭对话模式**会停止其队列，并不再要求提供摘要。开始麦克风输入也会停止活动对话语音。对话模式需要配置使用受支持格式的播放服务。

## 数据流与隐私 {#privacy}

本地听写的音频保留在设备上，不会切换到 API。使用 **API 提供商**时，麦克风音频通过 CodeNomad 服务器发送给已配置的转写端点。待合成文本通过服务器传到配置的 TTS 端点，返回的音频在客户端播放。API 密钥保留在服务器上。

请选择可信赖的端点来处理听写或朗读内容。OpenCode 凭据不会自动授权语音。更改密钥或端点只影响后续请求。向其他用户公开服务器前请参阅[安全](security.md)。
