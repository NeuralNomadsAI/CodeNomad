# 听写、播放和语音对话

## 设置语音 {#configure}

打开**偏好设置 → 语音**（在浏览器或远程窗口中为**设置 → 语音**）。**听写**、**播放**和**对话**卡片分别显示各自的状态。

1. 在本地桌面应用的**听写**卡片中选择[设备引擎](#desktop-dictation)。浏览器和移动端只能使用 API。
2. 要设置 API 听写和播放，从任一卡片打开 **API 凭据**。填写 **API 密钥**，按需填写**基础 URL**、**转写模型**和**语音模型**。如果两者需要不同服务，开启**为输入和输出使用不同供应商**，填写相应字段并**保存**。
3. **播放**卡片显示**提供商**。设置**默认语音**、**播放模式**和**输出格式**，然后**保存**。

语音设置和密钥属于所连接 CodeNomad 服务器配置，而非所选项目或 OpenCode 提供商连接。共享配置的其他客户端使用这些设置。保存的密钥会隐藏：空密钥字段保留已保存值；**清除已保存的密钥**会在保存时安排移除。某一方向既无自身端点也无密钥时可使用共享设置；单独端点需要自己的密钥，单独密钥也需要对应端点。更改端点时，请显式提供目标密钥并验证保存配置；端点变化会清除该槽位已保存密钥，而非发送到另一主机。

后端也可使用 `OPENAI_API_KEY` 和 `OPENAI_BASE_URL` 作为共享默认值。清除已保存密钥不会移除环境提供的凭据；若想移除后备凭据，请更改后端环境并重启。

| 设置 | 含义 / 默认值 |
| --- | --- |
| 基础 URL | 兼容 OpenAI 的 API 根地址，默认 `https://api.openai.com/v1`。输入使用 `audio/transcriptions`；输出使用 `audio/speech`。 |
| 转写模型 / 输入模型 | STT 端点接受的模型；默认 `gpt-4o-mini-transcribe`。 |
| 语音模型 / 输出模型 | TTS 端点接受的模型；默认 `gpt-4o-mini-tts`。 |
| 默认语音 | 提供商语音标识符；默认 `alloy`。不是操作系统语音选择器。 |
| 流式 | 默认值。提供商和浏览器支持所选格式时，音频到达即开始播放。 |
| 缓冲后播放 | 等待完整音频响应后播放。 |
| 输出格式 | `mp3`、`wav`、`opus` 或 `aac`；默认 `mp3`。兼容性取决于浏览器/提供商。 |

这些是向配置服务发出的请求，不保证每个兼容端点都实现每个模型、语音或格式。

## 测试输入和输出 {#test}

1. 先保存端点、密钥、模型和语音更改。
2. 选择**测试 API 输入**，授予麦克风权限，讲话后选择**停止录音**。检查返回转写。
3. 选择**测试播放**听示例；**停止示例**结束播放。

播放测试立即使用所选模式和格式，但端点、密钥、模型和语音来自已保存设置。无论选择哪个听写引擎，**测试 API 输入**都会将音频发送给已配置的 API 供应商。测试不会向对话发送提示词，但供应商可能会收费。

## 口述提示词 {#dictate}

1. 在**语音**中保持**提示词语音输入**为启用状态（默认开启）。
2. 在**更多操作**中勾选**听写模式**。选择另一种模式前，先取消勾选当前模式。
3. 按住**更多操作**旁边的麦克风讲话，松开后转写。如有提示，请允许访问麦克风。在兼容的远程窗口中，点击麦克风会打开本地录音控件。
4. 检查文字。只有草稿和选区均未更改时，转写文字才会替换原选区；否则，请在再次听写前，在普通模式下选择**插入转写文本**，或选择**丢弃转写文本**。听写不会发送草稿。

Linux 上的 Tauri 如果通过 API 使用备用 WAV 模式，听写和输入测试会在 24 秒时停止录音。录音会保留在此设备上，直到选择**转写**将其发送给语音服务商，或选择**取消**将其丢弃。

通过 API 使用压缩录音时，达到大小上限也会停止录音，并提供**转写**和**取消**选项。

### 选择桌面听写引擎 {#desktop-dictation}

在本地桌面应用的**偏好设置 → 语音 → 听写**中，选择**此设备的听写引擎**。此选择适用于该设备上的所有项目。**API 提供商**使用已连接服务器的设置，访问麦克风需要安全上下文。

- 如果已保存的引擎不可用，请在此选择 **Hex（本地）**（如有提供）或 **API 提供商**。使用 Intel Mac 或低于 macOS 15 的系统时，请选择 **API 提供商**。
- 语音设置会列出 Hex 尚缺的组件，以及各组件和总下载大小。点击一次**启用 Hex**即可验证、复用兼容文件，下载缺少的内容，并在准备好后选中 Hex。可以在语音设置查看进度，点击**取消启用 Hex**停止，或在出现**继续启用 Hex**时恢复。失败或取消后保留原引擎。重新打开偏好设置、选择已就绪的 **Hex（本地）** 或用它听写，都不会启动下载。
- Hex 可在符合条件的设备上使用：Windows x64/arm64、运行 macOS 15 或更高版本的 Apple Silicon，以及具备 glibc 2.36 或更高版本和所需库的 Linux x64/arm64。Intel Mac 以及使用较旧 glibc 或 musl 的 Linux 系统不兼容。引擎和模型不包含在 CodeNomad 安装程序中，无需使用终端或 API 密钥。

Ubuntu 24.04 满足 glibc 要求，Ubuntu 22.04 则不满足。Hex 会在 [Parakeet 支持的语言](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3)中自动识别所说的语言，其中包括英语和法语。此列表与应用的显示语言无关。

开始录音时，Hex 会在后台加载模型，并在上一次听写结束后保持模型就绪三分钟。

本地识别可离线运行，包括在本地应用中打开 WSL 项目时。在兼容的远程窗口中点击麦克风，打开**在此设备上听写**。确认目标后，使用该窗口的录音和插入控件。只有文字会返回草稿。远程项目仍需连接服务器。

在 Linux 的远程 Tauri 窗口中，**测试 API 输入**可测试服务器的语音 API，无需更改听写引擎。每次确认 API 录音前，请在原生麦克风对话框中核对服务器地址。录音使用 PulseAudio 或 PipeWire 的 PulseAudio 服务，并始终遵守上文所述的 WAV 录音 24 秒限制。

Linux 上的远程 Tauri 窗口不支持 Gemini Live 和 OpenAI Realtime：这些窗口使用原生录音功能进行听写和输入测试，WebKit 会阻止直接访问麦克风。

## 朗读消息 {#playback}

1. TTS 可用时，在消息上使用**朗读消息**，或在工具调用上使用同一操作。
2. 在同一控件上使用**停止播放**结束朗读；开始另一段朗读会停止当前朗读。
3. 在**播放**中更改语音、模式或格式，或在 **API 凭据**中更改模型，然后保存。

播放使用 CodeNomad 文本投影，而非对截图进行旁白：二进制/图片字节和权限回执不是语音内容。不会运行提示词或更改所选 OpenCode 模型。

## 语音对话 {#conversation}

Gemini Live 和 OpenAI Realtime 仅适用于打开此窗口的服务器上的会话。

在**对话**卡片中选择**对话引擎**：

- **经典**只需设置受支持格式的播放服务。在**更多操作**中勾选**对话模式**。CodeNomad 在当前主会话中朗读回复的完整 `spoken` 摘要。此模式在项目标签页中有效，直到取消勾选或重新加载。
- **Gemini Live** 和 **OpenAI Realtime** 各有独立的 **API 密钥**、**模型**和可选的**音色**。保存所选提供商的设置。打开目标会话，在**更多操作**中选择**对话模式**，提供商的同意对话框出现时，选择**同意并开始**。允许访问麦克风。

如果同意对话框打开期间提供商变得不可用，请选择**语音设置**打开对话卡片。

语音模型可以读取启动时锁定的会话状态、最近一条可见回复和近期错误，无法访问文件。你让它向智能体发送请求时，它会直接以你的名义发送消息，无需在屏幕上确认。[对话的权限模式](permissions.md#conversation-mode)仍然有效，智能体也会照常提问。

服务器允许每个已登录用户同时进行一场实时对话；通过远程控制连接时，每台已配对设备限一场。选择**停止**可结束音频并保留打开的转写。转写保留在内存中，直到关闭窗口；已经发给智能体的请求会保留为会话消息。两分钟没有说话、总时长达到八分钟、变更目标、关闭窗口或连接中断时，对话也会结束。系统不会自动重连或切换提供商。

在 OpenAI Realtime 中，**打断回复**会停止播放，并请求取消当前回复。在 Gemini Live 中，**停止播放**仅停止此设备上的声音；Gemini 仍可继续生成回复并向智能体发送请求。

## 数据流与隐私 {#privacy}

本地听写的音频保留在设备上，不会切换到 API。使用 **API 提供商**时，麦克风音频通过 CodeNomad 服务器发送给已配置的转写端点。待合成文本通过服务器传到配置的 TTS 端点，返回的音频在客户端播放。API 密钥保留在服务器上。

使用 **Gemini Live** 或 **OpenAI Realtime** 时，Google 或 OpenAI 会收到麦克风音频、项目名称、分支、工作树、会话标题和状态。提供商也可能收到智能体最近一条可见回复的文本和近期错误。所选提供商可能会向你的账户收取使用费用。

请选择可信赖的提供商来处理听写、朗读或分享的内容。OpenCode 凭据不会自动授权语音服务。向其他用户公开服务器前请参阅[安全](security.md)。
