# 更新

## 选择发布通道 {#feed}

1. 打开**设置 → 信息 → 更新**。
2. 将**更新通道**设为**稳定版**或**预览版和稳定版**。
3. 刷新/检查更新，接受安装前检查提供的版本。

通道保存在 CodeNomad 服务器配置中，只改变提供哪些版本。不会更改桌面数据配置文件、草稿、窗口、OpenCode 会话或服务配置。未显式选择时，标为预览版的构建默认使用预览，其他构建默认使用稳定版。

稳定通道选择最新正式版本。预览按发布时间排序，因为开发构建可能共用基础版本号；不要仅比较数字版本。预览包面向愿意测试预发布行为的用户；重启前请检查发行说明并保护重要草稿。

## 更新桌面安装 {#desktop-update}

1. 使用 **Help → Get Updates...** 或更新通知。
2. Electron 上，前往发行页面，获取与你使用的宿主/平台匹配的压缩包/软件包。
3. 符合条件的本地 Tauri 安装中，检查原生更新提示并显式选择**安装并重启**。
4. 安装/重启前保存每个窗口的重要工作，重新启动后查看**信息**确认。

| Tauri 安装 | 应用内安装资格 |
| --- | --- |
| Windows x64 NSIS 安装 | 支持，需内嵌更新器密钥和签名发行载荷。 |
| macOS x64 / arm64 应用 | 支持，需内嵌更新器密钥和签名 `.app.tar.gz` 载荷。 |
| Linux x64 AppImage | 要求 AppImage 包标记、非空 `APPIMAGE` 路径，以及签名更新支持。仅有 `APPRUN` 不足。 |
| Debian/RPM、独立 Windows 可执行文件、未签名/无密钥构建 | 打开发行页面，不在应用内安装。 |
| 偏好设置、远程窗口、登录/配对界面 | 回退到发行页面，没有本地更新权限。 |

Tauri 只提供所选通道/目标已发布更新清单的版本。新宣布的版本可能尚不可安装；通知可能改为打开其发行页面。安装前必须验证原生签名。更新器签名不同于操作系统公证/代码签名保证。

安装会将所有应用窗口状态写入存储，并在替换/重启应用前停止所拥有的 CodeNomad 后端。独立管理的 OpenCode 守护进程不在此关闭范围内。关闭 CodeNomad 仍会让依赖后端的功能暂时不可用，直到它返回；不要因 OpenCode 会话继续就推断界面服务不中断。

检查繁忙时，等待另一窗口操作完成。下载、验证或关闭失败时，阅读错误并重新检查；旧通知不授权重新安装过时字节。安装失败可能恢复后端并重新加载窗口，但不会自动重放安装。原生安装不可用时，请在发行页面获取合适软件包；参阅[安装](install.md)。

## 更新独立服务器 {#standalone-update}

1. 确认 CodeNomad 启动方式，保存依赖该后端的工作。
2. 使用正常进程/服务控制停止该 CodeNomad 服务器进程。
3. 更新同一软件包安装，然后用目标配置和标志重启。

| 启动/安装方式 | 更新命令 |
| --- | --- |
| 一次性稳定 npm 启动 | `npx @neuralnomads/codenomad@latest`，带正常标志 |
| 全局稳定安装 | `npm install -g @neuralnomads/codenomad@latest` |
| 本地稳定安装 | 在该软件包目录中运行 `npm install @neuralnomads/codenomad@latest` |
| 一次性预览启动 | `npx @neuralnomads/codenomad-dev@latest`，带正常标志 |
| 全局/本地预览安装 | 使用相同的全局/本地 npm 形式安装 `@neuralnomads/codenomad-dev@latest` |

已运行进程不会仅因 npm 完成安装就获取新代码。请有意识地保持相同配置路径；在设置中选择通道不会替换 npm 软件包或自动切换稳定/预览包名。重新启动时保留认证/TLS 标志；参阅[服务器](server.md)。

## 单独维护 OpenCode {#opencode-separate}

更新 CodeNomad 不等于更新所选 OpenCode CLI。更新 CLI 不等于重启运行中的共享守护进程。重新加载原生配置又是独立的显式操作，对已加载 Location 和请求有自身影响。

桌面 Node/npm 资源随应用提供；应用发行版负责更新它们。不会替换系统 Node/npm、Electron 内部运行时、平台 WebView 或独立管理的 OpenCode 服务。

使用**设置 → OpenCode**选择运行时、安装/更新和显式控制服务。重启或重新加载前请检查 [OpenCode 设置](opencode.md)，尤其当其他窗口/用户或任务共享守护进程时。切勿仅因更新/重连完成而重复不确定的提示词或修改操作。
