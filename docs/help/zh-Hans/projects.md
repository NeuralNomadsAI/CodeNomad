# 项目与工作树

项目标签页将 CodeNomad 连接到后端计算机上的文件夹。打开标签页、浏览检出目录和移动对话族是不同的操作。

## 打开项目 {#open-project}

点击 **新建实例**（`+`）或按 `Ctrl/Cmd+N` 打开新的空白标签页，从 **最近的标签页** 或 **浏览** 中选择项目。没有可恢复的标签页时，或关闭最后一个标签页后，CodeNomad 会显示空白标签页。 克隆和临时标签页使用本地后端。


在最近的标签页列表中，点击 **已打开** 可切换到当前窗口中的标签页。绿色圆点 **已在其他窗口打开** 表示项目服务器上有来自当前窗口之外的连接。选择该行会打开独立的标签页。

[在标签页中打开远程项目](remote-access.md#remote-project-tabs) · [SideCars](browser-sidecars.md#register-sidecar)

若需仓库副本，选择**克隆 Git 仓库**，输入**仓库 URL** 和**目标文件夹**，然后选择**克隆**。**目标文件夹** 会预填为上次克隆所在文件夹中以仓库名命名的文件夹(没有则为最近项目旁边)。**浏览** 用于选择存放克隆的文件夹;也可以手动编辑路径,包括克隆文件夹的名称。

浏览远程服务器意味着浏览该服务器的文件系统，而非你的手机或笔记本电脑。打开项目不会为每个标签页创建独立的 OpenCode 守护进程。对话是原生 OpenCode 会话；其生命周期不等于标签页的生命周期。

克隆会将仓库写入目标位置。**如果目标文件夹已存在，先将其删除。**具有破坏性：仅在其中所有现有内容都可以删除时启用。不确定时请使用新目标位置。克隆失败不是删除现有项目的理由；重试之前先检查报告的目标位置和错误。

最近条目是快捷方式。空白标签页的操作菜单按条目提供**重命名工作区**和**从最近列表移除**；文件和对话会保留。在空白标签页和快速启动器中，点击本地项目、远程项目或 SideCar 行都会创建新实例，即使已经打开。独立的**已打开**操作（**切换到已打开的项目**）则选择现有实例。

切换到已打开的标签页时，也可以选择正在等待服务器的标签页，原来的空白标签页会关闭。

## 使用新建实例启动器 {#new-instance-launcher}

长按或右键点击 `+`；键盘焦点位于此处时，使用 **Alt+Down**、**Shift+F10** 或 Menu 键。
Tab 进入搜索，方向键和 Enter 用于选择，Escape 将焦点移回 `+`。

## 关闭标签页以关闭项目 {#close-stop}

1. 使用标签页关闭按钮或命令面板中的**关闭标签页**（渲染器中为 `Ctrl/Cmd+W`）。
2. 关闭标签页会在 CodeNomad 中关闭该项目：不再跟踪其事件和请求。会话继续在 OpenCode 中运行。
3. 通过浏览或最近项目重新打开文件夹，即可再次找到这些会话。

| 操作 | 范围和影响 | 不会执行的操作 |
| --- | --- | --- |
| 关闭标签页 | 移除该标签页的 CodeNomad 项目连接；在同一文件夹上单独打开的其他标签页不受影响 | 不会删除项目文件或原生历史记录，不会停止会话，也不会卸载 OpenCode 的 Location |
| 停止会话 | 所选对话的执行 | 不会关闭项目或删除历史记录 |

已关闭标签页中未发送的草稿和附件，会在同一窗口中重新打开同一文件夹时恢复；窗口会为最近关闭的 16 个项目保留它们，直到窗口重新加载或关闭。它们不属于启动恢复。

关闭或重新加载窗口或浏览器标签页，或退出应用时，CodeNomad 会请求服务器释放相应的项目连接。如果无法连接到服务器，记录可能仍保留在服务器上。其他窗口的标签页保持打开。启动时恢复会重新连接已保存的标签页，并保留打开的临时文件夹。要结束运行，请明确停止；共享服务的维护请参阅 [OpenCode 设置](opencode.md)。

启用启动恢复后，每个保留的标签页都会恢复自己的面板选择、任务选择和阅读器，以及聊天或网页预览的选择。浏览器 URL 和历史记录按会话共享；只有显式重新打开网页预览时，才会加载已保存的页面。关闭其中一个标签页只会移除其保存的视图；重新打开文件夹会创建新的标签页。

复制浏览器标签页时，新标签页会建立自己的项目连接。只有在浏览器卸载并恢复同一个标签页时，才可能复用尚未关闭的连接。

## 恢复远程标签页 {#restore-remote-tabs}

启用恢复功能后，重新加载会恢复远程标签页的顺序、选中状态和草稿。服务器不可用时会留下等待标签页：服务器恢复后选择 **重试**，或通过用户名和密码或 **新配对链接** 中的链接 选择 **连接**。其他服务器仍可使用。 **找不到服务器**表示缺少已保存的服务器。

**重试**会重新连接已保存服务器上的项目，并在需要时重新建立连接。

即使关闭了启动时自动恢复，**重试**也能恢复等待中标签页。通知会选中现有的等待中标签页。重新发送结果未确认的对话操作前，请先检查其结果。

## 临时工作区 {#temporary-workspaces}

1. 在空白标签页顶部选择 **临时标签页**。
2. 在 CodeNomad 管理的空文件夹中工作；不会自动初始化 Git。
3. 关闭标签页时，选择**保留**、**丢弃**或**取消**。标签页菜单还提供**保留为项目**。

| 选择 | 影响 | 恢复方式 |
| --- | --- | --- |
| 保留 | 在 CodeNomad 中关闭该项目，保留文件夹和对话，移除临时状态并添加到最近项目 | 从最近列表重新打开；文件夹不会移动 |
| 丢弃 | 删除临时工作区的对话、文件和未发送的草稿 | 无法撤销；请先将所需内容另存到其他位置 |
| 取消 | 保持临时工作区打开 | 继续工作或稍后决定 |

没有对话、文件或未发送草稿的未使用临时标签页会在关闭时静默丢弃。打开的临时标签页参与正常的启动恢复。

对话正在运行或文件夹在其他标签页/窗口打开时，会拒绝丢弃。请先停止运行并关闭其他视图。丢弃失败时仍保留临时状态：请解决报告的问题后重试，不要手动删除父目录。

## 选择或创建工作树 {#select-create-worktree}

1. 打开父对话并使用其输入框中的工作树选择器。窄布局下它仅显示箭头。
2. 选择已发现的现有工作树，或选择 **+ 创建 worktree**。
3. 创建时输入**名称**并选择**创建并使用 worktree**。

如果项目是仓库中的某个文件夹，则只列出包含该文件夹的工作树。要从此类文件夹创建工作树，Git 必须跟踪该文件夹。新分支名从所选检出目录的 HEAD 开始。现有分支名使用该分支的当前修订；Git 可能拒绝已在其他位置检出的分支。工作树使用默认 `.codenomad/worktrees` 位置。未提交更改仍留在原检出目录；创建不会将它们复制到新工作树。

输入框选择器会将父对话及其递归后代作为经过验证的会话族移动。子会话无法独立更改此选择器。活动会话会阻止该操作：请先等待会话族完成或停止执行。等待移动完成后再请求下一次移动；出错时，请先检查刷新的对话/工作树状态再重试。

相比之下，[文件](files.md)中的**浏览工作树**只更改面板读取哪个检出目录。它不会移动对话、切换分支或更改下一条 Shell 命令的运行位置。

## 移除工作树 {#remove-worktree}

1. 在输入框工作树列表中，对可移除的分支工作树使用**删除 worktree**。
2. 检查目标文件夹。除非允许丢失本地更改，否则不要开启**强制删除（丢弃本地更改）**。
3. 确认删除并检查结果列表。

删除会移除工作树的本地文件夹。Git 主检出目录不是可移除目标。CodeNomad 会将受影响的对话族移回根检出目录，验证位置后才移除工作树；活动会话可能阻止移除。删除不是未提交文件的归档或备份。

如果 Git 因已修改/未跟踪文件而拒绝，请先保留或清理这些文件再重试。强制删除会明确丢弃它们。目录被锁定时，请关闭使用它的终端、编辑器、监视器和后台进程。共享诊断信息时，错误对话框提供**复制脱敏内容**；即使已脱敏，也请先检查文本。

## 初始化 Git 或在没有 Git 时工作 {#initialize-git}

1. 对于 Git 可用的普通文件夹，打开**文件 → 更改**或**提交**。
2. 选择**初始化 Git**。它会立即执行，不再额外确认。
3. 等待项目元数据和对话刷新；若在 CodeNomad 外初始化 Git，请使用**刷新**。

初始化会在显式打开的文件夹中创建仓库，而非其父目录。它不会创建提交。

如果后端无法运行 Git，显式打开的文件夹仍可在仅目录模式下使用对话和有界文件浏览。工作树操作和 Git 初始化要求该后端安装 Git。请参阅[安装](install.md)和[文件](files.md)。
