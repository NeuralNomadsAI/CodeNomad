# 项目与工作树

项目标签页将 CodeNomad 连接到后端计算机上的文件夹。打开标签页、浏览检出目录和移动对话族是不同的操作。

## 打开项目 {#open-project}

1. 点击**新建实例**（`+`）或按 `Ctrl/Cmd+N`，打开标题为**打开项目**的紧凑空白标签页。主页使用相同的**最近 | 浏览**选择器、数量、搜索和操作。**克隆 Git 仓库**、**新建临时标签页**和**新建 SideCar**位于列表下方的次要操作栏；克隆和临时文件夹以本地后端为目标。选择项目或 SideCar 会在原位置填充空白标签页。空白标签页保留到重新加载，关闭后不留下项目。标志打开主页，保留 CodeNomad 品牌、设置、语言、链接和**赞助**（[支持 CodeNomad](sponsor.md)）。
2. 在 **最近** 中选择一个项目；或打开 **浏览**，选择 **此电脑**，然后选择后端文件夹并打开。**浏览** 也列出已保存的 CodeNomad 服务器（[远程项目标签页](remote-access.md#remote-project-tabs)）和 SideCar（[SideCar](browser-sidecars.md#register-sidecar)）。
3. 若需仓库副本，选择**克隆 Git 仓库**，输入**仓库 URL** 和**目标文件夹**，然后选择**克隆**。**目标文件夹** 会预填为上次克隆所在文件夹中以仓库名命名的文件夹(没有则为最近项目旁边)。**浏览** 用于选择存放克隆的文件夹;也可以手动编辑路径,包括克隆文件夹的名称。

浏览远程服务器意味着浏览该服务器的文件系统，而非你的手机或笔记本电脑。打开项目不会为每个标签页创建独立的 OpenCode 守护进程。对话是原生 OpenCode 会话；其生命周期不等于标签页的生命周期。

在**浏览**中选择的服务器名称在登录和导航期间始终可见。登录字段带有标签；**最近项目**打开项目，**文件夹**用于导航。**打开此文件夹**打开当前文件夹，返回浏览则显示服务器列表。只有选择项目才会填充空白标签页。已知限制：后端浏览与原生视图独立认证，远程标签页可能要求再次登录。

克隆会将仓库写入目标位置。**如果目标文件夹已存在，先将其删除。**具有破坏性：仅在其中所有现有内容都可以删除时启用。不确定时请使用新目标位置。克隆失败不是删除现有项目的理由；重试之前先检查报告的目标位置和错误。

最近条目是快捷方式。主页和空白标签页的操作菜单按条目提供**重命名工作区**和**从最近列表移除**；文件和对话会保留。在主页、空白标签页和快速启动器中，点击本地项目、远程项目或 SideCar 行都会创建新实例，即使已经打开。独立的**已打开**操作（**切换到已打开的项目**）则选择现有实例。

## 使用新建实例启动器 {#new-instance-launcher}

1. 长按或右键点击 `+`；键盘焦点位于此处时，使用 **Alt+Down**、**Shift+F10** 或 Menu 键。
2. **最近的项目**仅搜索最近的本地项目、远程项目和 SideCar。点击行创建新实例；独立的**已打开**操作切换到现有实例。**打开其他项目…**打开空白标签页，用于浏览、添加服务器和创建项目。

普通点击打开空白标签页。快速启动器包含最近条目、搜索和**打开其他项目…**。在主页或空白标签页管理最近条目，在 **设置 → 服务器** 管理服务器，在 **设置 → SideCars** 管理 SideCar。Escape 关闭启动器并将焦点返回 `+`。

## 关闭标签页以关闭项目 {#close-stop}

1. 使用标签页关闭按钮或命令面板中的**关闭标签页**（渲染器中为 `Ctrl/Cmd+W`）。
2. 关闭标签页会在 CodeNomad 中关闭该项目：不再跟踪其事件和请求。会话继续在 OpenCode 中运行。
3. 通过浏览或最近项目重新打开文件夹，即可再次找到这些会话。

| 操作 | 范围和影响 | 不会执行的操作 |
| --- | --- | --- |
| 关闭标签页 | 移除该标签页的 CodeNomad 项目连接；在同一文件夹上单独打开的其他标签页不受影响 | 不会删除项目文件或原生历史记录，不会停止会话，也不会卸载 OpenCode 的 Location |
| 停止会话 | 所选对话的执行 | 不会关闭项目或删除历史记录 |

若另一窗口显示的是同一个项目连接，其标签页也会关闭，并且该窗口会显示通知；发起关闭的窗口不显示通知。关闭会立即生效；如果后端无法关闭该项目，会显示错误，主页上的**切换到已打开的项目**仍可访问它。不会自动重试。已关闭标签页中的未发送草稿不会保留在启动恢复中。

关闭整个窗口、退出或重新加载不会关闭其项目连接；正常的启动恢复仍然适用。如需确认执行已结束，请显式停止相关运行。CodeNomad 绝不会卸载原生 Location；共享服务维护请参阅 [OpenCode 设置](opencode.md)。

## 临时工作区 {#temporary-workspaces}

1. 在主页或空白标签页的列表下方选择 **新建临时标签页**。
2. 在 CodeNomad 管理的空文件夹中工作；不会自动初始化 Git。
3. 关闭标签页时，选择**保留**、**丢弃**或**取消**。标签页菜单还提供**保留为项目**。

| 选择 | 影响 | 恢复方式 |
| --- | --- | --- |
| 保留 | 在 CodeNomad 中关闭该项目，保留文件夹和对话，移除临时状态并添加到最近项目 | 从最近列表重新打开；文件夹不会移动 |
| 丢弃 | 删除临时工作区的对话和文件 | 无法撤销；请先将所需内容另存到其他位置 |
| 取消 | 保持临时工作区打开 | 继续工作或稍后决定 |

没有对话、文件或未发送草稿的未使用临时标签页会在关闭时静默丢弃。打开的临时标签页参与正常的启动恢复，但主页没有单独用于恢复已关闭临时文件夹的列表。

对话正在运行或文件夹在其他标签页/窗口打开时，会拒绝丢弃。请先停止运行并关闭其他视图。丢弃失败时仍保留临时状态：请解决报告的问题后重试，不要手动删除父目录。

## 选择或创建工作树 {#select-create-worktree}

1. 打开父对话并使用其输入框中的工作树选择器。窄布局下它仅显示箭头。
2. 选择已发现的现有工作树，或选择 **+ 创建 worktree**。
3. 创建时输入**名称**并选择**创建并使用 worktree**。

CodeNomad 通过 OpenCode 发现工作树，并验证它们属于打开的仓库。新分支名从所选检出目录的 HEAD 开始。现有分支名使用该分支的当前修订；Git 可能拒绝已在其他位置检出的分支。工作树使用默认 `.codenomad/worktrees` 位置。未提交更改仍留在原检出目录；创建不会将它们复制到新工作树。

输入框选择器会将父对话及其递归后代作为经过验证的会话族移动。子会话无法独立更改此选择器。活动会话会阻止该操作：请先等待会话族完成或停止执行。等待移动完成后再请求下一次移动；出错时，请先检查刷新的对话/工作树状态再重试。

相比之下，[文件](files.md)中的**浏览工作树**只更改面板读取哪个检出目录。它不会移动对话、切换分支或更改下一条 Shell 命令的运行位置。

## 移除工作树 {#remove-worktree}

1. 在输入框工作树列表中，对可移除的分支工作树使用**删除 worktree**。
2. 检查目标文件夹。除非允许丢失本地更改，否则不要开启**强制删除（丢弃本地更改）**。
3. 确认删除并检查结果列表。

删除会移除工作树的本地文件夹。Git 主检出目录不是可移除目标。CodeNomad 会将受影响的对话族移回根检出目录，验证位置后才移除工作树；活动会话可能阻止移除。删除不是未提交文件的归档或备份。

如果 Git 因已修改/未跟踪文件而拒绝，请先保留或清理这些文件再重试。强制删除会明确丢弃它们。目录被锁定时，请关闭使用它的终端、编辑器、监视器和后台进程。记录缺失时，请先刷新工作树并检查路径再重试。共享诊断信息时，错误对话框提供**复制脱敏内容**；即使已脱敏，也请先检查文本。

## 初始化 Git 或在没有 Git 时工作 {#initialize-git}

1. 对于 Git 可用的普通文件夹，打开**文件 → 更改**或**提交**。
2. 选择**初始化 Git**。它会立即执行，不再额外确认。
3. 等待项目元数据和对话刷新；若在 CodeNomad 外初始化 Git，请使用**刷新**。

初始化会在显式打开的文件夹中创建仓库，而非其父目录。它不会创建提交。失败时，请先查看消息并刷新再重试：不确定的回复不会自动重放。

如果后端无法运行 Git，显式打开的文件夹仍可在仅目录模式下使用对话和有界文件浏览。工作树操作和 Git 初始化要求该后端安装 Git。请参阅[安装](install.md)和[文件](files.md)。
