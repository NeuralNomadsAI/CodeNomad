# 设置与布局

## 打开设置并识别范围 {#open-settings}

1. 使用标签栏（macOS 桌面应用中为标题栏）或主页上的**打开设置**齿轮打开**设置**。模型选择器中的**管理提供商**、任务面板齿轮或通知历史中的**设置**齿轮等快捷入口会直接打开相应部分。
2. 选择部分。本地 Electron 和 Tauri 窗口会打开或聚焦唯一的原生偏好设置窗口；浏览器和远程视图使用内嵌设置界面。
3. 离开前检查设置范围及所有**保存**操作。

大多数选择立即生效，包括任务偏好，它会在你每次更改时立即保存。语音、自定义调色板颜色和配置文件保留显式的**保存**。保存失败不确认更改已生效；重试前请重新打开或刷新相关部分。悬停或聚焦设置标题旁的 **i** 可查看简短说明。如果图标链接到帮助，点击、按 Enter 或轻触即可在系统浏览器或独立标签页中，以界面语言打开相关章节。仅提供提示的图标在轻触时显示说明。**设置 → 信息**中还有**赞助 CodeNomad**卡片：**赞助或贡献**会打开[赞助 CodeNomad](sponsor.md)页面。

| 状态 | 控制内容 |
| --- | --- |
| CodeNomad 配置 | 使用该配置的客户端的界面偏好、语音、SideCar 和服务器设置。没有徽章的偏好也不会按设备存储；**服务器设置**标记服务器端配置，例如语音、SideCar、远程控制和环境变量。 |
| 窗口/项目标签页布局 | 打开的面板、所选标签页、阅读器状态和可恢复草稿/布局。它们不是 OpenCode 配置。 |
| 全局/项目 OpenCode 设置 | 在显示范围内的原生插件/配置更改。项目控件要求活动项目/Location。 |
| 桌面数据配置文件 | 原生窗口、恢复状态和浏览器存储，独立于配置文件和共享 OpenCode 服务。参阅[桌面窗口与数据](desktop.md)。 |

**统计**涵盖整个已连接的 OpenCode 服务（所有项目、独立克隆和子会话），而不仅是已打开的文件夹，时间范围为最近 7、30、90 或 365 天。它需要打开一个项目，显示的是 OpenCode 记录的令牌和费用，而非提供商账单或订阅额度；刷新期间可能显示先前保存的总计。计划配额属于**用量**状态部分。

更改显示偏好不会重启 OpenCode 或重放提示词。原生配置、服务维护和凭据有各自影响：参阅 [OpenCode 设置](opencode.md)、[提供商](providers.md)和[集成](integrations.md)。

## 语言与外观 {#language-appearance}

1. 在**常规**中选择**语言**：英语、西班牙语、法语、俄语、日语、简体中文、希伯来语、德语、尼泊尔语或土耳其语。
2. 在**配色方案**中选择**模式**：**自动**、**深色**或**浅色**。自动跟随操作系统。
3. 为显示的外观选择调色板。浅色和深色选择独立保存；自动使用相应选择。
4. 自定义颜色时，使用色块和**保存**；**重置**恢复内置调色板的颜色。使用**新建**为独立调色板命名，使用**删除**移除你创建的调色板。

界面更新无需重启对话。希伯来语使用从右到左布局；代码和技术值仍按各自方向保持可读。语言选择更改界面文本，不改变现有消息或智能体指令的语言。CodeNomad 窗口加载完成后，原生桌面菜单会切换为界面语言。

颜色难以辨认时，选择内置调色板或重置所编辑的调色板。切换调色板可能询问是否丢弃未保存颜色编辑；不会丢弃对话草稿。

## 保持电脑唤醒 {#keep-computer-awake}

在**设置 → 常规**中，**CodeNomad 运行时保持电脑唤醒**默认关闭。开启后，只要本地 CodeNomad 窗口处于打开状态（包括最小化状态），即使没有会话在工作，也会阻止系统进入睡眠；屏幕仍可能自动关闭。关闭此选项时，CodeNomad 仅在会话工作期间保持电脑唤醒。标题旁的 **i** 可查看此行为的说明。此选项仅在桌面应用的本地窗口和原生偏好设置窗口中显示，在浏览器视图和远程视图中隐藏。

## 智能体持久记忆 {#agent-memory}

记忆故障期间仍可继续发送。CodeNomad 会尝试删除会话中过时的记忆指令；如果清理也失败，之前的指令可能保留到下次成功刷新。请继续对照当前文件和命令验证记忆中的说法。

打开 **偏好设置 → 常规 → 记忆**（浏览器中为 **设置 → 常规**）。记忆默认关闭。启用后，智能体可跨对话保留有用的事实和偏好。开关适用于连接的 CodeNomad 配置；关闭后仍保留已保存的条目及其历史。

- **关于你**：最多 60 条，由使用此配置的项目共享。
- **项目**：最多 200 条。此界面使用“偏好设置”中选定的项目，内嵌设置使用主窗口的当前项目。智能体的 `codenomad_memory` 工具和会话指令使用该会话的目录。服务器以规范化的 Git 远程仓库地址识别项目，无法使用时回退到本地仓库路径；工作树共享该记忆。打开项目后即可选择此范围。

每个会话（包括子会话）都会收到记录规则和有长度限制的标题、类型列表（指令块最多约 8,000 个字符）。智能体被要求在行动前通过 `codenomad_memory` 读取相关条目，对照当前文件和命令验证内容，并说明已保存的记忆。记忆为空时也会收到记录规则。无法读取的范围会作为不可用而省略。如果 OpenCode 缺少可选的会话指令能力，集成会静默保持停用，并保留已保存的选择。

1. 选择范围和条目。**新增** 和 **已修改** 标示自此浏览器或桌面视图上次成功查看该范围以来的变化；标记会在本次查看期间保持可见。
2. 编辑 **标题**、**类型**（**事实**、**偏好** 或 **引用**）和 **正文**，然后 **保存**。标题最多 60 个字符，正文最多 2,000 个字符。**取消** 会恢复已保存的内容。若条目已在别处更改，请 **重新加载** 并检查后再保存。
3. 要移除条目，打开其操作菜单并确认 **忘记**。条目会退出当前记忆；本地 Git 仍保留包括旧正文在内的历史。忘记仅停止智能体使用该条目，并非安全擦除数据。
4. 记忆已满时，请先合并或忘记条目再重试。相同标题或高度重合的正文会替换现有条目，Git 会保留旧正文。

**待检查** 表示条目疑似含有绕过安全措施或泄露凭据的指令。此类条目仍可在此编辑，计入数量上限，但不会出现在智能体的标题列表或读取结果中。每次读取都会重新检查；请修改内容并保存，或选择 **忘记**。格式错误或无法读取的记忆会显示错误而非空列表；修复原因后再重试。

**整理** 会先请求确认，再在偏好设置所显示的项目中打开新对话，验证并合并所选范围。它会保留无法验证的条目和外部引用，并报告更改。使用前需打开项目，且记忆已启用、可读可写，并至少有一个未标记条目。若无法确认启动结果，请先检查项目对话再重试。

记忆由智能体维护。如果它已在 `.claude/…/MEMORY.md` 等其他位置维护记忆，则记录指向该文件的 **引用**；外部记忆文件仍由原有方式管理。CodeNomad 在配置目录下的 `memory/global/` 或 `memory/projects/<id>/` 中为每个条目保存一个 Markdown 文件，每次保存或删除都会生成本地 Git 提交。存储仅限本地，不进行远程同步。配置与数据配置文件的范围见 [桌面窗口与数据](desktop.md)。

## 面板与状态部分 {#panels-status}

拖动停靠面板的内侧边缘可调整其大小。拖动期间，即使指针移出边缘，拖动柄也会保持高亮，并持续捕获指针。松开即可结束。

1. 使用标题栏外角的**左侧面板**和**右侧面板**，或 **View** 菜单中的对应条目，显示或隐藏面板。
2. 在右侧面板打开**自定义右侧面板**。使用复选框选择内置标签页和状态部分；至少一个状态部分须保持可见。在这些复选框上拖动可一次设置多个。
3. 拖动右侧面板标签页重新排序。使用**重置**恢复内置布局选择。

已识别的[集成](integrations.md#integration-sections)也有状态区域。可通过相同的复选框隐藏，并通过拖动或上/下方向键调整任何状态区域的顺序。可见性和顺序在重新加载或集成暂时缺失后仍会保留。

状态包含 Token 信息、Yolo 模式、提供商用量、后台 Shell、MCP 和插件。只要对话有[目标](conversations.md#goal)，这些部分上方就会有一行显示它；该行不是部分，无法隐藏或移动。隐藏部分不会禁用服务或撤销权限。窄布局会关闭放不下的面板，而非挤压对话；在此布局中打开的面板浮于对话之上，打开一个浮动面板会关闭另一个。

内置布局属于窗口布局，而非项目修改。扩展复选框不同：它们会为使用该配置的全部项目激活代码。**重置**不改变扩展同意。参阅[面板扩展](extensions.md)。

## 对话详情与输入框尺寸 {#transcript-composer}

1. 打开**聊天**选择对话详情默认值。预设为 **无**、**精简**、**均衡** 和 **全部**；单项更改会产生 **自定义**。
2. 为思考、诊断、工具输入、令牌、系统消息和每种工具类型设置各行的**默认状态**（**隐藏**、**折叠**或**展开**），或使用对话的**消息内容**弹出框，它共享这些选择。
3. 在**常规**中按需勾选**显示消息时间线**、**将首条/最新消息箭头放在时间线下方**、**拆分显示工具调用的差异**和**将已发送的提示加入队列**（会话工作时将发送的提示加入队列，而不是引导它）。
4. 使用尺寸调整控件调整输入框；长草稿在字段内部滚动。

时间线为对话中显示的每个回复、推理、工具、压缩和系统上下文各显示一个标记，顺序相同。标记遵循**消息内容**：在其中隐藏某种工具类型、推理或系统消息也会隐藏其标记（有待处理权限的工具除外），**无**会隐藏全部工具标记。可见性和展开设置只改变呈现。不会移除存储的工具/推理或压缩模型上下文。破坏性操作请参阅[历史与清理](history.md)。

输入框高度跟随可见对话，包括软件键盘：最小 8%，下限 44 px，最大 60%。手动高度按比例记忆；窄宽度和长文本不会提高限制。展开权限/问题会暂时最小化输入框，不改变保存高度或草稿。收起或处理请求后可恢复调整尺寸。

## 通知与徽章 {#notifications}

1. 打开**通知**。为每类通知勾选其显示位置：**屏幕**（临时气泡）、**历史**（保存在标签栏铃铛的通知历史中，macOS 桌面应用中铃铛位于标题栏）和**系统**（操作系统通知）。在一行或一列复选框上拖动可一次设置多个。
2. 勾选**系统**复选框时，如有需要会请求权限。在**系统通知**下，缺少权限时**请求**会再次请求。
3. 启用**应用获得焦点时也通知**，以便在此窗口获得焦点时仍显示系统通知。否则，只要窗口没有焦点，即使仍在屏幕上打开，也会显示系统通知。

默认情况下，**会话正在等待你的回复**和**会话已结束**只发送到系统，因此短暂的会话状态不会堆积在历史中；它们涉及主会话而非子智能体，你自己停止的会话不会被通知。无论表格如何设置，错误始终显示在屏幕上并记入历史，简短的进度消息只显示在屏幕上。

浏览器/操作系统权限属于设备和应用来源；保存的偏好无法覆盖拒绝。被阻止时，请在浏览器或操作系统设置中启用通知，再返回此处。不受支持的环境保持系统列禁用。

铃铛/历史未读数量（只统计路由到历史的通知）驱动浏览器网站图标圆点和原生应用徽章。原生徽章汇总活动主窗口；不是运行会话数量，也不证明操作系统通知已送达。此功能不提供 PWA 启动器徽章。

## 高级选项 {#advanced}

1. 打开**高级**。
2. 只勾选或取消勾选需要的选项；每项更改都通过 CodeNomad 偏好保存。要更改会话执行环境，请展开末尾折叠的**环境变量**组。
3. 检查结果视图或下一次发送，而非猜测性重启共享服务。

| 选项 | 影响与注意事项 |
| --- | --- |
| 自动清理空会话 | 创建新会话时清理空会话；想保留时请关闭。 |
| 保留子智能体 idle 标记 | 未查看空闲标记保留至查看，而非五秒后隐藏。 |
| 再次启动时聚焦现有窗口 | 仅原生桌面；更改再次启动窗口行为，而非标签页创建。 |
| 提供商额度余额 | 在用量中显示补充余额；不购买额度或切换账户。 |
| 隐藏仅空白的更改 | 从更改及批量操作中省略仅空白/行尾更改的未暂存文件；已暂存文件保持可见。参阅[文件](files.md)。 |
| 暂停跟随较长的助手回复 | 流式回复超过视口时停止自动跟随。 |
| 环境变量 | 在每条提示词或会话命令前由服务器端应用；读取不会更新已运行执行。参阅 [OpenCode 设置](opencode.md)。 |

键盘配置参阅[键盘快捷键](shortcuts.md)；语音控件参阅[语音输入与播放](voice.md)。启动恢复和桌面数据配置文件参阅[桌面窗口与数据](desktop.md)。
