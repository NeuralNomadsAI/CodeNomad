# 提供商与账户

提供商认证属于所连接的 OpenCode 服务，而非浏览器设备或单个 CodeNomad 项目。模型显示偏好、订阅配额和网页搜索选择有不同作用域。

## 连接模型或搜索提供商 {#connect}

1. 打开工作区，然后打开**设置 → 提供商**。**模型**默认展开；搜索提供商请展开**网页搜索**。**图像**包含图像设置。
2. 在该组中选择**选择提供商**，然后选择**连接**。对于已在下方列出的模型提供商，请使用其行中的**添加账户** (+)，首次连接也使用此入口。
3. 对于模型提供商，完成提供的原生**认证方式**：API 密钥、OAuth 或命令。对于 OAuth，使用**打开授权页面**，仅在要求时提交授权码。搜索提供商通过 API 密钥连接。
4. 完成后检查已配置提供商行。**模型**会在连接、账户更改和重新连接后重新读取；**网页搜索**还提供**刷新**。

仅搜索集成显示在**网页搜索**下，而非**模型**下。保存认证不会选择模型或更改默认搜索提供商。API 密钥和 OAuth 凭据由活动 OpenCode 服务器保存。浏览器收到连接元数据，而非保存的凭据秘密。来自环境变量的连接在此界面中只读：请更改其所属环境，而非尝试在此断开。

授权窗口被阻止时，使用流程中的**打开授权页面**、**在此标签页打开**或**复制链接**。不要在诊断信息中公开授权链接或授权码。

## 选择和管理账户 {#accounts}

1. 在提供商行中使用**活动账户**选择已保存凭据。
2. 使用**添加账户**认证另一条连接。
3. 管理其他已保存账户时，先选择它，再使用**重命名账户**或**移除账户**。重命名使用**账户名称**和**保存**；**移除账户**会立即执行，无需确认。

选择、重命名和移除会影响该集成在整个 OpenCode 服务中的状态，包括其他项目和客户端。移除凭据可能导致那些客户端无法认证；不会删除对话历史或撤销提供商远程账户。环境连接不能作为可写的已保存凭据选择，也不能在此移除。操作失败时，CodeNomad 会重新读取账户：请再次检查**活动账户**后再操作。

### 自动选择限制 {#automatic-selection}

在受支持集成中保存多个凭据后，**自动选择账户**可选择启用基于配额的选择，在下一条提示词/自定义命令通过 CodeNomad 接纳前执行。设置按集成保存在 CodeNomad 配置中；产生的账户选择作用于整个服务。

| 符合条件的集成 | 符合条件的账户类型 |
| --- | --- |
| OpenAI / Codex | Codex 浏览器/设备 OAuth 订阅账户，不包括 OpenAI 按量付费密钥，也不包括 OpenAI 不提供用量的 ChatGPT 登录方式。 |
| OpenCode Go | Go 密钥，或**仅用于 Go 提供商**的 OpenCode Console 登录/密钥；Console 付费模型仍需手动选择。 |
| Anthropic | OpenCode 的 Claude Pro/Max OAuth 登录，**不是** Claude Code 登录。 |
| GitHub Copilot | 可读取高级请求配额的 OAuth；企业端点凭据不是可读取候选。 |
| 编码计划 | 基于密钥的 `zai-coding-plan`、`zhipuai-coding-plan`、`kimi-for-coding`、`minimax-coding-plan`、`minimax-cn-coding-plan`。 |

仅当前账户配额耗尽才触发切换；仅有额度更充足的替代账户不会触发。读取会检查显式保存的凭据，不激活候选或交换刷新令牌。Codex、Copilot 和编码计划要求候选明确可用。Go、Console 和 Claude 可以使用配额未知的候选，除非近期原生配额失败将其标记为耗尽。OpenCode Go 读数取决于可用 API 和凭据权限。

这**不是运行中的故障转移**。它既不重试失败请求，也不重放提示词、命令或修改操作。不会轮换环境连接、任意提供商、按量付费余额或外部 Claude Code 登录。准备选择期间会尊重手动账户更改；不存在跨客户端账户锁。发生配额/认证错误时，请检查**活动账户**，刷新用量，必要时通过凭据所属方登录，然后再有意识地发送。

## 模型可见性、收藏和思考 {#models}

1. 选择模型提供商旁的**管理模型**。
2. 按名称/ID 搜索并更改可见性；**全部显示**和**全部隐藏**影响该提供商的选择器列表。在复选框上拖动可一次更改多个模型。
3. 在对话的**模型**选择器中使用**添加到收藏**或**从收藏移除**；**显示所有模型**会退出仅收藏筛选。
4. 使用输入框中的**思考**选择所选模型提供的变体。

可见性和收藏用于组织 CodeNomad 选择器；不会卸载模型、移除凭据或阻止其他 OpenCode 客户端使用它们。隐藏模型不等于断开账户。思考选择后续发送的模型变体，而非对话中已有推理的可见性。使用**管理模型 → 全部显示**恢复隐藏模型。

## 用量、Token 数和过期登录 {#usage}

使用右侧面板的**用量**查看活动对话的提供商计划窗口、重置时间和受支持余额。这些提供商读数不同于每条消息的**令牌**和成本估算：订阅配额不是根据可见对话计算的账单。缺失、过时或未知读数不是零用量，也不能证明还有容量。**设置 → 高级**中的**提供商额度余额**控制补充余额显示。

对于使用 OpenCode 的 Gemini CLI 认证方式的 Google 连接，**用量**显示各模型的限额；对于 Antigravity 连接，显示 **5 小时**和**每周**限额，并在提供相关数据时按模型系列分别显示配额。无法获取配额时显示“用量暂时不可用。”。这些连接的账户选择保持手动。

Google 的 [Antigravity 常见问题](https://antigravity.google/docs/faq/)指出，通过 Antigravity 登录使用第三方软件违反其服务条款，并可能导致账户被暂停或终止。

对于 `opencode` 集成的付费模型，**OpenCode Console** 显示**今天（UTC）**、**7天（UTC）**和**30天（UTC）**的**请求数**。这些周期是包含今天的 UTC 日历日，分别从今天、六天前和 29 天前的 UTC 00:00 开始。**按模型统计请求数 · 30天**列出每个模型及其提供商。计数涵盖已连接的 Console 账户，数字按应用语言格式化。**服务账户预算**显示**预算不可用。** OpenCode Go 使用独立的配额读取器。

读取器使用已保存的 `opencode` API 密钥，并优先使用其 Console OAuth 连接。OAuth 要求 `https://opencode.ai/console` 以及连接的组织 ID；访问 Console 需要 **Usage › Read** 权限。CodeNomad 从不刷新这些凭据。即使同时保存了 API 密钥，无效或过期的 OAuth 连接也必须通过其所属服务修复。

Console 错误区分未连接、凭据无效或过期（401）、访问被拒绝（403）、用量响应无效及网络故障。遇到连接错误时，前往**设置 → 提供商**检查登录及权限，然后刷新**用量**。任一摘要或模型分页读取失败都会使整次 Console 读取不可用。

对于 OpenCode 免费模型（`big-pickle` 和 ID 以 `-free` 结尾的模型），**用量**显示**估算**：将此服务自 UTC 00:00 起记录的步骤数与每天 200 次请求的参考值比较，预计在下一个 UTC 午夜重置。步骤数近似请求数；其他客户端流量和动态 IP 限制可能使实际配额不同。免费模型步骤发生配额错误后，该 OpenCode 连接上的所有免费模型都标记为**已耗尽**，直到 UTC 00:00。进度条显示 100%，已知计数保持不变，未知计数仍为未知。该标记按连接保存在后端内存中，重启后清除。

连接 OpenCode Console 后，免费估算取本地步骤数与 Console 自 UTC 00:00 起统计的免费模型请求数中的较大值，并保留**估算**标记。没有可用连接或 Console 读取失败时，保留本地估算。Console 计数涵盖整个账户，包括其他客户端和 IP 地址；按 IP 计算的限制可能不同。估算、耗尽标记及付费 Console 计数仅用于显示；自动账户选择使用独立的配额读取器和规则。

OpenAI 不为某一种 ChatGPT 登录方式提供用量：此时用量面板会说明这一点，而不显示配额窗口。选择[查看 ChatGPT 用量](https://chatgpt.com/settings/usage)，即可在 ChatGPT 中查看应用用量，并管理应用对您的套餐和额度的访问。聊天仍可正常使用，重新连接同一登录也不会恢复该读数。

用量凭据的来源取决于提供商。通过 `anthropic`/`claude` 使用 Claude 时，采用 OpenCode 的 Anthropic OAuth。OpenCode 的 **Claude Agent** 提供商（`claude-agent`）和 `claude-code` 提供商使用守护进程主机上的 Claude Code 登录，包括其 WSL 发行版：先用 `CLAUDE_CODE_OAUTH_TOKEN`，再用已存储登录，文件存储由 `CLAUDE_SECURESTORAGE_CONFIG_DIR` / `CLAUDE_CONFIG_DIR` 或 `~/.claude` 决定；本地 macOS 可使用钥匙串。CodeNomad 不会用一种 Claude 登录替代另一种。

用量读取器仅可在服务器内存中刷新访问令牌，且仅限刷新令牌在每次使用时保持不变的提供商，包括 Gemini CLI 和 Antigravity。已保存的连接仍由 OpenCode 管理。其他提供商登录过期时，通过其所属方——OpenCode、Claude Code 或 Codex CLI——刷新/登录，再刷新 CodeNomad。CodeNomad 服务器登录过期是另一回事：重新连接/登录 CodeNomad，不要假定失败的提供商请求会重发。参阅[故障排查](troubleshooting.md)。

当 MiniMax 成功响应但未提供限额时，**用量**会显示 **MiniMax 不公开其限额**，而不是配额数值。

OpenRouter 的 **密钥限额** 显示密钥支出上限及其剩余美元金额；没有支出上限的密钥不显示此行。API 允许访问时，账户额度会单独显示。用量使用提供商配置的 `baseURL`（保留路径前缀），未配置时使用 `https://openrouter.ai/api/v1`。请使用不含凭据、显式端口、查询或片段的公共 HTTPS 主机名；IP 地址和 localhost 会被拒绝。URL 无效或网关不支持 `/key` 时，用量不可用；密钥仅发送至配置的目标，重定向会被拒绝。

对于 z.ai 和 Zhipu，用量优先使用配置的 `apiKey`，包括由 OpenCode 在其主机上解析的 `{env:…}` 和 `{file:…}` 值；该密钥不可用时使用已保存的凭据。既没有密钥也没有已保存凭据时，提供商显示为未配置。业务错误会以本地化的提供商错误及可用的数字代码代替配额值。套餐积分使用五小时和每周窗口；MCP 工具拥有单独的配额。

GitHub Copilot 的**用量**以**已使用 已用量 / 上限**显示消耗；对于无限配额，若 GitHub 提供已消耗点数则显示该数值，否则显示**无限制**。高级请求保留自己的标签。底部会显示已识别的套餐名称。Enterprise 连接根据已保存连接的主机名或 HTTPS 根 URL，访问 `https://api.<host>/copilot_internal/user`。请使用不含凭据、显式端口（包括 `:443`）、`/` 以外路径、查询或片段的完整主机名；IP 地址和 localhost 会在发送令牌前被拒绝。重定向会被拒绝。目标无效或服务器不提供此 API 时，用量不可用。Enterprise 连接仍不参与自动账户选择。

Kimi 支持 `kimi-code-plan-cn`（kimi.com）、`kimi-code-plan-global`（kimi.ai）、`kimi-for-coding` 和 `kimi`。**用量**会优先使用当前对话的集成，在同一个总时限内依次尝试各集成中已保存的当前有效密钥。可用的五小时、每周、**每月**和**每月编程**限额显示已使用百分比。每月限额遵循提供商给出的重置日期；任一每月限额耗尽的 `kimi-for-coding` 账户均不能作为自动选择的可用候选，即使较短时间窗口仍有余量。

OpenCode Go API 密钥显示可用的已用百分比和重置时间。通过 OpenCode Console 登录时，若具有账单读取权限，也会读取以美元计的独立钱包余额。启用**提供商额度余额**可显示该余额（默认关闭）；Go 配额与 Extra Usage 分别显示。只有余额时，自动选择仍将配额视为未知。当出现 **OpenCode Go 密钥已过期。** 时，选择[在 OpenCode Console 中创建新密钥并替换旧密钥](https://opencode.ai/console/login)。在 **Account → Personal API keys** 中创建密钥（或请管理员提供服务账户密钥），然后通过提供商连接流程替换已保存的密钥。过期密钥需要替换。

### 可选用量环境变量 {#usage-environment}

Cursor Enterprise 尽力通过私有仪表板 API 读取数据。个人资料包含团队成员资格和团队 ID 时，**用量**会显示已识别的 `gpt-4` 请求用量，以及 API 提供的独立 **每用户限额** / **团队限额**（USD）。支出未知时仅显示限额，请求限额未知时仅显示已使用数量。未知用量组和重置日期保持不可用。团队缺失、访问被拒和令牌过期有各自的提示；已验证的部分数据仍会显示。

请通过下列变量提供有效的 Cursor 访问令牌。Enterprise 读取需要团队仪表板数据的读取权限；[管理 API](https://cursor.com/docs/account/teams/admin-api) 使用独立的管理密钥。请更新过期令牌，并以更新后的环境重启后端。

启动前在 **CodeNomad 后端进程**环境中设置以下变量。它们是用量读取器凭据，而非浏览器设置或模型选择控件。更改会话**环境变量**编辑器不会更新运行中后端供这些读取器使用的 `process.env`。更改时请以目标环境重启后端；不要仅为用量读取器变量重启共享 OpenCode 服务。

| 用量集成 | 环境变量 |
| --- | --- |
| Cursor | `CURSOR_ACCESS_TOKEN`，回退到 `CURSOR_TOKEN` |
| Ollama Cloud | `OLLAMA_CLOUD_COOKIE` |
| OpenCode Go 补充用量 | 同时使用 `OPENCODE_GO_WORKSPACE_ID` 和 `OPENCODE_GO_AUTH_COOKIE` |
| ZenMux | `ZENMUX_PLATFORM_API_KEY`——平台密钥，不同于推理密钥 |
| exe.dev | `EXE_DEV_USAGE_TOKEN` |
| Command Code | 原生凭据不可用时回退到 `COMMAND_CODE_API_KEY` |

不要让令牌/cookie 出现在 Shell 历史、截图和报告中。可选读取器依赖提供商 API 和凭据有效性；配置变量不保证有可用配额数据。

## 网页搜索默认值和项目覆盖 {#web-search}

1. 在**设置 → 提供商**中展开**网页搜索**；如果搜索集成需要 API 密钥，请用其密钥连接。
2. 为全局配置选择**默认搜索**。
3. 使用**用于当前项目**为活动 Location 覆盖。悬停或聚焦该选择器，可查看带有最终有效结果的**此项目的搜索**。

更改自动保存。**默认 / 继承**使用继承配置或已保存原生选择；项目覆盖优先于全局。**已禁用**在所选范围关闭搜索；**自动选择提供商**请求原生自动选择提供商。**网页搜索**仅在展开时加载其连接和选项。**断开连接**会移除已保存的搜索密钥；由环境变量提供的连接标为只读，且没有**断开连接**。

即使提供商选择按项目生效，搜索凭据仍在服务全局共享。保存密钥不会将它选为默认搜索。读写失败时，请先刷新再重试；不要盲目替换配置。原生配置详情请参阅 [OpenCode 文档](https://opencode.ai/v2/docs/)和 [OpenCode 设置](opencode.md)。

## 图像生成与存储 {#images}

1. 在**设置 → 提供商**中展开**图像**。
2. 除非你更改，**图像生成**为**开启，自动选择模型**：也可以改选已连接提供商提供的某个图像模型，或选择**关闭**以在全局配置中关闭它。
3. 勾选**图像只存储一次**，让每张附加或生成的图像只存储一次，而不是存在每条使用它的消息中。

更改会自动保存到全局 OpenCode 配置，并应用于所有项目。两者都是 OpenCode 的实验性功能：**图像**只显示已连接的 OpenCode 版本支持的设置。只有在已连接的提供商提供图像模型时，智能体才能使用图像工具。每张图像都在后台生成并保存为文件；智能体会告知文件路径。**图像只存储一次**适用于新消息。如果项目自己的 OpenCode 配置文件决定了**图像只存储一次**，复选框会显示该处生效的值，保存时也会写入该文件。否则，当另一个 OpenCode 配置（例如项目自己的配置）代为决定某项设置时，**图像**会在该设置下方说明。如果保存会隐藏另一个 OpenCode 配置文件的实验性设置，**图像**会保持只读并加以说明；请改为在该文件中修改选项。

如需在专用对话中创建、比较和优化图像，请参阅[使用 Design 扩展创建图像](extensions.md#design)。
