# 提供商与账户

提供商认证属于所连接的 OpenCode 服务，而非浏览器设备或单个 CodeNomad 项目。模型显示偏好、订阅配额和网页搜索选择有不同作用域。

## 连接模型或搜索提供商 {#connect}

1. 打开工作区，然后打开**设置 → 提供商**。**模型**默认展开；搜索提供商请展开**网页搜索**。**图像**包含图像设置。
2. 在该组中选择**选择提供商**，然后选择**连接**。对于已在下方列出的模型提供商，请使用其行中的**添加账户** (+)，首次连接也使用此入口。
3. 对于模型提供商，完成提供的原生**认证方式**：API 密钥、OAuth 或命令。对于 OAuth，使用**打开授权页面**，仅在要求时提交授权码。搜索提供商通过 API 密钥连接。
4. 完成后检查已配置提供商行。

仅搜索集成显示在**网页搜索**下，而非**模型**下。保存认证不会选择模型或更改默认搜索提供商。API 密钥和 OAuth 凭据由活动 OpenCode 服务器保存。浏览器收到连接元数据，而非保存的凭据秘密。来自环境变量的连接在此界面中只读：请更改其所属环境，而非尝试在此断开。

不要在诊断信息中公开授权链接或授权码。

## 选择和管理账户 {#accounts}

1. 在提供商行中使用**活动账户**选择已保存凭据。
2. 使用**添加账户**认证另一条连接。
3. 管理其他已保存账户时，先选择它，再使用**重命名账户**或**移除账户**。重命名使用**账户名称**和**保存**；**移除账户**会立即执行，无需确认。

选择、重命名和移除会影响该集成在整个 OpenCode 服务中的状态，包括其他项目和客户端。移除凭据可能导致那些客户端无法认证；不会删除对话历史或撤销提供商远程账户。环境连接不能作为可写的已保存凭据选择，也不能在此移除。

### 自动选择限制 {#automatic-selection}

在受支持集成中保存多个凭据后，**自动选择账户**可选择启用基于配额的选择，在下一条提示词/自定义命令通过 CodeNomad 接纳前执行。设置按集成保存在 CodeNomad 配置中；产生的账户选择作用于整个服务。

| 符合条件的集成 | 符合条件的账户类型 |
| --- | --- |
| OpenAI / Codex | Codex 浏览器/设备 OAuth 订阅账户，不包括 OpenAI 按量付费密钥，也不包括 OpenAI 不提供用量的 ChatGPT 登录方式。 |
| OpenCode Go | Go 密钥，或**仅用于 Go 提供商**的 OpenCode Console 登录/密钥；Console 付费模型仍需手动选择。 |
| Anthropic | OpenCode 的 Claude Pro/Max OAuth 登录，**不是** Claude Code 登录。 |
| GitHub Copilot | 可读取高级请求配额的 OAuth；企业端点凭据不是可读取候选。 |
| 编码计划 | 基于密钥的 `zai-coding-plan`、`zhipuai-coding-plan`、`kimi-for-coding`、`minimax-coding-plan`、`minimax-cn-coding-plan`。 |

仅当前账户配额耗尽才触发切换；仅有额度更充足的替代账户不会触发。Codex、Copilot 和编码计划要求候选明确可用。Go、Console 和 Claude 可以使用配额未知的候选，除非近期原生配额失败将其标记为耗尽。

这**不是运行中的故障转移**。它既不重试失败请求，也不重放提示词、命令或修改操作。不会轮换环境连接、任意提供商、按量付费余额或外部 Claude Code 登录。

## 模型可见性、收藏和思考 {#models}

1. 选择模型提供商旁的**管理模型**。
2. 按名称/ID 搜索并更改可见性；**全部显示**和**全部隐藏**影响该提供商的选择器列表。在复选框上拖动可一次更改多个模型。
3. 在对话的**模型**选择器中使用**添加到收藏**或**从收藏移除**；**显示所有模型**会退出仅收藏筛选。
4. 使用输入框中的**思考**选择所选模型提供的变体。

可见性和收藏用于组织 CodeNomad 选择器；不会卸载模型、移除凭据或阻止其他 OpenCode 客户端使用它们。思考选择后续发送的模型变体，而非对话中已有推理的可见性。使用**管理模型 → 全部显示**恢复隐藏模型。

## 用量、Token 数和过期登录 {#usage}

使用右侧面板的**用量**查看活动对话的提供商计划窗口、重置时间和受支持余额。这些提供商读数不同于每条消息的**令牌**和成本估算：订阅配额不是根据可见对话计算的账单。缺失、过时或未知读数不是零用量，也不能证明还有容量。**设置 → 高级**中的**提供商额度余额**控制补充余额显示。

Google 的 [Antigravity 常见问题](https://antigravity.google/docs/faq/)指出，通过 Antigravity 登录使用第三方软件违反其服务条款，并可能导致账户被暂停或终止。

对于 `opencode` 集成的付费模型，**OpenCode Console** 显示 Console 报告的**24小时**、**7天**和**30天**的**请求数**。**按模型统计请求数 · 30天**列出每个模型及其提供商。计数涵盖已连接的 Console 账户，数字按应用语言格式化。**服务账户预算**显示**预算不可用。** 启用**提供商额度余额**后，Console 额度余额显示为**额度**。OpenCode Go 使用独立的配额读取器。

即使同时保存了 API 密钥，无效或过期的 Console OAuth 连接也必须通过其所属服务修复。

发生 Console 连接错误（401 或 403）时，请在**设置 → 提供商**中检查登录、组织 ID 和 **Usage › Read** 权限，然后刷新**用量**。OAuth 要求 `https://opencode.ai/console`。

对于 OpenCode 免费模型（`big-pickle` 和 ID 以 `-free` 结尾的模型），**用量**显示一个进度条：已连接 Console 账户在 Console 报告的最近 24 小时内的免费请求数，与 **800** 次的参考值比较；实际限制可能不同。计数包括同一账户的其他客户端，没有重置时间。启用**提供商额度余额**后，Console 额度余额显示为**额度**。通过**设置 → 提供商**连接 OpenCode Console 以查看免费模型请求数。

免费用量和付费 Console 计数仅用于显示；自动账户选择使用独立的读取器和规则。

OpenAI 不为某一种 ChatGPT 登录方式提供用量：此时用量面板会说明这一点，而不显示配额窗口。选择[查看 ChatGPT 用量](https://chatgpt.com/settings/usage)，即可在 ChatGPT 中查看应用用量，并管理应用对您的套餐和额度的访问。

通过 `anthropic`/`claude` 使用 Claude 时，采用 OpenCode 的 Anthropic OAuth。OpenCode 的 **Claude Agent** 提供商（`claude-agent`）和 `claude-code` 提供商使用守护进程主机上的 Claude Code 登录，包括其 WSL 发行版：先用 `CLAUDE_CODE_OAUTH_TOKEN`，再用已存储登录，文件存储由 `CLAUDE_SECURESTORAGE_CONFIG_DIR` / `CLAUDE_CONFIG_DIR` 或 `~/.claude` 决定；本地 macOS 可使用钥匙串。

OpenRouter 的 **密钥限额** 显示密钥支出上限及其剩余美元金额；没有支出上限的密钥不显示此行。用量使用提供商配置的 `baseURL`（保留路径前缀），未配置时使用 `https://openrouter.ai/api/v1`。请使用不含凭据、显式端口、查询或片段的公共 HTTPS 主机名；IP 地址和 localhost 会被拒绝。URL 无效或网关不支持 `/key` 时，用量不可用；密钥仅发送至配置的目标，重定向会被拒绝。

GitHub Copilot 的**用量**以**已使用 已用量 / 上限**显示消耗；对于无限配额，若 GitHub 提供已消耗点数则显示该数值，否则显示**无限制**。Enterprise 连接根据已保存连接的主机名或 HTTPS 根 URL，访问 `https://api.<host>/copilot_internal/user`。请使用不含凭据、显式端口（包括 `:443`）、`/` 以外路径、查询或片段的完整主机名；IP 地址和 localhost 会在发送令牌前被拒绝。重定向会被拒绝。Enterprise 连接仍不参与自动账户选择。

Kimi 支持 `kimi-code-plan-cn`、`kimi-code-plan-global`、`kimi-for-coding` 和 `kimi`。可用的五小时、每周、**每月**和**每月编程**限额显示已使用百分比。

每月限额遵循提供商给出的重置日期；任一每月限额耗尽的 `kimi-for-coding` 账户均不能作为自动选择的可用候选，即使较短时间窗口仍有余量。

OpenCode Go API 密钥显示可用的已用百分比和重置时间。通过 OpenCode Console 登录时，若具有账单读取权限，也会读取以美元计的独立钱包余额。启用**提供商额度余额**可显示该余额（默认关闭）；Go 配额与 Extra Usage 分别显示。只有余额时，自动选择仍将配额视为未知。

出现 **用量暂时不可用。** 或 **无法连接 OpenCode Console。** 时，检查网络连接并刷新**用量**。

OpenCode Go 密钥过期时，在 [OpenCode Console](https://opencode.ai/console/login) 的 **Account → Personal API keys** 下创建新密钥，再通过提供商连接流程替换已保存的密钥。

### 可选用量环境变量 {#usage-environment}

请通过下列变量提供有效的 Cursor 访问令牌。Enterprise 读取需要团队仪表板数据的读取权限；[管理 API](https://cursor.com/docs/account/teams/admin-api) 使用独立的管理密钥。请更新过期令牌，并以更新后的环境重启后端。

启动前在 **CodeNomad 后端进程**环境中设置以下变量。更改会话**环境变量**编辑器不会更新运行中后端供这些读取器使用的 `process.env`。更改时请以目标环境重启后端；不要仅为用量读取器变量重启共享 OpenCode 服务。

| 用量集成 | 环境变量 |
| --- | --- |
| Cursor | `CURSOR_ACCESS_TOKEN`，回退到 `CURSOR_TOKEN` |
| Ollama Cloud | `OLLAMA_CLOUD_COOKIE` |
| OpenCode Go 补充用量 | 同时使用 `OPENCODE_GO_WORKSPACE_ID` 和 `OPENCODE_GO_AUTH_COOKIE` |
| ZenMux | `ZENMUX_PLATFORM_API_KEY`——平台密钥，不同于推理密钥 |
| exe.dev | `EXE_DEV_USAGE_TOKEN` |
| Command Code | 原生凭据不可用时回退到 `COMMAND_CODE_API_KEY` |

不要让令牌/cookie 出现在 Shell 历史、截图和报告中。

## 网页搜索默认值和项目覆盖 {#web-search}

1. 在**设置 → 提供商**中展开**网页搜索**；如果搜索集成需要 API 密钥，请用其密钥连接。
2. 为全局配置选择**默认搜索**。
3. 使用**用于当前项目**为活动 Location 覆盖。悬停或聚焦该选择器，可查看带有最终有效结果的**此项目的搜索**。

更改自动保存。**默认 / 继承**使用继承配置或已保存原生选择；项目覆盖优先于全局。**已禁用**在所选范围关闭搜索；**自动选择提供商**请求原生自动选择提供商。**断开连接**会移除已保存的搜索密钥；由环境变量提供的连接标为只读，且没有**断开连接**。

即使提供商选择按项目生效，搜索凭据仍在服务全局共享。保存密钥不会将它选为默认搜索。原生配置详情请参阅 [OpenCode 文档](https://opencode.ai/v2/docs/)和 [OpenCode 设置](opencode.md)。

## 图像生成与存储 {#images}

1. 在**设置 → 提供商**中展开**图像**。
2. 除非你更改，**图像生成**为**开启，自动选择模型**：也可以改选已连接提供商提供的某个图像模型，或选择**关闭**以在全局配置中关闭它。
3. 勾选**图像只存储一次**，让每张附加或生成的图像只存储一次，而不是存在每条使用它的消息中。

更改会自动保存到全局 OpenCode 配置，并应用于所有项目。两者都是 OpenCode 的实验性功能：**图像**只显示已连接的 OpenCode 版本支持的设置。只有在已连接的提供商提供图像模型时，智能体才能使用图像工具。**图像只存储一次**适用于新消息。如果项目自己的 OpenCode 配置文件决定了**图像只存储一次**，复选框会显示该处生效的值，保存时也会写入该文件。如果保存会隐藏其他 OpenCode 设置，**图像**会保持只读；请在警告提示中标明的配置文件里修改选项。

如需在专用对话中创建、比较和优化图像，请参阅[使用 Design 扩展创建图像](extensions.md#design)。
