# सेटिङ र लेआउट

## सेटिङ खोलेर दायरा चिनाउनुहोस् {#open-settings}

1. गृह पृष्ठ वा कमाण्ड प्यालेटबाट **सेटिङहरू** खोल्नुहोस्।
2. खण्ड चयन गर्नुहोस्। स्थानीय Electron र Tauri विन्डोले एउटै नेटिभ Preferences विन्डो खोल्छन् वा focus गर्छन्; ब्राउजर र रिमोट दृश्यले embedded सेटिङ स्क्रिन प्रयोग गर्छन्।
3. छोड्नुअघि सेटिङको दायरा र **बचत गर्नुहोस्** कार्य जाँच्नुहोस्।

धेरै switch तुरुन्त लागू हुन्छन्। speech, palette र Mission preferences जस्ता editor मा स्पष्ट saving नियन्त्रण छन्। असफल save परिवर्तन लागू भएको पुष्टि होइन; पुनःप्रयासअघि सम्बन्धित खण्ड खोल्नुहोस् वा refresh गर्नुहोस्।

| अवस्था | नियन्त्रण गर्ने कुरा |
| --- | --- |
| CodeNomad कन्फिगरेसन | त्यही कन्फिगरेसन प्रयोग गर्ने क्लाइन्टका UI प्राथमिकता, speech, SideCars र server सेटिङ। UI को “Device” badge उही कन्फिगरेसन साझा गर्ने अर्को क्लाइन्टबाट अलगावको वाचा होइन। |
| विन्डो/परियोजना-ट्याब लेआउट | खुला प्यानल, चयनित ट्याब, reader अवस्था र पुनर्स्थापनायोग्य मस्यौदा/लेआउट। यी OpenCode कन्फिगरेसन होइनन्। |
| Global/Project OpenCode सेटिङ | देखाइएको दायरामा native plugin/configuration परिवर्तन। Project नियन्त्रणलाई सक्रिय परियोजना/Location चाहिन्छ। |
| डेस्कटप डेटा प्रोफाइल | कन्फिगरेसन फाइल र साझा OpenCode सेवाबाट स्वतन्त्र नेटिभ विन्डो, restore अवस्था र ब्राउजर भण्डारण। [डेस्कटप विन्डो र डेटा](desktop.md) हेर्नुहोस्। |

प्रदर्शन प्राथमिकता बदल्दा OpenCode restart वा prompt replay हुँदैन। native configuration, सेवा मर्मत र credential का छुट्टै असर छन्: [OpenCode सेटअप](opencode.md), [प्रदायक](providers.md) र [एकीकरण](integrations.md) हेर्नुहोस्।

## भाषा र रूप {#language-appearance}

1. **सामान्य** मा **भाषा** चयन गर्नुहोस्: अंग्रेजी, स्पेनी, फ्रान्सेली, रूसी, जापानी, सरलीकृत चिनियाँ, हिब्रू, जर्मन, नेपाली वा टर्किश।
2. **रूप मोड** रोज्नुहोस्: **स्वतः**, **उज्यालो (Light)** वा **अँध्यारो (Dark)**। Auto ले अपरेटिङ सिस्टम पछ्याउँछ।
3. देखिएको रूपको palette रोज्नुहोस्। light र dark चयन छुट्टाछुट्टै सुरक्षित हुन्छन्; Auto ले मिल्दो प्रयोग गर्छ।
4. custom रङका लागि swatch र **सुरक्षित गर्नुहोस्** प्रयोग गर्नुहोस्; **रिसेट गर्नुहोस्** ले त्यो palette का रङ फर्काउँछ। छुट्टै palette नाम दिन **नयाँ** प्रयोग गर्नुहोस्।

कुराकानी restart नगरी UI अद्यावधिक हुन्छ। हिब्रूमा right-to-left लेआउट हुन्छ; code र प्राविधिक मान आफ्नै दिशामा पढ्न मिल्छन्। भाषा चयनले interface पाठ बदल्छ, विद्यमान सन्देश वा agent निर्देशनको भाषा होइन। नेटिभ operating-system menu अंग्रेजीमै रहन सक्छन्।

रङ पढ्न गाह्रो भए built-in palette रोज्नुहोस् वा सम्पादित palette reset गर्नुहोस्। palette बदल्दा नबचाइएका रङ सम्पादन त्याग्न सोध्न सक्छ; कुराकानी मस्यौदा त्याग्दैन।

## प्यानल र Status खण्ड {#panels-status}

1. प्यानल देखाउन/लुकाउन बाहिरी header कुनाका **बायाँ प्यानल** र **दायाँ प्यानल**, वा **View** menu का सम्बन्धित item प्रयोग गर्नुहोस्।
2. दायाँ प्यानलमा **दायाँ प्यानल अनुकूलन गर्नुहोस्** खोल्नुहोस्। built-in ट्याब र Status खण्ड रोज्न checkbox प्रयोग गर्नुहोस्; कम्तीमा एउटा Status खण्ड देखिइरहन्छ।
3. क्रम बदल्न right-panel ट्याब तान्नुहोस्। built-in लेआउट चयन फर्काउन **रिसेट गर्नुहोस्** प्रयोग गर्नुहोस्।

Status मा token जानकारी, Yolo मोड, provider Usage, background प्रक्रिया, MCP र Plugins छन्। खण्ड लुकाउँदा सेवा अक्षम वा अनुमति खारेज हुँदैन। साँघुरो लेआउटमा प्यानल कुराकानी खुम्च्याउनुको सट्टा माथि तैरिन्छन्; एउटा floating प्यानल खोल्दा अर्को बन्द हुन्छ।

built-in लेआउट विन्डो लेआउट हो, परियोजना परिवर्तन होइन। विस्तार checkbox फरक छन्: तिनले कन्फिगरेसन प्रयोग गर्ने सबै परियोजनामा code सक्रिय गर्छन्। **रिसेट गर्नुहोस्** ले विस्तार सहमति बदल्दैन। [प्यानल विस्तार](extensions.md) हेर्नुहोस्।

## Transcript विवरण र कम्पोजर आकार {#transcript-composer}

1. transcript विवरण default रोज्न **च्याट** खोल्नुहोस्। preset **Minimal**, **Balanced**, **Detailed** र **Everything** हुन्; व्यक्तिगत परिवर्तनले **Custom** बनाउँछन्।
2. thinking, tool input/output, निदान र token विवरण मिलाउनुहोस्, वा साझा दृश्यता नियन्त्रणका लागि कुराकानीको **सन्देशको सामग्री** popup प्रयोग गर्नुहोस्।
3. **सामान्य** मा आवश्यकअनुसार **सन्देश टाइमलाइन**, **टाइमलाइन उपकरण कलहरू**, **डिफ दृश्य (Diff view)** र **फलो-अप व्यवहार** मिलाउनुहोस्।
4. resize नियन्त्रणबाट कम्पोजरको आकार बदल्नुहोस्; लामो मस्यौदा field भित्र scroll हुन्छ।

दृश्यता र expansion सेटिङले प्रस्तुति मात्र बदल्छन्। सुरक्षित tool/reasoning हटाउँदैनन् वा model context compact गर्दैनन्। विनाशकारी कार्यका लागि [इतिहास र सफाइ](history.md) हेर्नुहोस्।

कम्पोजर उचाइ software keyboard समेत देखिने कुराकानीअनुसार हुन्छ: न्यूनतम 8%, 44 px floor सहित, अधिकतम 60%। हातैले मिलाएको उचाइ अनुपातमा सम्झिन्छ; साँघुरो चौडाइ र लामो पाठले सीमा बढाउँदैनन्। विस्तारित अनुमति/प्रश्नले सुरक्षित उचाइ वा मस्यौदा नबदली अस्थायी कम्पोजर सानो बनाउँछ। resize फर्काउन अनुरोध collapse वा settle गर्नुहोस्।

## सूचना र badge {#notifications}

1. **सूचनाहरू** खोलेर अनुमति नदिइएको भए **अनुरोध** रोज्नुहोस्।
2. **सूचनाहरू सक्षम गर्नुहोस्** सक्षम गर्नुहोस्।
3. **सत्रलाई इनपुट आवश्यक छ**, **सत्र निष्क्रिय (idle) हुन्छ**, र **एप फोकसमा हुँदा पनि सूचित गर्नुहोस्** कि नगर्ने रोज्नुहोस्।

ब्राउजर/OS अनुमति उपकरण र application origin को हो; सुरक्षित प्राथमिकताले अस्वीकार override गर्न सक्दैन। रोकिएको भए ब्राउजर वा OS सेटिङमा सूचना सक्षम गरी फर्कनुहोस्। असमर्थित वातावरणमा नियन्त्रण अक्षम रहन्छ।

bell/history unread count ले ब्राउजर favicon dot र नेटिभ application badge चलाउँछ। नेटिभ badge ले live main विन्डोको कुल दिन्छन्; चलिरहेका सत्रको count वा OS सूचना पुगेको प्रमाण होइनन्। यस सुविधाले PWA launcher badge दिँदैन।

## उन्नत विकल्प {#advanced}

1. **उन्नत** खोल्नुहोस्।
2. चाहिएको व्यवहार मात्र बदल्नुहोस्; switch CodeNomad preferences बाट बचत हुन्छन्। सत्र execution environment बदल्दा **वातावरण चरहरू (Environment Variables)** छुट्टै सम्पादन गर्नुहोस्।
3. अनुमानले साझा सेवा restart नगरी नतिजाको दृश्य वा अर्को पठाइ जाँच्नुहोस्।
