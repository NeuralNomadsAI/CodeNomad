# प्रदायक र खाता

प्रदायक प्रमाणीकरण जोडिएको OpenCode सेवाको हो, ब्राउजर उपकरण वा एउटै CodeNomad परियोजनाको होइन। मोडेल-प्रदर्शन प्राथमिकता, subscription quota र web-search चयनका दायरा फरक छन्।

## मोडेल वा खोज प्रदायक जोड्नुहोस् {#connect}

1. कार्यस्थान खोलेर **सेटिङहरू → प्रदायकहरू** खोल्नुहोस्। **मोडेलहरू** विस्तारित अवस्थामा सुरु हुन्छ; खोज प्रदायकका लागि **वेब खोज** विस्तार गर्नुहोस्। **छविहरू** मा छवि सेटिङहरू छन्।
2. त्यस समूहमा **प्रदायक चयन गर्नुहोस्**, अनि **जडान गर्नुहोस्** रोज्नुहोस्। तलको सूचीमा पहिल्यै देखिएको मोडेल प्रदायकका लागि, पहिलो जडानसमेत त्यसको पङ्क्तिमा रहेको **खाता थप्नुहोस्** (+) प्रयोग गर्नुहोस्।
3. मोडेल प्रदायकका लागि दिइएको नेटिभ **प्रमाणीकरण विधि** पूरा गर्नुहोस्: API key, OAuth वा command। OAuth मा **प्रमाणीकरण पृष्ठ खोल्नुहोस्** प्रयोग गर्नुहोस् र माग्दा मात्र authorization code बुझाउनुहोस्। खोज प्रदायक API key बाट जोडिन्छन्।
4. सकिएपछि configured-provider row जाँच्नुहोस्।

खोज-मात्र integration **वेब खोज** मा देखिन्छन्, **मोडेलहरू** मा होइन। प्रमाणीकरण बचतले मोडेल चयन वा default खोज प्रदायक बदल्दैन। API key र OAuth प्रमाणिकरण विवरण सक्रिय OpenCode सर्भरले बचत गर्छ। ब्राउजरले जडान metadata पाउँछ, सुरक्षित credential secret होइन। environment variable बाट आएको जडान यस UI मा पढ्न-मात्र हो: यहाँ disconnect गर्न खोज्नुको सट्टा यसको स्वामी वातावरण बदल्नुहोस्।

authorization link वा code निदानमा सार्वजनिक नगर्नुहोस्।

## खाता चयन र व्यवस्थापन {#accounts}

1. प्रदायक row मा सुरक्षित credential चयन गर्न **सक्रिय खाता** प्रयोग गर्नुहोस्।
2. अर्को जडान प्रमाणित गर्न **खाता थप्नुहोस्** प्रयोग गर्नुहोस्।
3. अर्को सुरक्षित खाता व्यवस्थापन गर्न पहिले चयन गरी **खाताको नाम बदल्नुहोस्** वा **खाता हटाउनुहोस्** प्रयोग गर्नुहोस्। नाम बदल्न **खाताको नाम** र **बचत गर्नुहोस्** प्रयोग हुन्छ; **खाता हटाउनुहोस्** पुष्टि नमागी तुरुन्तै काम गर्छ।

चयन, नाम परिवर्तन र हटाइले अन्य परियोजना/क्लाइन्टसमेत OpenCode सेवाभर त्यो integration प्रभावित गर्छन्। credential हटाउँदा ती क्लाइन्ट प्रमाणीकरणविहीन हुन सक्छन्; कुराकानी इतिहास मेटिँदैन वा प्रदायकको रिमोट खाता खारेज हुँदैन। environment जडानलाई लेख्न मिल्ने सुरक्षित credential का रूपमा चयन वा यहाँ हटाउन सकिँदैन।

### स्वचालित चयनका सीमा {#automatic-selection}

समर्थित integration मा धेरै सुरक्षित credential हुँदा **खाता स्वतः चयन गर्नुहोस्** ले CodeNomad बाट अर्को prompt/custom-command admission अघि quota-आधारित चयनमा opt-in गर्छ। सेटिङ CodeNomad कन्फिगरेसनमा प्रति-integration हो; परिणामको खाता चयन सेवाभर हुन्छ।

| योग्य integration | योग्य खाता प्रकार |
| --- | --- |
| OpenAI / Codex | Codex browser/device OAuth subscription खाता; OpenAI pay-as-you-go key वा OpenAI ले usage नदिने ChatGPT sign-in विधि होइन। |
| OpenCode Go | Go key, वा **Go प्रदायकका लागि मात्र** प्रयोग हुने OpenCode Console sign-in/key; Console का सशुल्क मोडेलको छनोट म्यानुअल रहन्छ। |
| Anthropic | OpenCode को Claude Pro/Max OAuth login, Claude Code login **होइन**। |
| GitHub Copilot | पढ्न मिल्ने premium-request quota सहित OAuth; enterprise-endpoint credential पढ्न मिल्ने उम्मेदवार होइनन्। |
| Coding plan | key-आधारित `zai-coding-plan`, `zhipuai-coding-plan`, `kimi-for-coding`, `minimax-coding-plan`, `minimax-cn-coding-plan`। |

हाल प्रयोग भइरहेको खाताको कोटा सकिँदा मात्र switch हुन्छ; बढी क्षमता भएको विकल्प हुँदैमा हुँदैन। Codex, Copilot र coding plan लाई प्रमाणित उपलब्ध उम्मेदवार चाहिन्छ। Go, Console र Claude ले हालैको native quota failure ले exhausted नचिनाए unknown-quota उम्मेदवार प्रयोग गर्न सक्छन्।

यो **चल्दाचल्दै failover होइन**। असफल अनुरोध पुनःप्रयास वा prompt, command अथवा परिवर्तन replay गर्दैन। environment जडान, मनपरी provider, pay-as-you-go balance वा बाह्य Claude Code login घुमाउँदैन।

## मोडेल दृश्यता, मनपर्ने र Thinking {#models}

1. मोडेल प्रदायकछेउ **मोडेलहरू व्यवस्थापन गर्नुहोस्** रोज्नुहोस्।
2. नाम/ID बाट खोजेर दृश्यता बदल्नुहोस्; **सबै देखाउनुहोस्** र **सबै लुकाउनुहोस्** ले त्यस प्रदायकको selector सूची प्रभावित गर्छन्। धेरै मोडेलहरू एकैपटक परिवर्तन गर्न checkbox हरूमाथि ड्र्याग गर्नुहोस्।
3. कुराकानीको **मोडेल** selector मा **मनपर्नेमा थप्नुहोस्** वा **मनपर्नेबाट हटाउनुहोस्** प्रयोग गर्नुहोस्; **सबै मोडेलहरू देखाउनुहोस्** ले favorites-only filtering छोड्छ।
4. चयनित मोडेलका variant का लागि कम्पोजरमा **सोचाइ** प्रयोग गर्नुहोस्।

दृश्यता र मनपर्नेले CodeNomad selector व्यवस्थित गर्छन्; मोडेल uninstall, credential हटाइ वा अन्य OpenCode क्लाइन्टको प्रयोग रोक्दैनन्। Thinking ले पछिका पठाइको model variant रोज्छ, transcript मा भएको reasoning दृश्यता होइन। लुकेका मोडेल **मोडेलहरू व्यवस्थापन गर्नुहोस् → सबै देखाउनुहोस्** बाट फर्काउनुहोस्।

## प्रयोग, token count र म्याद सकिएका login {#usage}

सक्रिय कुराकानीको provider-plan window, reset समय र समर्थित balance का लागि दायाँ प्यानलको **प्रयोग** प्रयोग गर्नुहोस्। यी reading प्रति-सन्देश **टोकनहरू** र लागत अनुमानभन्दा फरक हुन्: subscription quota देखिएको transcript बाट गणना भएको बिल होइन। हराएको, पुरानो वा unknown reading शून्य usage वा बाँकी क्षमताको प्रमाण होइन। **सेटिङहरू → उन्नत** को **प्रदायक क्रेडिट मौज्दात** ले थप balance प्रदर्शन नियन्त्रण गर्छ।

Google को [Antigravity FAQ](https://antigravity.google/docs/faq/) अनुसार Antigravity लगइनसँग तेस्रो-पक्ष सफ्टवेयर प्रयोग गर्दा यसको सेवा सर्त उल्लङ्घन हुन्छ र खाता निलम्बन वा बन्द हुन सक्छ।

`opencode` एकीकरणका सशुल्क मोडेलका लागि **OpenCode Console** ले Console ले दिएअनुसार **२४ घण्टा**, **७ दिन** र **३० दिन** का **अनुरोधहरू** देखाउँछ। **मोडेलअनुसार अनुरोधहरू · ३० दिन** मा प्रत्येक मोडेल र यसको प्रदायक देखिन्छ। गणना जडान गरिएको Console खाताको हुन्छ र सङ्ख्या एपको भाषाअनुसार ढाँचाबद्ध हुन्छ। **सेवा खाताका बजेटहरू** मा **बजेटहरू उपलब्ध छैनन्।** देखिन्छ। **प्रदायक क्रेडिट मौज्दात** सक्रिय भए Console क्रेडिट मौज्दात **क्रेडिट** मा देखिन्छ। OpenCode Go ले आफ्नै कोटा रिडर प्रयोग गर्छ।

Console OAuth जडान अमान्य वा म्याद सकिएको भए, API key पनि सुरक्षित भए तापनि त्यसको स्वामीमार्फत जडान ठीक गर्नुहोस्।

Console जडान त्रुटि (401 वा 403) आएमा **सेटिङहरू → प्रदायकहरू** मा लगइन, त्यसको संगठन ID र **Usage › Read** अनुमति जाँच्नुहोस्, त्यसपछि **प्रयोग** रिफ्रेस गर्नुहोस्। OAuth का लागि `https://opencode.ai/console` चाहिन्छ।

निःशुल्क OpenCode मोडेल (`big-pickle` र `-free` मा अन्त्य हुने ID) का लागि **प्रयोग** ले एउटा बार देखाउँछ: Console ले दिएको पछिल्लो २४ घण्टामा जडान गरिएको Console खाताका निःशुल्क अनुरोध, **800** को सन्दर्भसँग तुलना गरेर; वास्तविक सीमा फरक हुन सक्छ। गणनामा सो खाताका अन्य क्लाइन्ट पनि पर्छन् र यसको रिसेट समय हुँदैन। **प्रदायक क्रेडिट मौज्दात** सक्रिय भए Console क्रेडिट मौज्दात **क्रेडिट** मा देखिन्छ। निःशुल्क मोडेलका अनुरोध हेर्न **सेटिङहरू → प्रदायकहरू** बाट OpenCode Console जडान गर्नुहोस्।

निःशुल्क प्रयोग र सशुल्क Console गणना प्रदर्शनका लागि मात्र हुन्; स्वचालित खाता छनोटले छुट्टै रिडर र नियम प्रयोग गर्छ।

OpenAI ले एउटा ChatGPT sign-in विधिका लागि usage दिँदैन: त्यसमा **प्रयोग** ले quota window देखाउनुको सट्टा त्यही बताउँछ। ChatGPT मा एपहरूको प्रयोग हेर्न र आफ्नो योजना तथा क्रेडिटमा तिनको पहुँच व्यवस्थापन गर्न [ChatGPT को प्रयोग हेर्नुहोस्](https://chatgpt.com/settings/usage) रोज्नुहोस्।

`anthropic`/`claude` मार्फत Claude ले OpenCode को Anthropic OAuth प्रयोग गर्छ। OpenCode को **Claude Agent** provider (`claude-agent`) र `claude-code` provider ले daemon होस्टको Claude Code login, त्यसको WSL वितरणसमेत, प्रयोग गर्छ: `CLAUDE_CODE_OAUTH_TOKEN`, त्यसपछि सुरक्षित login; `CLAUDE_SECURESTORAGE_CONFIG_DIR` / `CLAUDE_CONFIG_DIR` वा `~/.claude` ले फाइल भण्डारण निर्धारण गर्छन्; स्थानीय macOS ले Keychain प्रयोग गर्न सक्छ।

OpenRouter को **कुञ्जीको सीमा** ले कुञ्जीको खर्च सीमाको तुलनामा बाँकी USD रकम देखाउँछ; सीमा नभएको कुञ्जीमा यो पङ्क्ति हुँदैन। प्रयोगले प्रदायकको कन्फिगर गरिएको `baseURL` र त्यसको पथ उपसर्ग प्रयोग गर्छ; नभएमा `https://openrouter.ai/api/v1` प्रयोग गर्छ। लगइन विवरण, स्पष्ट पोर्ट, क्वेरी वा फ्र्याग्मेन्टबिनाको सार्वजनिक HTTPS होस्टनाम प्रयोग गर्नुहोस्; IP ठेगाना र localhost अस्वीकार गरिन्छ। अमान्य URL वा `/key` नभएको गेटवेमा प्रयोग उपलब्ध हुँदैन; कुञ्जी कन्फिगर गरिएको गन्तव्यमै रहन्छ र रिडाइरेक्ट अस्वीकार गरिन्छ।

GitHub Copilot को **प्रयोग** ले **प्रयोग भएको / सीमा प्रयोग भयो** को रूपमा खपत देखाउँछ, वा GitHub ले उपलब्ध गराएमा असीमित कोटामा खपत भएको क्रेडिट देखाउँछ; अन्यथा **असीमित** देखिन्छ। Enterprise जडानले सुरक्षित जडानको होस्ट वा HTTPS मूल URL बाट `https://api.<host>/copilot_internal/user` प्रयोग गर्छ। लगइन विवरण, स्पष्ट पोर्ट (`:443` समेत), `/` भन्दा बाहिरको पथ, क्वेरी वा फ्र्याग्मेन्टबिनाको पूर्ण होस्टनाम प्रयोग गर्नुहोस्; टोकन पठाउनुअघि IP ठेगाना र localhost अस्वीकार गरिन्छ। रिडाइरेक्ट अस्वीकार गरिन्छ। Enterprise जडानहरू स्वचालित खाता चयनबाहिर रहन्छन्।

Kimi ले `kimi-code-plan-cn`, `kimi-code-plan-global`, `kimi-for-coding` र `kimi` समर्थन गर्छ। उपलब्ध पाँच-घण्टे, साप्ताहिक, **मासिक** र **मासिक कोडिङ** सीमाले प्रयोग भएको प्रतिशत देखाउँछन्।

मासिक सीमाहरू प्रदायकको reset मितिअनुसार चल्छन्; कुनै मासिक सीमा सकिएको `kimi-for-coding` खाता छोटो अवधिको सीमामा क्षमता बाँकी भए पनि स्वचालित छनोटका लागि उपलब्ध हुँदैन।

OpenCode Go API कुञ्जीले उपलब्ध प्रयोग प्रतिशत र रिसेट समय देखाउँछ। बिलिङ अनुमति भए OpenCode Console लगइनले वालेटको मौज्दात पनि USD मा पढ्छ। यो छुट्टै मौज्दात देखाउन **प्रदायक क्रेडिट मौज्दात** सक्षम गर्नुहोस् (पूर्वनिर्धारित रूपमा बन्द); Go कोटा र Extra Usage छुट्टै रहन्छन्। मौज्दात मात्रै हुँदा स्वचालित छनोटका लागि कोटा अज्ञात रहन्छ।

**प्रयोग विवरण अस्थायी रूपमा उपलब्ध छैन।** वा **OpenCode Console मा सम्पर्क गर्न सकिएन।** देखिए नेटवर्क जडान जाँचेर **प्रयोग** ताजा गर्नुहोस्।

OpenCode Go key को म्याद सकिए [OpenCode Console](https://opencode.ai/console/login) को **Account → Personal API keys** मा नयाँ key बनाउनुहोस् र प्रदायक जडानबाट सुरक्षित key बदल्नुहोस्।

### ऐच्छिक usage वातावरण variable {#usage-environment}

तलका variable बाट हाल मान्य Cursor पहुँच टोकन दिनुहोस्। Enterprise पढाइलाई टोलीको ड्यासबोर्ड डेटा पढ्ने अनुमति चाहिन्छ; [Admin API](https://cursor.com/docs/account/teams/admin-api) ले छुट्टै प्रशासनिक कुञ्जी प्रयोग गर्छ। म्याद सकिएको टोकन अद्यावधिक गरी नयाँ वातावरणसहित ब्याकएन्ड पुनः सुरु गर्नुहोस्।

यी **CodeNomad ब्याकएन्ड प्रक्रियाको** वातावरणमा सुरु गर्नुअघि सेट गर्नुहोस्। सत्रको **वातावरण चरहरू (Environment Variables)** editor बदल्दा यी reader का लागि चलिरहेको ब्याकएन्डको `process.env` अद्यावधिक हुँदैन। बदल्दा अभिप्रेत वातावरणमा ब्याकएन्ड पुनः सुरु गर्नुहोस्; usage-reader variable का लागि मात्र साझा OpenCode सेवा restart नगर्नुहोस्।

| Usage integration | वातावरण variable |
| --- | --- |
| Cursor | `CURSOR_ACCESS_TOKEN`, नभए `CURSOR_TOKEN` |
| Ollama Cloud | `OLLAMA_CLOUD_COOKIE` |
| OpenCode Go थप usage | `OPENCODE_GO_WORKSPACE_ID` र `OPENCODE_GO_AUTH_COOKIE` सँगै |
| ZenMux | `ZENMUX_PLATFORM_API_KEY` — platform key, inference key भन्दा फरक |
| exe.dev | `EXE_DEV_USAGE_TOKEN` |
| Command Code | नेटिभ credential अनुपलब्ध हुँदा `COMMAND_CODE_API_KEY` fallback |

token/cookie लाई shell इतिहास, screenshot र report बाहिर राख्नुहोस्।

## Web-search default र Project override {#web-search}

1. **सेटिङहरू → प्रदायकहरू** मा **वेब खोज** विस्तार गरी, चाहिएमा, खोज integration लाई यसको API key सहित जोड्नुहोस्।
2. Global कन्फिगरेसनका लागि **पूर्वनिर्धारित खोज** रोज्नुहोस्।
3. सक्रिय Location मा override गर्न **हालको परियोजनाका लागि** प्रयोग गर्नुहोस्। प्रभावकारी नतिजासहितको **यस परियोजनामा खोज** हेर्न त्यो selector मा hover वा focus गर्नुहोस्।

परिवर्तन स्वतः बचत हुन्छन्। **पूर्वनिर्धारित / विरासत** ले inherited कन्फिगरेसन वा सुरक्षित नेटिभ चयन प्रयोग गर्छ; Project override Global भन्दा अघि पर्छ। **निष्क्रिय** ले चयनित दायरामा खोज बन्द गर्छ; **स्वचालित प्रदायक** ले नेटिभ स्वचालित provider चयन माग्छ। **विच्छेद गर्नुहोस्** ले सुरक्षित खोज key हटाउँछ; environment variable ले दिएको जडानमा पढ्न-मात्र label हुन्छ र **विच्छेद गर्नुहोस्** हुँदैन।

प्रदायक चयन Project-दायरामा भए पनि खोज credential सेवा-global रहन्छन्। key बचतले त्यसलाई खोज default चयन गर्दैन। नेटिभ विवरणका लागि [OpenCode दस्तावेज](https://opencode.ai/v2/docs/) र [OpenCode सेटअप](opencode.md) हेर्नुहोस्।

## छवि सिर्जना र भण्डारण {#images}

1. **सेटिङहरू → प्रदायकहरू** मा **छविहरू** विस्तार गर्नुहोस्।
2. तपाईंले नबदलेसम्म **छवि सिर्जना** **सक्रिय, स्वचालित मोडेल** मा रहन्छ: यसको सट्टा जडान भएका प्रदायकहरूले दिने छवि मोडेलमध्ये एउटा छान्नुहोस्, वा Global कन्फिगरेसनमा यसलाई बन्द गर्न **बन्द** छान्नुहोस्।
3. संलग्न वा सिर्जना गरिएको प्रत्येक छवि त्यसलाई प्रयोग गर्ने हरेक सन्देशभित्र नराखी एक पटक मात्र राख्न **छविहरू एक पटक मात्र भण्डारण गर्नुहोस्** चयन गर्नुहोस्।

परिवर्तनहरू Global OpenCode कन्फिगरेसनमा स्वतः सुरक्षित हुन्छन् र सबै प्रोजेक्टहरूमा लागू हुन्छन्। दुवै OpenCode का प्रयोगात्मक सुविधा हुन्: **छविहरू** ले जडान भएको OpenCode संस्करणले समर्थन गर्ने सेटिङहरू मात्र देखाउँछ। कुनै जडान भएको प्रदायकले छवि मोडेल दिँदासम्म मात्र एजेन्टहरूले छवि उपकरण पाउँछन्। **छविहरू एक पटक मात्र भण्डारण गर्नुहोस्** नयाँ सन्देशहरूमा लागू हुन्छ। प्रोजेक्टको आफ्नै OpenCode कन्फिगरेसन फाइलले **छविहरू एक पटक मात्र भण्डारण गर्नुहोस्** तोकेमा, बाकसले त्यहाँ लागू हुने मान देखाउँछ र सुरक्षित गर्दा त्यो फाइलमा पनि लेखिन्छ। सुरक्षित गर्दा अन्य OpenCode सेटिङहरू लुक्ने भएमा, **छविहरू** पढ्न-मात्र रहन्छ; चेतावनीको टुलटिपमा देखाइएको कन्फिगरेसन फाइलमा विकल्पहरू परिवर्तन गर्नुहोस्।

समर्पित वार्तालापमा छवि बनाउन, तुलना गर्न र परिष्कृत गर्न, [Design विस्तारसँग छविहरू बनाउनुहोस्](extensions.md#design) हेर्नुहोस्।
