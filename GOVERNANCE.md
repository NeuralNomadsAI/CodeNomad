# CodeNomad Governance

CodeNomad is an open-source project of the [NeuralNomadsAI](https://github.com/NeuralNomadsAI) GitHub organization, released under the [MIT license](LICENSE). Each contributor keeps the copyright of their contributions and publishes them under that license; the license's copyright notice names them together as the CodeNomad contributors.

## Maintainers

| Maintainer | GitHub | Role |
|---|---|---|
| Shantur Rathore | [@shantur](https://github.com/shantur) | Maintainer and administrator of the repository; owner of the NeuralNomadsAI organization |
| Pascal André | [@pascalandr](https://github.com/pascalandr) | Maintainer and administrator of the repository |

The maintainers have the same rights and responsibilities for the project. Either of them can change the repository's settings, manage its access, and act for the project with the services it uses, such as code signing, package registries and funding platforms.

Maintainers review and merge pull requests, publish releases and moderate the project's spaces under the [code of conduct](CODE_OF_CONDUCT.md).

## Decisions

- Day-to-day changes are proposed and discussed in pull requests to `dev`, as described in [CONTRIBUTING.md](CONTRIBUTING.md). Either maintainer can merge a pull request.
- Significant decisions need the agreement of both maintainers, recorded in a GitHub issue or pull request: changes to the license, this document or the code of conduct; adding or removing a maintainer; releases that break compatibility; and funding policy.
- When the maintainers disagree, the current state is kept until they agree.

## Becoming a maintainer

A contributor with a sustained record of quality contributions can be invited to become a maintainer with the agreement of all current maintainers. A maintainer can step down at any time by saying so in an issue.

## Funding

Contributions are received through the channels listed on the help site's [Support CodeNomad](docs/help/en/sponsor.md) page and in [`.github/FUNDING.yml`](.github/FUNDING.yml); today this is Pascal André's [GitHub Sponsors](https://github.com/sponsors/pascalandr). Each channel names who receives the money. A contribution buys no features, roadmap influence, support priority or license rights.

Any shared project fund requires the agreement of both maintainers, and no one approves their own expenses from it.

## Succession

If a maintainer becomes unavailable, the remaining maintainer continues the project. If no maintainer can continue, the maintainers hand the project over to new maintainers chosen in a public issue.
