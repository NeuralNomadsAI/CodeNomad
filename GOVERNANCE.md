# CodeNomad Governance

CodeNomad is an open-source project of the [NeuralNomadsAI](https://github.com/NeuralNomadsAI) GitHub organization, released under the [MIT license](LICENSE). Each contributor keeps the copyright of their contributions and publishes them under that license; the license's copyright notice names them together as the CodeNomad contributors.

## Maintainer

| Maintainer | GitHub | Role |
|---|---|---|
| Pascal André | [@pascalandr](https://github.com/pascalandr) | Maintainer and administrator of the repository |

Shantur Rathore ([@shantur](https://github.com/shantur)) created CodeNomad and owns the NeuralNomadsAI organization.

The maintainer reviews and merges pull requests, publishes releases, manages the repository's settings and access, acts for the project with the services it uses, such as code signing, package registries and funding platforms, and moderates the project's spaces under the [code of conduct](CODE_OF_CONDUCT.md).

## Decisions

- Changes are proposed and discussed in pull requests to `dev`, as described in [CONTRIBUTING.md](CONTRIBUTING.md), and merged by the maintainer.
- Significant changes are proposed in a public GitHub issue or pull request before they land: changes to the license, this document or the code of conduct, and releases that break compatibility.

## Becoming a maintainer

A contributor with a sustained record of quality contributions can be invited by the maintainer to become a maintainer. A maintainer can step down at any time by saying so in an issue.

## Funding

All sponsorship goes to Pascal André, through the channels listed on the help site's [Support CodeNomad](docs/help/en/sponsor.md) page and in [`.github/FUNDING.yml`](.github/FUNDING.yml). A sponsorship is a contribution, not a purchase: it buys no features, roadmap influence, support priority or license rights, and sponsors get the same CodeNomad as everyone else.

## Succession

If Pascal André stops maintaining CodeNomad, Shantur Rathore, as owner of the NeuralNomadsAI organization, can appoint a new maintainer.
