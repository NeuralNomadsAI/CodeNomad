# Wayfinder Mission

Start `mission.inspect` with template `wayfinder` and phrase the destination as the objective.

- Plan by default. The map is done when the route is clear, not when the destination has been implemented.
- Chart breadth-first. Create only sharp decisions; leave questions that cannot yet be phrased in the mission notes as fog.
- Cover all explicitly requested workstreams. Before waiting for one result, launch the other independent ready decisions with runtime-supported background or concurrent native calls. Keep real evidence/permission gates and resource/shared-write limits; state why any ready work must be serial. A blocked workstream does not park unrelated work.
- Prefer fresh native children for independent work. Exact eligible actor reuse selects context, not a `blockedBy` dependency; do not manufacture edges to reuse a session, and never continue an actor still busy.
- Create blockers before dependent tasks and connect them with `blockedBy`. The durable map derives the current frontier.
- Declare sharp decisions without demanding completed prerequisites; execution admits only the unblocked frontier. Run independent ready decisions and `research` in parallel when useful; `blockedBy` records real prerequisites, not an artificial sequence. One durable decision per task does not restrict its native helper tree. Pass the canonical `assignmentPrompt` into each ready task's ordinary native call, preserving its declared execution profile and native continuation checks. Independent roots require an explained location, lifetime, existing-root, or playbook exception.
- Use native Forms for `prototype` and `grilling` decisions that require a human. Never answer the human side yourself.
- Native children return the decision, actual evidence, rejected alternatives, and newly visible questions through ordinary native results. The coordinator records the business readout with `mission.report`, `taskKey`, and no `contract`; do not request duplicate child reports or forward task generations/bindings to helpers. Independent-root actors still submit their own assigned reports. The coordinator decides what graduates from fog, then uses revision-checked additive frontier tasks without requiring a replacement link. Existing contracts and historical proofs remain immutable.
- Human decisions require real native Form/session references and authoritative settled results, not a model-claimed human answer. No durable typed Form proof is presently enforced by the playbook report contract; do not invent a `humanForm` DTO or claim consent from prose. Hand off proof integration to the authority owner before enabling a human-proof completion gate.

Each native child owns its bounded assignment and may recursively decompose useful independent subtasks. Pass relevant scope, planning/human-decision constraints, safety boundaries and this delegation policy to each helper; Missions does not automatically propagate context. Helpers gain no coordinator topology or task-report authority and return to their immediate parent, which integrates actual returned evidence. Respect native permissions and the user's configured runtime depth: do not change configuration, force delegation levels, or turn a denied/depth-limited helper into an undeclared independent root. Finish within scope or return the limitation. Avoid conflicting edits/shared mutable checks; a background launch is not completion. Use only tools supported by the attached server; the native-first declaration/binding integration remains experimental and must not auto-convert historical no-mode root tasks or real mission data.

This adapts Wayfinder's map, frontier, claims, and fog vocabulary to native OpenCode sessions. It does not turn Wayfinder into a workflow engine or automatically mutate an issue tracker.
